# 调研：KataGo 的训练方法，哪些能搬到 Carbon League（2026-11-11）

背景：Master 的作者说"深度研究了 KataGo 的方案"，当天上榜的 Master3s 21 战全胜、领先第二名 200 分、每步只用 0.3 秒。
他具体做了什么不知道。本文只整理 KataGo 公开的方法（论文和官方方法文档，数字均取自原文），并逐条对照我们这两天撞上的问题。

来源：
- 论文 Wu, "Accelerating Self-Play Learning in Go"（arXiv 1902.10565）
- 官方文档 `docs/KataGoMethods.md`（论文之后新增的方法）

## 1. KataGo 是什么

AlphaZero 式的自我对弈（网络 + 搜索下棋，把搜索结果训回网络，循环），但训练效率高约 50 倍：
主训练 19 天、最多 28 张 V100、420 万局、2.41 亿个训练样本，超过了用两千张 GPU 训两周的 ELF。
论文明确说其中大部分改进与围棋无关，可以搬到别的问题上。

## 2. 论文里的六项改进和消融结果

消融表（去掉某一项后，达到同样强度要多花多少训练时间）：

| 去掉的部分 | 训练时间变为 | 是否与围棋无关 |
|---|---|---|
| 归属和目数的辅助预测目标 | 1.65 倍 | 思路通用，具体目标要换 |
| 全局池化 | 1.60 倍 | 通用 |
| 围棋专用输入特征 | 1.55 倍 | 否 |
| 快慢搜索随机切换 | 1.37 倍 | 通用 |
| 对手下一步的辅助策略目标 | 1.30 倍 | 通用 |
| 强制探索加策略目标修剪 | 1.25 倍 | 通用 |

逐项的机制：

**(1) 辅助预测目标（最大的一项）。** 终局胜负是"每局只有一个、还很吵"的信号。KataGo 让网络同时预测更细的量：
棋盘上每个点最后归谁、最终差多少目。理由原文说得很直接：胜负是这些细量的函数，把它拆开来预测能大幅改善学习。
网络输了一局，只看胜负不知道输在哪；有了归属目标，它能看到是棋盘哪一块出了问题。

**(2) 快慢搜索随机切换（playout cap randomization）。** 价值的学习缺的是局数（每局一个结果），
策略的学习缺的是每一步搜索的深度，两者抢同一份算力。做法：每一步以 25% 的概率做完整搜索（600–1000 次），
其余 75% 的步只做快速搜索（100–200 次）。**只有完整搜索的那些步记进训练数据的策略目标**；快速搜索的步不加探索噪声，尽量走强。
这样同样算力能多下几倍的局，策略样本的质量又不降。

**(3) 强制探索加策略目标修剪。** 搜索时强迫每个被试过的走法至少得到 k·sqrt(先验 × 总次数) 次模拟（k = 2），
避免好棋因为第一眼评估差而被埋掉；但写训练目标时把这些"被强迫的"次数再减掉，免得网络学去模仿噪声。

**(4) 全局池化。** 在卷积里加入全局信息，让网络能根据全局形势调整局部走法。

**(5) 对手下一步的辅助策略目标。** 多一个头预测对手接下来怎么走，只为帮助主干学到更好的特征。

**训练本身的细节**：策略目标是搜索的访问分布（软的，不是只取最好的一步）；样本从一个逐渐变大的最近数据窗口里均匀抽
（25 万增到 2200 万）；每训约 100 万样本出一个候选网络（几个快照的滑动平均），**和当前网络打 200 局、至少赢 100 局才换上去造数**。

## 3. 论文之后新增、和我们最相关的三项

**(6) 短期价值目标。** 除了预测终局，另加几个头预测"接下来若干步搜索评估值的指数加权平均"，
平均视野约 6、16、50 手三档。文档写的目的就是提供方差更低的训练信号。

**(7) 更软的辅助策略目标。** 另加一个策略头，目标是把搜索分布开 1/4 次方再归一化（温度 4），损失权重是主策略头的 8 倍。
原因：对一个很尖的目标做交叉熵，几乎不给网络压力去学"那些概率很低的走法谁比谁好"；软化之后这部分信息才学得进去。

**(8) 策略意外度加权。** 搜索结果和网络先验差得越多的局面，在训练数据里出现的次数越多
（一半权重均匀分配，一半按两者的 KL 散度分配），让"网络没想到的好棋"更快被学会。

其余几项（按不确定度给模拟加权、乐观策略头、子树价值偏差修正）都依赖完整的树搜索和短期价值头，对我们是更后面的事。

## 4. 对照我们这两天的问题

| 我们实测到的问题 | KataGo 对应的做法 | 差在哪 |
|---|---|---|
| 只改一个决定，终局分差就散开约 700；按整局输赢加权训练，7500 局得到 0 ± 42 | (1) 辅助目标 + (6) 短期价值目标 | 我们只有终局分差一个信号 |
| 分叉实验：50 步后的身家差和终局差的相关只有 0.33–0.42，10 步时为 0 | (6) 用几档不同视野同时预测 | 我们只试过拿单一视野当评价，没有做成训练目标 |
| 把搜索训回网络：学会 1 个弄坏 1.3–4.6 个；搜索选的走法网络原本只给 0.6% 的概率 | 软的访问分布当目标 + (7) 更软的辅助目标 + (8) 意外度加权 | 我们用的是"搜索选了哪一步"的硬标签，而且只训解码器 |
| 带搜索的对局一小时只能造几百局 | (2) 快慢搜索随机切换 | 我们每一步都做完整搜索 |
| 只训解码器学会率卡在 17–24%，与数据量无关 | 整个网络从头和搜索一起训 | 我们的主干是模仿出来的，没被要求算搜索需要的特征 |
| 新模型上不上榜靠人工判断 | 200 局里至少赢 100 局的自动闸门 | 我们已有配对考试，可以直接改成闸门 |

结论：这两天走不通的几条线，方向和 KataGo 是一致的（自我对弈、搜索当老师），差的是做法太粗。
KataGo 的消融说明，单是"辅助目标"和"快慢搜索切换"两项，就各自值 1.4–1.65 倍的效率。

## 5. 不能照搬的地方

- 围棋是轮流走、每步一个决定、信息完全公开。我们是双方同时走、每方十个单位、碳量有迷雾。
  KataGo 的树搜索不能直接用；我们的搜索是"在根节点比较几个候选走法、往前推演三步"，只覆盖附近有对方车的收集车。
- 所以先搬的应该是**不依赖树搜索**的那几项：辅助目标、短期价值目标、软目标、快慢切换、闸门、数据窗口。
- 规模：KataGo 的数字是 19 路围棋的。我们的棋盘 15×15、网络约 300 万参数，需要的局数会小很多，
  但自我对弈要达到"长出新打法"的程度，量级估计仍在十万局以上，是我们目前造过的（两万多局）的几倍到几十倍。这是估计，没有依据可以更精确。

## 6. 建议的落地顺序

**第 0 步（今天，已在做）：学 Master3s 的回放。** 它自我对弈发现的东西都在回放里。
只教种植员走法、12 局数据，我们的树收入每局 +714 ± 237。这是最快的涨分方式，与下面几步不冲突。

**第 1 步（1–2 天，不需要搜索，不需要新造数据）：给网络加辅助预测头。**
标签全部能从现有回放直接算出（天梯语料约 3300 局、自己造的两万多局、Master3s 的对局），`data/unit_ledger.py` 已能算出大部分：

| 辅助目标 | 对应 KataGo 的 | 标签怎么来 |
|---|---|---|
| 每个己方单位：未来 10 / 25 / 50 步内是否被撞掉 | 归属 | 回放里单位消失的时刻 |
| 每辆车：未来 25 / 50 步的入库量 | 归属 | 回放里的入库事件 |
| 每棵树 / 每个格子：未来 50 步被吸收的碳量、树是否被抢 | 归属 | 回放里的树收入和易主 |
| 双方身家差在 10 / 25 / 50 步后的变化 | 短期价值目标 | 现金 + 车上的货 + 树的剩余价值 |
| 终局分差的分布（分桶） | 目数 | 终局现金差 |
| 对手每个单位的下一步 | 对手下一步 | 回放里对方的动作 |

做法：这些头接在现有主干上，和原来的策略目标一起训整个网络，软锚保持原有走法不变。
验收：加了辅助头的网络，再做一次"把多车搜索训回去"（现有 1000 局数据），看"学会 1 个弄坏几个"是否离开原来那条曲线。
这是对"主干缺特征"这个判断的直接检验，一天内出结果。

**第 2 步（第 1 步有效之后）：按 KataGo 的方式造自我对弈。**
- 快慢切换：75% 的步纯网络直接走，25% 的步做完整的多车搜索并记录；预计造数速度提高到现在的三倍左右。
- 策略目标用搜索给每个候选的评分做成的软分布，另加温度更高的辅助软目标；搜索与先验差得多的局面加权。
- 价值类目标用第 1 步的短期目标，不用终局分差单打独斗。
- 每一轮候选网络过闸门（配对考试显著为正）才用来造下一轮。

**第 3 步：循环。** 每轮一天左右，三四台 64 核加一张 GPU。

## 7. 对 Master3s 的推测（只是推测）

- 它和 Master2s、M2、我们都不是同一种打法（种植员只招四成、每个多种 1.6 倍的树），这种差别模仿训练产生不了，符合自我对弈的特征。
- 每步 0.3 秒、不靠重搜索，说明提升在网络里。
- 他一天出一代，说明流水线已经转起来；之后还会继续出。只靠模仿，我们永远在它身后。
