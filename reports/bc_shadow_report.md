# 影子 Alpha（行为克隆）第一版报告

日期：2026-11-03。任务：用 Claude 家族回放训一个能当陪练的「影子 Alpha」，
验证它像不像 AlphaCarbon-2。数字全部实测；训练限 2 线程（与 v0.7 线并行）。

## 结论先行

- **影子已落地且能打**：`shadow_alpha.py` + `shadow_weights.npz`，标准
  `agent(observation, configuration)` 接口，NumPy 推理，实测 10.6–19.3 ms/步
  （目标 <50）。
- **它克隆到了 Alpha 的经济骨架**：开局双招采集、步 200 采集员编制 7–9
  （Alpha 7）、对弱对手全场存款 8.4–8.6k（Alpha 中位 8065）、种树 22–33 次
  （Alpha 31.5）、终局 30 步存碳冲刺 1369/2160（Alpha +997）、树净收入为正且强。
- **但它不是 Alpha 的强度**：最大失真是死亡纪律——对无对抗对手时自家采集员
  叠格自相残杀，单局死亡 60–76（Alpha 34）、丢碳总量 10–19k；种植员/成林
  在步 200 时偏少（0–1/0–5 vs Alpha 2/7）；对我方 v0.5（远强于 Alpha 的
  典型对手）现金只剩 108–416。定性：**合格的「Alpha 风格经济型陪练」，
  不合格的「Alpha 强度标尺」**。
- **本轮头号发现不在模型，在数据**：站点回放的动作标签与观测错位一步
  （见下节）。原始抽取的 `claude_family.npz` 全部标签错位；修正后重抽
  `claude_family_fixed.npz` 才训出能自举的影子。**`top_players.npz` 有同一
  缺陷，尚未修，勿用。**

## 数据口径（先写清，再训）

- 来源：`bc_data/claude_family.npz` —— 23 局 Claude 家族对局、6,877 个
  决策点（AlphaCarbon-2 占 1,196 个决策点）。划分按**局**：train 18 局 /
  val 5 局（val 含 AlphaCarbon-2、AlphaCarbon、opus-v53-nocamp、
  opus-v71T、opus-v65 各 1 局），无同局泄漏。
- **合法性契约**：特征只用实战中 agent 能合法观测的信息——碳图按自身
  可见性过滤（采集员见本格、种植员见 4 邻，与回放抽取口径一致）＋
  双方共享的 players 块（现金/基地/工人/树全可见）。回放里的
  `full_carbon` **从未进入特征**。推理端经一致性对拍验证：把 val 样本
  重新合成 obs 字典走影子的实机解析路径（`_canonical`→特征→NumPy 前向），
  准确率与训练端逐位一致（worker 0.5545、base 0.9428，两种路径同值）。

### 回放配对缺陷（实证，本轮头号成果）

站点回放格式中，`steps[t][player]` 条目里的动作是**产生 steps[t] 那个
观测的动作**（即由 obs\_{t−1} 决定），而不是从 obs\_t 出发的动作。用
「obs\_t → obs\_{t+1} 的工人实际位移」逐个核对：`steps[t+1]` 的动作标签
命中率 **100.0%**，`steps[t]` 仅约 40–45%（4 局 Alpha、双方、约 1.1 万次
移动核对）。`extract_bc.py` 按 (obs\_t, act\_t) 同条目配对，**全部标签
错位一步**（其 README 亦载明此口径而不自知）。

后果与修复：
- 错位标签下，开局样本被教成「0 工人＋现金 80 → 什么都不做」（23 个
  样本），影子实战无法自举（v1：4 局招募 0–1 人、现金 20–80 收场）。
- `extract_bc_fixed.py` 按 (obs\_t, act\_{t+1}) 重新配对产出
  `claude_family_fixed.npz`（原 npz 不动）：6,877 样本，校验计数干净；
  开局首样本基地动作变为 (RECC, RECP) 15 局、(RECC, RECC) 8 局。
- 标签边际分布基本不变——错位只改对齐、不改多重集，所以单看分布查不出
  这个病，必须用位移核对。
