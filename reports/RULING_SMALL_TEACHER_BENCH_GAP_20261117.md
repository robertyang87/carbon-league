# 裁定：小教师 B 档可达性原型与 §4 速度门对表（2026-11-17，策略组）

来源：作战室 09:10 提示转 DGX 09:07 直读回执。原型件 `results/bench_latency_dgx.json`（09:05，DGX 座）——工程组 `bench_latency.py`，同座同真实位置 selfplay-994400 取 18 位置×16 cycles，batch=1。以下数字为 DGX 经作战室转报，策略组尚未读回原型件原件（原件 md5 待补入仓后验合）。

## 报告数

- 生产教师（06a03d9c）：均值 **29.71 ms/局面**
- B 级随机学生：均值 **6.90 ms/局面**
- 比值 **4.31×**（p95 4.26×）；钉版件 md5 全合

注册 §4 门（不变）：固定局面集 manifest、batch=1、spot-36 同机测两教师 trunk，均值＋p95 入册；达标＝小教师均值 **≤5 ms/局面**且同机 **≥8×**。

## 对表（先钉尺后看数）

1. **原型不是 §4 的过/不过。** 座位（DGX，非 spot-36）、局面集（18 位置自 selfplay-994400，非正式 2,048 局面分层 manifest）、方法（16 cycles）三项均与注册 §4 正式口径不同。正式门仍按注册走，不改；DGX 数不得作 §4 证据引用。
2. **随机权重延迟是有效信号，不是伪影。** 设计 §5.1 已钉：延迟只取决于架构与推理路径、与权重数值无关。B 档 6.90 ms 这一读数本身可信，须当作差距处理，不许以“随机权重”打发。
3. **差距两边都有，不只一边：**
   - 绝对值：6.90 vs 5.00，超门 **+38%**（6.90/5＝1.38）。
   - 比值：4.31× vs 8×，缺口因子约 **1.86×**（8/4.31）。
   - 教师口径差：DGX 教师 29.71 ms vs 注册约 38–40 ms，DGX 侧快约 22–26%。但即使按教师 38–40 ms 计，学生 6.90 ms 也只得 5.5–5.8×，仍不到 8×。**教师座位差单独解释不了比值缺口；学生侧慢于设计估计（4–5 ms）是另一半。**
   - p95 比值 4.26× 与均值 4.31× 接近，非尾部驱动。
4. **两点线性外推仅作假设，不作证据：** 以教师（719M MACs，29.71 ms）与 B 档（64M MACs，6.90 ms）两点拟合 `延迟＝固定开销＋k·MACs`，得 k≈0.0348 ms/MMACs、固定开销≈4.67 ms；据此 C 档（21M MACs）预测约 5.40 ms，仍超 5 ms 门。**此数是推断，不是实测。** 它的作用只有一个：不许未经分解就盲降 C 档——若固定开销果真占大头，降档 alone 可能仍不过门。须以分项实测证实或证伪。

## 裁定

1. **工程组须在正式测量前先出差距说明（gap note），不许先训后测。** 内容四项：(a) 原型方法＋原始件落仓（`bench_latency.py` 与 `bench_latency_dgx.json` 的 md5、逐位置均值/p95、warmup/cycles、线程数/CPU 负载）；(b) 教师 29.71 vs 38–40 的口径对账（座位 CPU 型号、线程钉死、计时范围是 `pol.act` 本体还是含 `observe`、局面集差异）；(c) B 档 6.90 的分项分解（编码器/解码/Policy 调用开销/BLAS 各占多少，固定开销实测值）；(d) C 档在同座位同方法下的预测＋判断：降档 alone 是否 plausibly 过门，还是固定开销占优须走推理侧优化路径。
2. **B 档训练暂停，harness 与数据生成不停。** 设计 §5.1 序列是“先证 §4 可达再投入训练”——5 万局面小样与全量训练在 gap note＋策略组定档（B vs C vs 自带优化 Policy）之前一律暂停。harness 三件＋构造冒烟继续；数据生成（教师输出，与学生档无关）在 harness 落字＋派单后可按原计划走。处置顺序仍按设计 §7 #10：先降 C 档，仍不过才议学生文件内自带优化 Policy（须重审事实表 §6 审计）。注册数字一字不改。
3. **正式 §4 仍在 spot-36。** 固定局面集 manifest（设计 §5.1 建议 2,048 局面分层抽）须在测量前落字；测量执行归 L20，座位窗口由作战室协调。DGX 座的剖析只作诊断，不作闸证据；不许在 DGX 上反复重跑 bench 去追数字。
4. **与在途诊断互不阻塞。** 本件不占用归因诊断六座与 S2-3 尾局座位；gap note 是工程组代码/剖析工作，座位协调走作战室。L20 租约 2026-11-20 23:59:59 的硬约束不变。
