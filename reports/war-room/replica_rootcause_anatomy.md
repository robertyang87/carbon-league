# BC 替身保真度缺口·根因解剖（离线分析，2026-11-12 23:40）

数据源：本地 exam_snapshots 逐局线（h23/h24，behavior_stats.py 同口径重算）、仓库 main 的 matches/corpus 回放（教师行为）、exams.md 与 L20 正式战报。残树口径＝终局树集合大小（trees[-1]），与 behavior_stats 一致。按 REVIEW R09：残树是诊断项，分差是主证据。

## 结论先行

1. **根因在共享层，不在单个数据集。** 替身残树对本尊残树的相关为负（r≈−0.46，n=8 臂点）：本尊残树从 2.1（Master3s2）到 3.92（it260）近乎翻倍，替身组均值反而从 6.71 微降到 6.40。四个教师、三种数据规模、注意力/对照/加权三种配方，替身残树全部落在 4.87–7.13。同一批考试局里，对手位的 Master2 真身残树只有 1.97–2.70、完美清算 15–31%——低残树在这套考试环境里可达，替身达不到是策略类型问题：**所有学习型策略（替身、乃至 Echo2 本尊，对 M2 残树 6.23）都收敛到 ≈6，只有显式逻辑/搜索型策略能清算到 ≈2。** BC 的逐歩动作模仿目标里没有终局价值项，终局行只占训练集约 9.7%，清算又是多步计划而非单步众数动作——ep10→ep19 残树 5.71→6.8 越训越差，是同一结论的纵向证据。
2. **分差缺口的主项是「胜局压缩＋败局从无到有」，不是尾部崩盘。** 对 Echo2：3s2 本尊 8 胜 0 负、胜局中位 +2215；替身 r1 胜局中位只剩 +795（36%），且多出 28% 的败局（中位 −484）。全部 12 个本地归档替身场（2400 局）里 margin ≤−5000 的局数是 **0**，≤−2000 占比 0–0.5%，最差单局 −2252。唯一例外是 it260 r1 对 Echo2 的 −13320（1/200）：这一局贡献了该场约 62% 的总方差，剔除后其均分由 +331 升到约 +400（推导值）——是单臂异常，不是系统性输法。
3. **桥定级测的更多是本尊基线的高度与宽度，不是替身保真度。** 唯一合格的 m7bsr1 行为并不好（残树 5.66/5.03、完美清算 1.5–2.5%，本尊 3.44/14.1%）；它过桥是因为 M7Bs 本尊对 Echo2 的基线只有 +88±287（n=7，本尊自己胜局中位仅 +104）。原始分布全面更强的 m3s2r1（对 Echo2 +472、144 胜、胜局中位 795）却因本尊基线 +2256 被判低约 12 SE。**合格序与原始强度序是反的**；M7Bs v2 又复现一次：原始更强的 r1 是 1.01 SE「陪练可用」，g1 以 0.55 SE 过桥。另注意 m7bsr1 对 Master2 校准 −226 不过闸，而本尊天梯对 Master2 是 4 胜 0 负 +1371——「合格替身」在另一根轴上并不保真。
4. **Fable 是唯一的臂特异失败。** 本尊对 Echo2 本来就弱（−187，3 胜 2 负），替身却连种树量都没学到：对 Echo2 只种 15 棵/局（同场 Echo2 种 33、本尊天梯约 33），胜率 60%→10.5%。这与源码型教师的确定性打法无法靠回放 BC 捕获的判断一致；其余各臂种树量都贴本尊（±10% 内）。
5. **修复方向（证据指向）**：同配方重训已被三条独立证据排除（加权试点、更多 epoch、注意力 vs 对照，残树都 ≈6、桥都不过）。缺口在「无终局价值信号＋无搜索」这一层，对应已预备的线 B 专家迭代（终局搜索重标，主指标用双边终局曲线 +702、残树降为诊断）。另建议桥定级并行报告原始分布，避免宽基线把弱替身判成「合格」。

## Q2 假设检验：「替身残树 ≈6 与本尊无关」——成立

- 臂级配对（本尊残树 → 替身残树，对 M2 场）：2.1→{6.80, 6.70, 7.13, 6.19}；3.92→{6.63, 6.06, 6.51}；3.44→{5.66}。Pearson r≈−0.46（n=8，教师只有 3 个独立值，统计力弱——关键看斜率方向与组均值：本尊残树近乎翻倍，替身组均值 6.71→6.40 纹丝不动）。对 Echo2 场方向甚至反转（3s2 组 5.30 vs it260 组 6.10）——符号随考官翻转，即无教师信号。
- 方差归属：替身残树的考官效应（对 M2 比对 Echo2 平均高约 +0.9）大于任何教师间差异；臂间散布 sd 仅约 0.44。
- m7bsr1 例外解剖：它不是靠行为过桥（见结论 3）。与不合格臂比分布：对 Echo2 胜局中位 674（m3s2r1 是 795）、败局中位 −503（−484）、最差 −1607（−2252）、胜率 61.5%（72%）——**每一项都不优于 m3s2r1**，唯独本尊基线低且宽（+88±287 vs +2256±131）。它的残树 5.66/5.03 确是替身里最低，但只比组均值低约 0.7，不足以解释定级差（12 SE vs 0.52 SE）。

## 数据缺口（如实标注）

- **fable r1、m7bsv2 r1/g1 无逐局线归档**（spot-29 快照链故障，逐局线只在机上）：残树均值与 margin 分位数取不到，只有 harness 汇总（均值/se/最差/胜场/plants）。注意汇总里的 tree 字段是树量积分、不是残树（已用 m7bsr1 校验：汇总 3480/200＝17.4 vs 真残树 5.66），不可混用。
- it260 三臂的胜/败分段分位数不在离线源内（逐局线在 L20 本机）；其残树/种树取自 L20 正式战报，完美清算只有三臂合并的 0–1.5% 口径。
- Fable 本尊行为是 n=16 小样本（前 48 场 matches 中有语料覆盖的子集）；全量复跑被 GitHub API 403 限流挡住，方向与其它本尊一致但精度有限。
- 回放口径的「种树」是教师全场持有过的不同树 id 数（含夺树），是 harness plant_count 的上界；残树口径与 behavior_stats 完全一致。
- 本尊对 Echo2 的天梯样本只有 n=5–8，桥基线本身宽——这是桥定级噪声的结构性来源。
- K4 双臂不在本解剖范围（搜索臂、非 BC 替身；且其对 E0 的探针结果另有 SEARCH 是否真启用的未决核验）。
