#### (a) U 叶接线前置项（硬前置，缺一不可；执行人＝工程组，草案全文见 stage1_s1-2_draft.md）

- **A1 新 U 叶接入教师**：`cnet2_np.py` 的 `Policy.act` 加 `want_u=True` 返回四元组
  （`u = sigmoid(ctx @ w["utility.weightT"] + bias)`，不改默认三元组）；`stage0_teacher.py`
  的 `_leaf_u` 改取新头 `u` 直用，删 `value_to_u` 调用并改写 docstring。验收：numpy `u`
  与 torch `forward_heads` 的 utility 逐项对齐（容差 1e-5）且与旧 `value_to_u(v)` 不同；
  缺 utility 键时必须大声失败、不得静默回退旧价值头；u 恒在 [0,1]。
- **A2 终局叶改 F01/F04 计分**：教师终局分支现用现金差近似（未计灭绝罚分）是错的——改
  为与 `eval_v53.py` L493–494 逐字同口径（灭绝方得分 `steps_played − 300 − 1`；幸存方
  取终局步之前的现金；无灭绝超时取终局现金）。验收：手算 3 个终局算例＋20 个真实终局局面
  与 eval_v53 逐项对数。
- **A3 guard 配置统一**：教师 H=2 续弈与候选生成全程 guards off、生产侧 GUARD=True 是错配
  （纠正第②点）。定死生产口径 `GUARD=True, GUARD_NARROW=True, GUARD_CASH=40.0, LOWW=2`，
  贯穿教师候选生成、H=2 续弈、贪心对照臂、q 闸与 ΔU 闸的真实续弈。把 `bankrupt_guard`
  从 `make_search_agent` 闭包抽成可复用有状态守卫类（分支各持快照副本、不得全局单例串状态），
  教师 `pol` 从裸 `NP.Policy` 换 `CachePolicy`（守卫重解码要 `enc_for`）。不改道经
  `make_search_agent`（会连带吃进生产 CONF 下不生效的规则编辑）。验收：抽取前后奇偶一致；
  教师 guard-on 模式 50 根局面冒烟跑通。
- **完成标准**：A1–A3 全过＋三文件改动入 main、md5 读回；预注册头写明权重 md5（heads v2

#### (b) q 收益闸（小规模、独立；阈值作战室已定案）

- 场景集：m3s2 语料新增的 34 局（清单 118→152）对半分——q 闸 17 局、ΔU 闸 17 局，两闸
  对局集不交；**前提核查**：采样前按对局 id 逐项确认这 34 局不在 ds_m3s2 的对局清单里。
  位置采样：步数 40–240 按阶段分层（40–120 / 120–200 / 200–240），每局每层随机抽 1 个
  局面；**N_q = 150**。采样 RNG 种子预注册写死（建议 995300 段，与 S1-1 的 995200+ 不重）。
- 评的 q 分布：每局面 `evaluate_root` 输出的软目标 q（K≤16、M=8、H=2、新 U 叶、统一 guard）。
  主指标 **Q 收益**＝mean[Q(argmax q) − Q(greedy)]（U 单位）；另报严格改进率
  P(argmax q ≠ greedy 且 Q-gap > 0)、q 熵＋有效臂数、agree_greedy（诊断）。
  独立锚点（防教师自评）：30 个局面子集，q-argmax 臂与 greedy 臂各真实续弈到终局
  （统一 guard、对手＝裸网贪心、同种子配对、F01/F04 计分），报实现 ΔU 点估计＋95% CI
  （n=30，只作符号检查，不作闸）。
- **阈值（已定）**：通过＝Q 收益均值 ≥ **+0.01 U** 且严格改进率 ≥ **25%** 且独立锚点实现
  ΔU 点估计 > 0；不通过＝Q 收益均值 ≤ 0 或严格改进率 < 10%（教师无收益或有害，停）；
  其间＝场景集翻倍（同协议、种子段顺延一次）再判一次，仍不定则按不通过处理，不许无限扩样。
  成本：150 次 `evaluate_root`；Studio 串行约 14 分钟（并行 22 worker 约 1 分钟）。

#### (c) S1-2a ΔU 闸（主闸；阈值沿用已定值）

- 场景集：q 闸之外的另外 17 局新对局（前提核查同 (b)）。位置采样：步数 40–240 按阶段分层，
  另加开局层（步数 0–40，占 10%）；**两阶段定 N**：Stage A 试点 N=30（测配对 ΔU 的样本
  标准差 σ̂ 与新 U 叶 `evaluate_root` 的实测单调用成本）；Stage B 定 N = ceil((140·σ̂)²)
  （单侧 α=0.025、功效 80%、检出 ΔU=+0.02），下限 N ≥ 150、上限 N ≤ 600；超上限跑上限
  并明文报告实际功效（功效不足只会让真效应更难过闸，不会造成假过闸，方向 fail-safe）。
  采样 RNG 与续弈 RNG 种子块预注册写死，与 q 闸、S1-1 均不重。
- 双方走子方式（跑前冻结）：Guided 臂每步 `evaluate_root`（K=16、M=8、H=2、seed_base 由
  局面 id 派生、teacher=1、新 U 叶、统一 guard）走 argmax-q 臂；Greedy 臂同权重裸网贪心
  （统一 guard）；对手＝裸网贪心（同权重、统一 guard），两臂同一对手、同一对手种子；
  终局计分 F01/F04（A2 口径）。分组统计：ΔU 按根局面成组（每局面一对 guided/greedy 续弈
  差值）再平均；95% CI 用配对 t 区间，bootstrap（10,000 重采样）作敏感性检查并行报告、
  不得替代 t 区间。
- **通过阈值（已定死，抄录不改）**：配对 ΔU 点估计 ≥ **+0.02** 且配对 95% CI 下界 > 0。
  不通过即不产正式标签，不许事后在均分/胜率/+1 SE 之间挑口径改判。
- 成本（纠正后算法；单调用成本以 Stage A 实测为准）：每局面 guided 续弈按平均剩余 160 步计。
  Stage B N=400：Studio 并行 22 worker 约 4.5 小时、DGX 64 worker 约 7.8 小时；N=600 上限：
  Studio 约 6.7 小时、DGX 约 11.7 小时。机器选择由 Stage A 实测单调用成本定。
- 预注册头（跑前必须写死并入仓）：权重文件＋md5、三文件 md5（接线后）、guard 四键、对手
  （裸网同权重＋md5）、场景对局 id 清单（17 局）＋采样种子、续弈种子块、N 公式与 Stage A
  实测 σ̂ 与单调用成本。未预注册不得开跑。
- 验收：ΔU 点估计＋95% CI（t 区间＋bootstrap 敏感性）＋场景清单＋成本实测＋guard 触发统计
  （诊断列）。
- **与 §3.4 最终确认的分工**：S1-2a/b 验的是**教师**（蒸馏前）；§3.4 最终确认验的是**蒸馏后
  冻结裸网**（Carago g1 新种子＋未见对手各 200 局），在联合动作蒸馏完成后、候选冻结后才启用，
  一次性。两闸的种子块与对手不得重用。
