# 对手下一步预测模块报告（跨原型离线验收 + 调用规格）

日期：2026-11-03。任务：把「预判对手下一步」做成全线共用、可验收的共享
模块。**全部数字离线实测、按对手原型分开报**；样本与口径见 §1。
交付物：本报告 + `opponent_predictor_tables.npz`（三家拟合好的桶表，
可直接查）+ `pred_data_{alpha,deepseek,v53}.npz`（验证集）+
`pred_{build,eval,eval2,mlp}.py`（可复现管线）。

## 结论先行

- **最强配置 = bucket+prev**（上下文桶分布 + 上一步动作条件化）：
  工人 top-1 按原型 **Alpha 49.0% / DeepSeek 49.8% / v53 55.3%**
  （停留基线 37.3 / 35.5 / 42.3）。决定性输入是**上一步动作**这个
  惯性通道：无状态桶只有 44.5 / 42.4 / 48.1，纯惯性本身就有
  45.8 / 45.9 / 52.1——**只报上下文特征的预测器会系统性漏掉最强
  的单一信号**。
- **出击预测是本模块最强的头**（安全定价与猎杀的直接输入）：
  危险出击 D（敌采集员下一步踏入我方更重采集员所在格、它更轻会赢）
  AUC **0.956 / 0.967 / 0.996**；工作点示例：DeepSeek 家在阈值 0.2
  有 精确 0.61 / 召回 0.92。这已经是可以直接进案 C 定价公式的概率。
- **v53 内置周期检测器名不虚传**：离线等价复现，覆盖率（对采集员）
  46.1%（v53 自家）/ 32.1%（Alpha）/ 26.0%（DeepSeek），触发时下格
  命中率 **80.5% / 65.0% / 54.7%**。它是一个高精度、低覆盖的确定性
  通道，与概率桶互补——路线图要求「pred_next 并入主 DP 成本层」
  的做法有实测支撑。
- **基地招募头是弱头**：静态上下文桶 top-1 只比「永远不招」高
  0.3–0.7 个点，RECC/RECP recall 仅 5–21%。招募时机由轨迹量驱动
  （上步损失、自上次招募步数），影子基地头带 seq 特征时 RECC
  recall 有 77.3%——差距在特征集，不在模型。v1 只把它当**速率先验**
  交付，不当点预测器（见 §5）。
- **成本**：桶模型批量摊销 4.4–7.9 µs/工人；生产形态（拍平字典直查）
  预算 ≤5 µs/工人、≤50 µs/步。MLP 对照在同等无状态输入下不敌桶表
  （41.0 / 38.7 / 45.3），且 torch 前向约 100–160 µs/工人——v1 不
  推荐 NN 形态，NN 的增量要靠 prev 嵌入 + 局部贴图（影子架构的
  60.2% 是那一类输入，见 §3 注）。

- 动作编码：0 停留 / 1 上 / 2 右 / 3 下 / 4 左（与 extract_bc 一致）。

## 3. 出击事件预测（采集员，验证集）

事件定义（t 时刻位置口径）：**E1 接战** = 敌采集员下格有我方任一
工人；**D 危险接战** = 敌采集员下格有我方采集员且其携带**严格大于**
敌采集员（碰撞规则下轻者胜，D 即「它踏进来会赢、我方会丢货」的
事件）。预测器 = 出击桶（敌携带档 × 最近我方采集员相对携带档 ×
距我方采集员距离档 × 阶段）。

| 原型 | 事件 | 基础率 | AUC | P/R @0.5 | 推荐工作点 |
|---|---|---|---|---|---|
| Alpha | E1 | .134 | .909 | .61 / .44 | @0.2：.54 / .57 |
| Alpha | D | .033 | .956 | .51 / .68 | @0.2：.44 / .78 |
| DeepSeek | E1 | .086 | .954 | .68 / .63 | @0.2：.48 / .91 |
| DeepSeek | D | .066 | .967 | .67 / .81 | @0.2：.61 / .92 |
| v53 | E1 | .091 | .883 | .53 / .17 | @0.1：.28 / .92 |
| v53 | D | .018 | .996 | .43 / .36 | @0.1：.37 / .93；@0.2：.38 / .90 |

- 机会子集（距我方工人 ≤2 格）内基础率约翻倍（E1 .21–.28、D
  .04–.12）；@0.5 的报警实际只在该子集内触发（子集外概率到不了
  0.5），故子集口径 P/R 与全局 @0.5 相同——报警天然聚焦在有机会
  的格上，这正是定价层想要的形态。
- **用法是概率本身、不是阈值报警**：案 C 的公式需要 P（出击|上下文）
  连续值，阈值表只是给需要硬开关的消费方（S3 猎杀戒备）留的工作点。

## 5. 调用规格（最强配置）

**形态**：每原型一套桶表（工人动作 ×2 头（按类型）、出击 ×2 头、
基地 ×1 头），已拟合并导出 `opponent_predictor_tables.npz`
（363 KB，264 个数组）。表结构与 `pred_eval.BackoffBuckets` 一致：
每头 5–7 层回退（最细 → 全局边际），键 = 该层特征元组按列序以
64 进制混合编码为 int64；`{前缀}_L{层}_enc/_cnt` 存（键，5 类计数）。
查询：自最细层向下，取第一个样本数 ≥ min_count（工人/基地 25、
出击 40）的层，分布 = (计数 + 10×父层分布) / (n+10)；全程纯字典
查找 + 小向量运算，无 NN 依赖。

**输入（每个敌方工人，全部来自我方当前 observation 与自维护跟踪）**：

| 特征 | 取值 | 说明 |
|---|---|---|
| wtype | 0 采集 / 1 种植 | 公开块直读 |
| cargo | 原值（内部按 0 / 1–74 / 75–149 / 150–299 / 300–449 / 450+ 分档） | 公开块直读 |
| d_base | 到**敌方**最近基地的环面曼哈顿距（内部分档 0,1,2,3,4–6,7+） | 由敌方基地格算 |
| d_ebase | 到**我方**最近基地距（同上分档） | MLP/扩展用；桶头未用 |
| d_tree | 到最近树（任意归属）距（分档 0,1,2,3+） | 公开块直读 |
| d_foe | 到**我方**最近工人距（分档 0,1,2,3,4+） | 公开块直读 |
| phase | step 分档 <30 / 30–99 / 100–199 / 200+ | |
| on_base / on_tree | 站自家基地 / 站树格 0-1 | |
| **prev_act** | 敌方该工人上一步动作 0–4（未知=5） | **关键输入**：由我方逐帧位置差跟踪，存活工人恒可得 |
| 出击头附加 | rel = 最近我方采集员携带 − 该敌采集员携带（仅当距 ≤3，否则「无目标」档）；d_foe_coll = 到我方最近采集员距 | |

**输出**：
1. 每敌方工人：5 类动作概率分布（argmax 即点预测；分布本身供
   期望计算）。派生：下格分布 = 按动作把概率质量搬到 pos+delta。
2. 每敌方采集员：P(E1)、P(D) 两标量（出击头）。
3. 周期通道（可选、与 v53 同算法）：对每敌方采集员维护 26 步位置
   历史，周期 (1,8,4,2,6,12) 两点确认命中时输出**确定性下格**
   （覆盖/命中见 §2）——命中时应覆盖概率输出（见案 C 接法）。
4. 每敌方基地：{不招， 招采， 招种} 先验分布（弱头，仅作速率参考）。

**成本预算**（实测，研究实现，4 核共抢口径）：桶批量摊销
4.4–7.9 µs/工人；单次调用（10 工人一批）1.0–6.0 ms——固定开销在
numpy 的 unique/投影脚手架，**生产实现必须拍平**：离线把每头的
回退解析结果预计算为「最细键 → 最终分布」的直查字典（+ 短回退
链），预期 ≤5 µs/工人、整步（≤10 敌工人 + ≤10 出击头）≤100 µs，
相对 v53 的 30–40 ms/步可忽略。MLP 形态实测不推荐（见结论）。

**原型选择**：三套表并行交付。消费方按 S2 的原型判定选表；S2 落地
前按对手身份直选（天梯对手身份通常已知）：规则/DP 型 → v53 表，
NN 型 → DeepSeek 表，Claude 系混合 → Alpha 表。未知身份时可用三套
表对已观测动作做序贯对数似然累加、自动收敛到最贴合的一套（这同
时就是 S2 的识别器骨架，见 §6）。

## 6. 给消费方的接入建议

- **案 C 安全定价**：风险价 = P(D | 出击桶） × （我方携带 c + 30 +
  货归敌摆动项），直接替换现行 0.5 平价；桶样本数 < 40 的格回退到
  现行保守价（冷启动纪律与路线图一致）。周期通道触发时，把该敌
  采集员的下格占用当作近确定事件写入 C0/C1 成本层（命中率
  .55–.80 远高于任何概率格；未触发不减分）。P(E1） 用于「冲门/
  守门」类期望：run_b 的出击率桶可与本头并桶校准。
- **S3 猎杀**：目标下格分布取桶+prev 的派生分布——猎手站位对准
  **众数下格**（采集员点预测命中 .51–.58）；周期通道触发时改站
  确定格。P(E1） 反用：我方猎手评估「踏入敌采集员下格众数格」的
  成功率时，用同头（双方视角对称，特征按猎手视角重算）。
- **S1 树防**：对每棵我方树，取相邻敌种植员的动作分布，算
  P（下一步踏上该树格） = 落入该格的动作概率质量；守树/反抢的
  出动条件 = P × 树剩余价值 > 出动成本。敌种植员 top-1 只有
  .39–.44，但**质量集中在一个格上**的概率才是决策量，不要用
  argmax 代替分布。基地 RECP 先验（弱）只作「敌方要补种植员」的
  慢信号，不作触发。
- **S2 原型识别**：三套桶+prev 表即三原型的似然模型——每步对每个
  敌方工人累加 log P（实测动作 | 对应表），局内 30–60 步即可分开
  三家（各家停留率 .32/.36/.47、动作剖面差异显著）；周期通道的
  **触发率本身**是强特征（v53 .46 vs DeepSeek .26）。识别输出再
  回喂本模块的选表，形成闭环。

## 7. 已知边界（不许当没写）

- v53 家族只有 20 局且全是镜像自博弈——它对**多样对手**的行为
  分布未验；v53 表的数字是自博弈区制内的。Alpha 家是混合池
  （AC2 本体 val 仅 1 局 2,784 样本）；DeepSeek 家是约 28 变体
  的池，榜二本体 RL-policy-1 是全场最难预测的对象（桶 .388）。
- prev 通道依赖逐帧身份跟踪：工人死亡/同格叠穿时离线链会断
  （覆盖 .95–.99）；实局跟踪死亡即销号，无此问题，但**新招募
  工人首步无 prev**（表中 prev=5 档已含此情形）。
- 出击事件按 t 时刻位置定义（我方工人下步也会动）——这是定价层
  在决策时唯一能用的口径；真实碰撞率还取决于我方位移，消费方在
  期望里自行合成，不要把 P(D) 当成交割概率。
- MLP 对照为瘦身训（60k 样本/4 epoch，算力共抢所限）：结论是
  「同等无状态输入下桶 ≥ 小 MLP」，不是「NN 路线无价值」——带
  prev 嵌入 + 局部贴图的 NN（影子式输入换我方视角）仍是 v2 的
  候选，但必须先证明能赢桶+prev 的 49–55% 才准替换。
- 基地头 v1 是已知弱项（§4），消费方不得把它当点预测用。
