# 输局优化旁路 ①：败局崩盘点分析

**预注册编号：Gen-5 预注册 32628283（策略组核准注记）**。本报告为 ① 的机制证据交付：塌方定位与分布。权重三式（a/b/c）的取舍论证在 §5；(d) 式所据的搜索优势分布不在本报告范围（见 §5 末句）。

## 0. 生产隔离声明

本分析为纯分析：未触任何生产训练路径，未改任何生产文件，未杀任何进程。评估在 L20 自建 scratch 目录 `/root/lossprobe/` 内以 CPU 前向（只读加载检查点与语料）完成；权重通道未实现、未入任何训练——定版件经策略组核准前不得进生产训练（② 的纪律，本报告仅确认 ① 本就无此接触）。

## 1. 估值口径（全程一致）

- **网络**：Gen-3 代检查点，实体 = L20 `/root/carbon/katago/work0/gen3/ckpt.npz`，**md5 `708f8cca57f5674d00d1e5e56758e14c`**（与作战室给定短指纹 708f8cca 一致；DGX 无此实体，故在 L20 座上作业）。经 `tools/katago_m3s2/model.py` 的 `load_main_npz` 加载 MainNet（6×96），sid 按 train.py 同规则取 snames 中 `layout.SID_NAME` 的下标（实测 sid=100）。
- **轨迹**：对每局逐步重构神状态 S_t（t=0..299，共 300 个状态，含终局状态），v_t = 网络 value 头输出 u 在 S_t 的读数。value 头的训练目标即 U(终局分差)（train.py 中 `l_v = MSE(v, score_utility(margin))`，U(d)=0.6·tanh(d/600)+0.4·clip(d/2500,±1)），故 v_t 是与训练同口径的 utility 估值。
- **视角与时点**：特征按生产转换器口径以**败方（Echo）座位**编码（me=Echo 座位、全图碳知识 FULL），v_t 为 Echo 视角估值；时点为**落子前**——S_t 是第 t 步双方落子执行前的状态。
- **输入表示**：与训练行逐字同形——转换器量化形（uint8 存、/100 喂入），sc 标量同源。前向为 fp32 CPU、无 autocast（分析读数取确定性参考，不取生产 GPU 的 bf16 读数；特征表示与生产同形不变）。
- **解码路径**：复用生产转换器 `convert_echo9.py`/`convert_echo10.py` 的同构重构（同一 encode 调用、同一回放发散校验），仅扩展至终局状态并旁记实现事件。逐步以回放内神状态校验现金与碳图，任一发散即整局中止。
- **塌方步定义**：单步跌落 d_i = v_i − v_{i+1}（i=0..298），塌方步 i\* = argmax d_i。**步号 i\* 为跌落的出发状态下标，与该局训练行下标同号**（行 t ↔ 状态 S_t）；跌落落点为 S_{i\*+1}。本作的步是**双方同一步联合落子**（回放 steps[i+1][p].action 为双方在 S_i 的落子），单步跌落不存在单方归因——§3 的「谁落子」以该步实现效应分解代答（口径见 §3）。
- **回升比**：(塌方后轨迹最大值 − v_{i\*+1}) / 塌方跌幅。**可逆判据：回升比 ≥ 0.5 记可逆，< 0.5 记不可逆**；回升比 ≥ 1.0 另记「曾完全回升」。
- **总跌落**：净跌落 D = v_0 − v_299（派单注册口径）。另并行给出毛跌落（全部正跌落之和）作对照——两口径结论不同，§4 并列呈现，不许只取其一。

**幅度**（u 单位）：中位 0.142，[Q25, Q75] = [0.120, 0.174]，范围 0.081 – 0.296。对照背景抖动：全部 15,249 个步间 |Δv| 中位 0.019、p90 0.058、p99 0.116——塌方步幅度约为日常步动的 7.5 倍（中位比），但与 p99 仅差约 1.2 倍，**与轨迹自身的抖动尾部没有量级分离**。

**归因（该步实现效应分解）**：本作步为双方联合落子，故以塌方步内实现现金变动与死亡事件分解——败方自身现金损失 own_loss=max(0,−Δcash_败方)、对手实现得分 opp_gain=max(0,+Δcash_对手)；own_loss ≥ 2×opp_gain 记「自身受损主导」，opp_gain ≥ 2×own_loss 记「对手得分主导」，两者之和 < 5 记「无现金事件（局面性重估）」，余为「混合」：

| 归因 | 局数 | 占比 |
|---|---|---|
| 对手得分主导 | 21 | 41.2% |
| 无现金事件（局面性重估） | 20 | 39.2% |
| 败方自身受损主导 | 8 | 15.7% |
| 混合 | 2 | 3.9% |

塌方步内败方有工人死亡的 21/51 局。**即：塌方步的跌落只有 15.7% 主要对应败方自身在该步的实现损失；41% 是对手在该步得分，39% 该步根本没有显著现金事件、纯属局面重估。**

**回升（可逆性）**：回升比中位 0.881，[Q25, Q75] = [0.274, 1.546]。按注册判据（≥0.5）：**可逆 34 局（66.7%）、不可逆 17 局（33.3%）**；曾完全回升（≥1.0）23 局（45.1%）。但须并读两个终局事实：**30/51 局（58.8%）终局估值低于塌方谷值**；回升峰之后普遍再现二次塌方（二次最大跌落中位 0.094 u，约为首次塌方的 2/3）。即多数「可逆」是**暂时回升**——估值回到塌方前附近后再次跌落并以更低点收场。

分语料：Echo9（33 局）总跌落占比中位 0.494、位置中位 0.241、可逆 19 局；Echo10（18 局）占比中位 0.427、位置中位 0.289、可逆 15 局。两语料形态一致，无结构性分歧。

## 4. 核心判读：几步坏棋，还是全程被压制

塌方跌幅占总跌落的比例，两口径并列：

| 口径 | 塌方步占比中位 [Q25, Q75] | 前 5 大跌落步占比中位 |
|---|---|---|
| 净跌落（v_0 − v_299，注册口径，n=49） | **0.494** [0.234, 0.714] | 1.701（>1，回升抵消所致） |
| 毛跌落（全部正跌落之和） | **0.035** [0.028, 0.044] | 0.133 |

毛/净比中位 12.6 倍——轨迹是**高振荡**的：估值全程大幅上下，净跌落只是毛跌落与毛回升相消后的余量。净口径下「单步占一半」是相消的产物，不是单步主导的证据；毛口径下单步仅占 3.5%。

集中度检验（判读的关键量）：

- 每局达到塌方幅度一半以上的跌落步数：中位 **9 步**；
- 塌方跌幅 / 次大跌幅：中位 **1.18**，仅 **2/51 局 ≥ 2 倍**——最大步与次大步**没有量级分离**，不存在干净的「单步失误」签名；
- 但相对均匀漂移仍显著集中：前 5 步占毛跌落 13.3%，是均匀期望（5/299 ≈ 1.7%）的约 8 倍。

**判读：两极端均不成立。** 不是「几步坏棋」中的单步版——没有哪一步在量级上与其余大跌落步分开；也不是「全程被压制」的均匀漂移版——跌落明显成簇。数据支持的形态是：**每局约 5–10 个量级相近的大跌落步成簇承载跌落，叠加全程高振荡与反复的暂时回升、二次塌方**。若必须在两极端间取舍，「几步坏棋」更接近（跌落确实集中于少数步），但「步」是复数簇、且凭轨迹无法逐个可靠指认（抖动 p99 与塌方幅度同量级）。

另有 2 局（`82cbda809db65ad8721a93b64935a88d` −24.57、`1f765a0d69a3727e5d13d38f37e5b019` −58.33）净跌落 ≈ 0（≤0.01）：网络轨迹根本未把这两局的败局登记为跌落——任何以轨迹为靶的方案对此二局是盲的（此点在 §5 对 (c) 适用）。

## 5. 权重三式取舍（对照机制发现）

候选三式：(a) 整局清零、(b) 降权、(c) 仅塌方步清零。以下只依据本报告的机制发现论证，不依据任何训后读数。先行事实：败局的病灶在 policy 目标（照单模仿实际落子），value 目标＝U(终局分差) 是真值——三式的作用面是 policy 权重，value 权重独立、不在病灶内。

- **(a) 整局清零——过头，不对准。** 被指控的步约占每局步数的 3% 量级（中位 9 个大跌落步 / 299 步），整局清零把其余约 97% 未被指控步的 policy 行一并灭掉；若清零及于整行（连 value 监督），更把 51 局 × 299 行的真值 value 监督全数丢弃——而败局恰是「局面如何恶化」的 value 监督信息最 dense 的局。机制证据是「少数步成簇」，(a) 是全有全无，与之不相称。
- **(b) 降权——对准。** 机制形态是「坏步成簇但不可逐个可靠指认」：大跌落步量级相近（最大/次大中位比 1.18）、与轨迹抖动尾部分离度差（p99 0.116 vs 塌方中位 0.142）。在此形态下，按局均匀降低 policy 权重，与坏步在局内的弥散分布相称：不假装轨迹支持外科精度，不丢 value 监督，坏步的教学影响按其局内占比被等比压低。三式中唯一与「成簇而不可指认」形态同构的，是 (b)。
- **(c) 仅塌方步清零——不足且靶向不准。** 其一，覆盖不足：清 1 步仅触及毛跌落中位 3.5%，每局约 9 个同量级大跌落步留置全权重，二次塌方（中位 0.094 u）更在射程外。其二，靶向不准：塌方步的跌落仅 15.7% 归因于败方自身该步受损，41% 是对手该步得分、39% 是无现金事件的局面重估——被清的那一步落子常非跌落主因，清它而留其余坏步，是拿最显眼的一步顶替成簇的病灶。其三，盲区：2/51 局轨迹无跌落可定位，(c) 对其无从下手。
- **结论：机制证据支持 (b) 降权；(a) 过头，(c) 不足且靶向不准。** 降权的幅度（降到多少）不在本报告证据内——本报告只判式、不判量，量由 ② 的设计与策略组定档给出。

(d) 式存废判别所据的搜索优势分布由 ③ 设计验证段给出、本报告塌方清单为其输入（机器可读交付 `collapse_positions.json`：逐位置 game id、步号、座位、双方实际落子、塌方跌幅）。

## 7. 与后续训练行的重叠关系

- **同局同源**：本报告的判读轨迹与训练行出自**同一批回放文件**（仓内 `data/echo9_corpus` / `data/echo10_corpus`，本分析在座上逐件以仓内 manifest 的 sha256 验身），经**同一转换器编码路径**（`convert_echo9.py` / `convert_echo10.py` 的 encode 与重构校验）产生。
- **逐行对应**：训练行 t（每局 299 行，t=0..298）= 回放状态 S_t 的编码行；本报告轨迹点 v_t 就是 gen3 网络对**该行输入（x, sc）的 value 读数**——行 t ↔ 轨迹点 t 一一对应、无错位。轨迹的第 300 点 v_299（终局状态）无对应训练行（终局无落子目标，转换器不出行）。
- **成员关系**（以座上现存转换产物与其转换日志逐 id 核对）：已判读 Echo9 败局 33 局中 **25 局**在 `echo9_rows_full`（61 局集，Gen-3 训练取数）内有全套 299 行；已判读 Echo10 败局 18 局中 **5 局**在 `echo10_rows`（18 局集）内有全套 299 行。其余已判读败局（Echo9 8 局、Echo10 13 局）在座上现存转换产物中无对应行——其语料在仓，日后转换仍按同一逐行对应规则生成。
