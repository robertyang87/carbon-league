# Master3s2 派生版对原版

本线从仓内 Master3s2 的代码和权重出发。在预先固定的 100 张未用地图上，每图交换两席打两场。同一批 200 场须至少 180 胜、平均官方终局分差至少 +500。灭绝按官方裁判结算，平局计入分母，超时判负。按地图聚类报告不确定度。当前尚未启用正式考卷。

## 从哪一版出发

原版考官单文件 SHA-256 为 `65f268b2919ce30fe19355115a928eada032a6beaa018d801662d434c083f2b5`。它的策略骨干有 6 个残差块、96 个内部通道，输入是含信念估计的 54 个特征平面。考官以温度 1 自然采样，每步搜索按 0.58 秒墙钟预算自适应。该文件具备载入小型推演网络的接口，发布字节里只有策略与价值两件参数；在当前原件上，推演实际使用大网。无 PyTorch 时原件会关闭搜索，考场需核对真实候选数、完成深度及回退次数。[原版源码](../../sources/master3s2/master3s2.py) · [平台要求](../agent-guide.md)

作为代码派生版的参照，Apex V1 即 Echo7（文件名含 v4tta），SHA-256 为 `f2882881e71b036421c9236b4fa0f1deef1919ed8045822191ed1632323bd54a`。它沿用原版网络权重，改变了搜索和根部对称变换。在 Studio 归档的 40 场中，V1 对原版 28 胜（70%）、平均官方分差 +341.5；对同一组考官，fix2 为 17 胜、+5.6。V1 另有三场对天梯同名对手全部落败。历史成绩涉及不同机器与搜索深度；源码版本、权重和同机复测须能分别核验。[V1 源码](../../code/apexcarbon_v4tta_search.py) · [40 场版本对照](../GEMINI_APEX_V1FIX2_20261119.md) · [天梯记录](../ECHO7_PLACEMENT_LOSS_ANALYSIS_20261119.md)

## 本轮的神经网络改动

在 Master3s2 已训练的 96 通道棋盘表征上，拟合己方当前局面的动作评分修正，并将它接入真实搜索的根部候选生成。对手建模、后继推演和价值评估继续用原版网络，便于归因。训练前锁定五名选手的 80 张历史地图，60 张拟合、20 张留出，包含他们对 Master3s2 以及其他对手的实战。留图上分别查动作分布、最终实发指令和反例。正式强度取决于双方完整响应到终局的比赛。[训练图、留图与方法](root_policy/protocol.json)

每个新包绑定自己的哈希，在独立的每方 1.5 核 CPU、512 MiB、断网进程里逐局记录初始化、含通信的逐步耗时和整场官方比分。旧 Sapling 的训练数据与结果留在原台账，新增 Master3s2 派生版的比赛在本目录登记。[此前 Sapling 实验](../sapling_1200k/MASTER3S2_90.md)
