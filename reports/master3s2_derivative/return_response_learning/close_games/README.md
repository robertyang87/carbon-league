四张不同的已曝光开发图、两席各两张。每根只有一次改令，双方随后都通过真实公开入口重新决策至官方终局。冻结的网络对“当前持货工在 12 拍内交回多少原有货”判对 3/4 个候选差值方向。将它叠加到原生搜索后，四根仍都选择原生第一，终局分差方向判对 2/4。四对中没有一对改变胜负。这个模型没有在本组给部署带来增胜。[盲预测](model_blind.json) · [独立评分](model_grade.json)

## 这些根如何取得

先登记 592、593、598、599、600、601、602、603 共八张旧开发图，每图双席，每席只看 t279、285，共 32 个候选根。排除了已用于同型研究的 594/595、另一项研究的留图 604–607、新预留的 608/609 和正式考卷。接近度只用当拍已实现的现金和剩余时间内几何上够到己方基地的在途货。对每个根同时限制已实现现金差与“现金加可达货”的差；28/32 入围。该可达货量只是忽略碰撞与拥堵的上界，用以选样，未当作对局收益。[选样协议](protocol.json) · [32 个公开根和排序](public_pool.json)

按登记的席位轮换和地形去重处理。原封线上 V2（8b4c4baf）在根上实际执行温度 1、0.58 秒搜索，要求两个原生 H8 候选的联合令确实改变了有货采集工的返家距离或友军落点冲突。一共 13 次原生菜单检查：6 次原生赢家未达到或未居于所需的 H8 排序，3 次虽到 H8 却没有合格的载货工动作差异，4 次合格。合格四根全是原生第一、第二，未采用更低名次替代。其余候选根因按序占用地图及去重等原因未被调用，未计为打平。四根菜单及原生值的冻结 SHA-256 为 3b737e03…b355a。独立训练线在首条续弈前冻结 7a1270e3 模型的逐根预测，文件 SHA-256 为 8d90d61a…88489。[全部尝试与完整菜单](menus.json) · [盲评协议](model_protocol.json)

## 对手与计时

历史根的棋盘由四张旧开发图的实际指令恢复，逐拍核对双席公开观测、规则和两侧现金。592 来自 8b4c4baf 实际指令历史，其余来自 7cf5c6c9。历史上未归档私有随机状态；两臂共用新登记的状态和同一个全量原版 65f268b2 当拍自然应手。根以外我方统一为 8b4c4baf，两方全程真实 0.58 秒、温度 1。对手根据每条新轨迹重新决策，后缀不使用历史敌令。所有八条续弈均为双 DONE，20+14+14+14 个联合根后时段各双臂，合计 124 次联合推进。每根共享当拍两方调用，双臂全程 248 条逐席计时记录中有 8 条共享记录。

单核固定、同一根两臂串行，臂顺序逐根交替；不同根可用不同核。四对含复原的 CPU 合计 105.03 秒，并行过程从首对开始到末对完成共 80.48 秒。最长实测公开调用 0.652 秒，慢步 0。宿主总 CPU 配额 4 核、内存 16 GiB，这些是开发诊断；完整平台资格另看原开发赛的受限容器收据。每个根每臂仅一次自然响应，四张择近开发图既不能估整体胜率，也不足以估同一动作的期望收益。
