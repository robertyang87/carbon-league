# 双视角根动作的真实续弈

在两张已研究过的地图各改一次第 247 步的己方联合命令，随后两条分支都由同一 v4 对原版 Master3s2 打到官方终局。四条后缀各 52 拍。旋转候选在 1/2 张图上提高终局分差，两次分差变化分别为 -61.49、+339.46。

回库包括落到本方基地的实际交付额。树净包括地面吸收、敌货树税和归树主的碰撞款，扣掉本段种植与夺树开支。两方均从第 247 步前同一钱包起算；表中回库和树净是该后缀的现金流。

- 图 621758580 席 1，根前官方现金己 6,411.88、敌 5,952.59。第 10 拍的分差变化是 -110.55，终局为 -61.49。对手从第 248 步开始在两个实际棋盘上发出不同命令。各分支（v4令、双视角令）双方最慢调用及超 1 秒次数分别为 0.672s / 0拍；0.733s / 0拍。
- 图 621758608 席 0，根前官方现金己 5,790.10、敌 6,008.68。第 10 拍的分差变化是 -401.40，终局为 +339.46。对手从第 248 步开始在两个实际棋盘上发出不同命令。各分支（v4令、双视角令）双方最慢调用及超 1 秒次数分别为 0.778s / 0拍；0.572s / 0拍。

两次实验选自先前预登记根级对照中确实改变出令的四根，每张物理图只取最晚一步。每场只共享一次根部原版对手动作。其后双方用各自席位的实际局面和冻结的模型重新选择。双方同根随机流与信念、裁判树/工编号和根前每拍双席公开请求均已核验。原始线上私有随机未被保存，复演使用协议公布的实验随机种子。

复核用四份保存的实发命令重走官方裁判，独立核对全部 208 个后缀转移及两边终局官方分。单核本地共享墙钟可改变后续实际搜索深度；两张图各一次配对只支持上述两个局面的观察结果。正式独立考卷仍未运行。
