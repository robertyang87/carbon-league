# 原生搜索对照

在线 v4 与双视角候选在 4 张历史地图、两席共 16 个登记局面上分别接收同一方当时可见的局面和实发历史。父包 `cd230d40a08f`，候选 `cb64b1065192`。原生入口采用 0.58 秒预算与温度 1，两次父包和两次候选按 ABBA 或 BAAB 交错；每个局面另做四次等工作量复演。

原生时钟下，两包首次比较有 9/16 处实发不同；至少有 4/16 处可归因于双视角策略。计入后一个数须满足同包两次实发一致、真实父包的菜单/叶分/发令在工作量对照中全部复原、两包实付候选数/深度/轮数和深度分布相同且敌令相同，以及对照后两包各自仍发原先的那条令。等工作量对照单独观察到 9/16 处物理动作不同。

历史自适应搜索拥有自然随机和墙钟，复演固定同根随机与父包上一拍成本以便归因。这里直接测量同机公开 Python 函数耗时；平台还有通信、整场与容器限额。两包打过的真实整局胜负需要另行统计。
