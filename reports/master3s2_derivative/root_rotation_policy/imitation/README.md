# 根策略旋转后的实际动作预测

在 8 张已曝光开发图上，180° 双方向预测降低了真实 Master3s2 所出动作的负对数似然（NLL），8 张图全部同向。实际命令成为网络首选的频率从 85.94% 降至 83.33%。两种读数衡量不同能力，前者衡量给实际动作分配了多少概率，后者衡量它有没有排到第一。[逐图评分](scores.json)

| 目标侧与样本 | 有效对局 | NLL，v4 → 旋转 | 首选命中率，v4 → 旋转 |
|---|---:|---:|---:|
| Master3s2，原留图 602–605 | 8 | 0.67826 → 0.60931 | 86.29% → 83.18% |
| Master3s2，外部复核 580–583 | 7 | 0.71021 → 0.64483 | 85.59% → 83.49% |
| Master3s2，全部 | 15 | 0.69424 → 0.62707 | 85.94% → 83.33% |
| 同盘另一方历史策略，全部 | 15 | 0.67024 → 0.61841 | 86.13% → 83.00% |

每个物理图等权。每图的可行动基地与工人各占一半。父本是线上 v4 的 cd230d40，候选是 cb64b106。预登记的 16 场中，582 号图的一场双方初始化失败，缺少实发动作；其余 15 场均依真实联合命令复演到官方终分。每场两席均评分，入选时点固定为 42 个，最后一个是 284。为避免把事后观察误当作推理输入，实际接触、交付和树权变动只在两个头的预测之后核对。[登记](protocol.json) · [复验代码](evaluate.py)

两个回库例子说明了收益的边界。在 580 号图席 1 第 228 拍，9 号工人存入 168.47，v4 对实发动作的 NLL 为 11.35，旋转后降到 0.69，且将该动作排到第一。583 号图席 1 第 284 拍，38 号工人存入 185.16，v4 已经把实发动作排第一，旋转反而把原地不动排第一。602 号图席 1 第 214 拍也出现了概率与排序分离，47 号工人参与接触，实际方向的 NLL 从 18.54 降至 0.73，两个头首选仍都错。

这些读数评价对已发命令的模仿。未记录候选部署后改变的实际命令、对手随之做出的响应或新对局收益。外部复核地图没有用于已发布 v4 根动作头的拟合，但曾用于其他开发工作。
