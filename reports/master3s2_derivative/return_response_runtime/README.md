## 原搜索与网络如何协作

母包为线上 v2 `8b4c4baf`。只在第 279、285 拍，对完成同一对手情景、同一深度 8 的原生首选和次选比较一次。冻结网络从本席公开状态和各自完整队令预测已有采集工的在手存货在 12 拍内由同工送入己库的金额。次选加分等于两令预计回款差乘 0.0002792100。它沿用原有 0.58 秒搜索时钟和原首选相对贪心令的保护门槛。未完成、比较过程中有灭绝、推理失时或结果非有限均返回原令。新增计算只评两个根令，无额外世界推进、大网前向或额外搜索预算。[构建与原码绑定](build.py) · [重排函数](selector.py) · [17 项边界用例](fixture_results.json)

## 现役包上的实际可触发程度

对 590–595 六图、两席、两个冻结时刻共 24 根，在相同单核上用 `8b4c4baf` 运行一次公开入口。前史来自旧包 7cf5 的真实归档整局，恢复其本席可见历史；对手本拍实令不入模型。每根恢复阶段使用同一预设成本向量，使用预设采样种子，因此这组根测量不能外推现役在线的触发率。20 根未完成单情景 H8。其余四根的「原首选领先、加给次选的修正」依次为 (0.006287, −0.001279)、(0.005447, +0.002225)、(0.049959, +0.001643)、(0.004393, +0.001159)，全部保留首选。按现役模型复算的四组备选无独立自然续弈标签，仅用于查实际菜单和修正幅度。[24 根逐条公开决策](native_roots.json.gz) · [采集程序](probe.py)

复用母包已有的方向/距离表后，导出和拟合代码的 8 对完整队令预测逐值相等。历史四根单次两令神经推理本机约 0.95–1.37 毫秒。历史收据的原码墙钟与单独测定的推理耗时分列，属于本地接口验算；本批无拟上场制品和天梯容器耗时认证。[同一生产选择函数的四根回放与几何校验](receipt_check.py)

后续若扩大这个头的覆盖，优先将现有留图揭示的两类盲区做成可监督的对照。一类是空载工是否封住对手交仓、是否护送载货友军，另一类是距离相同但不同回库通道上未来数拍的敌方可占位。训练应以新抽取的独立图配对自然应答区分净回款和终局分差。复用上述四图作筛选会高估改进。
