# 用双边回库预测校正 v2 的候选估值

在 8 张留出开发图上，根据双方可见位置和载货，预测今后十拍实际记入双方基地的现金差。相比只用双方总货和载货工人数，按图等权的绝对误差从 **179.25 降至 140.34 分**，8 张图均改善。214 个实际回库差不高于 −250 的根中，命中从 49 提高到 99；误报由 28 增至 31。未来的实际到账仅作标签。统计分母是 8 张地图、1,344 个重叠时段的根，不能当作 1,344 场独立比赛。[留图表](held.json) · [各根预测与实际到账](held_rows.json.gz)

训练是另外 14 张物理图、两席换位、2,352 根。双方都是自有 v2 和仓内完整原版。每局 t40–289 每三拍抽根。以官方动作和逐拍现金重放得到基地实际到账，包括敌工把货送入本方基地；种树、夺树及税收单列。相比总货读出，新头增加离家距离、轻货敌工的一步碰撞威胁、最短路线分支和到库地点堵截等特征。两个岭模型均按地图等权、无截距，在固定原图上先训练并冻结后才评分。输入只需当前同一席公开数据，对换席严格反号。[状态计算](features.py) · [训练程序和标签](study_forecast.py) · [冻结清单](protocol.json) · [权重](weights.json)

## 接入原搜索
