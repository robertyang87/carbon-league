# 用另一个首拍敌令复核 H8 换招

从 v2 和仓内原版权重直接构建。完整 H8 已成立且打算替换原策略时，候选如有预算，用同一分布下的对偶抽样另取一个敌方首令。仅额外模拟两次真实联合推进并用原价值网评分，分别对原策略和 H8 选中的动作。H8 的优势加上首拍优势变化的一半，作为对额外应手的近似敏感性修正。只可能撤销换招，没完成、已超内部预算或敌令相同则保留原决定。上下游权重、模拟后继策略及 0.58 秒时钟不变。这项估计假设 H1 对应手的变化能近似解释一部分 H8 的变化。[构建器](build.py) · [对偶抽样验证](check_sampling.py)

冻结候选 SHA-256 为 `db2b4d9873e80cbad436a8f913aff994319369a4163ca2b7b890025e5cdbbb2f`，2,905,945 字节。以四个已曝光对完整原版的开发图双席 t254、278 共 16 个公开局面实跑。32 次自然候选调用中实际额外估值 9 次（5 根）、敌令重复 8 次、其它情况未启动 15 次。9 次修正均减小搜索换令优势，数值介于 −0.00277 和 −0.00004，未触发一次撤销。3 根首次自然发令有差异；同工作量与重复检验后没有稳定改令，不能归因于复核。候选自然调用最长 0.570 秒，为本机回放诊断。固定工作量检查额外复算 8 次，也无撤销。[冻结回放协议](search/protocol.json) · [逐根候选、原敌令及额外敌令](search/results.json.gz)
