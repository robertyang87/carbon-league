## 训练和盲检方法

固定父版在同一局面的两个不同联合命令，取原搜索同深 8、同一组 rollout 的第一名和第二名。两条分支共用根上未改 Master3s2 的实际回应，随后各自走到官方终局。训练图 8 张、留图 4 张，每图一个根。先冻结训练权重，再接触留图标签。此处每个样本是一个有两条终局的地图，两个终局各是对应策略的一次随机续弈。[地图、席位与选根](../action_rank_data/protocol.json) · [学习和停机条件](protocol.json)

冻结原网络，通过每条原始搜索叶的 54 个平面与 5 个标量重算原价值。附加的两个系数以双方在途货物的差额作为输入。第一项度量按最短路已来不及回基地的货额；第二项对仍然来得及的货额乘以「回家步数 / 剩余步数」。两者都取敌方减我方并除以 3,000。叶值使用原神经值加这两项乘以拟合系数；已终止叶保留官方值。按同一批 rollout 等权平均，再比较两条动作。该换算表示账面运输暴露，实际能否避敌、进仓与存入仍需对手响应和裁判结算。[公开特征](physical.py) · [输入身份、原网前向与有界岭回归](train.py)

监督目标是候选方每臂的官方终局分差各自经过原函数 `clip(m/3000, −2.5, 2.5) + 0.5 sign(m)` 后相减。原始分差、胜负和超过 ±7,500 的截断照录。对照保留原值、仅学习不可交货系数及仅按叶上现金差评分的版本。预测平局执行第一名；目标平局不贡献严格排序修正计数。每张地图展示两条得分、选臂的分差和终局值。小样本条件与零样本保持在报告内。[独立判定和合成反例](metrics.py)

复现使用完整检出，在上游原始回执齐备后以同一输出目录执行。训练只读取八张训练图的终局； `predict` 只读当张的叶、公开状态和已冻结权重，`settle` 才开启四张留图的终局。训练信息量不足时脚本记录停机，预测命令将要求已有可用权重。

```bash
study=reports/master3s2_derivative/terminal_value_pairs/train.py
out=/tmp/master3s2-terminal-value-pairs
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
python "$study" train --out "$out"
for ordinal in 8 9 10 11; do
  python "$study" predict --ordinal "$ordinal" --out "$out"
done
python "$study" settle --out "$out"
```
