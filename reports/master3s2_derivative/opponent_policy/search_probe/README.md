# 对手预测头在原版完整搜索中改变了哪一步

预先选取四张留图的双方席位，每席固定 t85、t215，共 16 个根。16 个根的己方网络初选动作在所有条件下逐字一致。只有一处对手模拟命令改变，最终也只有这一处己方实发命令改变。该结果满足预先约定的开发场机制条件，整局收益仍需双方能持续响应的对局测量。 [搜索收据](full_search.json.gz) · [训练地图注册](../protocol.json)

具体是地图 621758326 的席 0、t85。原版把对手 20 号工人的根动作采样为向左，新头采样为留驻。在历史实际记录中，该对手确实留驻。己方 6 号工人在原版两次搜索中均向左，候选两次均向右。四次比较的己方菜单完全相同，逐候选评到的深度依次是 8、8、1、1。较深的两个动作中，原版估值为 −0.588、−0.552，选择第二项；新头下为 −0.570、−0.618，选择第一项。这段回放的己方实发是向上，所以历史终局不能归给向左或向右。 [双方回放命令](../held_orders.json.gz)
