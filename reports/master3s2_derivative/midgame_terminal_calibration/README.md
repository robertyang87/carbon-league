# 以完整原版对局的终分校验中盘价值网

用 v2 对未改原版 Master3s2 的 44 局。14 张图、28 局用于拟合，另外 8 图、16 局冻结留出。每局 t25 至 t265 每 20 拍取同一 v2 席位的公开输入，复核两席单文件身份与自然 0.58 秒、温度 1 的考官收据。当前网络的五个标量、原输出及冻结价值层特征全部从已可见碳、公开状态和过去本方动作重建，未来信息只出现在官方终局标签。拟合与验证分别为 364、208 个时点，独立物理图分别为 14、8。[冻结数据与设置](protocol.json) · [复算与训练脚本](study_calibration.py)

同一终值口径下比较原值、以当前钱包差代入终值函数、按当前阶段校准原值、用冻结价值表征拟合岭残差。目标为官方分差进原版终值公式。模型按物理图等权拟合，验证用训练时未读取的新标签。当前钱包不是最终奖励，只作基线。[权重](weights.json) · [训练分图](fit.json) · [留图分图](held.json)
