# 只凭种树前的局面，能预测第 9 拍起这棵树还能收多少钱？

在 8 张留出地图的 464 棵成功新种树上，23 个公开特征得到的图均绝对误差为 **26.62 现金**。来自 24 张训练图的均值及中位数预测，误差均为 33.13。逐地图与均值比，8 张均有改善；与中位数比，7 张改善。在第 8 拍前被夺、或临近终局的树都保留在样本中。[事前协议](protocol.json) · [8 张留出图结果](held.json)

## 预测的是什么

假设 t 是实际种植命令发出前的步号。H=8 的模拟走过 t 至 t+7 的行动，到达状态 t+8。取 t+8 的行动起原种植方实际获得的逐树收入，直到首次失去树权、自然凋谢或整局结束。当拍先发生撞款、后发生夺树时，两笔分别归相应的实际受益者。本实验逐项保留地面吸碳、从敌工载货吸碳，以及碰撞直接汇入树主账户的资金。首次种植费及前 8 拍的收入已经发生，均与尾款分开。以后抢回同一棵树产生的收入也单列在这个目标之外。[逐树归属规则](../../ladder/tree_payback/labels.py)

复用已登记且按物理地形隔离的 24 张训练图和 8 张留图。用行动前己方公开观察与 3、5 步己席历史形成 23 维输入，逐棵按比赛、席位、行动步、格、树 ID 和种树工 ID，与官方实令重放产生的收入核对。没有剔除任何成功种植样本。训练时每张地图等权，再在图内把权重等分给所有种树行动。训练权重先锁定，再读取留出标签。现金回归只拟合一个岭模型，λ=0.1。对三个模型同样应用剩余不超过 8 拍时尾款为零的规则。完整未截断预测的留图图均误差为 26.96。[冻结地图](../../ladder/tree_payback/maps.json) · [特征](../../ladder/tree_payback/runtime.py) · [冻结权重](weights.json) · [复演与回归](estimate.py)

## 两棵方向相反的错估

两棵都来自留出地图 04dfaebc、席 1。t138 在 121 格种树，花费 82.95，模型预期第 9 拍以后还能收到 112.87。t143 即被夺，晚期实际收入为 0，整个首次持有期净亏 44.94。t162 同一方在 179 格种树，模型仅估 89.80，实际持有到 t212 凋谢，晚期共收 183.78。单图中即能出现「高估即时被夺的树、低估长期稳定的树」两种错误。另有留出地图 3708e17c，模型 MAE 24.98，弱于中位数对照的 24.42。[逐图误差与原始反例](held.json)

样本只包含历史策略选择种植、且当拍实际种成的行动；未经选择、种植失败或改走其他格的相应回报未知。预测现金也与原版无量纲叶值单位不同。它能给历史种植行为提供一个可核验的长期监督目标；要用于部署动作排序，还需要同一战局合法替代动作与真实对手续弈的终局分差证据，以及独立的单位标定。[样本定义及边界](protocol.json)
