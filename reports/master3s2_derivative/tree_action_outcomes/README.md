## 选择与复核

在看分支赛果之前按物理地图冻结 592–595 四个根。每图在 t272–286 按已训练模型的正负方向找行动机会，偶数图要求预测亏损、奇数图要求预测盈利，跳过已有注册根与常用 t279/t285。选中的四根碰巧都在席 0，母包都实际要求种植工离开空地。四张地形与树模型原有 24 张训练图、8 张验证图无交集。这组样本覆盖末段、原本要移动、同一席位的种植工；没有对不同阶段和两席进行总体胜率推断。[冻结条件和完整队令](protocol.json) · [登记工具](register.py) · [已有隔离构造器](../tree_control_response/isolated_proposals/README.md)

每根重建官方前缀和双方当时可见的状态。母令取自旧整局真正执行的完整队令，另一臂只改登记种植工。两臂用同一份当拍原版对手命令、相同赛局与双方历史信念快照；根以后由原版派生母包 `7cf5c6c9` 和仓内原版 `65f268b2` 通过各自公开入口重新发令，均使用真实自适应 0.58 秒搜索、温度 1。四组对手都从根的下一拍开始出现不同的完整队令。全 8 臂到 t299，共 204 个环境转移，官方与 FastCarbon 逐拍核对玩家、碳图、树与钱包；最长本地公开调用 0.650 秒。绑核 CPU 4，期间另有诊断进程曾短时使用同一核，记录保留原始时钟，无按深度、墙钟或赛果剔除、补跑。平台配额、通信和整场资格须另核。[运行器](run.py) · [对照身份、终局及钱包校验](settle.py)

## 预先约定的跨图学习检验

仅用行动前预测的“单树首段净收”作为输入，用两臂真实终局分差作为目标。四次轮流整张地图留出，每次在另外三图拟合一维带截距岭回归，同时计算只报训练图均值的参照。没有在同图内拆帧，也没有按结果选择阈值。

| 对四张分别留出的图 | 分差 MAE | 驻留优劣方向命中 | 采用其选择，相对全部离开的本批平均分差 |

| 用三图拟合的终局差校准器 | 288.32 | 0 / 4 | −48.10 |
| 只报另外三图的真实平均差 | 159.50 | 1 / 4 | −31.24 |

**不发布校准权重。** 这批数据提供了两个重要反例：单树的账算对，整队的最佳行动仍可能相反；同样的首拍碰撞，也会走向相反的终局。以后增加独立训练图时，需要同时覆盖对手立即抵达拟种格的机会、种植工生存、双方在途回款及联动经济，不应拿上述四图继续选到一个更好看的系数。[逐图预测、训练地图、系数与标签](settlement.json)
