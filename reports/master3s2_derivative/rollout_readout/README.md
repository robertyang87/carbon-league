# 搜索对手行动的 776 参数浅层读出

**不接入对局。** 在四张留图的 128 个模拟棋盘上，即便共用原版随机数，新网络只在 **1/128** 个棋盘上重现完整对手队令。工人目的格 631/1,245 一致，基地实令 225/256 一致。仅知道若干独立工人的大致倾向，无法维持原版搜索见到的整队应手。 [事前判据](protocol.json) · [训练及逐图结果](fit.json)

原版有六个残差块。本次固定原权重，读第 2 块输出的 96 个逐格特征，以两个线性头分别预测工人 5 类、基地 3 类动作，共 (96+1)×(5+3) = 776 个可训练参数。教师目标是同一次原版搜索在模拟分支中交给敌方动作采样器的第 6 块 logits。实际线上已经成熟的己方根策略、价值网都未参与拟合。对照组把原来的最终动作头直接接在第二块上。 [可复现权重](weights.npz) · [原版计算和浅层读出的接口](timing/forward.py)

### 样本和成本

沿用项目已有的 24 张训练图与另外 4 张原留图，全部双席。只用历史真局恢复该席行动前状态，各席在 t72、215 调用原版公开搜索，保持真实 0.58 秒墙钟。每次在深度 1、2、4、6 按原生遍历顺序各取最先出现的至多两个对手模拟行动。112 个根全部搜到深度 8，原生搜索自身累计报告 27.92 秒，另有回放历史、离线重算特征和拟合耗时。此轮未开新的整局。

取到 896 条模拟记录。去除十条同一条轨迹下输入完全相同的记录，留下训练 758 个棋盘（7,421 个工人和 1,516 个基地），留图 128 个棋盘（1,245 个工人和 256 个基地）。每个留图深度各 32 个棋盘。验证过训练与留图的物理地图无交集，敌方输入逐字节哈希也无跨组交集。教师只用模拟时的原版输出，原局后来走的动作和最后比分都未当监督。深度上的多个分支关联很强，独立地形数仍是四张。 [冻结的数据、原始标签和分支指令](simulated_rows.zip) · [采集程序](collect.py)

### 留图上哪些决策失真

以下“命中”表示与同棋盘、同温度、同原版随机数下教师的物理选择一致。完整队令始终走原版现金、工位、占格与冲突解码。原样保留教师模拟的己方同时动作，并据此核对双方是否选择相同目的格。它们描述模拟中的差别。

| 留图项目 | 分母 | 原最终头接到第 2 块 | 训练后的两个头 |
|---|---:|---:|---:|
| 全队命令全部一致 | 128 | 0 | **1** |
| 工人目的格相同 | 1,245 | 327 | **631** |
| 基地动作相同 | 256 | 226 | **225** |
| 自身载货 ≥50 的采集工 | 374 | 104 | **215** |
| 距己方基地 ≤2 格的采集工 | 296 | 85 | **131** |
| 距其他任一工人 ≤2 格的工人 | 943 | 268 | **488** |
| 距敌方载货 ≥50 采集工 ≤2 格的工人，补充统计 | 207 | 51 | **127** |
| 教师模拟中与己方工人同目的格 | 33 | 命中 7、误报 30 | **命中 14、误报 27** |

举例：621758327、席 1、根 t72 的深度 6 第一条模拟分支，对手 13 号采集工在格 140、载货 57.75。教师向右去 141，新头让它留在 140；同一拍本方有工人要去 140，新头因此制造了原版没有预期的接触。可在逐项留图输出中查到同一根、分支和队令。 [逐分支完整队令](held_orders.json.gz)

四张图等权的教师到学生 KL，工人由 4.188 降至 0.978，基地由 10.815 降至 0.825；预定目标均为 ≤0.04。训练端本身的 KL 已达 0.886 / 0.516，完整队令也只复现 1/758。两个头都用完预先固定的 100 次 L-BFGS 迭代。这些结果说明本次固定前两块加线性头的拟合远未达到替代精度，不能断言其他中间层、其他网络或更大数据也做不到。 [逐图梯度、误差与采样覆盖](fit.json)

### 复算

从本目录运行 `python fit.py --cpu 0` 会从冻结采样件重新拟合并计算验证结果，可将 CPU 编号改为当前机器可用的编号。需要另行按原版自然墙钟重新取样时，先运行 `python collect.py --cpu 0 --cache /tmp/m3-readout-new`，再运行 `python fit.py --cpu 0 --cache /tmp/m3-readout-new`。重采时应另存原有冻结件，时间预算可能改变原版访问的分支。 [拟合和核验代码](fit.py)
