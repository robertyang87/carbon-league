## 四张地图给出的不确定度

登记场次中已确认胜局的比例为 62.5%。各图这一比例依次为 1、0.5、0.5、0.5。把整张图及两席一起有放回重采四次，枚举全部 256 种有序组合，取线性插值的 2.5% 和 97.5% 分位，得到描述性区间 **[50.0%, 87.5%]**。对有官方数值的场次，在每个重采样本中用数值分差总和除以有效场数，得到 **+65.83 [−257.26, +327.89]**。这后一项仅描述七个已定数值。登记时约定的全体八场数值分差区间仍为空。四个独立地图簇给出的尾部精度有限。[按图和分席原始数](hosted/settlement.json)
