每张图、每个席位都保留，双方失败或提前终止只统计实际执行并有双边命令的前缀。工位上限 10、每次招募 30；一张图有两座基地，机会按原生基地遍历顺序扣实际前一基地的支出，因而另附发令前两基地共享工额的口径。真实对手命令和己方当拍命令仅用于出预测后的标签、分类与下一步历史。求每个局面的预测只对原版共享骨干运行一次，复用同一己席碳估计、同一原生根随机数和同一动作解码器。这里测到的是观察到的同拍预测误差，归因到胜负需要独立干预与对照。 [逐根命令及可招工记录](forecast.json.gz) · [复算程序](audit.py)
