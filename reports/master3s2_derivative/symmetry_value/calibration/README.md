## 测量对象

使用自有真实对局中原版席从开局开始的公开观察和自身已提交命令，逐步恢复 `BeliefTracker`。每场取 t=7、20、…、293。每个位置都以原版估计碳地图和实际上一拍位置编码。主口径按搜索叶的约定把 `known` 平面置 1，同时提供原生的五个标量（现金差、在途货量差、步数、树数差、工人数差）。在原版网络上给成对输入算值；旋转保持玩家身份、标量与同一步静态局面，空间平面和方向通道均旋转。真实可见度掩码另算一次，旧留出的 MSE 变化为 +0.001368，另一域为 −0.001698。[共用物理旋转](../rotate.py) · [合法视角与评分程序](measure.py)

每条标签都是当场原版官方分减对手官方分，再用原函数 `clip(分差 / 3000, −2.5, 2.5) + 0.5 × sign(分差)` 换算。对比在实际走过的轨迹上进行。双方策略、守卫和对手都可能有方向偏好，旋转后在相同规则下也可能走出不同回报。同一根上哪条备选队令价值更高，需要两条备选各自的真实终局支持。

完整检出后，从仓根运行以下命令，使用仓内裁判、NumPy 1.26.4、CPU PyTorch 2.5.1。原观察档、考官源码、决策席和四图划分均有身份检查。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  python reports/master3s2_derivative/symmetry_value/calibration/measure.py \
  --out /tmp/master3s2-symmetry-calibration
```
