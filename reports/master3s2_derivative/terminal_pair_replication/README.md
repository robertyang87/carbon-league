# 用两次原版续弈复核同一对动作的终局标签

八张历史开发图换席，固定 t289，共 16 个根。每根在两臂同敌令、同深度的研究搜索中选出 V2 的首选和原生价值次选。为保证可比，离线生成统一限八候选、八层，研究侧不套用线上 0.58 秒截止。16 根全部取得两条不同的同深队令；生成只读该席公开历史、成本记录和原权重，未读替代动作真实赛果。[冻结协议](protocol.json) · [采集入口](collect.py)

每个根用两份不同的自然采样流。每份流内，两条动作共用完整原版实际产生的首拍敌令。第一拍之后两方分别以完整 v2、仓内完整原版各自继续，保留 0.58 秒自适应时钟与温度 1。全部 **64 条**在官方规则下正常打到第 299 状态；共 640 个联合步。原版续弈每步对照独立规则引擎的工人、树、全图碳和钱包。最长单步本地 0.603 秒，属于开发诊断。本件的地图都已曝光，正式 100 图仍未动用。[原始轨迹第一分片](part0/rows.json.gz) · [第二分片](part1/rows.json.gz) · [第三分片](part2/rows.json.gz) · [第四分片](part3/rows.json.gz)

## 一次真实终局对动作排序有多少信息

同一对动作在两份自然应对下，**9/16 根的官方分差方向翻转**。只看四张留图，8 根中有 6 根翻转。其中 4 根的两个续弈流在根上甚至给出同一条敌令；之后的动作分歧和真实墙钟都可能造成结果差异。留图每根两个分差差值的绝对差平均 **203.88 分**。例如 621782471 席 1，原首选相对次选从少 32.98 到多 346.44；621782470 席 0 从多 365.22 到少 36.04。全部 32 组流内对照只有一组胜负发生变化，其余主要辨别两种动作的分差。两条流仍不足以估计某个动作的真实期望收益。[逐根分差及两份原版应手](held.json)
