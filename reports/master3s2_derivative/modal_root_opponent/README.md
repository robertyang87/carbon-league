# 对手根令使用最高概率动作的检验

以线上 V2 为母包，只将对手的第一拍推演改成每个单位取最高概率动作，仍通过同一招募与占位解码器。更深的双方动作保留各自原版采样，预算、权重和我方候选生成均沿用母包。[单文件](candidate.py) · [冻结局面和构建](protocol.json) · [复算程序](probe.py)

已曝光的四张开发图各两席，取第 117 和 247 步，得到 16 个局面。签名的实际敌令来自同一局中仓内未修改原版的自主发令，在预测完成之后打开。16 根的匹配诊断保持我方候选菜单、宽度、深度及各候选完成深度相同。全局整令命中两包都是 1/16，工人动作命中由 **128/156 降至 124/156**，基地保持 31/32。按地图等权的工人命中由 82.01% 降到 79.47%。[签名实发与逐根预测](predictions.json) · [复算](predictions.py)

有两个局面，我方的改令经自然重复和匹配工作都得到确认。两处对敌工人动作的预测都比原采样更差，分别 5→4、8→6，因此此版本在局面测试后结束。公开棋面是既有开发图，样本不足以估算整包胜率。原始回执的 `v4` 与 `critic` 是复用程序的字段，分别指本报告签名的 V2 和候选。原程序的 `reliable_change` 要求两臂共用同一敌令，本实验以 `predictions.json` 的 `stable_own_change` 核验不同敌令下的实际改动。[逐根时钟与候选](results.json.gz)
