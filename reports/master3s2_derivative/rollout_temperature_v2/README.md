## 在另一批原版实战上复查敌令概率

另取未参与拟合及首次校准留图的 4 张开发图，每图 v2 对原版的双席旧档。按 v2 己席可见状态估算碳，以已签名当拍双方动作重建下一拍，用原版下一拍实发令计分。预定 472 根全部有对齐的实体，冻结参数未重拟合。按地图等权，单位动作 Brier 从 0.29120 降到 0.25196，交库／重合／招工联合事件 Brier 从 0.15277 降到 0.13308。单位首选命中由 83.52% 降至 82.79%，16 次抽样中恰好复现整队原令的次数由 1,371 降至 665。变平的概率提高了校准度，同时降低了实发整队令复现率。下一拍对应的是已执行分支，其他候选的反事实动作与整局强度由另外的对照检验。[复算](check_transfer.py) · [完整留图读数](transfer_check.json.gz)
