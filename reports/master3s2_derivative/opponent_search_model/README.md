# 用一步对手搜索预测 Master3s2 的实发命令

从 ds-pro-v1 自己能看到的局面，替对手推演一步，**略能猜准更多工人，但整队预测输给更便宜的先验排序**。四张留图、双席、392 个决策点上，先验四选一猜中 75 条完整敌令，加入经训练图校准的对方价值后猜中 68 条，原版单次抽样猜中 64 条。本次没有通过预设条件。资料可用于改进对手候选生成，暂不值得为现役搜索扣除这部分墙钟。[试验登记](protocol.json) · [留图结果](held.json)

## 可见信息与原版身份

取 12 场既有 ds-pro-v1 对仓内原版 Master3s2 的双方换席档案。两张物理地图 621758590、591 共 196 根拟合系数，另外四张 592–595 共 392 根检验。在每场固定考查第 8、14、…、296 步，仅用本席公开观察、先前本席指令和本席信念器估算的碳图。对手自己的私有观测、当拍真实双方命令、我方实际搜索选项均未传进推断函数。双方实令只在完成预测后用于评判。候选是同一个 7cf5 原版派生包的预测；充当对手的 65f268b2 使用公开原版 0.58 秒搜索、温度 1。地图均已用于过往研发，这里的留图只隔离本次拟合。[验过哈希的逐场来源](../opponent_rollout_calibration/protocol.json) · [分图和真实命令核对](study.py)

每根保留原搜索的第一条对手联合令，并从同一原版对手视角加采三条，去重。再从我方视角的原版策略独立抽一条我令，所有对手候选都与它同步推进。对每个后继，用对方视角的原版特征和平视该席的五个标量，将整批送入原版价值网。分别比较原单样本、候选先验、单用对方价值、先验加价值。先验只用于排序，是全体单位所选动作 logits 之和。物理落点约束使其不能解释成整队联合概率。按两张训练地图等权的工人命中率冻结系数 β=4，训练中相对仅先验提高 0.056 个百分点。16 个额外抽检根在原包真实搜索开始第一次联合推进时截取敌令，均与我们菜单中的第零条逐字相同。[实现](model.py) · [冻结权重](weights.json) · [原搜索截取与时钟](verification.json)

**最难的局面出在对手真的改了网络原招时。** 对完整考官每拍的累计改令计数作一阶差分，392 根中 294 根原版搜索改变了本方实发。这样的根，整条真实敌令在最多四个候选内出现仅 **21/294**。原抽样全中 11 个，先验 9 个，纯价值 13 个，冻结组合 11 个。其余 98 个未改令根中，真实敌令入菜单 75 个，先验猜中 66 个，组合 57 个。这项分层在推断后完成，没有重训。它解释了完整策略的局限：即便能事后挑到最合适的候选，也有 **273 个实际搜索改令根**无法重现。另有 158/392 根的四次抽样只产生一种物理命令。可先在廉价离线预测中扩充候选覆盖，例如围绕可争执的同一交汇格，联动更改两个单位、保留不干预的一臂，按图检验真实敌令、接触和回款是否一起改善。[真实改令分层](search_changes.json) · [还原方法](search_changes.py)

## 一步预测占用多少预算

对另取的 56 个同根，两次运行轮流用进程 CPU 钟与墙钟记录，每次重算均逐条核对候选与价值。单线程、固定逻辑 CPU 4，既有本地 PyTorch 后端，未施加天梯 cgroup。较原版单次对手抽样新增工作的 P50/P95 如下，单位毫秒。各分项的分位数不能直接相加。[逐根配对时钟](timing_roots.json.gz) · [末端资源测量](verification.json)

| 阶段 | CPU P50 / P95 | 墙钟 P50 / P95 |
|---|---:|---:|
| 额外预测一条我令 | 7.17 / 10.53 | 15.28 / 20.52 |
| 其余敌令和先验得分 | 1.44 / 2.30 | 1.47 / 6.23 |
| 联合推进与编码 | 1.33 / 2.58 | 2.01 / 6.28 |
| 对方价值单批前向 | 9.84 / 17.50 | 21.60 / 36.61 |
| **总新增** | **20.56 / 30.98** | **40.69 / 61.92** |

新增墙钟 P99 为 68.39 毫秒，最慢 70.33 毫秒；原有单次对手预测墙钟 P50 为 15.48 毫秒。调度负载影响明显，另一次提取全体 392 根时新增墙钟 P50/P95 为 16.86/24.66 毫秒。加入现役时，这些工作会占用同一 0.58 秒搜索截止前的时间。这里没有发车，没有新比赛结果或单步限时认证。即使未来完全猜中某个敌令，预判概率和对替代策略真实应手的收益仍要分别测量。
