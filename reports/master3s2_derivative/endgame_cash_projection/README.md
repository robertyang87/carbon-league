# 残局双方还可能赚多少现金

ds-pro-v1 对 1C-Test 的第 294 步领先 583.22 分，五步后仅赢 93.26。为了让网络识别类似局面，本实验预测从当前现金差到官方终局分差，还会增加或减少多少。输出单位为官方分。它使用当前同时公开的工人位置、货量、基地和树龄，换席后严格反号。规则引擎的真碳图只用于地图身份核对。[窄胜回放与现金账](../ladder/observation_nov20/README.md) · [预测实现](runtime.py)

## 训练、留图与原版实战

从过去前五选手至少一方参赛的回放中，按开局地形 SHA 排序登记 160 张训练图和 40 张留图，排除之前树回本研究图、已登记的派生开发图和本线当时的天梯图、正式卷保留号段。每图在第 249、254 至 294 步取十个行动前状态。只取实际打到的根和双方 DONE 的官方数值终分；训练中一图在窗口前终止。每图在损失中等权，席 0 和席 1 的镜像只计一个样本。[冻结地图清单](maps.json) · [地图选取与标签](data.py)

参照一沿用当前现金差；参照二拟合双方总现金、总货、树数、工数的差以及各量与剩余时间的交互。增强模型在相同训练样本上增加 14 个特征，反映货物距基地的时间余量、轻敌可否威胁最短路下一格、树可继续吸收的时间等。两个拟合模型都使用无截距 Huber 损失，分差以千分为单位，δ=1，L2 系数 0.02。先冻结权重，再读取本实验 40 张留图的终局标签。主要判据为留图等地图权的平均绝对误差同时低于两种参照。[训练实现](fit.py) · [冻结权重](weights.json) · [训练逐根结果](fit.json)

## 在原考官上验证用途

另一组开发赛在 621758594、621758595 换席，用两个固定考生各自与完整原版对战。两考生运行的是已冻结的护货候选和母包。本读出未参与这八场选招。权重 SHA-256 为 `ceed9c721d2ff70bcd2a47bb47dacb5ca88b51073e8a7fb9beefe3598e679cd6`。新场沿用相同步段、三种模型和物理地图等权误差；两图必须等所有已登记比赛结束后整批计算。[复核入口](original_domain.py) · [该场登记](../ladder/cargo_defense/development/protocol.json)

局面终分预测与动作收益是不同的问题。两个合法动作的估值差可能远小于当前预测误差，过去某个动作打出的真实结局也带着后续采样波动。读出保持离线，整局对未改原版的观察胜率仍由完整换席实战决定。

## 同一局面换一步，真实结果如何变化

另取此前已和原版打到终局的 11 对不同己方指令，另有一个根未到同深，保留缺项。用母包的第八层模拟局面逐对复算两种选择。增强读出改选 3 次，在已经发生的真实续弈中分别多得 190.17、77.29、338.13 分。连同另 8 个未换令局面，每图平均 +55.05。只用搜索叶的现金改选 4 次，有一张图变差，全图平均 +30.19；使用公共总量拟合为 +49.18。两条分支在这 11 张图上全部已经赢过原版，所以胜负翻转数为零。分支各自只走过一次自然采样，结果也已在以前的工作中公开。这里能确定回顾性选令对上了哪条轨迹；本模型能否在完整搜索的真实截止前发出同一条指令、并在新图上提高胜率，还须另外验证。[锁定的根输入](paired_inputs.json.gz) · [逐根复核](paired.json) · [复算](paired_audit.py)
