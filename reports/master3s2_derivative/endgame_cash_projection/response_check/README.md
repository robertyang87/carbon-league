# 同一残局只替换一手，原版随后会怎样应对

**8 个事先登记的根中，现金预测头在相同搜索工作量下改变了 2 个最终联合指令。两次改令都经原封单文件、实际墙钟再次产生。** 一次使官方分差减少 163.01，一次增加 105.48。6 个同令根的配对差为零，8 根合计平均 −7.19 分。仅有两张独立物理地图，两图方向相反，不能据此确定换头能提高胜率或收入。[方案与八根清单](protocol.json) · [逐根及逐图汇总](results.json)

两处均只换根上一个工人的动作。第一处两臂的候选方与原版比分分别为 9,265.35 比 8,631.41、9,206.78 比 8,735.85；第二处为 9,020.22 比 8,533.51、9,076.63 比 8,484.44。两处的替代令和母令都赢。价值头在第一处预计增益 60.05、第二处预计增益 53.55，只有后一处与实收方向相符。四段从同根打到终局的两方实际队令、搜索计时、现金到账和终局均已落档。[594 号逐根](roots/3.json) · [595 号逐根](roots/7.json) · [四段公开实战](branches/defense)

两图各有四个根，来自该图母版与护货版两种来源轨迹、各两个席位。同图内四根平均分差变化分别为 −40.75 和 +26.37。6 个完全同令根按同一未来随机流计零，双方终局绝对比分留空。四段实际续弈共 68 次联合推进，约用 51.31 单核 CPU 秒。两分支共享该根原版一次自然应手，随后双方依各自新局面完整出令，以同一个 7cf5 母包面对同一仓内原版 65f2。模拟环境与影子引擎逐步对账；原版 0.58 秒自适应搜索保留。本研究根级试验没有新开天梯或托管开发整场。[逐根恢复](recovery.py) · [续弈执行程序](run.py)

**墙钟引入另一个真实差异。** 托管源只给对面的原版记录搜索候选数、深度和轮数，受试席没有历史搜索工作量或私有随机状态。因此在真实历史公开观察及双方已下队令上，重新登记同根策略随机状态，先运行原封 7cf5 和 c522，再按本机原封母包当次实际完成的工作量对照。8 根的母版菜单、候选原分和深度都逐项复现；6 根同工量走到 H8、2 根停于 H6。未经修改、实际墙钟运行共有 3 根返回不同令，其中 2 根就是表中经续弈的两根。另一根为 595 号原母版来源、席 1、279 步，本机母版走到 H8、新包只走到 H7。等工量两者同令，故该差异不能归给现金读出；它未做独立续弈，整包墙钟差异的总收益仍未知。[该根完整双口径](roots/6.json)

本批使用已曝光的开发轨迹。端到端 CPU 计时没有正式天梯容器认证，固定工作量重建只用于解释动作因果；配对的两个真实后缀仍受原生墙钟及宿主资源波动。每个分支只有一条实现轨迹，报告的分差变化不等于该行动的期望收益。
