# 用开局树的后续到账校正 v2 搜索

前一批 44 局复盘显示，v2 的 22 场败局前 100 拍平均少收 314.20 树净现金。这轮从行动前能看到的既有树和双方位置，预测每棵树未来 16 拍仍归原持有者的现金。用 14 张物理图、28 局、4,518 条树在局面中的记录拟合。另 8 张图和两席在权重冻结后评估，2,516 条记录。采样时点每五拍一次，从 t20 到 t100。重复观察的树及同图换席不计为独立地图。[上轮逐拍诊断](../v2_original_cash_paths/README.md) · [训练留图合同](protocol.json)

输入 14 项，包括树龄、周围碳量估计及未知格数、相邻树、双边种植工距离、敌方附近工人数和载量。双方树都从 v2 席自身的观测和既往己令推断，未读对方私有观察或全图碳。输出按真实规则重放逐树记账，包含吸碳、过路货税和直接碰撞现金，首次换手或凋谢后停止归给原树主。购买已发生，未重复扣费。未模拟新出现的树。同期剩余寿命乘训练集每拍平均收入构成基线。[公开特征](features.py) · [复演和拟合](train.py) · [模型权重](weights.json)

## 部署入口是否改令

从 v2 原单文件构建试验包，在 t20–92 的完整末层输出上增加租金预测相对寿命基线的两席差估计。加入四分之一，按原现金尺度 3,000 换算并限于 ±0.06。原策略、网络权重、候选生成、先前剪枝都沿用。系数为诊断取值，未根据完整对局拟合。[构建脚本](build.py) · [冻结候选](candidate.py)

四张留图各双席、t45/t85 共 16 根。两臂各做两次原生墙钟和两次匹配父包搜索的完整入口调用。匹配工作时 13 根的至少一个叶分变化，最大全量差 0.01024。**最终发令改变 0/16**。自然时钟下候选在一根连续两次发出不同的动作，但 v2 完成 H5/H7，候选两次到 H8；匹配父包工作量后恢复相同动作。候选自然调用最慢 0.573 秒，这批为单逻辑 CPU 的本地诊断。[冻结根](search_protocol.json) · [逐次搜索读回](search/results.json.gz)

当前结果验证了早盘存量树现金的预测，尚未验证用它在完整对抗中改善选址或防守。这个候选停在机制检验，没有开新整局或报送天梯。
