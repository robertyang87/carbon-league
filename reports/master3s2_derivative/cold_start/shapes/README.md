# 原版派生网络在稀疏预热后的首次批推理

从四张已有训练图取 32 个己席公开状态，用原版信念跟踪器编码对手根输入，取同一虚拟席位的价值标量。按固定顺序采用这些输入的前 N 项。旧包 `245b5814` 和启动修订包 `7cf5c6c9` 在九种批量、三类输出上的 244,936 个数逐字节一致，最大绝对差 0。所比输出为 225 个格子的工人动作 logits、基地动作 logits、各局面 critic。 [代码差异](../release.json) · [逐张量哈希与来源](results.json)

每个“包×批量”使用独立 Python 进程，该进程完成该包真实导入与原生预热，再连续前向三次。表中“复测”为后两次的中位数，单位毫秒。两个包交替先后，绑定本机同一 CPU 4，原生 Torch 两线程共享一颗核。每种条件只有一次首次读数。

在本机这一次观测里，新包首次相对自身复测的最大额外耗时为 26.45 ms（N=32），最大首次总耗时为 284.95 ms（N=32）。N=32 是两个包都显式预热的对照；N=3 虽未列入新包预热循环，上游选择 Winograd 后端时本就用三局面批做数值校验，故其首次真局面读数也带这次先验热身。
