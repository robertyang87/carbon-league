# 下种前预测这棵树能否回本

天梯前五历史对局的 8 张留出地图上，两席实际新种 464 棵树，其中 154 棵在首次连续持有结束前没挣回种植费。用当时己席可见的信息，模型把按地图等权的一步预测 Brier 误差从 **0.1540 降到 0.1422**，地图内 AUC 从 **0.8145 提到 0.8433**。八图有五图误差下降，通过事前登记的回本预测判据。**哈基米已曝光的三棵亏损树仍被低估**，估计失败率只有 10.5%–14.3%。本研究测的是已种树的风险，能否靠改令提高收入，要另测替代行动和对手响应。[冻结协议](protocol.json) · [留出结果](held.json)

## 从真实收入建立标签

按开局完整碳图去重，在本地回放登记册的 1,660 张有结果的地图中排除定位图、已登记训练/评估用图及正式考卷保留段；1,580 张满足本次取样条件。按地图哈希排序固定取前 32 张，首 24 张用于拟合，末 8 张留出。同图双席始终同组。哈基米等已曝光天梯定位图独立处理。完整碳图只做地图身份核验。[地图清单及回放档案位置](maps.json) · [选择器](register.py)

每棵树从实际付费的种植拍开始记账，依照环境推进顺序加计地块吸收、敌方携货吸收以及该树直接获得的碰撞款。第一次被夺、凋谢或正常终局即结算。即使后来夺回，也保留第一段持有的独立账。结算器逐拍对照真实双方余额、工人与树的状态，逐树核验回放中公布的吸收额，并核对同拍同席多工种树的实际扣款。哈基米全场 53 棵初植均与另存的逐树账对齐。特征侧仅知道下种前公开报价；每棵的报价另与事后实际扣款核对。[结算器](labels.py) · [已曝光逐树账](../hajimi_v3pro/tree_ownership.json.gz)

训练的 1,371 棵里有 448 棵未回本。学习目标是预测“首次连续持有期间实际收入 < 初植成本”的概率。四项参考模型也在同样的 24 图拟合，其输入为当时报价、种植工四邻可见碳、余步（封顶自然树龄）、最近敌种植工距离。完整模型共 23 个连续特征加截距，增入同一敌种植工三个和五个回合的接近趋势、周围友军与敌军职业分布、邻树争碳及双方基地距离。种植工本拍可见四个正交邻格的碳；被选格的裸碳不在特征里。全程使用物理己席的私有碳视图及公开棋子，不读对手本拍命令。特征间相关，单项系数无法解释成该行动的因果效果。[纯 Python 预测接口](runtime.py) · [拟合及评分](study.py) · [冻结权重](weights.json)

## 复现

从仓库根运行。拟合使用 NumPy 与 SciPy；部署读出仅用 Python 标准库。程序校验回放压缩字节、开局地形、协议、地图清单与已冻结的权重身份。已有本地缓存时传入旧回放 gzip 所在目录，也可从登记的 Git 历史存档读取。三个模式顺序执行，先将权重单独落盘。

```bash
study=reports/master3s2_derivative/ladder/tree_payback/study.py
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python "$study" train --out /tmp/tree-payback-results
python "$study" held --out /tmp/tree-payback-results
python "$study" exposed --out /tmp/tree-payback-results
```

本实验未变更任何在飞赛包，也未新开天梯赛。[训练逐树记录](train_trees.json.gz) · [训练摘要](train.json)
