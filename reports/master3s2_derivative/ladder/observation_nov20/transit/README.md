# ds-pro-v1 残局在途货与十步回款

在这七张已打过的图上，公开在手货量对未来十步双方回款差有预测力。观测中工人到最近己方基地的最大距离只有 9 格，全部 2,885 个正载货工人时点都满足十步可达。这里无法给“十步可达”这一筛选条件本身记功。

每局取 t250 至 t289 的 40 个行动前公开状态。输入只用双方公开工人位置、持货量和基地、现金。目标为随后十次官方实际转换中双方自己的采集工回本方基地的净到账差。另评分 t+10 的实际现金差，它也包括种树、树收入和招工等。全局账本、工人和树逐拍对官方状态读回。所有现金误差和预测符号均以 ds-pro-v1 为正。

从预测终局前十步的现金看，在 t+10 复用当前现金差的平均误差为 309.4，加上在手货差后为 257.0。按单图细看，在 Carago 从 326.6 增为 370.9，在 Master2s 从 301.2 增为 371.8。树的收入和投资、招工、截获及行路途中增货能改变最终现金差。

## 能到与真正交回

2,885 个起始正载货的工人时点中，同一工人 3、5、10 步内有正到账的分别为 454、738、1,407，约 15.7%、25.6%、48.8%。按当时载货量加权，后来在相应窗口内到账的工人在窗口起点分别持有全体在手货的 19.9%、31.2%、55.5%。这些比例涉及重叠窗口，也只跟踪工人身份，不能精确追溯每份碳的来源。1,407 个十步内到账的工人时点中，977 个的第一笔到账高于起点载量。

- 1C-Test 的 t283 当时现金落后 86.54，在手货多 452.75，随后十步实际回款多 567.65。到 t289，现金领先 480.80，在手货却少 206.32，之后十步实际少回 434.06，终局仅赢 93.26。
- 对 Master2s，t289 我方在手货少 409.85，此后十步却多回款 458.24。对手三名载货工在状态 t295、297、298 被截，三名获货的我方工人也均未在终场前交回。本局同时给出方向反例与兑现反例。没有干预对照，不能断言被截工若存活必定交回。
- 安生 N27 的第 0 席 worker-63 在 t285 携 17.52，接下来两步原地采集至 38.36，t287 向右入库时同队另一名载货 198.95 的采集工也进入同格。根据唯一轻载工存活的规则，worker-63 在 t288 实收 237.31。该笔超过起始载量的 219.80 含同伴转货及这两步采集；把增长全归于抢对手会产生错误标签。

该指标适合用来提示“当前领先可能被追近”，不能直接给各工发返航令、将手中货当成现金，或当成训练收益证明。复算入口是 probe.py 和 examples.py，参数为仓库根路径；固定口径保存在 protocol.json。
