# 两名采集工同时进库

复赛 t290 行动前，Krypton 的 49 号和 56 号分别在格 69、71，随后同时进入己库 70。较轻的 49 号接到同伴的 150.38，加上自己的 24.95，t291 状态显示实收 175.32。回放可验证合款，无法判定对手是否有意牺牲一名工人。V4 的原生解码已允许最后 12 拍两个采集工同时选择同一己库。[双方逐拍及资金来源](../../v4_observations/increment_0926/README.md)

此前对小肥鱼 v5 的低树税路线实验对己方落点作过保守限制，挡住了队友已选的基地格。本次补测只放开一种局面。携货采集工距己库一步，另一携货采集工本拍也将进同库，两者载货不同、该库未在招工，且没有敌方采集工一步可达时，允许合款。其余动作沿用前次路线，仍然根据该拍可见局面与本方联合命令选取。

复用四张已曝光开发图、8 局 v4 对完整仓内原版的已登记轨迹。每局仍只改 t290 选中的一名采集工直至首次交货或死亡，其余命令沿用历史记录。新旧两套返航政策在这八个后缀上发出完全相同的命令，逐拍现金、所选工人位置、交付和终分也全部重合。两者相比原始 V4 路线均平均少 23.24 分。这一批对合款动作本身的收益没有辨别力，对手在 Krypton 复赛做过一次合款也不能说明我方照做就能赢。两个规则引擎逐拍核了所有分支以及原始比分。[原八局](../../v4_fish_plain/route_transfer/README.md) · [复算](compare.py) · [全部收据](receipts.json.gz)
