### 训练、身份与权重

基线是实际上传的 `ds-pro-v1` 单文件 `7cf5c6c9`，包含已部署的敌方预测头。只用 CarbonEdge-Eco 和 CaiV3 两场、我方均在席 0 的历史实令训练。前者 2,200 个命令，NLL 5.49664 → 5.35735，纠正 18、改错 7；后者 2,183 个，NLL 7.55527 → 7.38256，纠正 20、改错 6。训练图重载组分别仅 57 和 14 个，合计净少猜对 1 个。[训练结果](train_result.json)

模型只学习两个 float32 数。给“停留”动作的 logit 加 **1.5**，达到预定上界。对每个合法单步方向，用走这一步减少的环面返航距离乘以 `min(当前货量/200,1)`，将结果乘 **−0.51074415** 后加到原 logit。这个负系数反映两张训练图中的拟合方向；留图重载表现提示，单纯依据货量和最近基地距离，尚不足以预判重车什么时候回家。训练使用等图权重和固定 L2 惩罚。第一批 4,383 个命令拟合完成后，权重、代码、两张留图局号及席位在 Git 提交 `4fa07419` 冻结，随后才读取其余两场的行动记录。[训练权重](weights.json) · [拟合与独立验证程序](calibrate.py)

每步只给模型当时本席可见的碳、双方公开单位与基地状态、此前实发的己方指令。公开录像的完整初始地形仅用于四图去重。对手名称、录像结果、后续行动、隐藏碳均不进入预测。归档的最小轨迹按行动前状态和行动后命令分别保留；保留原单位字典顺序，供原生采样器复演。[训练轨迹](train/) · [留出轨迹](held/)

### 推理接入与证据边界

`runtime.adjust(lwo, players, op, coefficients, _OPP_STEPS, FEAT_DIST)` 只需在 V2 调完 `_opponent_root_readout` 后，对敌采集工的五维 logits 应用一次。低于 200 货的返航项按实际货量线性缩小，空载时归航项为零。训练和两场留图的每一根都执行了同一个运行时函数，逐位核验其输出与评分输入一致。[运行时函数](runtime.py)

每场按全部 299 个根复演。线上回放未提供实际每拍搜索是否进入敌手建模分支及其私有中间值。上面的数字是冻结政策在真实公开局面上的预测评估。没有替换线上包，没有用这些预测重新打一场；对己方实际出招、终局胜率或收益的影响尚未测得。
