# 采集工护货模型

目标是让采集工在下令前比较五个落点的危险程度。四张留出地图上，对“载货至少 200、敌方确实够得到该格”的候选，学习模型把地图等权 Brier 误差从 **0.2689 降到 0.2177**。四张图中三张改善。同一工人同一拍的安全、危险选项排序 AUC 从 **0.5113 升到 0.6524**。这通过了事前登记的一步预测判据。每位对手只有一场，整局胜率、收入和因绕行损失的后续交仓均待实战验证。[冻结协议](protocol.json) · [留出结果](held.json)

## 怎么学、怎么验

模型按敌方采集工分别预测停、上、右、下、左五种反应。22 个共享系数读取出令前本方能看到的双方位置、货量轻重、上一拍位移、到双方基地的环面距离、附近工人分布和剩余时间。同一位置受多名敌人威胁时，合并各敌人可能进入的概率；该计算近似假定对手的不同工人独立行动。敌基地可能招募工人的概率由训练局估算。参照模型在同样的敌我几何关系上给五种敌方动作等概率；两者使用相同的基地招募先验。对既有对手策略网的增量仍待衡量。[部署读出](runtime.py) · [22 个权重和招募先验](weights.json)

四场训练均为席 0，对手为 CarbonEdge-Eco、CaiV3、安生N8、Krypton-Light3s2-v3，共 2,162 条可接触的“本方工人、敌方工人、拍数”记录。真实敌令只用于训练标签。四张留出图各代表一个从未用于拟合的对手。另把已知败局 Makabaka-v1.3 整场留给个案回放。按开局完整碳图及两席基地签名复核，九张地形各异。模型看不到完整碳图、当前敌令、下一拍或终局标签。[训练代码](study.py) · [逐局来源哈希](protocol.json)

每次只更换一个本方采集工的行动，双方其余工人保持历史实发命令；按官方结算处理移动、招工、同格碰撞和基地结算。五个选项都有标签。原命令的存亡与真实下一帧核对。被轻载敌工夺走的货与现金到账单独计算。正例是加入对手后才阵亡；纯粹己方工人相撞另记。标签器用 10 组构造局面、50 个方向逐一对照官方引擎。[结算与自检](labels.py) · [指标计算](metrics.py) · [逐工人逐令证据](held_orders.json.gz)

总计 9,668 个采集工决策，其中 947 个载货至少 200。扣除几何上不存在敌方威胁的方向后，计 552 个方向、194 个在历史真实敌令下会被拦截。137 个工人时点在受威胁方向之间同时有安全和致命选项，用于同根排序。表中每行按一张图单独评分，最后一行四张等权。

| 对手 | 受威胁方向 / 其中致命 | 可比较的工人时点 | Brier 等概率 → 学习 | AUC 等概率 → 学习 |

| 地图等权 | 552 / 194 | 137 | **0.2689 → 0.2177** | **0.5113 → 0.6524** |

地图等权 NLL 从 0.7514 降到 0.6252。补充的五档校准图中，学习模型给 0.25–0.50 风险的 300 个选项预测均值为 0.364，实发敌令下发生率 0.350。最高档只有 3 个选项。各方向和同局工人相关，应按整图理解证据。[逐图逐层数据](held.json) · [事后描述性分箱](reliability.json)

按预登记的使用方式，实发方向风险至少 0.25 才查看替代方向，替代方向风险还须至少低 0.10，且周围没有己方其他单位也能到该格。947 个重载时点中触发 7 次，找到可换方向 6 次。两次从会阵亡改为能存活，当拍少被夺 **477.12** 货；另四次原令已安全。六次都会使回家几何距离变长，合计 9 格。实际到账和后续存亡取决于双方接下来的反应。[全部逐令](held_orders.json.gz)

## Makabaka 已曝光败局

概率按“停 / 上 / 右 / 下 / 左”顺序列。预测时只用己席已知局面，结果列使用双方历史单拍命令复算。这两处既未参与拟合，也未计入四图结论。[原始概率与响应](exposed.json) · [全局逐令](exposed_orders.json.gz)

| 时点 | 携货 | 五个方向被截风险 | 原令 → 模型备选 | 历史对手响应下会被截的方向 |
|---|---:|---|---|---|
| 138，工人 3 | 633.55 | 0.000 / 0.380 / 0.518 / 0.244 / 0.000 | 上 → 停 | 上、右 |
| 140，工人 11 | 387.94 | 0.446 / 0.398 / 0.248 / 0.232 / 0.382 | 左 → 下 | 停、右、左 |

第 138 步原地和向左在一拍内均不受轻敌直接威胁，留在原地离家更近。第 140 步五个落点都有几何风险，模型选的“下”避开了实际围堵；它给“右”也打了接近的 0.248，而“右”会丢货。“上”估为 0.398 却安然无事。这一局所有重载决策合计改 4 次，其中 2 次原令本已安全。

## 复现与成本

从仓库根目录执行。需要 Python、NumPy、SciPy；部署预测只依赖 NumPy。复现证据写入独立目录。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
study=reports/master3s2_derivative/ladder/cargo_defense/study.py
python "$study" train --out /tmp/cargo-defense-results
python "$study" held --out /tmp/cargo-defense-results
python "$study" exposed --out /tmp/cargo-defense-results
```

本地单核 92 个训练旧局面，每根给全部己方采集工打五个分，每根重复 3 次。独立读出中位耗时 0.70 ms、P95 1.17 ms、最大 1.70 ms。原策略推理、搜索、通信、冷启动和整场平台认证另计。该版本用于离线验证，尚未合入在飞赛包。[计时凭据](local_cost.json) · [分箱与计时代码](diagnose.py)
