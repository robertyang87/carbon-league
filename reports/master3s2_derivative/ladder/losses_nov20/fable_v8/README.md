## t116 的防守选择：封哪条路，值不值得调人

## 下一轮怎样验证网络学到了什么

1. **攻防选择。** 在其他地图按行动前条件抽取“敌方重载有多个归库入口、己方轻载有机会先到”的所有根，保留封不住和守错入口的根。候选包括继续经营、守一路和护己方货。先由公开轨迹预测对手的目标基地与下一步，再让对手看见新局面后自行选路。分别记录敌方少交了多少、我方截获后实际交了多少、抽调防守使我方少收多少，以及官方终分差。Fable 的实际后续命令仅用于回放核验。
2. **种树与撤出。** 同一公开局面比较原地种、移到相邻合法格和暂缓投入。给网络输入当前种植成本、附近可吸收碳、双方种树工到达时间、剩余寿命及替代行动收益。训练与检验同时含 t127 型被夺未回本和 t215 型先回本后被夺的局面。按地图留出测试，报告漏掉坏树和误拦好树两类代价。
3. **到账时机。** 从每次大额到账前 3、5、10 步取当时可见的双边位置、在途货、通路与其他单位的职责，比较立即返航、继续采集与截断对手三种决定。冻结候选后，在未用图上换席，使用同一冻结对手续弈到官方终局；收支分解用来解释动作，最终比较仍用全批官方分差和胜负。
