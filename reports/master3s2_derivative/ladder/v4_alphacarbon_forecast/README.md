## 哪些量在当时实际可见

官方定义把两席的现金、基地、全部工人的位置／携货／职业、存活树置于共享的 players。对手工人走进己方观察范围以外时，携货数依旧公开。各席只能看到特定格子的地面碳，裁判的 full_carbon 为隐藏字段。本次顺着实际命令复演两个完整官方环境，在 **600 个 V4 席方状态**逐帧取真实的 agent 请求观察，并核对共享资产与己席碳字段。预测函数只接受公开的 players、席位、拍数及规则配置。安生一局 V4 在席 1，亦按相同官方投影处理。[官方观察定义](../../../../code/env_src/carbon_challenge-master/zerosum_env/envs/carbon/carbon.json) · [官方 agent 请求合成](../../../../code/env_src/carbon_challenge-master/zerosum_env/core.py)
