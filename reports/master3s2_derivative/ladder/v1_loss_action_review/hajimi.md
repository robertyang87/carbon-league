本例的最小复算方法如下，工作目录为仓库根目录，解释器使用仓内已有仿真依赖。输出为实发分差、625 条序列的范围、获胜条数及只改首令的官方计分口径下终局现金差。两席均正常存活。

```python
import copy, gzip, itertools, json, sys
from pathlib import Path

sys.path.insert(0, "reports/sapling_1200k/all_top5")
from economy_extract import FastCarbon

prefix = Path("reports/master3s2_derivative/ladder/replays")
game = json.load(gzip.open(prefix / "3f0a1dfa0e1ac4a00a9f63f9cf644af9-1.json.gz"))
frames, cfg = game["steps"], game["configuration"]
root = FastCarbon(cfg).reset(full_carbon=frames[0][0]["observation"]["full_carbon"])
for t in range(295):
    root.step(*(p["action"] for p in frames[t+1]))

def score(plan):
    sim = copy.deepcopy(root)
    for i, t in enumerate(range(295, 299)):
        pair = [dict(p["action"] or {}) for p in frames[t+1]]
        if i < len(plan):
            if plan[i] == "NONE":
                pair[1].pop("player-1-worker-37", None)
            else:
                pair[1]["player-1-worker-37"] = plan[i]
        sim.step(*pair)
    return round(sim.cash[1] - sim.cash[0], 2)

moves = ("NONE", "UP", "RIGHT", "DOWN", "LEFT")
values = [score(p) for p in itertools.product(moves, repeat=4)]
print(score(()), min(values), max(values), sum(v > 0 for v in values), score(("LEFT",)))
# -272.66 -403.25 -142.08 0 -142.08
```

## 应怎样改原模型、怎样验

1. **先测候选覆盖。** 原包的 `_sample` 对两个采集工同格的放宽限于终局己基地，`_deviations` 会跳过已有己工预定格。对已有完整我令新增一个有界的“末段交接”候选：只改一名无法安全自行交付的载货工，指定仍可到库的较轻队友。门控特征应包含双方载量、队友原路径、几何余时、敌方拦截、交接后我方新增死亡和基地招募。让原搜索在相同预算下与原令比较。将非末段同队同格、同载量双亡、中段牺牲后续产能作为负例；这些局面不宜靠开放全局友军碰撞解决。[原包候选生成](../../cold_start/candidate.py)
2. **用已到账的队伍收益训练动作价值。** 为 t174 的路由保存“货物由谁持有、最终由谁交付、敌方少交多少”；为 t295 的交接记录团队净交付及工人死亡。以同一公开根的原令和替代令为单位，冻结首拍敌令，随后由独立原版对手自然应手至官方终局。树投资另存首任持有净收益和被夺后的敌收，避免把全寿命产量都算给首任。区分生成器漏掉好选项与价值头在已有选项中排错。[同图树权和护货实证](../hajimi_v3pro/README.md) · [现有原版自然续弈样例](../../tree_action_outcomes/README.md)
3. **留图检验副作用。** 在其他已登记的训练地图选候选，以上三张曝光图留作机制回归；另用未参与开发的地图，与父包交替换席按原版 0.58 秒墙钟测真实终局和搜索深度。分列“候选生成、实际采用、现金到账、额外死亡、己敌官方分差”；只保留同一对手响应分布下能解释整局收益的改动。哈基米胜局 t269–279 曾回撤 1,340.33，最终仍胜 1,496.84；十步回撤和某一步预计会丢工都不能单独担任整局标签。[同对手胜局的回撤与最终实收](../hajimi_v3pro/rematch/README.md)
