# 树易主预测能否指导采集工防守

在 592–595 号四张已曝光开发图上，“五步内易主风险至少 20%”的 85 个树时点中，82 个当拍没有轻载采集工能到预判拦截格，另 3 个母包已派工到该格。按实际可改动作重新排序，仅取两张不同旧图上风险最高的机会。真实对手续弈中，一次确实保住了树，两次最终分差都下降。可以保留风险模型作为候选生成信号，现有证据不足以支持“预测易主就派工”。[原抽样登记](protocol.json) · [逐拍规则](every_step_protocol.json) · [两根排序及冻结](relative_risk_tickets.json)

## 选根和分母

每张图读取两个席位各自 V2 母包的完整历史真身场，输入为该席行动前公开观测、前 1/3/5 拍公开历史，以及母包当拍已发联合令。用冻结权重预测自家存量树接下来五拍内至少一次被夺的概率。将最近的敌种植工向目标树行进一格作为拟拦截目的地，已在树上则预计原地，岔路优先延续其上拍方向。寻找载货不超过 20、一步可抵、改令后不与己方其他目的格冲突的采集工，比较只改该工的一步动作。选根期间未取本拍敌令或未来数据。预测“树易主”的概率与猜中敌人“下一步往哪走”的概率是两个不同的量。

| 根的取样 | 发令前局面 | 己树时点 | 敌种植工距树≤4 | 模型风险≥20% | 其中可改令 |
|---|---:|---:|---:|---:|---:|
| 原训练模型的五拍节奏，270/275/280/285/290 | 40 | 199 | 73 | 16 | 0 |
| 270–294 所有拍，包含上行 | 200 | 966 | 355 | 85 | 0 |

第 295 拍起不足五次转移。不同树、不同拍重复出现，同一场观测存在相关性。松开 20% 绝对筛选后，出现 45 个可执行的单工改令组合。事前只按预测风险和可执行性排序，登记不同图最高两根后才读取原版当拍响应和终分。这个补充试验有别于原先已落空的绝对门。[原节奏收据](selected.json) · [逐树覆盖、原因和全部合法候选](every_step_selected.json)

## 复验边界

两核各跑一对，每对两臂串行交错先后。历史公开观察和实令逐拍核对，完整官方状态、树编号及双方实际时钟余额恢复到根。原场未记录私有 RNG 与成本估计，用前缀前三拍预热、注册随机状态，两臂共用快照。分支内历史实令用于根及之前，根后对手独立重算。四段所有请求≤0.611 秒，无一慢步；实际深度和 CPU 分列在收据内。主机为共享环境，计时仅供开发诊断。每个动作只有一次配对响应，不能估计平均胜率或排除其他对手走法。

重建选根用含 NumPy、SciPy 的 Python 执行 `experiment.py grid` 和 `experiment.py every`；重建分支用含仓内裁判及 CPU PyTorch 的环境单线程、单核执行 `experiment.py continue 0` 或 `1`。新实跑应在独立工作副本生成，历史文件校验会拒绝覆盖不同字节。[复验程序](experiment.py)
