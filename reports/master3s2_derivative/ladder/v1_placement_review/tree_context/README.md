# ds-pro-v1 种树前能看见什么

在官方 32 局定位赛中，ds-pro-v1 成功种下 1,104 棵树，917 棵第一次持有期间收回了种植费。152 棵回本前就被夺。以「敌种植工距这块地不超过 2 格，且我方一格内没有空载采集工」标记高风险，156 棵符合，其中 **114 棵仍然回本，34 棵在回本前被夺**。其余 8 棵净收为负但持有到枯死或终局。只用这个条件报警，总共能覆盖 34/152 个早夺案例，六败中仅覆盖 9/45 个。[32 局官方快照](../snapshot.json) · [逐株记录](trees.json.gz)

## 如何复算

在仓库根目录以包含 NumPy 的 Python 执行 `python reports/master3s2_derivative/ladder/v1_placement_review/tree_context/analyze.py`。程序按冻结赛卡逐局核对 32 份回放 SHA，调用已有逐树现金复算程序。t 是命令发出前的步号。以本方采集工携货恰为 0 且距树格不超过 1 标记「空工邻近」，另存任意货量采集工的一格条件、所有采集工距离和货量、所有敌种植工距离。四个正邻格是当时这名种植工实际能看见的资源。标签只含首次连续持有期间已入账的地租、敌工携碳吸收与碰撞到账，减去一次种树费；随后再夺回不并入。每局只有一张地图，重抽以整局为单位（4,000 次，固定种子），分层中有对应树的局进入该层。没有种下的格子缺少可比较的回报。[复算代码](analyze.py) · [首段现金标签](../../tree_payback/labels.py)
