## 最后两拍的 538.79 在途货

第 297→298 步，我方 4、24 号靠较轻载货分别截获 237.29、171.25。两名被截的敌工此前都是距自家基地两格、剩两步，具有赶回的几何可能。两笔截获结束时，我方持货位置距己方基地都还有 7 格，全场仅剩 1 步。它们阻止了对手当时的返航，无法直接送入我方基地。未被截时的真实后续应手与回库还需另证。

## 与 Makabaka 首败的区别

Makabaka 在两次中盘碰撞中从我方取得 1,021.49 货物，随后由获胜采集工实际回库。该场我方回库落后 653.49，终局载货为 0。本局我方回库领先、交战中获取的敌货也更多，树净收入与布防和回库的时间差值得单独检验。可用于训练或成对续弈的局面有两类：夺取老树前将其未来剩余产出与可替代种植比较；对最后数步的抢货同时估算阻止敌方到账的价值及本方实际回库时间。[Makabaka 两次碰撞和实收轨迹](../makabaka_v13/README.md)
