# v2 的早盘种植工是否把在场时间变成了树租

样本沿用 v2 对仓内原版 Master3s2 的 22 张物理开发图、双方换席 44 局。逐拍重放双方签名命令，按新种、夺树及凋谢重建前 100 拍每棵树的持有段，再核对现金和官方期末奖励。终局负的 22 场与胜的 22 场分别计。每个平均数以局为单位，双席均包含。[44 局官方赛果和现金](../v2_original_cash_paths/README.md) · [逐树持有段](cohorts.json.gz) · [脚本](analyze.py)

**败局的种植工行动时间够，但首树晚了 5.41 拍，前 100 拍平均少种 2 棵。** 只计新种后的最初持有段，v2 少了 114.05 树权拍。其中 −52.12 拍来自少种，−61.92 拍来自每棵在窗口内的平均持有时间更短。夺树多带来 16.36 拍，未填平缺口。短持有包括种得较晚、自然凋谢、被夺，以及第 100 拍截断；观察不到完整寿命时不能一律算被抢。前 12 拍内被夺的新树数量为 v2 25/217、原版 26/261。[逐图和两类持有段](tenure.json)

将每局地租差分别乘上两席平均持有拍数和两席平均每树拍租金，精确重组 −368.06 分。负项中 **−276.51 分来自持有拍数较少，−91.55 分来自每树拍收入较低**。这个分解是结果核账。它不把终局输赢认作干预的效果，也不能保证多种树在任一局都会增收。若测试开局改动，应同时记录首棵树的落地时间、后续控制权、实际地租和回库，防止把“多种了几棵”当作净增收益。[分组现金及精确分解](groups.json)
