## 原版视角及训练

24 张旧训练图，各图两席，共 48 场，每局固定 23 步。训练标签是未修改 Master3s2 对手实际提交的搜索后指令。用专家**自己席**行动前的可见碳、原生 `BeliefTracker` 返回的 `known`、自己真实的历史命令和原版根网络的量化输入恢复 96 通道特征。程序在每个来源局首个抽样根把取特征版本与无修改原版的工人和基地 logits 逐字比较。地图与两组留图不交叉，也避开 590、591。旧训练与留出共 56 场的官方终局和沿途现金均由原规则重放校对，另一域直接核验当时保存的双席公开请求和命令。[原图与身份清单](../opponent_policy/protocol.json) · [开发域归档](../dev1/hosted/settlement.json)

训练 10,035 个工人令及 516 个起始现金和名额允许招工的基地令。用两个线性残差拟合动作分布，共 776 个可学习系数；另存两组归一化均值和尺度。各训练地图等权，保留对旧分布的 KL 约束与 L2 正则。权重以 float16 存档，离线评分使用从 float16 恢复的修正。1,104 个训练根都有正深搜索记录，414 个还有确切 K/H；两个测试域 345 根都有确切深度。原比赛中搜索真的改过整队命令，训练可核的 414 根里有 272 根，旧留出有 123/184，另一域有 127/161；其余 690 个训练根没有原场改令标记。先前的 postsearch/exact 用原版标签训练 Sapling，原有 opponent_policy 用另一席的信念预测敌令；本次直接校准原版自身根读出。[真实搜索工作量](search_work.md) · [拟合实测](fit.json) · [权重](weights.npz)

评估中两版共享同一局面随机流，走原版自己席的选招、`go_home`、收尾及冲突处理。表里“整队”比较两版**入搜索前**发出的完整候选队令与原局搜索后真正执行的队令。对照使用独立固定的随机流，原对局的私有采样流未复用。这个比较直接检验训练对自身下令的影响，不能用来估计加入完整搜索后的胜率、分差或耗时。下一步实战资格取决于预定双域门，本轮没有取得。

## 复现

从仓根执行下列命令，需 NumPy、SciPy、CPU PyTorch 和仓内原版裁判。脚本按预登记的 63 场重新恢复特征、拟合、计算实发动作，并核对四份归档的字节。原执行环境使用 NumPy 1.26.4、SciPy 1.17.0、PyTorch 2.5.1 CPU。[训练和复现程序](study.py)

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  python reports/master3s2_derivative/own_search_prior/study.py --out /tmp/reproduce-own-search-prior
```
