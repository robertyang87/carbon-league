## 监督对象与数据隔离

训练只用 590、591 两张已归档开发图，双方换席，236 个行动前局面，1,738 个采集工动作和 390 个种植工动作。训练目标是原版考官下一拍真正发出的动作，输入来自我席真实可见碳及既往信念。以双边这次的实际指令选择一条历史后继，对它运行原模拟器，再预测下一拍对手。既往已发指令只用来确定评估的是哪条分支，下一拍实发动作只用于评分。对手的碳视野、隐藏图和终局分数均不入策略。原坐标、我席和敌席按每局座次还原；模拟新生 ID 按席、格位、工种与下一帧官方单位对齐。236＋472＋354 根全部成功匹配。

每类工人四个系数给直行、原路掉头、移动后停下、停留后继续停留四类动作调整 logits。其余转向维持原 logits，新出现的工人没有上一步位移，所有增量归零。L2 正则固定，同一批冻结训练图只拟合一次。采集工系数依次为 −0.036、−0.020、−0.019、+0.181，种植工为 −0.045、−0.285、+0.262、+0.036。最大可见倾向出现在种植工的反向折返与到地停留。实例上落点还依赖共享现金、招募和同队占位，预测核验走原版 `_sample`。每根三种方法共享相同的 16 个随机流，目标是同一条真实队令。上表“众数”取这 16 抽的单位实落点众数，16 次不计为独立比赛。

留图沿用 592–595 的原版正式资源开发场次。跨对手组按旧版天梯 32 局的时间顺序，对每个注册 ID 取最早的一局，共前六个注册 ID，与本次拟合的原版考官不同。这些均为已曝光历史对局，按盲于比分的顺序固定，系数冻结后才计算成绩。逐根抽样位置均为后继 t3、8、…、293。对比只覆盖由对手已实发命令形成的历史分支。模拟中从未实走的反事实分支没有对手真令供监督。八个系数及此次对照未进入整局训练或天梯包。[冻结源索引与采样时点](../opponent_rollout_calibration/protocol.json) · [472 根记录](held_rows.json.gz) · [354 根记录](ladder_rows.json.gz)
