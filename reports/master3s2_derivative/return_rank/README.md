# 返航选路能否改善 v1

原版 Master3s2 搜索的时间预算为 0.58 秒。我们在同一个 ds-pro-v1 父包上训练了一个小型回款网络，让它在己方重货接近基地时给原搜索提供另一条路线。冻结包在 24 个预登记机会中没有一次可归因地改变实发指令。因此本次没有动用为它保留的新地图。[实发检查](development/README.md)

训练取 48 张历史图，留出另外 16 张地形，均与当时的 ds-pro 天梯图排重。标签在其他单位沿历史动作时枚举一名采集工五种首步，估计六拍内的折扣回库和失货。用官方引擎校验过对角树税、同拍树权变化及碰撞后的采集。16 张留出图共 1,113 个局面，按图等权计算，所选动作相对同根标签最好动作的平均遗憾为 0.0617，最短路 0.0977，原危险预测头 0.0769。新网络出现 269 次先采再成功回库，也有 18 次被截，原危险头有 11 次。历史动作固定的六步标签无法直接衡量独立对手的整局收益。[标签及逐根结果](offline.json) · [训练范围](train_manifest.json) · [冻结权重](weights.json)

复核了历史开发批次里相同 SHA 的父包对原版 Master3s2 的全部 12 局。六张图逐图换席，合计 8 胜 4 负，平均官方分差 +155.66。对这六张图枚举有放回重抽，胜率描述性 95% 区间为 33.3% 至 91.7%，分差区间 −243.62 至 +546.64。四个败局平均归库少 638.61，而树净多 8.48。全 12 局共 2,937 个符合「载货至少 100、离库 1–5 格、步数不晚于 293」的工人步，没有一个在当拍把重货交给了敌人。局中另有三次重货被截发生在此范围外。这些统计提醒我们，要区分失货、采集效率、回款周转与对手进账，单靠防截货覆盖不了这组败局。两类样本与天梯混合对手赛卡分开记录。[12 局逐局账](parent_games.json) · [复算](parent_games.py)

完整包保留原网络、温度、搜索预算和相同候选数量。在受测公开入口，网络的提议主要被过滤或输给了已有候选；无 Torch 时原包与派生包的搜索都会关闭。本地时延属于诊断，未给此候选签天梯容器整局资格。[源码、耗时及依赖](package/README.md)
