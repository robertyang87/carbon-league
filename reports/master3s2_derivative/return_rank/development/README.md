# 回款网络在原版搜索中实际改了几次指令

修正对角树税后的单文件 `1cb68dec` 在四张独立开发图留下的 **24 个回款机会里，0 次可归因地改变实发联合指令**。24 个根全部完成了四次公开入口调用。按预登记，本轮没有符合条件的终局续弈，也没有整局胜负结果。[原始收据](root_results.json.gz)

这些根来自此前母包 `7cf5c6c9` 对原版 Master3s2 的 8 场归档，每图换席，分别从第 80–149、150–219、220–279 步选一个根。筛选用当步己席公开可见的回款距离、载货与附近轻载敌人。根清单在查看新模型输出前已冻结。四张图与训练和离线检验网络用的 64 张图按地形排重。[根清单](root_protocol.json) · [筛选代码](register_roots.py)

真正增加新指令的是地图 `621758593`、席 1、第 273 步。工人 31 携带 164.89，网络估计原地比向上高 0.0795，于是把原地版本加入菜单第 9 项（从 0 计）。四次搜索都比较 10 项、完成 8 层。两次开启网络时均选择原菜单第 6 项。当次搜索中第 6 项叶值 −0.5865，新项 −0.6377。两者都是搜索估计值。[完整菜单和逐次计时](root_results.json.gz)

另有 7 根第一次开启网络时与母包实发不同。这 7 根的重复调用都出现完成深度不同，均未满足同工作量下可复现的改令条件。本机使用原版 0.58 秒搜索、温度 1 和单 CPU 亲和性，在同根多次调用前还原相同的公开历史与随机数流。这里测得的是该搜索载体采纳提议的频率。它不能给出整局胜率或被拒提议的真实收益。[复演代码](root_responses.py)
