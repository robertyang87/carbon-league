## 如何读取标签

官方逐拍重放从原图开局开始。两席各自的可见碳图、公共树和人员、己方历史实发令与上一拍观测用于恢复原策略的信念追踪。历史裁判没有保存自然采样的私有随机状态或耗时估计；本试验登记了新的分席随机流，耗时估计由本机三个真实公开调用校准。同一个根的两臂共享逐位相同的自然采样流起点、时钟参数和原版首令。恢复的首拍意图在每一臂都以实际发出的我方动作覆盖，后续公开入口全部实调。每拍另用模拟器核准人员、钱包、树和完整赛场碳图，完整碳图仅供裁判检查。两臂是原版响应在本机实际墙钟下的一次配对观测；未复原历史后半场原始随机序列。时间是单核进程内含推理的观测值，正式平台资质沿用另档原比赛的独立容器检测。[续弈程序](run.py) · [独立结算](settle.py)

训练记录分开保留首拍是否真的种成、己方是否保住种树工、持有期树收和官方终局分差。树的毛收可能与全局分差反向，原因可以是失去工人、后来换手、未占替代树位或其他单位改变应对。两根各只有一个随机实现，后半场真实应手中伴随自然采样与墙钟波动，绝对分差不应直接解释为这棵树的因果收入。
