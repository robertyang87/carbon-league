两根来自已经暴露的 dev1 败局，由既有的大额回款事后选定。重建时逐拍比对两个物理席的公开请求和实发前缀，由官方引擎还原地形与根状态。替代动作只在冻结的 V2 公开入口当场产生的菜单中选择，选择时仅读取己席公开状态。选定后，原版独立产生一次真实的同步根回复，两臂共用。偏离臂将实际改发的指令写回己方信念跟踪器。此后两边每一步各自读取新盘面，用 7cf5c6c9 对完整原版 65f268b2 执行公开入口。历史私有随机熵与逐拍四项成本未归档，配对使用共同重建的随机流及本机前三次公开调用校准的成本。每根每臂各一条续弈，墙钟和后续策略反应会随轨迹变化。[执行器](run.py) · [独立重放与核算](settle.py)
