## 制品与运行时

- 实包 2,909,204 字节，母包与天梯提交收据 `8b4c4baf…` 相同。逐行差异为两处纯插入；原文件每个字节均可按原顺序找回。构建器、运行时代码和产物的 SHA256 与 manifest 一致，`agent(observation, configuration)` 签名、导入集合均与 v2 一致。没有新增训练权重。政策参数解码后的二进制 SHA256 前缀 `4219028a`，价值参数 `a7a9fd60`；敌手策略头和两个停留/返库校准参数也各自验证相同。[完整哈希](receipt.json) · [构建清单](../manifest.json)
- 单独拷贝制品到空目录，隔离 Python 路径，禁止网络连接并移除 Torch、外置环境 helpers，step 0 的公开入口仍能返回本席招工指令。此时实际 `_SEARCH_OK=False`，策略进入原有 NumPy 单网降级，新增搜索提案不会执行。官方指引明确支持 Python 3.12、NumPy 1.26.4、PyTorch 2.5.1+cpu 及环境 helpers；有 Torch 的实际入口完成了上表五个根的搜索。[平台指引](../../../agent-guide.md)
- 同机单核开关测量属于机制验证。独立 1.5 核、512 MiB 整场资源资格与开发赛应以其执行器实际收据为准。运行 `python verify.py` 可复核字节并重复固定五根；`V3_PROBE_CPU` 可指定对照核。完整记录含入选项、被替换项、逐候选估值/深度、每次调用耗时和实际根回复。[复核脚本](verify.py)
