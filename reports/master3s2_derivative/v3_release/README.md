# ds-pro-v3

[下载天梯单文件 submission.py](submission.py) · [SHA-256 与构建记录](manifest.json) · [仅含本次逻辑的源码](runtime.py)

这个版本在已上线的 ds-pro-v2 上增加一种可选的整队指令。当对手一名重载采集工接近基地，己方一名较轻工人有机会赶在它前面封住返航入口，搜索可额外比较这条路线。除这名工人的动作外，其余工人和基地沿用同一基础指令。网络权重、敌方首令预测、官方计分和原搜索时限均沿用 v2。本版最终单文件为 **2,909,204 字节**，SHA-256 为 `016bc047554dde98844ddf4b7e8be03f52fcbe474017a0c5732d83f97485e31d`。[从线上 v2 逐字重建](build.py)

两版的实战给出了这样修改的具体理由。v2 对 ClaudeFable5.2-v7 的第 152 拍已预测对敌方 27 号向下，旧菜单却只允许我方 28 号原地或向下，漏掉了提前向上的比较。对 v1 的 doubao-flash-v2，第 215 拍等待能截到 277.34；三拍后追另一名更轻的工人却会丢掉自己的货。对 v2 的 stephen 局，模拟 t160 抢到货后继续执行原轨迹，330.89 会送进敌方基地；改走己方基地，实际可交付 315.67。这些分支固定了历史对手指令，说明动作的物理后果。新版本在出令时只能用当前可见局面、上一拍状态及自有对手模型。[v1 分析](../ladder/v1_loss_action_review/README.md) · [v2 分析](../ladder/v2_loss_review/README.md) · [v2 预测与候选逐根对照](../ladder/v2_loss_review/detail/fable_v7/README.md) · [拦截后的实际收款人](../ladder/v2_loss_review/detail/doubao_stephen.md)

新增方案会检查双方载重、保护中的返航工、同拍队友占位、己方招募以及其他轻敌能否抵达。敌方基地格排除，带货正要进入己库的工人保留原令。新增候选至多一个；菜单已满时，只允许在至少三个选项的菜单末位替换一个原选项，保留原首选 A0。沿用原生搜索继续向前推演，完成比较后才由搜索选出实发令。此版本没有添加专门解决抢货后所有后续返航选择的网络，长期树收益预测也继续在开发线检验。[可审计的候选比较](runtime.py) · [护树模型及真实应手](../ladder/v1_loss_action_review/tree_defense/response/README.md)

正式目标为冻结后在 100 张未用地图上换席 200 局，对完整原版 Master3s2 至少 180 胜且同批平均官方分差至少 +500。天梯排名、曝光图复盘以及小批开发赛分别记账。

## 原对局复演与对照赛

在 doubao-flash-v2 第 215 拍的实际盘面，v3 两次都选中新增拦截。放入双方当时的真实指令重放，敌 44 号当拍消失，我方工人带货 445.53；历史路线在四拍后本会让对手交 277.34。第 218 拍的另一名敌工更轻，错误追击没有进入 v3 的搜索。截到的货尚需归库才会变成官方分数。[同根官规复验与固定后续的局限](checks.md)
