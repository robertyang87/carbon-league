# 原生价值网会不会改变公开入口发令

在四张开发图、每图两席的八条 V4 对仓内原版 Master3s2 实战历史上，预先取第 117 和 247 步，共 16 个局面。两包同读该席的公开历史，按 ABBA 或 BAAB 顺序交替。每个局面使用同一已登记的根随机种子与初始搜索成本，并完全沿用温度 1 和原生 0.58 秒墙钟。V4 与新价值网各调用公开入口两次，再分别做两次同工作量诊断。诊断锁定 V4 第一次完成的候选数、深度和采样量，并检查分支深度分布及对手首步采样相同。四图此前已用于 V4 复验，位于本价值网的训练集之外。[预登记与包哈希](protocol.json) · [复算](check.py) · [全部出令和时钟](results.json.gz)

| 指标 | 局面数 |
|---|---:|
| 首次自然搜索的命令不同 | 10 / 16 |
| 两包各自两次自然搜索都发出同一命令 | 12 / 16 |
| 匹配控制准确复原 V4 的原搜索结果 | 16 / 16 |
| 同工作量、同敌首令 | 16 / 16 |
| 自然改令在各自重复和匹配控制中都复现 | **7 / 16** |

每包对这四张开发图实测 32 次公开调用。V4 的墙钟中位数 0.492 秒，最大 0.567 秒。价值网候选中位数 0.493 秒，最大 0.563 秒。该时钟来自本机单核诊断，计时范围仅为公开观察的求解。整局资源使用须以执行器完整收据为准。

## 原版自主续弈

按地图号取前两张在第 247 步稳定改令的图，席位从小到大破同分。两臂只改变当拍我方联合命令，对手的首拍命令相同。从下一拍开始，两臂都使用 V4 对完整原版，按各自棋盘继续自然发令。四个后缀打到官方终局。历史私有随机数不可重建，比较使用登记的新种子。[冻结办法](response/protocol.json) · [对局与账目](response/results.json) · [复演程序](response/run.py)
