**第 621461120 图有一个容易误认的正例。** A、B 两条根命令经过八步模拟后，54 个量化平面和 5 个标量逐字相同。实际两臂终局差 279.95 分。旧 Wino 批前向给 A 多约 1.19×10⁻⁷，新 Wino 给 B 多约 1.19×10⁻⁷。逐浮点值比较会把它算成第三次向好换令；这个差异完全可以来自批次位置的数值舍入。在相同输入保原的结果中，这一根计零。另两根相同输入的真实后缀分差同样可以不同。[完整预测](score.json)
