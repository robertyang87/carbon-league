## 能否区分两条真实续弈

25 个已曝光双臂根共占 21 张地图，全部从本轮训练与单轨留出中剔除。11 个根保有两条备选各自在同深 H8 的原生 54 个平面和 5 个标量、真实分支与官方终分。7 张的历史角色名为 train、4 张为 held，对本次价值学习全部是额外留图。其余根缺少同口径 H8 叶。所有 11 对均为两臂同胜，能检验选臂后的分差。[独立核验协议](pairs/protocol.json) · [逐对真实分与父子估值](pairs/score.json)

8 对有物理输入差异。按两臂网络估值选取实际较高分差的次数从 2/8 变为 4/8。两处变化分别出现在地图 621591808 席 0 t279（1,170.58→1,360.75）和 621758326 席 1 t279（1,376.56→1,505.85）。其余三对的两臂输入完全一致。将三对都按平局取第一臂计算，11 个根的平均已实现分差变化为 +29.04。直接比较浮点数时出现的另一次选臂变化来自同输入行间 1.19×10⁻⁷ 的舍入差。预测两臂分差差值的平均绝对误差由 159.55 分升至 166.45 分。每臂只有一次真实续弈，比较只涵盖已存的两个命令。新模型在完整搜索中可能改变此前淘汰的候选。[原生值复演](pairs/parent.json) · [全部真叶比较](pairs/score.json)

## 信息、训练和部署

48 场、29 张训练图贡献 1,520 个局面。训练及留出共含 35 场我方各版对原版的公开双席独立执行器记录，另外 28 场取已核实的 V1/V2 天梯行动席。天梯旧图的划分已经公开。每局每席取 t6 起每 15 步的一帧，至 t291。该局官方双席得分按我方视角转为原公式 V = clip(m/3000, −2.5, 2.5) + 0.5 × sign(m)。每张地图总权重相同，地图内再按局、席和可用步等权。收益为实际双方续弈的一次实现。[预登记脚本](register.py) · [数据抽取](data.py)

信念跟踪器仅接收本席可见碳、公开双方单位，以及本席截至上一拍实际发出的命令。当前 54 平面使用该席估计碳，模拟搜索 view 的 known 掩码全部置一，另附原版五个标量。训练板取历史真实局面，属于模拟叶的近似输入。H8 对照使用搜索当时真正生成的叶，能直接检验这个分布差异。天梯每个时刻的动作从下一帧读取。起始全碳仅用于核验地形摘要。模型只消费当前局面和已发生的己方行动，不消费对手同拍实令。[编码程序](data.py) · [真实 H8 双臂](pairs/measure.py)

冻结原 96×225 特征张量。价值网保留空间 1×1 投影、ReLU、全局均值与最大池化、两层全连接和现金跳接。按全批 Huber 终局误差（δ=0.75）与旧输出平方差（系数 0.5）做固定 40 次 Adam 更新，学习率 0.0003。训练目标值从 0.16408 降至 0.13985。[训练实现](fit.py) · [权重冻结收据](fit.json)

单文件从线上 V4 `cd230d40` 的源码逐字节重建，仅替换 `_VALUE` 一个 Base64 工件。候选 SHA-256 为 `04169552bb2aa670e98c9458dfa45b35756dff68a206935a142aa811cd4b71a9`，2,909,349 字节。六张量 FP16 压缩包 SHA-256 为 `4e1c6517aa32083e7cfeb4948d4f9fb2cb33ebecd3e747cf14f8f7b565bf5076`。8 个公开留图局面上，父子网络在 Torch 和 Winograd 后端各自的工人与基地 logits 逐位相等。新值在两后端最大差 1.26×10⁻⁶。原程序的搜索 look 在每个实际求值深度都使用这些参数。新包的整局强度与天梯时限均待实测。[封装与模型](model.py) · [单文件](candidate.py) · [FP16 权重](weights.npz)

复验使用 Python 3.12、CPU PyTorch 2.5.1 和 NumPy 1.26.4。在该目录、固定单核运行下列命令。按物理图进行 10,000 次自举。主判据为两项预登记的 MAE 点值。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
python register.py
python fit.py fit
python fit.py test
python pairs/measure.py weights.npz
```
