# 用实际终局给原版搜索的前两项动作排序

每张旧地图取一个事前登记的第 279 或 285 步局面。冻结的 V2 在 0.58 秒内完成 H=8、同一个对手情景的比较后，按自身分数取两项不同的联合指令。候选随后与原版 Master3s2 用各自公开入口逐步续弈至官方结算。每根只改首次发令，后续己方使用同一个 V2。每个动作各有一条轨迹，因此终局差包含原版随机采样和实际时钟波动。[12 个根的事前登记](protocol.json) · [采集器](collect.py) · [逐拍复核](verify.py)

## 文件与复核方式

每个根的文件名由地图、己席和根步组成。对应 `*_root.json.gz` 保存自身可见历史恢复出来的当前公开观察、两侧现金载货及树数、此前每笔经济分类的累计、本轮候选及原始分值。`*_leaf.npz` 的 X 按动作、共享展开编号、54 平面、15×15 棋盘排列，使用 uint8 储存，乘以 float32 的 0.01 可逐位重建原版实际输入。另存五个原版标量、叶步、候选编号、原值和精确终局标记。模拟后继只使用根己席估得的碳图。

`*_first.json.gz` 和 `*_second.json.gz` 分别包含两臂原始续弈。根前独立重放整条旧盘面轨迹，核对地形、双方公开输入和官方逐拍现金。根处只有一份原版对手命令，两个后继在官方状态、两方历史信念和根后私有随机流上以同一快照起步。自己的信念记录各臂真正执行的根令，之后两方逐拍响应新局面。旧档未记录原场私有熵与每拍耗时，收据记录本机共同重建的随机状态和实测成本。每臂的未截断官方分差及经原版 _terminal 映射所得的目标保存在 `*_pair.json`，后者可能在大分差时饱和。

训练数据共 244 次联合推进，488 条逐席记录，扣除重复记账的共享根后为 474 次不同的公开调用。另有 1 次不合格根调用与 48 次前缀预热；训练采集总墙钟 263.40 秒、进程 CPU 259.27 秒。此处计时来自共享宿主、单逻辑核的真实公开调用；天梯盒子的通信、配额与超时资格需独立执行。训练和验证用旧对局均排除出正式考卷。

留图使用与八张训练图不同的四张地形。新的二参数价值修正先在训练材料上冻结。每个留图的原版输入先发布，再由训练端写入绑定根、叶和权重的独立预测收据。采集器读回配对身份后才向原版索取首次应手并开始这张图的两个真实后缀。[训练权重冻结件](held_training_freeze.json) · [盲预测与学习判据](../terminal_value_pairs/)
