# Master3s2 搜索里，到底哪些行动受随机采样影响？

完整原版在每局用新私熵采根策略，另按步号、席位为内部搜索生成可复现的随机数。对 438 组归档的同根同深分支，**100 组（22.83%）出现至少一方幸存单位分配到不同的随机数槽**。重新让同 ID 的对手在两个兄弟分支共用同一抽样分位，在第 2 分支原状态和网络输出保持固定时，**16/438 组（3.65%）的对手物理整队命令改变**。这既量出了可修的错位，也限制了该改动能影响多少动作。[438 组原始分支与受影响实体](branch_receipts.json.gz) · [复验代码](audit.py)

## 根策略与推演采用不同随机源

原版变量是 `_SEED`，默认 None，每次开局新建随机数发生器。搜索自身则用 `seed0 = (1000003 × (step+1) + 17 × seat) mod 2³¹`，同拍同席跨图重复该种子。行动候选中还用 2.5、1、3.5、5 倍工作温度提案，并有离散单工人替换。根上对手用 `seed0+7+31m` 生成共同应手，分支内续弈随深度用 `seed0+7919d+31m+1/2` 分别给双方抽样。原版每候选的情景数 m 只有一档。工人抽样前先给每个基地抽一次，随后依存活工人字典顺序逐个消耗 U。来自同一随机流的第 k 个 U，可能在两分支中被分配给不同工人；分支内每个具体工人仍然各自按其正确边际概率采样。[原版单文件](../../../sources/master3s2/master3s2.py) · [既有同工作量检验](../search_efficiency/README.md)

同根收益估计中，共用随机数能在它让候选收益正相关时降低差值的方差。未修前某一对单位槽位错开，既不能保证该候选的价值有偏，也不能推出共用后一定更好。独立后续真实对局仍需要完整计时、计分和对手自然响应。

## 开局和晚段的自己策略

在 7 场真实原版考官 H2H 的公开席位，从己席可见历史与实际己令恢复考官信念。双方初始化都超时的第 8 张赛卡无可用根，单列。每局固定 t0、20、72、215、267、285、296、298，每根对 32 组新私熵比较 T=1 与 T=0 的原生策略提案。两个版本均经过回家、联合占格、现金和招工限制。保留原版实际比赛发令作独立对照。下表统计的是进入搜索前的提案。归档未记录原局的私熵，绝不能把这些新抽样当成当日的根提案。[56 个原版根与逐段统计](own_roots.json.gz) · [七场实令与一场初始化故障的归档入口](../freight_forecast/dev_tapes.py) · [复算](own_roots.py)

## 同一候选树内抽样错位有多频繁

使用仓内既有 28 张历史地图的两席原版搜索内部记录，每席 t72/t215，深度 1/2/4/6 只取归档所含的前两个不同模拟局面。数据由实际原版公开入口在既有 H2H 历史状态上重新搜索得到，与原比赛的私熵、当场 CPU 时序分别记账。886 条归档敌方网络输出、实令和抽样种子经原版 `_sample` 全数读回相同。共 438 组能在同根同深组成一对。工人以外的基地也计入抽样槽分母；基地数量在这些分支中不变。[原始归档与采集规则](../rollout_readout/README.md)

- 己侧 87/438 组有幸存单位槽号移位（349 / 4,983 个共有实体实例），敌侧为 82/438（353 / 5,058）。两侧合并后 100/438 组。
- 只在第二分支重排敌方 U：共有 ID 沿用第一分支的槽，新 ID 接在第一分支末尾。原版网络输出、状态、概率和冲突解码全保持该分支值。13 个共有实体的抽样动作变化；重解码后 16 组整令变化，含 12 个共有实体和 7 个新增实体的物理命令，其中 9 组改到至少一个共有实体。锚定第一分支是用于测灵敏度的审计方法，正式部署可从真实根的 ID 建立共同槽。
- 图 620098101 席 0 的 t72/H6，敌 11、15、17 三名共有单位真实解码令全部受影响。图 621460121 席 1 的 t72/H2，己方 20–24 号的槽位变化，敌方 20 号的物理行动改变。这些公开过的诊断图应留作回归用例。
- 若直接将归档敌方模拟动作改成 T0，整队令有 287/886 不同，具体工人却只有 375/8,666 不同。既有小推演头实验在四张检验图仅复现 1/128 个整队令；两个结果都说明，逐工人准确度不会自动转成整队应手的准确度。[已有推演头检验](../rollout_readout/README.md)

低成本的下一项对照是只固定同根同席同深各存活实体所用的随机分位，保留原网络、温度、候选菜单、对手模型和每步预算。先在同工作量的公开根验证零消亡分支逐字等价、有消亡分支实际改到物理行动，再按原版自然应手在独立图上交换两席评估。上述行动比例本身没有测出终局收益。
