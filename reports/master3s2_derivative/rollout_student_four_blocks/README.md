# 用原版前四块训练模拟对手的轻量策略

本轮用原版 Master3s2 的前四个残差块和新的轻量读出，蒸馏同一个原版六块教师。冻结原权重，保留每个决策位置的 96 通道中心、四邻格差分及整图均值，共 576 个输入，训练 48 单元残差头。只考虑替换模拟后继的敌方策略，实际根控制与价值仍应使用原版完整网络。[拟合脚本](study.py) · [原三块学生及数据](../rollout_policy_learning/student/README.md)

复用既有 1,506 张模拟盘。24 张物理训练图中按哈希预留 4 张调参、其余 20 张训练。按校准图等权的工人和基地 KL 固定第 32 轮权重，冻结后才运行原先的另外四张留图。候选队令沿用原解码器、现金和位置占用约束，并与原教师共享随机种子。两份留图结果使用逐条哈希相同的 248 张后继盘面。[冻结协议](protocol.json) · [校准结果](fit.json) · [权重](weights.npz)

四块学生的概率更接近教师，整队命中率仍只有 8.5%，离冻结的 80% 最低线很远。带货工人的动作命中没有净增。四块和三块实验的校准与架构均有变化，不能把改进单独归因于多保留一块。现有结果不足以让该头进入完整搜索包。无新比赛、计时认证或天梯提交。[留图分组及分母](held.json) · [逐队动作对照](held_orders.json.gz)
