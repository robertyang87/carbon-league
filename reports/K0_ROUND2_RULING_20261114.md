# K0 第二轮设计裁定（策略组，2026-11-14）

> 裁定对象：`reports/K0_ROUND2_DESIGN_DRAFT_20261114.md`（commit 4438b4ab，起草基线 main 3af0ddc5）。
> 裁定结论：**有条件通过**——草稿采纳为第二轮设计之准，下列修正与条件并入后生效。本裁定不含开跑授权（见 §4）。

## 1. 对草稿 §13 五项请裁事项的逐项答复

1. **§4.2 根续弈配对作主测量：接受。** 与教师 pilot 同构（留出根、同对手同种子续弈、按根配对按局聚类），把引导臂换成学生裸网，不需要教师调用；它测的正是本轮窗口限定的问题（step 200–299 内的裸网强度差）。整局考试降为不劣检验，正确。
2. **δ_plan 规则与「超预算不启动」：接受。** δ_plan = max（窗口闸 CI 下界， 0.01)，按现行数字 = 0.01；N 超留出池或墙时预算则不启动、先加强教师，不降功效硬上。此条与闸 0 合起来，就是本轮版的「仪器答不了问题就不开跑」。
3. **C 臂定义（Q 置平、保留候选集与先验 0.5 次幂）：接受。** S 与 C 的唯一差异收敛到 Q 的信息含量一项，候选集构成与先验塑形两个副作用被正确地留在共模里。判读措辞须与之一致：本轮隔离的是 **Q（价值引导）分量**，不是「搜索 vs 无搜索」。
4. **整局不劣阈值 −0.04：接受，附修正 D**（检验对象改最差种子，见 §3）。
5. **§10 三件代码的动工许可与归属：许可，附条件 I**（见 §3）。

## 2. 验算记录（裁定的事实基础）

- §4.1 反推自洽：waux1 双场 SE 0.0234/0.0292 → σ_pair 0.331/0.413（×√200)，合并 SE 0.0187 与两场独立平均的合成式逐位合；MDE = 2.8·SE 与 N = (2.8σ/δ)² 两表逐项复算一致（δ=0.02 → 约 2,150–3,350 对；400 对合并 MDE 0.052）。**结论成立：整局尺对 0.05 以下效应是盲的，教师点估计 0.026 落在盲区。** σ 的出处人群也对：waux1 双场与本轮不劣检验同构造（Master2/Echo2 双考官、同种子配对基线），就该用它；策略组 v0.1 曾用 A4 配对场的 0.22–0.28 作考试侧 σ，那是另一人群（打包件对打），**就本轮用途以草稿的 waux1 口径为准，v0.1 的功效表作废**。
- §4.2 算式自洽：(2.8·0.158/0.02)² ≈ 490 局、δ=0.01 ≈ 1,960 局，与草稿量级参考合。0.158 仅作量级参考、正式 N 由预跑实测锁定，纪律正确。
- §8 的 1/20：无差别时 3 个 S 全部高于 3 个 C 的概率 = 1/C(6,3) = 1/20，与 5% 水平相当，草稿表述无误。
- §7 标注估算：4 万根 × 7.58 s ≈ 84 h 单工人、12 工人约 7 h，算术合（单价为 v1 口径，属估计，v3 单价待填后重算；§11 的 50% 超支止损覆盖此风险）。

## 3. 修正与条件（并入草稿生效）

- **A. N 锁须用双臂差值的 σ̂**：预跑至少跑 2 个 C 种子，σ̂_diff 取其逐局配对差值的 sd（这正是主判据 Δ_S − Δ_C 在零附近的方差口径）；测不到时退用 √2·σ̂（单臂 C 对 P)。N_games 按 σ̂_diff 锁，并连同留出池产量可行性一并回报（按现 σ̂ 量级，δ_plan=0.01 需约 2,000 局新留出局，生产量须进 N 锁时的预算核对）。
- **B. 标定用根是花掉的根**：σ 预跑与 §6.4 配方标定共用一个登记在册的根集（约 50 局），与 §4.2 正式测量根集逐 id 不交；标定看过的局面不得回流正式测量。
- **C. §6.4 的「与 0 不可区分」须在运行清单里操作化**：扫描网格、每档根数、中性判据（如 |ΔU_C| 点估计 ≤ δ_plan/2 且 CI 并报）须在看 S 之前冻结写入清单。标定只用 C 的纪律不变。
- **D. 不劣检验对象改最差种子**：§8 次判据的检验对象 = §4.2 口径下最差的 S 种子（对「损伤」方向最保守），不用最优种子——用整局考试自身挑最优再验不劣是顺风口径。400 对合并口径（双考官）与 −0.04 阈值不变（该阈值只在合并 SE 0.0187 下成立，分场读数不得单独套用）。
- **E. shard1 跨线登记**：标注进料 gen1r shard1 的 200 局 id 须在正式切分（Stage B）落刀之前登记为「K0 标注已消费」，切分时该批 id 只能落 train 侧或剔除，不得进切分的 test 分区。此条由策略组在切分确认时执行核对。
- **F. 待填一项即时关闭**：B0 的 KL 已于 2026-11-14 13:34 补测落地——mean **0.9361**、p99 **2.9533**(n=19,136，held-out gen-25d05b8b；已入 `reports/K0_STAGE_A_20261114.md` §3)。草稿 §6 第 5 条与 §12 的对应待填按此数填入。
- **G. 合并 estimand 写明**：Δ_S、Δ_C 的「合并」= 先逐局算各种子的配对差、再对种子取均值，CI 按局聚类于「种子均值后的逐局值」；此定义写入运行清单，不得临场改合并方式。
- **H. 五条件的落点在本轮的对应关系**（防日后误读为遗漏）：条件 1（可复现/噪声带）走「多份对照标定噪声带」一支（草稿 §5，不做逐字可复现）；条件 2（screen 基率预注册）本轮无 screen 判据（KL 只监测、无事件筛查闸），敞口不存在，待辅助头重启时按 v0.1 已钉的合并口径执行；条件 3（锚点 = 对初始网络的 KL）即草稿 §6.2 的对父代 KL；条件 4(U 头热身）本轮以更强形式满足——价值/辅助头全部冻结、根本不训练，无随机初始化头梯度进骨干；条件 5（保护线可达性）随 KL 降为监测项改形为 §6.4 的对照臂标定（配方先在 C 上证明中性，才准用于 S)。
- **I. §10 动工范围与护栏**：三件均可动工，归属按本队先例——工程线实现、策略组验收（标注器的 §13-C schema 一致性由策略组核）。测量驱动（件 3）**不得改动 v3 pilot 在飞期间被钉住的闸门文件**：另建模块复用其续弈原语，或等回执落地解钉后再动。第 1 件标注器的窗口参数以 §3 闸 0 的窗口登记为准（当前仅 step 200–299)。
