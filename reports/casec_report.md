## 2. 归因（全部有测量支撑，`casec_g0_diag.py` / `casec_g0_diag2.py`）

先排除两个假嫌疑：
- **ghost 不是另一局**：ghost 动作与留痕动作一致率 100% / 100% /
  83.2%（seed2000 的 17% 是双教师共享随机流与 ghost 独立流在近并列
  加权抽选处的分岔，状态由留痕帧驱动、信念始终同步）。
- **(ii) 在执行步是对的**：真实种树/抢树执行步上 (ii) 给出相同
  （意图, 目标）的比例 93–100%。两路在「事情发生的那一步」描述的是
  同一个教师。

真正的原因是两路口径的结构性错位（设计预见的两个归因各占其一）：

**(a) ghost 读数口径缺陷（采集员 DP 步行）**：(ii) 把「12 步 DP 路径
擦过自家基地且带碳」一律读成 RETURN_BASE。实测：RETURN 标注段最长
49 步；437 个 RETURN 步中 301 步距下一次真实存碳 >15 步、18 步之后
再无存碳；其中 122 步工人正可观测地在采碳（(i) 标 DWELL_COLLECT）——
(ii) 把「带碳在家门口采碳、顺路可能存碳」的长段误读为返航任务。
这是真缺陷：语料生成前应按教师自己的索赔语义改读（步行索赔到的
停留格定义任务，基地只是途经点时不算返航）。但它只解释 RETURN
一项（6732 步中的一部分）。

**(b) 密度/删失的结构性不可通约（主因）**：(ii) 是稠密的「当前任务
持有流」——教师大量任务持有后被改派、从未执行：PLANT 标注步中
**60%（158/263，诊断局）所指的格子从未被该工人种下**；(i) 按设计
是「事件锚点＋承诺回填＋中途失效删失」的稀疏流，未执行计划在留痕
里原则上不可见（等待中的种植员朝向 A 还是邻格 B，行为不可区分）。
按各意图可达上限粗算（PLANT ~47%、STEAL ~45%、HUNT 影从步 ~50%、
GUARD ~30%、DWELL ~60%、改口径后 RETURN ~85%，以 (ii) 定论步为分母
加权），**双路一致率的数学上限约 56%**，与 85% 阈值之间不是任何
一轮规则修补能跨过的距离——除非事后改指标定义（违反预注册纪律）
或逼 (i) 虚构未执行计划（毁掉独立校验的意义）。故未烧掉设计允许的
「一轮修复」去做一个上限已被证明不够的尝试；(a) 的口径修复建议
保留，待裁决后与新口径一并处理。

各意图一致率（(ii) 定论步为分母）：DWELL_COLLECT 31.2%、
RETURN_BASE 14.9%、PLANT 29.1%、STEAL 17.1%、GUARD 7.8%、
HUNT 0.7%（影从角色 2963 步 vs 全程仅 ~2.2 次真实猎杀/局）、
DWELL_HOLD 0%（n=10）。
