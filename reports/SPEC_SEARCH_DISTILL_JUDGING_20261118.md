# 规格判读半边：搜索蒸馏——保真／孪生／漂移三件裁定（策略组，2026-11-18）

- 配套：预注册框架 reports/PREREG_SEARCH_DISTILL_FRAMEWORK_20261118.md（954ba51c）。本件钉三件数值与协议，与工程半边合卷为完整规格；只及环 3 起，环 2 照现行。

## §1 保真指标与阈值（闸一）

- 比对对象：标定集留出根上 π̂（快标注）vs π_search（全搜索）逐根比对。**按步带分层判**：[0,100)、[100,200)、[200,300) 三带各自过闸，任一带不过即不过（防总体达标掩盖尾窗崩坏，q 闸前科在册）。
- 指标与闸值（每带与全集同查）：
  - 策略顶翻转率 flips ≤ 2%；
  - |Δq|：中位 ≤ 0.01、p95 ≤ 0.05；
  - Δdu：带内 |mean| ≤ 0.005（系统性偏差闸，从严）、p95 |Δdu| ≤ 0.05；
  - KL(π_search‖π̂)：均值 ≤ 0.05、p95 ≤ 0.2（系统性偏移哨兵，硬闸）；
  - Q 的 MAE 只报不闸（尺度随局变，作闸不稳）。
- 量级依据：随机误差类参照 Stage-4D Tier 2 实质项；系统性偏差类从严（训练平均不掉系统性偏差）。Phase 0 试点（现成全搜索分片、零新标注）先验此组闸可达性；不可达项的修订只许在试点判读时以「闸值修订＋理由」入仓、先于环 3 应用，不许环 3 产出后调。

## §2 孪生学生 ΔU 协议（闸二，放行主判据）

- 形态：同 50 局双路标注（全搜索标签 vs 快标注标签含回退机制整体），同配方同种子训孪生学生，配方与环内正式训练同构（试点可缩量、缩量比规格写明）。
- 判读量：两学生**镜像双场直对**配对 ΔU（与环验收同口径），不用定标对手作主判据（定标是绝对量级口径，其噪声带不迁移；双考官小场旁证只报不闸）。
- 方差锚：直对配对差 SD 取环 1 验收实测 0.6263（同口径最近实测）；孪生验收块 **800 局**。非劣判读线：**点估计 ≥ −0.01 且 95% CI 下界 > −0.04**（容忍劣化上限小于环增益 +0.094 的一半，快标注墙时收益不以吃掉环增益为代价）。试点后若孪生差实测 SD 显著更小，可在环 3 前入仓缩块，判读线数值不动。
- 生产期频率：闸二不必每环跑（成本约一臂训练＋800 局考试，会吃掉收益大头）——**每 3 环复验一次＋快网版本／配方变更必验**；环内把关靠闸一（标定留出）＋闸三（监控）。

## §3 漂移与回退判据（闸三）

- 监控：每环快标注根随机抽 2% 以全搜索重标，逐根比对 §1 指标集。漂移超阈定义：flips 率或 Δdu 带内 |mean| 破 §1 闸值的 **1.5 倍**（小样本放宽系数，预注册），或 KL 均值破 **2 倍**。
- 处置分级：首次破线（未及硬线）→ 监控升至 10% 复检，该环标签作处置标记暂存不入训练；复检仍破线、或首检即破 2 倍硬线 → **该环快标注标签整环作废、回全搜索重标**。不设「单次小样本波动即整环作废」，亦不设「只升监控永不回退」。
- 高熵回退：阈值以标定集 π_search 熵分布分位数预注册（规格中写明分位数点与预期回退比例），不许看产出后调；**回退比例上限 15%**，超限即快网覆盖不足、该环快标注作废回全搜索。

## §4 边界（重申框架件）

- 快标注只产训练标签，不进考试／校准／验收测量链。任一闸不过该环回全搜索；连续两环（或两次复验）闸二不过，快标注线停、回策略组议。
