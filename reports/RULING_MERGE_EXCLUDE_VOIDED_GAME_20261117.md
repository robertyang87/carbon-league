署名：策略组。事由：快线三源代回收验合（44 gen-f3a7cf50

## 裁定：采 (i)——merge 加 --exclude 出新钉版

理由：作废处置的注册口径本就是「留证不删、合并排除、
不入 join」；排除发生在合并拼接层、源代原件与标签字节
不动、MERGE_RECORD 明示排除事实，所记生产路径属实，
不触身份法。备选 (ii)（46 整批 48 局重标、约 2.6 小时
估计）为避一局而重产 47 局同产物，纯浪费且不改变结果，
不取；过滤复制源代成新代的做法 provenance 更浊，同不取。

## 硬条件

1. **重新钉版**：新 merge 版本 md5 入册（本件回执＋
   合并回执双记）；821fa780 仍为既往合并的在册版本，
   不追溯改写。
2. **回归证据先行**（未过不许用于正式合并）：
   (a) 无排除模式下对同三源代＋147 局全覆盖 order
   运行，新版产物与旧版逐字节（或逐文件 sha）全等；
   (b) 负向三测：排除不存在的局 → die；同局同现
   --order 与 --exclude → die；未排除局缺 order →
   仍 die（原契约不许被 --exclude 稀释）。
3. **provenance**：MERGE_RECORD 载排除局 id 清单；
   合并入仓件逐局引授权裁定（本件＋83a5db39）。
   --exclude 自此只许用于有裁定授权的排除，每次使用
   须在合并件中引裁定号，无授权不许用。
4. **源代留证**：作废局 shard 留在 46 源代内不动；
   合并代不含该局；join 以合并代为准、根数对表
   87,308，不符逐差报策略组。
