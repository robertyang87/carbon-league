# 稀疏标签数据流设计（策略稀疏＋价值全量）

工程组，2026-11-18。依据：Codex 复核 `reports/DECISION_REVIEW_FOR_LOOP3_20261118.md`（3f28c966）§0 第 2 条与 §5 权重纪律；直读 `code/k0_distill_u.py`（06826f59）与 `code/k0_join_u.py`（9054aadc）现行版。**只设计，不动代码。**

一句话形态：同一 joined 数据集内，**策略监督（CE＋锚 KL）只落在被抽中标注的根上（下称 q 根），价值监督（终局 U/wdl/margin）落在全部根上（价值全量）**；未抽中根（下称 v 根）不携带任何伪造的策略标签，其终局标签来自对局结果本身、与教师搜索无关，因此零新增教师计算即可取得。

### 1.2 loss 形态（k0_distill_u.py `forward_terms`，L1177–1215）

现行每根 loss 是一个融合标量（L1210–1214）：

```
loss_root = ce_root + kl_beta·kl_root + lambda_u·mse_u + lambda_w·ce_w + lambda_m·mse_m
loss      = (w_t · loss_root).sum() / w_t.sum()        # w_t = 1/pi（IPW）
```

- `ce_root`（L1190）：对构造目标的全联合动作 CE；`kl_root`（L1191）：锚 KL(pi_student‖pi_parent)，按候选数平均。两者都经 `joint_logp_kl` 在**候选展开批次**上算（`expanded_batch` L1166：每根按 K 个候选各复制一行、逐候选以自身前缀 teacher-forcing 解码）。
- 价值三项（L1198–1208）：utility/wdl/margin 三头读**候选槽 0 的 ctx**（注释 L1196–1197 明示 encode 不看候选轴、ctx 逐候选不变），分别 MSE(utility, terminal_u)、CE(wdl, terminal_wdl)、MSE(margin, terminal_margin/1000)，λ 默认 1.0/0.5/0.5（L1006–1011）。
- 结构性事实：**策略项与价值项共用一个 IPW 权重与一个归一化分母**。稀疏化必须拆开——否则 v 根要么被迫带权重进策略分母（稀释/污染），要么价值项被 q 抽样概率加权（价值明明是全量总体，不该有抽样权重）。

### 1.3 价值监督现状

- 终局标签来源与教师搜索**完全无关**：join_u 从 producer 边车 `terminal_u.json` 按 (game, seat) 并入（L622–632），并与 build 原始标签逐座交叉验（1e-9 级，L484–544 段）；每局两座各一份 (u, margin)，该局**每一根共享**本座的终局标签。
- joined 根集＝标注根集：`R = A["step"].shape[0]`（L545），每根必须在 build 代里找到特征行（L551–565，找不到 die）；**build 里未被标注的根不进产品**。而 build 代本就含入选局的全部根特征（双座×全步）——价值全量的原料已经在盘上，缺的只是 joined 产品的根集定义与合同。
- 训练批次：全根随机置换、按 bs 切（L1268–1276）；断路器对 ce/kl/三价值项的 batch max 逐项验（L1284–1295）；每步日志记 denominators={roots, candidates}（L1313–1317）。

## ② 目标数据流设计

### 2.1 mask 语义与计数口径

新增逐根 `has_q ∈ {0,1}`（落位见 §③）。语义钉死：

- **has_q=1（q 根）**：与现行 /2 完全同义——策略项（CE＋锚 KL）与价值项都算，全部现行记录闸逐字适用。
- **has_q=0（v 根）**：**不产生任何策略梯度**。CE 与锚 KL 对该根不定义（不是记 0 后参与平均——该根根本不进策略项的分子与分母）；其候选展开不发生（见 2.2）。价值三项照常算。
- 拆分归一化（取代 L1210–1214 的融合式）：

```
loss_policy = Σ_{r∈batch∩Q} w_r · (ce_r + kl_beta·kl_r) / Σ_{r∈batch∩Q} w_r
loss_value  = Σ_{r∈batch} (lambda_u·mse_u + lambda_w·ce_w + lambda_m·mse_m)_r / |batch|
loss        = loss_policy + loss_value
```

w_r 的口径见 2.4（二选一、注册在案）。价值项分母是 batch 全根数（价值全量总体，无抽样、无权重）——与策略项分母（q 根权重和）**分开记账**，日志 denominators 扩为 {roots_total, roots_q, candidates_q, ess_q}。
- 断路器：ce/kl 的 max 只在 q 根上取，价值三项在全根上取（现 L1284–1295 的逐项结构不变、取值域按 mask 分）。
- 锚 KL 随策略 mask 走，不单独对 v 根施加：KL 的定义域是候选集（`joint_logp_kl` 逐候选），v 根没有候选集即无定义；且锚在本配方里是策略项的组成（SS6 同一 IPW 加权平均），不拆成独立的全根正则。

### 2.2 价值分路（含 trainer 侧形态）

- v 根走**单行路径**：特征行只进 encode 一次，三头读该行 ctx（与现行「槽 0 读取」数值等价——encode 不看候选轴，L1196–1197 已有明注）；不做 K 倍候选展开、不跑 decode 与 parent decode。q 根维持现行展开路径、价值读槽 0 不变。两路在 batch 内拼接后统一算价值三项。
- 副收益：v 根省掉展开与双网 decode，trainer 侧每 v 根计算量显著低于 q 根（量级估计，未校准）——但本设计的主节约在标注侧教师搜索，不把 trainer 节约写成主张。

### 2.3 冻结头纪律：正面处理

- 本设计**只落在 U 线**（/2 格式＋k0_distill_u）。该处 `FROZEN_PREFIXES = ("aux.",)`（L175）：**utility/wdl/margin 三头本就可训、且现行已在吃终局监督**（L1198–1208）。把同一组三项 loss 从标注根扩到全根，落在完全相同的可训路径上——**与 U 线冻结纪律不冲突**：aux.（真碳 conv）仍冻结、仍逐位验（L1240–1248 的发布闸不变），本设计不新增任何 aux 上的 loss、不解冻任何前缀。
- 必须明示的两条边界：
  1. **价值梯度经共享 trunk 回流**：trunk 可训，价值根集扩大（v 根 ⊃ q 根数倍）会改变每步价值:策略梯度配比（λ 不变、根数比变）。这是配方事实、不是纪律问题，但必须可见：运行戳记须记 n_value_roots/n_q_roots（见 §③），验证协议须盯策略侧读数（ΔU、KL 监控）防 trunk 被价值项带偏（见 §④）。
  2. **钉版 k0_distill.py（BC 线）不在本设计范围**：该处四头全冻（utility/wdl/margin/aux）、无终局 loss 项、/1 格式无终局字段——价值监督在那边**没有可落的可训头**，硬接必须解冻价值头、直接违反其冻结纪律与逐位闸。本设计明确不向钉版线移植；若 BC 线将来要价值全量，须另行裁定立项，不许借本设计顺延。

### 2.4 采样概率记录（数据合同）

- 抽样发生在**标注计划层**：哪些根送教师搜索，由注册采样器决定。逐根记录 `p_q`（该根被抽中送标的**设计包含概率**，float64）：必选层（strata）记 1.0，抽样层记其层率；`has_q` 是实现值。采样器身份（sampler id、种子、分层定义与各层率、根宇宙定义）记入标注代 meta 并由 join 透传 joined 代的 meta＋producer 块（与 terminal_labels 的来源记法同格）。
- 与既有 pi 的关系**不许混**：pi（pi0/pi1）是标注器内部两段通过概率的记录（SS13-C），p_q 是计划层包含概率，两者是**两次独立抽样**。一根 q 进入训练的总概率是 p_q·pi。凡涉及权重，只许用总概率，不许只用其一冒充。
- 采样器确定性：按 (game, step, seat) 稳定序＋注册种子，同输入同种子必同选集（与合并采样器裁定 7283a3f3 同口径）。

### 2.5 IPW 与声明加权：二选一，注册在案

一轮运行在开跑戳记里钉死一种口径（`weighting_caliber`），混用即拒：

- **口径 A（IPW，主张全根策略目标无偏）**：q 根策略权重 w_r = 1/(p_q,r · pi_r)，自归一（除以 Σw，Hájek 形，与现行 L1214 的除以权重和同形——有限样本下是近似无偏、一致，戳记须如实写 Hájek 不写「精确无偏」）。价值项不加权（全量总体）。代价明示：p 小时权重放大（p=0.10 → ×10 量级），有效样本量 ESS=(Σw)²/Σw² 随之缩水，须逐运行报告 ESS 与 min(p_q·pi)；权重截断（clipping）若要用，属另一配方决定、须另注册，不许默认夹带。
- **口径 B（声明加权，课程目标）**：权重是声明的常数表（如全 q 根 1.0、或按层声明倍率），目标函数明示为「q 抽样子总体上的策略损失、按声明加权」——**不主张对全根总体无偏**。声明文本与权重表入戳记。
- 与复核 §5 的衔接（硬约束）：**不许在声明加权的混回/课程设计上再隐式叠一层 IPW 把已声明比例抵消**——IPW 的开启只能来自口径 A 的注册选择与记录本身（承袭现行「权重只从记录激活、无其他开启路径」的纪律，L89–95、L661–668），且戳记里 `ipw.active` 一眼可查（现戳记已有该字段，扩 p_q 统计并列）。

### 2.6 红线守法（逐处）

- **不补假 q**：v 根在产品中以根级惰性形存在（§③），trainer 对 v 根**不构造 target**（不调用 `construct_target`）、不做存储 q 交叉验——因为根本没有 q。任何「用 priors 均匀分布/父网分布冒充 q」的实现都违反本条、验收时按造假论。
- **不把无标签记零**：v 根的策略 loss 不是 0 而是**不存在**——不进分子分母（2.1 的拆分归一化就是为此）；日志与戳记记 roots_q 与 roots_total 两个数，任何把 v 根以 ce=0 混入平均的实现都会在 denominators 对账时露馅（平均 CE 会被系统性稀释），验证协议含此项对账（§④ 正确性闸）。
- **终局标签不许从 q 推**：v 根的价值标签只来自 join 的边车/原始结果路径（1.3），与该根有无 q 无关；一局未终局（无终局标签）则该局全根（含 q 根）按现行 join 纪律拒入，不许只丢 v 根了事。

## ④ 验证协议（回放抽稀，零新增标注）

原料：环 1 joined 全标产品（150 局 / 89,700 根，全根有 q 与终局标签）。抽稀在 **join 层离线造 mask**：按注册采样器从全标数据生成 has_q/p_q 变体产品——被抽掉的 q 只是藏起来不用，其真值留作评分，**不新增任何标注**。

- 臂与率：采样器两臂 × 两率——（甲）随机覆盖：按 step 段×座分层均匀抽；（乙）关键局面加标：随机打底＋关键层必选/高率。关键层只能用 **plan 时可得的 build 侧可观测量**定义（如尾步段 [200,299)、终局分差小的局的根、现金/植株数特征分位），不许用 q/Q 本身定义（那是偷看答案）。率：10% 与 25%（对齐复核 §0 的成本尺度）。
- 对照：同父网、同更新数、同 bs/种子流的全标基线跑；每变体一跑；口径 A/B 各选一代表变体跑（不全交叉，省算力）。
- 正确性闸（先于一切质量读数）：① has_q 全 1 的 /3 变体与 /2 基线同种子短跑，loss 逐项与 batch 流对账合（浮点容差内）；② denominators 对账：任一变体的平均 CE 不得出现「v 根以 0 混入」的稀释签名（用 roots_q 重算应逐项合）；③ v 根惰性形与 mask 外 q 泄漏检查（被藏 q 不得进任何 loss/监控统计）。
- 读数清单：配对 ΔU 轻判（40 对口径，复核 §3：只作停查报警、半宽约 ±0.20，不作非劣认证）；价值校准（在**留出局**上读 utility MSE / wdl CE / margin MSE——留出局的终局标签不进训练，防自评）；学生策略熵（留出根上）；锚 KL 监控漂移；逐 step 段 ΔU 分层；口径 A 的 ESS 与权重分布。
- 通过线建议（报策略组裁，不自钉）：稀疏臂 ΔU 点估计 ≥ 基线 −0.02 且 CI 下界 > −0.10（报警线口径）；价值校准相对基线恶化 ≤10%；无 step 段 ΔU 跌破 −0.10 报警线；正确性闸三项全过为硬前置。

## ⑤ 成本

- **实现（估计）**：join_u 稀疏发射＋/3 自验 1.5–2.5 人日；distill_u /3 loader＋两路 forward＋拆分 loss＋戳记 2–3 人日；验证 harness（抽稀变体生成＋对账）1 人日；生产期计划层采样器（标注器计划改造＋注册）另 1–2 人日。合计验证期约 4.5–6.5 人日、生产期追加 1–2 人日（估计）。
- **验证算力**：训练短跑共约 7 跑（基线 1＋两臂×两率 4＋口径对照 2），单跑 CPU-hours **未校准**（无 distill_u 在本语料上的实测单价在册）——开跑前先以基线跑实测单跑 CPU-hours（进程 user+system 累计/3600，复核 §0 口径），总额以实测×7 报备并设上限，超限即停。ΔU 轻判的对局算力另按考场口径计、不混入训练账。
- **收益对照（标注侧，复核 §0 表）**：全环全标 60.28 单座等效机时；25% → 15.07 h、10% → 6.03 h——本设计是把该表从「条件算术」变「可执行合同」的前置件，收益在验证通过后才成立，不预支。
- **对环 3 时间线的影响面**：零侵入段 1 现行路径（全标、/2、现行 trainer 均不动）；验证全程离线、用已付费数据，与段 1 并行不抢标注产能；生产期稀疏只可能用于后续段的标注试点、且须先过 §④ 与策略组裁，不构成段 1 的前置。
