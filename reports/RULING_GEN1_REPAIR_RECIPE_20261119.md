# 裁决：Gen 1 塌陷修复配方（策略组）

策略组，2026-11-19。依据：L20 定位探针事实包（gen0_replay 固定 512 行真实局面、两代检查点同批前向、float32 无 autocast）；作战室三项请裁。

## §1 根因接受

定位结论入册：**策略头坏（主犯）、价值头未坏**。根因结构性且证据闭合——gen1.log 三轮 pw＝pb＝0.0000；行权重＝searched＋(1−searched)·fast-policy-weight，Gen 0 数据 searched≡0（deep-frac 0）且 fast-policy-weight 默认 0，策略损失恒零、策略头零梯度，16,563 步里只有价值/aux 梯度在动共享主干（aux 随机初始化、早期梯度更大），主干在策略头脚下转走、策略读出方向性崩坏（工人头 top-1 一致 29.3%、LEFT 质量 0.195→0.0001、RECPLANTER −92%，与首读行为签名逐项对上）。价值头无爆炸无塌缩、对 U(margin) 的 MSE 0.129 反优于 Gen 0 的 0.230。

附带观察（在册、非本轮变量）：corr(v, U) 两代同负（−0.69/−0.66），定位判为数据口径共性、非 Gen 1 新增缺陷，本轮不动；定位报告落字时须写明该相关的视角约定（谁的分差、哪个座位），使记录无歧义。若后续代际价值侧读数异常，此约定为第一复查点。

## §2 裁定三项

**① fast-policy-weight ＝ 1.0，采。** 本轮数据无 searched 行，fpw＝1.0 使每行策略权重恒 1、策略头对记录目标（Gen 0 自身策略输出）全权自蒸馏锚定——这是对现存数据唯一不欠定的修法；产 searched 数据是 Gen 2 的事、现冻结，不为它拖延本轮。范围钉死：本取值只管本轮 Gen 0 数据修复重训；将来 searched 行入池后，行权重配比随数据构成另行登记，本件不预授。

**② aux 头本轮不动，采；打包前闸按下列数值线执行（探针同法复跑、同 512 局面）**：

- 闸 0（机械）：重训日志 pw＝pb＝1.0000，非零即本轮作废、先查配置不查模型；
- 工人头 top-1 一致率（对 Gen 0）≥ 80%（坏值 29.3%）；
- 基地头 top-1 一致率 ≥ 80%（坏值 43.7%）；
- 对记录目标交叉熵：工人 ≤ 0.35、基地 ≤ 0.35（Gen 0 自洽 0.070/0.104；坏值 5.31/2.66）；
- 工人头熵 ∈ [0.034, 0.136]（Gen 0 0.068 的 [0.5×, 2×] 带；坏值 0.402）；
- RECPLANTER 质量 ≥ 0.040（Gen 0 0.0825；坏值 0.0063）；
- LEFT 质量 ≥ 0.100（Gen 0 0.195；坏值 0.0001）。

六线全过才许打包；任一线不过，不打包、回定位，不许放宽线重跑。

**③ 修复重训，采。** 自 gen0 init、用现有 Gen 0 数据（3,134,417 行）重训，不新产数据；打包 u 模式。首读协议钉死：**种子 977200–977299（与坏 Gen 1 首读同块、配对）**，双读——(i) 对坏 Gen 1（−2654.6／U 0.0772）：须决定性回升，量的是修复本身的效果；(ii) 对 §3-2 基线 fix3 −395.5／U 0.3314（异种子同尺）：回到基线量级（CI 交叠读法）即修复确认、训练链解冻。首读只判「修复成立与否」，不判增益；仍塌陷则 fpw 假设证伪、回定位另裁。
