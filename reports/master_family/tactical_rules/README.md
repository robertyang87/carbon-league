# 从天梯前五提炼经济与防守决策

目标是改善 Sapling 在实战中招工、存碳、护树的选择。这里分别测量榜首怎么走、对手下一步能否预测、加入这项预测后 Sapling 会怎么走。棋力仍用新地图上相同考官的配对终局效用 ΔU 验证。

**本次结果。** 120 万实验版有两项实际行为改变。给安全返航小幅加分后，4 次改选都当步交付，同一组 8 局到第 100 步总交付增加 324.83，全部差异集中在一张地图的两席。另一次对照中，加入敌种树工的停留概率后，采集工改向回防并保住一棵原本会被夺走的树。两项实验使用不同地图和对手，尚未测得整局胜率增益。

后续分析在同一批回放上拆开了招工、停采、抢树、护货与末班返航，并在独立对局检验了对手短期记忆是否真的改变预测和动作。[按局势选择动作的详细报告](detail/README.md)

## 三个决策

在相同条件下比较五家。返航列为畅通、一步可进站时，轻载（0 < 载货 < 30）与重载（载货 ≥ 100）指向基地的比例。护树列限定树未到期、树上无友军、有友军相邻，比较敌种树工已站上树与没有敌种树工在一步内时，友军指向树格的比例。分母是符合条件的决策机会，同一对局可有多次。每格的逐局分母见附表。

| 玩家 | 出场 | 首回合两基地招工 | 轻载 / 重载返航 | 敌已上树 / 敌不在附近时友军进格 |
|---|---:|---|---:|---:|
| Master5s | 196 | 双采集工 | 37.3% / 79.1% | 84.5% / 16.1% |
| Master6 | 178 | 基地 0 采集、基地 1 种树 | 34.4% / 66.8% | 76.7% / 15.7% |
| RyanX it720-preview | 203 | 一采一种，换席时两基地对调 | 35.4% / 80.0% | 77.7% / 15.3% |
| RyanX M9XJ-630 | 300 | 一采一种，换席时两基地对调 | 33.3% / 77.9% | 81.4% / 16.3% |
| ClaudeFable5.2-v7 | 280 | 双采集工 | 36.8% / 79.8% | 88.9% / 15.4% |

1,157 次首回合都花了 60 碳，同时在两基地招工，至少有一名采集工。局末风格分化很大。第 280–298 步，M9XJ-630 在 294 局里的 4,615 个资金和编制允许招工的决策中一次都没招，其他四家仍在各自 13.3%–22.8% 的同类机会招工。[逐局招募](top5_recruit.json) · [逐局返航](top5_returns.json) · [逐局护树](top5_defense.json)

**招工要看局面和工种。** 首步共享现金 80、工人数为零、两基地都能招的布局，可以同时启动两条生产线。中局要看现金、空余编制和落点，残局再看新工人还有几步能收回成本。单用“应该多招”作监督，容易把此前 Sapling 的漏招变成乱招。此前同一留出集的 55 次实际招工，大网只招对 8 次；加大稀有动作权重后，原本应等待的场景又出现 193 次误招。[Sapling 训练记录](../../sapling_1200k/training.json) · [招募逐局记录](top5_recruit.json)

**返航给候选动作加分。** 只看有载货、基地在一步之内且目标基地只有一个的采集工；“畅通”指目标格无现有工人，且没有敌工一步可达基地。重载更常进站，但双方同时行动，友军也可能正要招工或回家。实际动作应继续核前缀里的友军落点、掉货风险和最后可到达步。表中是下达进站指令的比例，交付是否成功须另查结算。[返航逐局记录](top5_returns.json) · [前两名新增九局的时间顺序复查](return_probe.json)

**护树要区分靠近、站上、留下三个时点。** 对方种树工刚走到我方树格，要到后续一步选择停留、存活且结算时付得起费用，才能夺走树。可达性提供候选，进站路线、树的剩余寿命、护卫本身带了多少碳，决定是否值得改动。全样本中，敌种树工选择留在树上且友军也实际指向树格的 4,506 个树步，发生夺树 0 次。友军进格时另有 25,534 次敌人在同一步离开。回放中的友军进入树格也可能另有动机，双方同时选动作，无法从轨迹读出对手本想袭击还是撤走。[树权转移与进格记录](top5_defense.json) · [前两名逐步实例](elite_defense_evidence.json)

同一真实结算器里的例子能看清代价。一棵 9 步树上站着有钱的敌种树工。本方工人若空载，上树能撞掉选择停留的敌工并保树。若本方采集工带 50 碳、同时可以回家，同样的回防会推迟这 50 碳入账。若敌工离开，回家也保得住树。若另有空载敌采集工能赶到，载货护卫还可能先被撞死。双席六类构造局面、每个对手五种动作、我方两种选择，共核验 120 次一步结算。[逐分支现金、载货和树权](tree_screen_probe.json)

## 对手下一步预测层

现有 Sapling 输入已经有敌方工种和载货、可达区域、己方基地距离、友军预留和树木信息。新增的研究层估计每名敌工停留、上、右、下、左的条件概率。它读取我方当前和前一步的可见观察，为两种工种各学 16 个动作特征系数，共 32 个参数。训练来自 8 张自有规则自博地图；测试使用另外的规则地图和真实前五回放。在所有评估中，因碰撞死亡的工人只要提交了动作便保留。[已有输入](../../../code/cnet2_feat.py) · [预测层](opponent_intent.py) · [权重和自有对局测试](opponent_intent.json)

真实回放另以固定哈希在五人各自的仓内对局中取 8 局，每席 4 局，不含彼此直接交手，每隔五步取一个决策时点。40 局中，己方现有工人距被预测的敌工至多两步的决策共有 12,149 次。下一动作命中率为 **36.5%**，原有手写对手模型为 **29.9%**，按工种动作频率预测为 **20.8%**。在推断完成后，用观察方实际提交的联合动作确定其现有工人的目标格，再计算敌工撞上这些格子的条件概率，新招工人不参与这一测量。实际敌我指向同格有 524 次，占 4.31%，新层给出的平均概率为 3.84%。同格概率的 Brier 误差为 0.0397，原有规则为 0.1045，全部预测为零则为 0.0431。按局等权，40 局对原规则的 Brier 差均为负，均值 −0.0614，按玩家分层重采样的 95% 区间为 [−0.0666, −0.0561]。同格也可能是有利拦截，预测发生同格不能直接解释为死亡概率。[40 局名单、工人决策和误差](top5_intent_check.json)

## 接入 Sapling 的影响

**开局招工。** 在 4 张另选地图各换席一次，只在首回合要求两基地同时招工、至少一名采集工。120 万原版本来就在 8/8 次开局招一采一种，加入约束后的动作改变为 0，各局到第 60 步的完整状态逐对相同。两组均有 5/8 局完成采集交回，交付总碳 230.23。此前在留出示范中漏掉的招募不能解释成“它第一步不会招人”。[开局开关对照](opening_probe.json)

**载货避撞。** 在 120 万版的逐槽动作解码中，若载货采集工的首选落点会被较轻或同载敌采集工撞死，才考虑不与己方已选落点冲突的安全替代。四张新地图各换席、各跑 100 步，原版 800 次调用都与真实 int8 包一致。628 次载货决策中该条件触发 0 次，两组都是 3/8 局成功采集交回，合计交付 99.83。额外 24 个有敌方空载采集工的构造位置里，原版也都选择了安全落点。给这种情况再上一层硬拦截，没有测到新增收益。[防守特征](defense.py) · [真实动作与反事实记录](defense_probe.json)

**把对手意图接进动作评分。** 在实际 120 万 int8 包的逐槽解码器里，对安全、无已预留友军落点的护树候选加分。加分上限为 1.5 logit，乘敌种树工停留概率与树的剩余有效寿命比例；载货且能马上入账的护卫进一步折扣。候选未获选则沿用演员原动作，改选后重新解码后续槽，若引入新的友军冲突就撤销。第一版只在敌方步前现金已够夺树时启动，可能漏掉同一步先交付再夺树的情况。Sapling 主体权重冻结，32 参数层仅在实验开关开启时参与实际决策。[接入实现](intent_policy_probe.py)

4 张新地图各换席，对会袭扰的自有策略打到第 100 步。对照的 800 次行动与发布版完全一致。8 对轨迹中 7 对完全一样。唯一分叉在地图 `620096002`、席 1、第 83 步：敌种树工已在己方树上，预测它停留的概率为 54.8%。原版向右，护树候选“向上”的得分由 0.162 升至 0.853 后被选中。对手确实停留。原版中同一棵树（player-1-tree-2）从席 1 转给席 0；实验版的采集工撞掉敌种树工，树仍属席 1。该步改选需要的停留概率约为 40.1%，固定填 50% 也会触发，因此这局支持护树评分的作用，无法把收益单独归给学习到的概率。该局两组交付均为零，到第 100 步本方现金 95.50 → 76.52、对手现金 1,615.20 → 1,471.54。全八局两臂合计正常交付均为 381.78。48 个构造根及另 168 个位置探针均未触发改选。这个案例验证“预测 → 改动作 → 对手受影响”可贯通；当前有效暴露只有一对，不足以判断平均收益与棋力。[配对局、实际动作、对手反应和现金](intent_policy_probe.json)

**让安全返航随载货量增加优先级。** 另取 4 张新图各换席一次，对手会根据实际局势行动。在“离唯一畅通基地一步、目标未被友军动作预留”的场景，给进站动作加 `min(载货 / 100, 1)` 个 logit；其余动作仍用原模型评分。重新解码后续单位，有新的友军冲突就撤销。本次固定加分不根据天梯回放调参。[接入实现](return_policy_probe.py)

| 到第 100 步，8 局 | 原版 | 加返航得分 |
|---|---:|---:|
| 全部正常交付碳合计 | 483.11 | 807.94 |
| 本方平均现金 | 74.65 | 117.32 |
| 完成过采集并交付 | 2/8 | 2/8 |

实验版 35 个符合条件的工人决策里改了 4 次；4 次都在该步交回了实物碳，合计 675.41。后续对局双方都重新行动，到 t100 对照净多交了 324.83。**四次全部发生在同一地图的两席**，分别比原版多交 321.06 和 3.77；其余三图的六局动作轨迹均与原版相同。返航得分在已经有货、能走到基地旁边的局面有实测作用；这次没有增多能建立生产循环的地图。正式策略需要在不同地图和能干扰交付的对手上做整局复验。[逐局对照、改选与当步入账](return_policy_probe.json)

正式训练可将敌工下一步的五分类预测设为辅助损失，只用行动前的观察推断、行动后的记录给标签。要检验它有无帮助，用相同训练集、相同初始权重与更新预算，只切换这项监督；用独立地图同时考核终局 U、真实被夺树、碰撞失货和正常交付。弱网很少产货时，受袭次数少可能只反映没东西可丢，必须同时报暴露机会和经济产出。[Sapling 全场低产出的逐局证据](../../sapling_1200k/external_3s2.md)

## 复现

从仓库根目录运行，Python 需有 NumPy。恢复程序先读取 Git 对象，也支持按归档公开 URL 恢复回放；公网站点使用 IP，若本地证书不能匹配主机名，脚本提供显式的 `--insecure` 选项。程序独立核验归档的规范化内容 SHA-256、逐场比分和席位。下列 `/tmp` 路径用于复跑结果。

```bash
D=reports/master_family/tactical_rules
python "$D/top5_inventory.py" --out /tmp/carbon-rule-replays --insecure
python "$D/top5_recruit.py" --scores "$D/top5_score_rows.json" --replays /tmp/carbon-rule-replays --out /tmp/recruit.json
python "$D/top5_returns.py" --scores "$D/top5_score_rows.json" --public-dir /tmp/carbon-rule-replays --out /tmp/returns.json
python "$D/top5_defense.py" --score-rows "$D/top5_score_rows.json" --replays-dir /tmp/carbon-rule-replays --out /tmp/defense.json
python -m unittest discover -s "$D" -p 'test_*.py'
OPENBLAS_NUM_THREADS=1 python "$D/opponent_intent.py" --out /tmp/intent-weights.json
OPENBLAS_NUM_THREADS=1 python "$D/top5_intent_check.py" --weights /tmp/intent-weights.json --out /tmp/intent-top5.json
```
