## 两种能赢的开局

**Master5s 先派两个采集工，仍然每局都能交货。** 它在胜局中的首次交付中位步为 7，败局反而为 6。更明显的分化在中局。t100 的现金差中位数在 180 场胜局中为 +492.38，在 11 场败局中为 −376.30。单独奖励“越早交第一笔越好”会忽视后续持续产出。同样，从它的一次有效截获也不能直接推出现金收益。对 it720 的一局，5s 的空载工在 t296 格 162 截得 339.76，到 t299 仍未存入。截获前它已经领先 113.77。[该局逐步记录](pages/games-013.md#g-edb585cf77ed804bcf68276515b1f78e-1) · [Master5s 案例](cases/master5s.md)

**Master6 第一轮就给种树工一个名额，胜负局中首交付的中位步都为 6。** 它在胜局的全局树收入差中位数约 +3,593.76，在败局约 −70.98。对 it720 的一场大胜里，决策步 100–199，Master6 平均保有 9.84 个工人、11.14 棵树，对手为 3.53 个工人、0.26 棵树，100 步中有 84 步现金低于 30。这段双方自家基地交付 1,685.91 对 192.21。整局对手经碰撞转给 Master6 的已知载货仅 3.17。这样一场相差 8,578.74 的比赛，可以从持续生产和对方补员困难解释其过程。[该局逐步记录](pages/games-015.md#g-5b4f5ceaa627db4ff6228b2b18e3aecb-1) · [Master6 案例](cases/master6.md)

**直接交手由 Master6 两胜，过程相差很大。** 一场领先 671.93，另一场领先 7,078.55。大胜局在状态步 51–100，Master6 与 Master5s 实收树收入分别为 1,982.83 和 145.58。这期间双方都有大量工人消失，Master6 更有钱补员。两次交手只代表这两张地图、席位和实际动作。对共同对手 it720，双方战绩次序就不相同。[两场直接交手与共同对手](head_to_head.md)

**终局返程可以做局部反事实。** 在 Master6 小负 it720 的比赛中，t297 的采集工 61 距基地两格。它实际留采一次，最后一格没走到。固定其他所有已记录动作，只把这名工人的最后两步改为连续返航，重放使其比分从 8,409.65 升至 8,441.69，仍负 6.33。原轨迹末步的 52.96 载货包含放弃返程换来的最后一次采集。这个例子适合检验学生能否权衡继续采集和及时兑现。[逐局记录](pages/games-015.md#g-d2c7d061739bef723dc4abfffb22de2a-1) · [重放结果](return_counterfactual.json)

## 对 Sapling 的直接含义

Sapling 的未训练基线在 Master3s2 固定集 1,000 局里，存入、植树和树收入均为零。两名榜首采用不同的招募组合，却都能在大量地图上把碳变成基地现金。首轮学习值得先看一条可观察的轨迹：首次在有碳格留采、首次正载、向本方基地正额交付、补员后仍能持续交付。首次亲植和首次夺树分别记录。开局做法保留弹性，目标用正常打包策略在未参与训练的地图上检验。这 352 局供诊断与对照，正式训练和选模使用独立数据。[Sapling 考试记录](../../EXAM_SAPLING_VS_MASTER3S2_20261119.md) · [Sapling 网络与数据隔离口径](../../SAPLING_551K_20261118.md)

## 如何读一张局卡

每局有完整比赛 ID、真实席位、原回放、双边开局、首树、满员、多个状态截面、强弱各一个连续 25 步现金窗口、三段交付与碰撞账，以及具体可回看的工人、格子、步数。现金窗口是事后定位变化的工具，观察到的增长可同时受树收入、交付、招募和种树支出影响。载货在碰撞后可能由同队回收、归敌或落地；抓货后携带者也可能未能存入。比赛胜负取官方结算。352 局中有一局 t17 双方工人均为零，最终同得 −284 而打平，末状态的现金却相差 3.75。[逐局索引](INDEX.md) · [提前终局示例](pages/games-028.md#g-8a563a5e59432d54074bbef70c9d8a54-1)

公开回放可以识别实际行动和局面演变。候选动作、网络值、搜索深度、训练奖励及对手重新响应后的结果均未记录。这里的中位数保留实际对手和席位分布，用作行为描述。双方各自的胜负分组对局难度不同。[逐局可筛选数据](all_games.csv) · [来源及哈希](inputs/replay_sources.json)

## 复现

在仓库根目录运行。公开补档从比赛观战页读取，按固定清单核 JSON 的 SHA-256；仓内回放取 Git 提交 `37965ea5`。公开服务使用 IP 地址，下例按该服务的证书条件下载，再与存档摘要比对。局卡与事件模块使用 Python 标准库，两步反事实另需 NumPy。

```bash
D=reports/master_family/deep_review
python "$D/recover_public.py" --source-manifest "$D/inputs/replay_sources.json" \
  --repo . --ref 37965ea5 --out run-cache/replays --insecure
python "$D/test_carbon_deep_events.py"
python "$D/review.py" --cache run-cache/replays --work run-cache/derived --out run-cache/report
python "$D/replay_return_counterfactual.py"
```

完整性检验从回放独立计算终分、状态步、双方席位、现金等截面、首次空间事件和领先翻转，再与逐局卡逐项比较。[检验结果](inputs/card_verification.json)
