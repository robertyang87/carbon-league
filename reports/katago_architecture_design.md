## 0. 结论先行

**推荐架构一句话**：保留现网混合骨干（卷积干＋CellAttn＋单位 token Transformer＋GRU 联合动作解码器），
把三个地方换掉——① 价值头从 tanh 标量换成**终局分差分布头**（KataGo 式分箱交叉熵＋灭绝概率头＋
终局归属图等辅助头）；② 测试/训练搜索从「关键单位分支枚举＋rollout＋手工 leaf」换成
**候选臂 PUCT**（臂＝策略解码器生成的候选联合动作，叶＝价值网批量评估）；③ 训练主线从
BC→PPO 换成**代际自博弈循环**（生成→回放缓冲→候选集蒸馏训练→预注册门控晋升→历史对手池）。
冷启动不赌：**热启动（m3s2r1 / snipe 最新快照二选一，Stage 0 摆擂台定）为主线，
随机初始化冷启动只作并行探针**，在固定算力点用留出集对比，数据说话再决定是否切换。

设计依据（全部已实测，不是推测）：

- BC 替身全线撞墙：val 0.93 的 Fable r1 定标 −1101；全部 BC 替身终局残树收敛 5–7，
  本尊 Master3s2 为 2.1；最好替身 m3s2r1 对 Echo2 桥差本尊约 12 SE。缺口在**估值与决策时计算**，
  不在动作分布拟合（gap plan 17:58 回填：种树量已复刻到位 −2.3%，残树随 BC 轮次反变差）。
- Master3s2 作者自述 Transformer＋KataGo；其行为指纹（残树 2.1–2.3、完美清算率 31%）
  与「分差价值＋决策时搜索」的行为签名一致。it320 以反制画像（更早更重的压制）击败 3s2，
  但清算更糙（残树 3.6、完美清算 16%）——说明**压制面可以靠风格赢，清算面只有估值/搜索能赢**。
- 现搜索的三个硬伤：叶是手工公式（cash＋0.9·cargo＋30·worker＋2.0·tree…，`cnet2_search.leaf`），
  与训练目标无关、不可学习；rollout 叶成本高（dry-run 实测约 2.85 s/状态，沙箱口径）；
  搜索只在关键单位触发，不是全步的 improvement 算子。
- 现价值头与目标错位：tanh(margin/3000) 标量在 ±3000 外饱和（−13320 与 −4000 不可分），
  PPO 回报又被 clamp 到 [−1,1]，尾部信息系统性丢失（REVIEW_FIXES §6）。
- 部署端有约 10 倍余量：n1r（3.48M 裸网）1.5 核实测单步 p95 63.8ms 对 1s 软限——
  **部署时搜索在时限内是可行的**，这是 KataGo 式「训练与部署都带搜索」的前提。

## 1. 网络

### 1.1 骨干：推荐混合骨干（现网形态＋加深全局注意力），否决纯 Transformer 主干

现网骨干已经是混合体：15×15 环面卷积干（circular padding）＋CellAttn（225 格全格注意力，
零初始化残差）＋单位 token（kind/cargo/坐标/8 步历史）Transformer＋标量 MLP＋teacher 风格嵌入
→ context → GRU 自回归解码 12 个槽位（10 工人 5 动作＋2 基地 3 动作）的联合动作。

- **推荐**：保持此形态。卷积干给环面平移等变性与局部纹理（碳分布、树龄场），CellAttn 给
  一层直达的全局关系（谁压谁的采集员、清算几何），单位 token 层处理「个体」语义，
  GRU 解码器处理联合动作的槽间条件依赖——这四件事在 KataGo 的纯棋盘设定里不存在对应物，
  是本游戏的结构（多单位联合动作）逼出来的，不是历史包袱。
- **被否：纯 Transformer 主干**（225 格 patch token＋全注意力，无卷积；即作者暗示的形态）。
  理由：① 我们的 CellAttn 已经在卷积干内提供同款全局注意力，纯化边际收益未证；
  ② 在我方数据/算力量级（自博弈日产万局级，非百万级），卷积的归纳偏置是样本效率；
  ③ 解码器与特征管线（cnet2_feat/cnet2_np 双实现）全部围绕现骨干验证过，换主干等于
  Stage 0–2 全部重验。**保留复活口**：Stage 1 摆一个同参数量纯 token 臂作表征探针
  （固定算力、留出集分差价值 MAE＋裸网定标对比），探针赢了再议主干切换，不预先下注。
- **被否：加深卷积干代替注意力**（NB 8→16、无 CellAttn）。理由：清算/压制决策是长程关系
  （采集员—树—基地三角几何），深卷积的感受野扩张成本高于一层全格注意力，且已有实现零风险。

### 1.2 全局特征：补 KataGo 的两件——global pooling 升级＋plancards 式全局平面

现 context＝[trunk 全图 mean(C), token masked-mean(D), MLP(20 标量), teacher 嵌入 16]。

- **Pooling 升级**：trunk 汇聚从单一 mean 改为 concat[mean, max, attention-pool]（KataGo
  global pooling 的对应物：让网络能读「全场最大威胁/最大金矿」这类极值统计，mean 会抹掉）。
- **Plancards 式全局输入**：把全局标量（步数相位、双方现金差、双方树数按龄带、工人数按型、
  在途 cargo 总量、当前招募价/种树价、剩余步数）扩成约 40 维，一路进标量 MLP，
  **另一路广播成约 6 张常数平面拼进 33 张地图平面**——让每个格子在第一层卷积就「知道」
  全局局势（终局相位、价格），这是清算决策的关键条件变量，现网只能经 context 晚注入。
- teacher 风格嵌入保留：单网多风格是我方已有资产（exp 考官与池对手都靠它），
  搜索内对手建模与池子共用一体，避免每对手一份权重。

### 1.3 多头输出：价值头重做是全设计的核心

| 头 | 形态 | 监督信号 | 用途 |
|---|---|---|---|
| policy（保留） | GRU 解码器，逐槽 logits | 自博弈候选集分布（§3.3）/ BC 标签（冷启动数据期） | 先验＋候选生成 |
| **分差分布头（新，主价值）** | context → MLP → **83 个分箱 logits**：[−4000, 4000] 每 100 分一箱（81 箱）＋双侧溢出箱 | 终局真实分差（原版计分，含灭绝罚分，见 §4.1），交叉熵 | 搜索叶 E[margin]、P(胜)、尾部风险 |
| 灭绝头（新） | 2 个 logit：P(我方被灭绝)、P(对方被灭绝) | 终局终止类型 | 叶值修正与尾部解释；灭绝是 −300 量级罚分，不建模则分布头左尾被污染 |
| 终局归属图头（新） | trunk 特征 → 1×1 conv → 225 格 × 5 类（空/我树/敌树/我基地/敌基地） | 终局局面快照（语料/自博弈终局可得） | KataGo ownership 头对应物：逼骨干学「终局时每格归谁」，是清算价值的空间表征 |
| 终局计数头（新） | 4 个标量回归：双方终局树数、双方终局现金 | 终局快照 | 低成本多任务锚，帮助分布头校准 |
| 短程分差头（新） | 1 标量：30 步后现金分差（回归） | 轨迹内 cash270 式字段（harness 已支持） | 中盘信用分配辅助；搜索浅层备份的平滑剂 |
| 碳图 aux（保留） | 现有 1×1 conv 预测 full_carbon | 引擎真值 | 已在网，不动 |

分箱而非标量回归的理由：分差分布是多峰的（灭绝局与现金局是两个峰），标量回归学均值会把
「五五开的清算赌局」和「稳赢 800」估成同值；交叉熵分布头同时给 E[margin]、P(胜) 与
左尾概率，搜索备份用 E[margin]、门控与风险口径用尾部。tanh 饱和问题随之消失
（溢出箱承接 −13320 级爆局，不再与 −4000 混同）。

### 1.4 参数两档与部署预算核算

天梯约束：1.5 核 / 512MiB；单步软限 1s、硬限 3s；每局慢步（>1s）≤3 次且额外耗时合计
≤5s；初始化 ≤20s；整局 ≤1500s。

| 档 | 配置草案 | 参数（估计，建网时实测计数） | 裸网单步（1.5 核） | 部署搜索（§2.4） |
|---|---|---|---|---|
| **S 档（部署主力）** | C=128, NB=8, D=128, TA=4, TNH=4, L=2, NH=4 ＋新头 | ≈3.5M＋新头约 0.2M（现 snipe 配置实测 3,480,130） | **p95 63.8ms（n1r 实测）** | 全步搜索，sims ~12–24（0.7s 墙钟帽，见 §2.4） |

## 2. 搜索：候选臂 PUCT（价值叶替换 rollout 叶）

### 2.1 为什么不是教科书 MCTS：联合动作空间

一步动作是最多 12 个槽位的联合动作，原始分支因子不可枚举。现搜索的解法是对的骨架：
以策略解码器的贪心联合动作为默认臂，只对「关键单位」做单单位偏离、后续槽位由解码器
自回归重解码（forced-prefix）。**本设计保留这个候选生成器，把它升级为 PUCT 的臂集合**：

```
候选臂生成(state, net, opp_net):
  arms = [ 贪心联合动作 ]
  for unit in 关键单位排序(cargo 赌注/敌我相邻/终局清算候选, 上限 K=6):
      for move in 该单位的合法非默认动作:
          arms += [ 解码器以默认前缀强制、该单位强制 move、后续槽重解码 ]
  arms += [ 解码器温度采样 S 个联合动作 ]        # 覆盖多单位协同偏离
  去重后按解码器联合 logp 归一化为先验 P(a)      # 联合 logp = 各自槽 logp 之和
```

### 2.2 PUCT 与叶评估

- 节点＝FastCarbon 状态；边＝候选臂；对手步同理用对手网生成候选臂
  （自博弈时同一网、池战时池成员网；部署时对手＝其冻结考官/未知对手用我方网镜像，
  与现搜索的 belief 口径一致）。
- 选择：PUCT，Q 用 E[margin] 经根节点运行均值/方差归一化；c_puct 初值沿用现配置 1.5 量级，
  Stage 0 扫一档。
- **叶＝价值网一次前向**（分布头 E[margin]＋灭绝头修正），**彻底删除 rollout 与手工 leaf**。
  终局/灭绝节点用原版计分直算（与 F01 修正后的 search leaf 终止分支同口径）。
- **批量叶评估**：虚拟损失并行展开，一批 frontier 叶（训练时 128–256、跨并发局共享）
  一次 GPU 前向；部署端 CPU numpy 按批 8–16 叶一次前向（cnet2_np 已有批量 encode 路径）。
- 备份：叶 E[margin] 沿路径回传（无折扣，终局目标本身不折扣，见 §4）。

### 2.3 探索与 playout-cap randomization 的对应物

- 根节点 Dirichlet 噪声加在**臂先验**上（ε=0.25 量级，KataGo 惯例），只在自博弈生成时开。
- 温度：按相位——开局（step<50）解码采样温度高（风格多样性），中盘降，终局（step≥270）
  近贪心但搜索 sims 拉满（清算步不许靠采样碰运气）。
- **Play-out cap randomization 对应物（三件）**：
  ① *sims-cap 随机化*：生成局中约 25% 的步给全额 sims（其访问分布作 policy 目标），
  其余步给低 sims（只作走子与价值目标）——KataGo 原味；
  ② *搜索起始步随机化*：一部分生成局从 step≈200 起才开搜索（「终局冲刺局」，
  起点局面从全程局的轨迹库抽），以约 1/5 成本量产终局带标签状态，直攻清算缺口；
  ③ *局长 cap 随机化*：少量生成局在 250/280 步以价值头判定提前结算（该局只进价值训练、
  不进 policy 目标，样本打标），换取终局样本密度。

### 2.4 sims 预算（分别定，不许混用）

| 场景 | 预算 | 依据 |
|---|---|---|
| 部署（S 档） | 墙钟帽 0.7s/步硬停（沿用现 BUDGET 守卫模式），预期 sims 12–24（**估计**，Stage 0 用 cnet2_search_timing 在 1.5 核 cgroup 实测标定） | 软限 1s、慢步 ≤3/局：必须 p99 步 ≤1s，0.7s 帽留尾 |

## 3. 自博弈循环（代际制）

### 3.1 循环总图

```
        ┌────────────────────────────────────────────────────┐
        ▼                                                    │
 生成 workers ──► 回放缓冲(按局存档) ──► 训练(候选集CE+分布CE) ──► 候选网
 (当前冠军+池采样对手, 带搜索)              │                        │
                                            │              门控晋升(预注册):
                                            │              vs 上一代 + vs 固定考官
                                            │              ＋留出集终验
                                            └──── 晋升 ──► 新冠军入池(历史代际常驻)
                                                  不晋升 ──► 候选降为池成员(多样性保留)
```

### 3.2 生成与缓冲

- 对局：当前冠军（带搜索）对从对手池采样的对手（可为裸网旧代/BC 替身/快照，
  对手侧搜索按其档位给低配或不开——算力集中在我方 improvement 上；
  镜像局 SELF 占固定比例，沿用 rollout 的 mirror 记录法）。
- **存档格式沿用仓库惯例**：只存（seed、双方动作序列、对手 id、sims 配置、终局分差与
  终止类型、每步访问分布的稀疏记录），训练特征在建集时由 FastCarbon 重演生成——
  与现有语料（回放文件）同构，cnet2_build 管线可复用，避免存 33 平面特征的 IO 爆炸。
- 缓冲：按局环形，容量目标 200–400 万步行；采样新近加权（指数半衰约 2 代）但
  **每局采样次数设上限**防同局多 epoch 相关性过拟合；终局冲刺局与全程局分开计数配比。
- 防自我过拟合三件（对应 REVIEW_FIXES §6「固定考试集」条）：
  ① **种子三分**：生成种子段、门控种子段、留出种子段互不重叠（沿用现有种子段纪律，
  考试 99xxxx 段永不进生成）；② **留出对手**：2 个 BC 替身风格（如 Carago g1、M6 r1）
  永久退出对手池与门控，只在代际终验时出场；③ 门控集只作晋升判定，
  **代际验收数字只认留出集**，防对门控集的选择性过拟合。

### 3.3 训练目标（候选集蒸馏，不是 PPO）

每步样本的损失＝

- **policy 候选集交叉熵**：对该步的候选臂集合 A，目标分布＝PUCT 访问占比 π̂(a)；
  模型侧对每个臂算解码器联合 logp，softmax over A 后与 π̂ 做 CE。
  （联合动作没有单一标签，这是把 KataGo 的「访问分布蒸馏」搬到联合动作空间的关键适配：
  不强迫解码器逐槽拟合访问分布，而是让**实际被选/高访问的联合动作整体概率上升**。）
- **价值分布 CE**：分差分箱头对终局真实分差；灭绝头 BCE；归属图/计数/短程头各自损失，
  权重小（0.1–0.25 量级）只作表征塑形。
- 无 gamma、无 GAE、无 advantage——improvement 算子是搜索本身，训练只做蒸馏＋价值回归。
  这是与现 PPO 栈的根本分工：PPO 用采样回报做信用分配（方差大、被塑形口径污染），
  本线用搜索访问分布做目标（每步都有全信息监督）。

### 3.4 门控晋升（全部预注册，事后不改口径）

候选网晋升为新冠军须同时过：

1. **对上一代**：门控种子 200 局，均分差 > 0 且 ≥ +1 SE（或胜率 ≥55%，二选一在
   每代开跑前写死）；
2. **对固定考官**：Master2 真身＋Echo2 各 200 局（现有定标口径与种子），校准分不回退
   超过 1 SE，且至少一项有正增益；
3. **留出终验**：留出种子＋留出对手 200 局，校准分同向（符号一致、量级 ≥ 门控读数的 50%），
   防止门控集过拟合。
不过门：候选不废弃，降为池成员（风格多样性资产），本代以冠军续跑并记录失败归因
（价值 MAE 漂移/访问分布熵/终局段单独分差三项必查）。

### 3.5 对手池（snipe 池的推广）

- 成员：全部历史冠军代际（常驻）、晋升失败候选（降级入池）、BC 替身压迫型
  （线 C 既有规则：≥2 个压迫型常驻，不被强度迭代挤出）、代内快照（snipe 的 SNAP 机制直用）。
- 采样权重：按「对当前冠军的胜率接近 50% 者优先＋新近加权＋压迫型地板」混合，
  避免只打弱旅（无梯度）或只打最强（信号全负）。
- snipe_n1 现池（m7bsr1、it260 三臂、M7Bs v2、m3s2 双臂、m6r1）**整体迁入**作第 0 代池。

## 4. 目标对齐

### 4.1 价值目标：只认原版终局分差（F01 修正口径）

终局分差定义（原版 `compute_next_board`，与已落地的 F01 修正一致）：

- 正常到时（299 步）：终局现金差；
- 灭绝终止：灭绝方 reward ＝ step − episodeSteps − 1（≈−300 量级，随终止步变化），
  存活方保留**终止步之前**的 reward（其终止前现金）——分差按此合成，**不是**终止后现金差。

价值分布头、搜索终局节点、门控分差、线 B 重标 value 字段，四处共用此唯一实现
（建议抽 `terminal_margin(state)` 单函数四处引用，杜绝 F01 式口径漂移再发）。

### 4.2 gamma 与 worth 塑形：新线绕开，旧线用预注册 A/B 决胜（不许默认沿用）

- **新线**：价值目标是终局分差本身（无折扣回归/分布拟合），搜索备份无折扣——
  gamma 与 worth 塑形在本线**不存在**，§6 的问题从根上绕开。
- **旧 PPO 线**（若按 §7 处置继续跑）：现口径有原理性错位——dworth 是**无折扣**的
  势函数差分，而 GAE 用 gamma=0.995；势函数塑形只在折扣一致（F＝γΦ′−Φ）时保最优不变，
  现组合不保。且回报 clamp[−1,1]＋tanh(/3000) 使 |margin|>3000 的尾部不可分。
  **决定性 A/B（预注册）**：同 init（同 snipe 快照）、同算力（30 代）、同池——
  臂甲 现行（γ=0.995＋worth）；臂乙 γ=1.0＋dense 现金分差（dmargin，无 worth）；
  臂丙 γ=0.995＋dmargin。主指标：定标对（Master2/Echo2 各 200 局）均分＋留出种子复核；
  判读：某臂以 ≥+100 均分（且 ≥1 SE）胜出才换默认，平局保留现行并记录「塑形无显著效应」。
  A/B 只跑一次、结论入仓，不许凭手感反复翻。

### 4.3 训练采样 vs 部署贪心的口径差（§6 第三条）

自博弈走子带温度＋Dirichlet＋搜索；部署是贪心＋搜索。**验收对象永远是部署制品本身**
（冻结的 网＋搜索配置＋候选生成参数 打包同测），裸网数字只作诊断列（量化搜索增益），
不许拿裸网或训练口径数字当验收。现 n1r 的「同制品双口径」评估法直接继承。

## 5. 冷启动 vs 热启动

### 5.1 两条路的成本/风险（GPU 日按 L20 单卡，吞吐见 5.3，均为估计）

| | 热启动（推荐主线） | 冷启动（并行探针） |
|---|---|---|
| 起点 | m3s2r1 或 snipe 最新快照（Stage 0 摆擂台：两 init 各训新头，比叶搜索增益与价值 MAE 定胜负） | 随机初始化（KataGo 原味） |
| 头训练（在存量语料上） | 骨干冻结训新头约 0.2–0.5 GPU 日；全网微调再 0.5–1 GPU 日 | 无存量可用（分布头可借语料预训，但 policy 必须自产数据） |
| 到 Stage 1 短跑起点 | 约 1–2 天（工程就绪后） | 需先自产 ≥5–10 万局才有可训信号，约 +3–7 GPU 日（估计，取决于实测局/日） |
| 主要风险 | **BC 盆地偏置**：先验集中在 Master3s2 的动作分布，探索可能被锁在替身行为邻域——正是撞过的那堵墙的邻域 | 时间成本与不确定性：KataGo 在 Go 上是数周×大集群；本游戏规模小一个量级以上，但「几代能出 +412」无实测锚 |
| 风险对冲 | 高初温＋Dirichlet＋池多样性；Stage 1 验收含「行为剖面不得与 m3s2r1 同构」（残树/首树步/现金曲线三项与替身剖面距离下限，诊断项） | 探针固定算力点（3 GPU 日）与热启动同口径对比，输了即停，沉没成本封顶 |

### 5.2 推荐

**热启动主线＋冷启动探针并行**（探针用 DGX/Studio 空闲算力，不占 L20 主线）。
探针在累计 3 GPU 日点与热启动主线同测（留出集价值 MAE＋裸网定标＋叶搜索增益）：
冷启动任一主指标反超 → 提请所有者切换主线；否则探针数据归档、主线不变。
纯冷启动作为唯一主线被否：与「先做出最强对手」的当前优先级（时间优先于纯度）冲突，
且热启动的风险（盆地偏置）有可测的诊断与对冲，冷启动的收益（无偏置）有探针保底。

### 5.3 吞吐锚点（估计，Stage 1 第一天实测后锁定）

- 裸网 rollout：571 局/分（L20，PPO lockstep 实测）——无搜索生成的上限参照。
- 带搜索生成：叶评估批量化后，瓶颈在 FastCarbon 步进与树操作（Python）；
  按标准 200 sims＋PCR 摊薄（有效约 60–80 sims/步），估 **15–40 局/分**（32–64 并发局），
  即约 2–5 万局/日/卡。此数不确定性最大，Stage 1 的第一交付物就是它的实测值；
  代际规模（Stage 2 每代局数）在此实测前不锁死。
