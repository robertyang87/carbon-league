## 0. 一句话

第二轮只回答一个问题：**教师在已过质量闸的局面窗口里给出的改进，能不能通过联合 q 蒸馏转移到冻结裸网上。** 用一个功效足够的专用测量来答，用自蒸馏对照隔离 q 的作用，用多种子对照标定训练噪声。辅助头不进本轮。

## 1. 答什么，不答什么

| | 内容 |
|---|---|
| 本轮回答 | 单代蒸馏后，学生在教师被验证过的窗口内是否强于父代；效应量多大 |

## 4. 闸 1：功效先行（仪器能不能回答问题）

第一轮倒在「量的东西测不准」。本轮在排产前先算清楚两把尺各自能看见多大的效应。

### 4.1 整局考试尺（§17 的尺）功效不足以作本轮的主测量

由已有考试回执反推每对局 ΔU 的标准差（waux1 双场，`STAGE1` §15 附记）：

| 场次 | SE | 反推 σ_pair | 80% 功效可检出的最小效应 | 要让 CI 下界 > 0，观测值至少 |
|---|---|---|---|---|
| Master2，200 对 | 0.0234 | 0.331 | 0.066 | 0.046 |
| Echo2，200 对 | 0.0292 | 0.413 | 0.082 | 0.057 |
| 合并 400 对 | 0.0187 | 0.374 | 0.052 | 0.037 |

算式：最小可检出效应 ＝ 2.8·SE（双侧 5%、功效 80%）；所需对数 N ＝ (2.8·σ_pair / δ)²。

按 σ_pair 0.33–0.41 代入：

| 真实效应 δ | 所需配对局数 |
|---|---|
| 0.02 | 约 2,150–3,350 |
| 0.03 | 约 950–1,490 |
| 0.05 | 约 340–540 |

结论：**400 对的整局考试只能可靠看见 0.05 以上的效应。** 教师自己的效应点估计是 0.026，学生的效应大概率落在这把尺的盲区里。若只用这把尺，本轮会重复第一轮的错误 ②。

这一条同样适用于 PPO-U 线的 §17 检查点（§17 预算确认里已注「功率有限」），此处只记录数字，不改该线的规则。

### 4.2 主测量：窗口内根续弈配对（本稿新增）

教师 pilot 用的测量本身就是高功效设计：从留出局的根局面出发，两臂用相同对手、相同种子续弈到终局，按根配对、按局聚类。把「教师引导臂」换成「学生裸网臂」即可直接复用，而且不需要任何教师调用，成本只是裸网续弈。

- 两臂：学生裸网 vs 父代裸网，均带生产 guard；对手＝父代裸网（与 pilot 一致）。
- 根集：留出局的 step 200–299 局面，与标注语料、与教师 pilot 用过的局**逐 id 不交**（见 §7）。
- 统计：按局聚类的配对 ΔU，t 区间为主、聚类 bootstrap 并报。
- 所需局数：N_games ＝ (2.8·σ̂_game / δ_plan)²，即现行 N 锁算式 (140·σ̂)² 在 δ＝0.02 时的形式。

σ̂_game 以 v3 pilot 回执为准（**待填**）。仅作量级参考，用 v1.5 pilot 的 0.158 代入：δ＝0.02 需约 490 局，δ＝0.01 需约 1,970 局。学生对父代的差值方差不一定等于教师对贪心的方差，所以**正式 N 由一个小型预跑（学生臂用对照臂 C 代替，约 50 局）实测 σ̂ 后锁定**。

### 4.3 规划值 δ_plan 的预注册规则

- δ_plan ＝ 教师终局 pilot 的 CI 下界与 0.01 两者中的较大者。按现有数字即 0.01。
- 依据：不假定学生效应等于教师点估计（0.026），按教师效应的保守端规划；0.01 是本项目认为仍有决策价值的最小效应（低于它，一代蒸馏的收益抵不上标注成本）。
- **若按 δ_plan 算出的 N_games 超出留出池或墙时预算，本轮不启动**，改为先加强教师（见 §9 决策表），不得降低功效硬上。

## 5. 实验臂

| 臂 | 目标分布 | 种子数 | 作用 |
|---|---|---|---|
| P | 不训练（父代冻结） | — | 基线 |
| S | 教师 q | 3 | 被测对象 |
| C | 同一候选集、同一公式，但把所有候选的 Q 置为相等，即 q₀ ∝ P_A^0.5 | 3 | 自蒸馏对照 |

- S 与 C 除目标分布外逐项相同：同一批根、同一候选集、同一步数、同一学习率、同一批次顺序。差异只有「Q 里的信息」这一项。
- C 的定义特意保留了候选集与先验的 0.5 次幂，否则「只在 16 个候选上训练」和「先验被压平」这两个副作用会混进 S 的效应里。
- **训练噪声带**：C 的 3 个种子各自对 P 做 §4.2 的测量，这 3 个 ΔU 的散布即训练噪声。S 的效应须超出这个散布才可声称（判据见 §8）。
- 不做逐字可复现：多种子对照已经直接量出了噪声带，比追求确定性求和更便宜，也更贴近真实使用方式。

## 6. 训练配方（先在对照臂上标定，再用于实验臂）

第一轮的错误 ① 是闸和配方没对过表。本轮顺序反过来：

1. **策略损失**：对有 q 的根做完整联合动作交叉熵，−Σ_k q_k · Σ_s log π(a_s | I, a_<s)，逐候选重放各自前缀。不在候选集内重新归一。
2. **锚点**：对父代策略的 KL，不用硬标签交叉熵。作用于同一批根的全部己方槽位。系数由步骤 4 标定。
3. **不训练的部分**：U/WDL/margin 头与辅助头全部冻结。本轮不引入随机初始化的头，去掉第一轮那个全臂共有的漂移来源。
4. **学习率与步数的标定（预注册流程）**：在 C 臂上从小到大扫学习率×步数，取满足「C 对 P 的 §4.2 ΔU 与 0 不可区分」的最大一档。含义是：自蒸馏本身不改变强度的前提下，给 S 尽可能大的更新量。标定只用 C，不看 S。
5. **KL 只监测**：记录 S、C 相对 P 的 KL 均值与 p99，不设线、不裁决。B0 的 KL（**待填**）作为「硬标签锚点＋lr 0.001」配方的参照写入记录，说明本轮为何换锚点。
6. **稀疏标注权重**：若根是抽样标注，按 §13-C 的 π 做逆概率加权；本轮建议在窗口内全标（见 §7），避免再引入一层权重。

## 8. 判据（全部预注册）

**主判据（§4.2 测量）**，记 Δ_S ＝ S 三种子合并对 P 的 ΔU，Δ_C 同理：

| 结果 | 条件 | 记为 |
|---|---|---|
| 转移成立 | Δ_S − Δ_C ≥ δ_plan，其按局聚类 CI 下界 > 0，且 S 三个种子的点估计全部高于 C 三个种子的最大值 | PASS |
| 转移不成立 | Δ_S − Δ_C 的 CI 上界 < δ_plan | FAIL |
| 证据不足 | 其余 | INDETERMINATE，只许按同一协议顺延扩样一次 |

- 比的是 S 对 C，不是 S 对 P：这样「多训了几步」的效果被减掉。
- 「S 全部高于 C 最大值」这一条就是训练噪声带的用法。两臂无差别时，3 个 S 全部高于 3 个 C 的概率是 1/20，与 5% 的显著性水平相当。

**次判据（整局不劣）**：S 最优种子对 P 做 400 对整局考试，CI 下界 > −0.04 记为不劣。阈值取 400 对考试的分辨率量级；它只用来发现明显的窗口外损伤，不用来证明收益。

**晋升**：本轮不产生晋升。即使 PASS，学生入池或上榜仍走 §17 的整局尺与所有者裁定，本稿不改。

## 10. 需要新建的代码（本轮裁定通过后才动工）

仓内现状：没有把教师 q 落盘的标注器，也没有联合 q 的蒸馏训练入口（`cnet2_exit_train.py` 是旧的单槽位软目标，价值仍学 tanh）。需要三件：

1. **标注器**：按局分片、断点可续，输出 §13-C schema 的封存 generation。验收：身份绑定读回、抽样重算 q 逐位一致、窗口与隔离清单硬校验。
2. **联合 q 蒸馏入口**：§6 的损失、冻结清单、C 臂的 Q 置平开关。验收：合成夹具上联合 logp 与逐槽重放一致；Q 置平时梯度与 q₀ 目标一致；冻结的头逐位不变。
3. **根续弈测量驱动**：闸门 `du` 模式的「策略对策略」变体（两臂都是裸网，无教师调用）。验收：两臂同权重时 ΔU 严格为 0；与现有 `continue_game` 的终局计分逐值一致。

三件都不触碰教师、闸门裁决逻辑与 PPO 链路。
