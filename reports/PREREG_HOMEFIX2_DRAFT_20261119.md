  占位的目标格对后续工同样按致命计（防保护臂内部友军相撞）。
- 集成形态：归家步只作为**一个额外候选臂**进入候选生成（以贪心联合动作

  候选 0；全部候选一律经同一 H=2 续走＋裸网叶值定价后才可被选中执行；
  执行动作恒为某条已定价臂的逐字动作。检查不过（全致命/全掩码）→ 该工

## 5. 插桩三读数（裁决新增前置，回执必备）

由 `Homefix2Recorder` 在保护臂全程记录（定义见变体文件类注）：

1. **保护触发率** = 触发根数 / 记录根数（分母：保护臂全部已评估根）。
2. **保护候选入选率** = 被采纳根数 / 已出价根数（offered：保护臂实际
   进入定价集的根；另并列报告 被采纳 / 触发，供分母口径对账）。
3. **A0 与保护组的叶值差分布** = offered 根上 ΔQ = Q_prot − Q_A0 的
   分布（n / 均值 / 中位 / p10 / p90 / min / max / ≥0 占比）。
   回答裁决存疑点：H=2＋裸网叶价下保护候选到底「叫不叫得回」载货工。

场景记录开关：`CARBON_HOMEFIX2_RECORD=<path>`（JSONL 逐根落盘）。
