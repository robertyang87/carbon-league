## §1 可行性算术

记：标定（全搜索）局占比 c＝10%，监控抽检 m＝2%（自快标注根中抽、全搜索重标），高熵回退占比 h（快标注根中熵超 τ 而改走全搜索者），快网每根前向当量 k（以教师一次前向为 1 单位；紧凑网实测折算，规划取保守 k＝3，上限目标见 §2.3）。

- 每根评估当量：E(h) ＝ 609×(c＋m＋h) ＋ k×(1－c－m－h)。h＝0 时 E ≈ 76（骨架件的约 64 对应 k＝1 且 m 并入 c 的乐观角，规格按 76 规划、64 记为乐观沿）。
- h 敏感性（k＝3）：h＝5% → E≈107；h＝10% → E≈137；h＝15%（闸三上限）→ E≈167。h 是本方案的经济生死变量：回退占比每升 5pp，当量涨约 30。
- 墙时模型（剖析桶折算，快标注部分仍付特征构造与场景开销）：新墙比 ≈ (1－f) ＋ f×E/609，f 取评估桶占比。E＝76：主口径 f＝0.834 → 0.270（约 3.7×，13.5h→约 3.7h）；灵敏度口径 f＝0.918 → 0.197（约 5.1×，→约 2.7h）。另加快网训练墙时（Phase 0 实测回填，预估 0.3–1h 量级、GPU）。
- **诚实区间：整环标注墙时约 2.7–3.7 小时＋训练，合计约 3–4.5 小时（估计）**，对现行 13–14 小时约 3.1–4.9×。骨架的 2–3 小时需 E 与 f 双双落乐观角，不作规划值。

## §2 管线设计

### 2.1 标定集（环内 10%）
- 选取：局序等距抽取（每 10 局取 1，与框 A 冻结 12 局同法），确定性、可复算，不用随机抽（防分布漂移与复现争议）。
- 标注：以环 3 时现行生产标注器全搜索标注（钉版或届时已采用的候选，身份随环记录）；产物即正常分片，另兼快网训练集与闸一筛查集。

### 2.2 训练集构造
- 输入特征：与教师同口径特征张量——由回放＋步/座经 `cnet2_feat` 确定性重建（快照/队列管线的场景重建 machinery 已证可逐根复现状态），逐根与分片对齐。
- 目标：分片 `priors`（π_search）、`Q`（逐臂）、`q`（根值）。**字段语义以钉版代码直读为准、Phase 0 开工首日核完入卷**（不凭字段名假设）。
- 划分：见 §3 的几何问题（会签点 A）。

### 2.3 快网
- 形态：紧凑网，同特征输入，双头输出（π̂ 策略分布＋Q̂ 逐臂值，q 由 Q̂ 派生或独立头，Phase 0 定）。尺寸预算：单次前向成本 ≤ 教师 1/20（目标值，Phase 0 实测 k 回填 §1 公式）。
- 实现：新文件（如 `code/fastlabel_net.py`＋训练脚本），独立身份；集成进标注器时以新 code_md5s 键登记。训练在 L20 GPU（环内排程约束见 §5）。

### 2.4 快标注路径（标注器新模式）
- 逐根流程：场景重建（现行 machinery 不变）→ 特征构造 → 快网前向 → 得 π̂/Q̂ 与熵 H(π̂)；H＞τ → 回退全搜索 `evaluate_root` 原样执行；H≤τ → 发快目标。
- 逐根路径标记：分片新增 `path` 数组（0＝全搜索标定／1＝快标注／2＝高熵回退／3＝监控重标），join 侧须容忍并透传（§5 工程项）；环 progress 身份段新增：模式、快网权重 md5、τ、监控率、标定代 id。
- config：新字段只在快模式下进 `teacher_config`（全搜索环 config 逐字不变，保既有身份兼容——构造性论证同 batch-2 O-1 口径，集成时双跑哈希验证）。

### 2.5 监控与处置状态机（闸三的工程形态）
- 监控抽样：确定性哈希抽样——hash(环种子, 局, 步, 座) mod 100 ＜ 2（预注册、可复算、不占 RNG 流）。监控根双算（快＋全），**出货用全搜索目标**，快目标入比对侧车供闸三判读（避免已算的全搜索被浪费、且比对无偏）。
- 状态机：NORMAL（2%）→ 破 1.5 倍线 → ELEVATED（监控升 10%、该环标签暂存隔离、join 封锁）→ 复检仍破或首检破 2 倍硬线 → VOID（整环快标签作废、回全搜索重标）。状态与每次判读随环留档（判读半边 §3）。
- 回退上限：h＞15% 即 VOID（判读半边 §3），逐根计数实时累计、超限当环即停快路径。

## §3 Phase 0 试点（离线保真，零新标注）

- 数据：现成 annot_a/b/c 共 150 局／89,700 根全搜索分片（已落盘验合）。
- **会签点 A（闸一几何）**：判读半边闸一筛查集为「标定集留出根」。但生产几何是跨局泛化（快网训 10% 局、标 90% **别的局**），同局留出根只测局内插值、系统性偏乐观。Phase 0 双测：(i) 局内留出根（闸一原几何）；(ii) 整局留出（生产几何）。预注册决策规则：若 (ii) 显著劣于 (i)（任一闸一指标带内差超其闸值一半），生产闸一改采「标定 12% 局＝10% 训＋2% 整局筛查」几何；否则照判读半边原几何。此点请策略组在合卷时裁。
- 建议划分（待 A 裁后定版）：训 annot_a＋annot_c 局、筛 annot_b 局（整局留出即 (ii)）；(i) 在训练局内再留 20% 根。
- 产出：闸一全指标三步带分层表（(i)/(ii) 双份）、熵分位→预期 h 曲线（τ 候选点回判读半边钉）、快网实测 k 与训练墙时、§1 墙时投影更新、闸一可达性判读材料（阈值修订只许在此判读点以「修订＋理由」入仓，判读半边 §1 已钉）。
- 座位与算力：L20 闲窗（GPU 训练＋CPU 保真计算）；纯分析部分可放 Studio 探针位（其长进程约 3 分钟被杀的限制只影响分析脚本切分、不影响结论）。**不占五座**。周期约 1–2 天（估计）。

## §5 生产集成（环 3）与工程项清单

1. 标注器快模式实现（§2.4）＋config 身份双跑验证。
2. join／join_u 对 `path` 字段与双路分片的容忍与透传验证（逐字段闸不误杀）。
3. 快网训练排程：环内标定完赛后 L20 GPU 训练（与环内学生训练错峰，窗口写入环链路卡）；训练失败/超时 → 该环直接全搜索（降级路径常备，不等判读）。
4. 坏根预扫不变：join 后全集照现行判据扫（与标签来源无关）。
5. 环链路卡新增段：标定→训练→闸一筛→快标注→闸三监控→（或有）作废重标，各段具名与触发条件按链路卡制度写死。

## §6 风险登记

- Stage-4D 前科（§0）：闸一可能不可达——Phase 0 即为此设，死也要死在零标注成本处。
- 跨局泛化缺口（会签点 A）：(ii) 几何若崩，方案退到「标定比例上调」或整案止损，均在 Phase 0 判读点裁。
- h 失控：回退占比超 15% 整环作废（闸三），经济性先于质量崩（§1 敏感性表）。
- 环间分布漂移：快网环内重训为固有设计，跨环不复用权重（复用须另行立项验证）。
- 快网训练吃 L20 GPU 窗口与学生训练争用：§5.3 错峰＋降级路径兜底。
