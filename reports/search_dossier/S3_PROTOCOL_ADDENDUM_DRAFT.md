# S3 协议附则（搜索组拟稿 · 2026-11-16 · 待策略组验收）

依据：预注册 PREREG_ECHO4_TACTICAL_SEARCH（53ca3850 起的现行链）＋ MS03 裁定（根名单冻结、采样概率登记、先按局聚合、H=0 真回 A0 在主尺记 0、异常/泄漏/执行失败记无效不填 0；无效上限与估计式由搜索组拟、策略组验收）＋策略组 2026-11-16 追加义务（「结算区分度保底」必须正面处置、不许留白）。本附则未验收前不开 S3 任何测试。

## 1. 根总体与冻结法

- 根总体来源：S3 专用诊断种子块 **986200–986499** 上的 Echo4 自博弈对局（基线包 SEARCH=False 推进、双席），在每步以注册触发条件筛根。触发条件按注册三类战术逐类写死在本附则执行版（几何判据＋步带），与生产 CONF（Echo4 CONF 原样）一致。
- 冻结时点：开测前将根名单（局号、种子、席位、步号、触发类）全量落盘并 md5 钉版入仓；开测后名单只读，任何增删使本趟作废重报。
- 采样：若根总体超过执行预算，按触发类分层随机抽样，**采样概率逐层登记**（层＝触发类×席位带），估计时以登记概率做逆概率加权；不许事后按结果挑根。

## 2. 估计式（主尺与副尺）

- **先按局聚合**：每局先算局内根的加权均值，再跨局等权平均（局为独立单位）；CI 按局级聚类口径（与 q 闸 t-cluster 同族）。
- **主尺**：全部入样根的每根收益（改子臂相对 A0 臂的终局现金差，经续弈口径见 §5）；其中 H=0（预算内一轮未完成、真回 A0）的根**记 0** 进主尺——这是部署形态的真实组成，不剔除。
- **副尺（分开报、不混主尺）**：H≥1 条件收益（仅完成至少一轮的根）、按触发类分层收益、按席位收益（席位仅敏感性级、只报方向）。
- 覆盖等级照注册：三类战术＝裁定级；席位＝敏感性级；三类之外＝不覆盖。

## 3. 无效口径与上限

- **记无效（invalid）、绝不填 0** 的情形：执行失败（异常/超时未达终局）、状态泄漏或快照恢复复现检不过、根在冻结后被证伪（如触发判据误报）、双臂任一未到权威终局。
- **上限**：无效根占入样根比例 >5% → 本趟结果整体降为敏感性级（只报方向、不支撑裁定）；>15% → 本趟作废、原因归因后重报注册。单局无效占比 >50% 的局整局剔除并在报告中点名（剔除规则先行声明于此，不事后裁量）。
- 无效逐根登记原因码，随证据包入仓。

## 4. 结算区分度保底（正面处置：立规则）

**问题**：先验序截断 K≤4 可能把唯一能区分结算优劣的候选挡在比较之外（S1 电池 P3 实证：被截掉的候选恰是结算可区分者，该次其值为劣、未致害；对称情形——最优者被截——同样可能）。

**规则（本附则立）**：对**结算可判定根**（H=1 且全部合法候选的一步结局可精确计算的根，典型为近终局/交付可一步结算的根），准入集**必须包含一步结算 argmax 候选**（与 A0 的结算差最大者；并列时取先验序靠前者）；其余名额仍按先验序截断至 K≤4（含 A0）。非结算可判定根不适用本规则（无精确结算可依，强行保底只能凭叶值、与截断目的自相矛盾）。

**不立更宽规则的理由**：对一般根以叶值做保底等于取消截断（叶值本就是被比较对象）；本规则只利用「精确可算」这一客观子集，成本为一步结算计算、不引入新估计。**不采「完全不立保底」**：P3 已证风险真实存在且方向对称，留白即把已知机制风险带进裁定级测量。

## 5. 续弈与叶版本钉版

- 每根双臂续弈口径与 S1 续弈腿相同：双席完整记忆快照＋恢复复现硬检、生产守卫全程、权威终局 299；本附则执行时以考位重跑已验的 verify3 机械为准。
- **叶版本钉版**：S3 主臂用叶①（启发式叶、恒等 affine、原始分差尺度，身份＝源码 md5 随证据包钉版）。L-vnet33 须四项验收齐＋按 MS04 另行注册（新叶版本）后才许以独立臂进入，不与叶①臂混测、混报。
- 对手形态 J=1（确定性根动作）为 S3 注册口径；多情景扩展属 B/C 臂范畴，不在本附则。
