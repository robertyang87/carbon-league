## 范围

纯离线：不训练、不改 state、不动 trainer。A/B 只做前向与算术；C 为条件触发的诊断对局（probe 种子、无任何闸效力）。根集离线根为语料局（非该运行自身 rollout)，绝对校准水平有 off-policy 混杂——**只有同根跨检查点差值与定位形态是证据**，绝对值不作结论。

- 真实终局 U(root)——**续弈定义写死**：root 的真值 = 其源局**按已记录的实际对局打到底**的终局结果（续弈即语料生成过程在该根之后实际走出的那条轨迹，不作任何重演、不换任何检查点的策略续打），按 root 席位定向：U = 0.5·W + 0.5·sigmoid(margin/1000)，W∈{1, 0.5, 0}；来源字段与构造方式入回执（build 产品在册终局）。由此测的是「批评家对数据生成续弈下终局的校准」；与检查点自身策略续弈的真值差异即范围节所述 off-policy 混杂，只读同根跨检查点差值。

## 测项 A · 价值校准

每检查点对全部根报：bias = mean(v̂ − U)、MAE = mean|v̂ − U|、Pearson 与 Spearman 相关；拆分：席位 {0,1} × 步段 {200–249, 250–299} 与全体。
判读线（对 bias 取 |bias| 增量、对 MAE 取增量，均为 95 减 74）：
- **指认**：[ΔMAE ≥ 0.020 或 Δ|bias| ≥ 0.020]，且该指标的变化有步定位：换头相邻步（74→78 或 78→79）合计占 74→95 总变化 ≥40% → 记「指认（换头步）」；r19 相邻步（79→82 或 82→85）合计占 ≥40% → 记「指认（r19 步）」。两记均为价值通路被指认（C 触发口径同）。
- **证伪**：ΔMAE ≤ 0.005 且 Δ|bias| ≤ 0.005——批评家终局预测未退化，价值校准故事死。
- **中间（退化成立、步归因不成立）**：达指认的量级门但任何相邻步组占比 <40%（渐进退化）。

## 测项 B · 优势符号定位审计

定义 A_taken(root) = U_realized − v̂_ckpt(root)（语料实走动作的已实现优势）；与 it74 的 A_taken 符号一致率（|A|<1e-6 的根剔除并计数入回执）。残局根 = 距其源局终局 ≤50 步。
明示：B 是对 A 同一量的定位审计（单独不能定罪），其可证伪内容是集中形态。
判读线：
- **指认形态**：不一致率（95) ≥ 15%，且残局不一致率 ≥ 非残局的 2 倍，且不一致率（79) ≥ 不一致率（95) 的 50%（翻转随换头时代到来、非渐进）。
- **证伪形态**：不一致率（95) < 5%，或残局比 < 1.25 倍——集中形态死。

## 测项 C · 价值头互换配对场（条件触发）

触发条件：A 指认，或 A 中间且 B 指认形态。A 证伪且 B 证伪形态 → 不触发，本诊断以「价值侧未指认」关闭、回终审另议组件（训练中实际使用的奖励塑形不在本诊断可见范围内，明示）。
构造：价值消费型玩家（仓库 search 玩家、价值头作叶评估）；两臂同配置：P_orig = it95 策略＋it95 价值，P_swap = it95 策略＋it74 价值；对手 m3s2g1（探针冻结包）；配对种子 **990400–990499**（过签修改：探针域新切、登记归本诊断；原块 990000–990199 已花且其一号场主体正是 it95 对同一对手，避自适应复用），每 seed 打席位互换一对、每臂 200 局、同 seed 同席位跨臂配对；ΔU 只在 C 内两臂间比（不与探针 pack 口径混读）。
判读线：
- **回收（因果指认）**：ΔU_swap − ΔU_orig ≥ +0.030 且配对 bootstrap CI95 下界 > 0。
- **未回收**：差 ≤ +0.010——A/B 指认成立时亦须记「批评家退化真实但非竞争力弱因」。
- **构造作废条款**：若 search 玩家决策可证不消费价值头，C 按构造作废、停报；因果验证改走训练侧探针，须另行授权。
- **不可构造骑缝（过签）**：it74 价值头移植进 search 玩家若因接口不合无法忠实构造，C 报「不可构造」＋理由停报，不许即兴拼替代臂（与构造作废同族）。
