# 预注册框架：搜索蒸馏（快标注网）验证闸——结构先行钉死（策略组，2026-11-18）

- 对象：所有者令算法级大优化「搜索蒸馏」——环内 10% 局全搜索标定→训紧凑快标注网→90% 根单次前向出目标＋2% 抽检漂移＋高熵根回退全搜索；预期评估量约 609→64/根、墙时 13–14h→2–3h 量级（均估计，待规格与实测）。
- 范围：环 2 照现行跑；本框架与后续预注册只及**环 3 起**。与 batch-2 裁决独立。验证口径由逐根恰零改为统计保真＋孪生 ΔU A/B——口径变更在此预注册，不追溯既有判读。
- 数值阈值在工程组规格定稿时一并入仓补钉，**先于环 3 任何读数**；本件先钉闸结构与判据定位。单期预注册只许加严。

## §1 判据定位（先钉，防规格带偏）

- **放行主判据＝孪生 ΔU A/B（下游实测）**；统计保真只是前置筛、不是放行判据。依据两条在册教训：探针 (b) 中间指标（翻转率）热闹而 (c) 类实测零改善；小教师 Stage-4D 保真三项实质项全不过、线封存。快标注网本质是小教师思路的环内化，其标签质量最终只认「用它训出的学生不劣化」。

## §2 三闸结构

- **闸一 · 保真前置筛**：在标定集留出部分上，快标注 vs 全搜索逐根比对：策略顶翻转率、|Δq| 与 |Δdu| 分布（中位＋尾部）、q 分布距离。阈值参照 Stage-4D Tier 2 实质项量级，规格定稿时钉死；不过筛即不进闸二。
- **闸二 · 孪生 ΔU A/B（放行主判据）**：同配方、同种子块孪生训练——全搜索标签臂 vs 快标注标签臂（含回退机制整体），学生配对 ΔU 差按非劣判读线判（界值规格定稿时钉死）。验证成本（多训一臂）在规格中明算，与每环节省墙时对账。
- **闸三 · 回退与抽检纪律**：① 高熵回退阈值以标定集分位数形式预注册，不许看产出后调；回退比例设上限，超限即该环快标注整体作废、回全搜索。② 2% 抽检逐根对全搜索比对，漂移判线预注册；破线处置预注册（加抽比例／整环回退，二选一在规格中钉死）。③ 抽检与回退的执行记录随环留档，供判读复核。

## §3 边界

- 快标注网只产训练标签，不进考试／校准／验收任何测量链；测量链标注仍全搜索。
- 任一闸不过：环 3 起该环回全搜索现行形态，不带病推进；连续两环闸二不过，快标注线停、回策略组议。
