# Sapling V4 的训练与独立留出

V4 从 V3 的 1,206,476 参数网络热启，固定训练 320 次更新后封存。新权重 SHA-256 为 `2ce3c214683bc4d132ca7502e4864c5fcd7961840e13354671bf7c1173b13a00`。本次箭头均表示同一批教师前缀局面上，V3 与 V4 的贪心动作一致率。比赛中从自己的前缀继续行动，会访问不同局面，胜率需要另行实测。

**招种植工学过了头。** 在高手的 454 个基地选择中，实际招工分布为空过 250 次、招采集工 123 次、招种植工 81 次。V4 给出的相应次数为 104、4、346。在另六张 V3 到访地图，教师招种植工 167 次，V4 预测 252 次。这两批数据都指向招工配置失衡。模型在实际新种场景中的一致率提高，同时也在许多高手宁愿保留现金或招采集工的场景给出了招种植工指令。

## 训练怎么做

- **39% 损失**来自 V3 自己到访的 18 张地图、2,028 个根，由冻结的 Echo4 无守卫贪心策略按实际可见状态重新给出完整动作前缀。种植工、可选基地、载货至少 30 的采集工和邻敌工人分别占 13%、7%、10%、9%。另六张 683 根留作验证。这里的防守统计是邻敌场景中与教师行动相同的比例。
- **20%** 保留 V3 现金训练清单，沿用原来的 22 训、6 验。
- **41%** 来自原有 Top5 互赛 79 个训练局。真实发生的新种/夺树占 10%，采收/交付占 8%，原有攻守机会占 13%，招种植工演示占 4%，普通选择占 6%。21 个独立验证局按每局 48 根均匀抽取，两席都有机会入样。训练阶段才为稀少和已确认的动作补抽行。
- 真实事件用相邻的公开回放帧核对。新种和夺树以树所有权变化区分。采收须该工人在无敌方一步可达威胁的非基地格停留且载货增加。交付须该工人带货抵达己方基地并清空载货。按相邻两帧中该工人的当前位置和上一位置配对，避免工人槽位重排。最后一帧缺少下一决策行，排除比较。
- 人为倾斜的抽样和损失是此版的设计选择。每组在本批内独立归一，加权动作交叉熵仅施加于策略；价值相关输出没有终局监督。AdamW 学习率 0.00018，种子 551191，CPU 两线程耗时 170.9 秒。轮数和权重配方在获得考分前固定。

在三个真实双席回放上，另用原始工人 ID 逐个核对训练代码标记的事件。新种 185、夺树 143、采收 2,887、交付 440，四类均零漏标、零误标。该核对覆盖上述三场中的可配对帧。

## 复跑

下列三个变量分别指向新 24 图、旧现金 28 图和原 Top5 互赛 100 图的本地清单，分片沿用各自清单的相对路径。V4 的独立现金验证保留旧清单原本的地图切分。输出请选空目录。完整回执含父权重、清单和训练程序的 SHA-256。

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 python code/sapling_tree_train.py \
  --tree "$TREE_MANIFEST" --cash "$CASH_MANIFEST" --elite "$ELITE_MANIFEST" \
  --out "$RUN_DIR/tree_v4.npz" --receipt "$RUN_DIR/tree_v4_training.json" --threads 2
```

## 招工偏置消融

另冻 `tree_v4_basecal.npz`，SHA-256 为 `af9ab94e4b8e2544776b86ef79de98e399726c52af7c48707bfa47e76784f8bf`。逐张量比对发现只有 `bhead.bias` 的两个元素有改动，空过截距固定，招采集工增加 0.0730，招种植工降低 1.5067。保持整个策略干线、逐条件的基地特征系数及工人头不动。去除训练时对招种植工演示的额外抽样，改用新 18 张训练图中已采记录的全部 1,389 个可选基地槽，以及 Top5 原 79 局共 24,630 个可选槽的均匀随机 4,096 槽。以两个来源各占一半的交叉熵拟合一次，封存权重字节，再打开各自留出。

| 全部可选基地留出 | 槽数 | 教师实际招种植工 | V4 预测 | 校准版预测 | V4 → 校准版一致率 | V4 → 校准版交叉熵 |
|---|---:|---:|---:|---:|---:|---:|
| 六张 V3 到访地图 | 404 | 167 | 252 | 85 | 64.60% → 46.53% | 0.883 → 0.961 |
| 21 场 Top5 互赛 | 5,858 | 1,147 | 4,685 | 3,413 | 37.38% → 44.83% | 1.597 → 1.047 |

此表涵盖 21 场高手互赛的**全部**可选基地槽，与上表每场均匀抽 48 个根的口径不同。校准后，高端对局分布仍过招，V3 到访局则从过招转为少招。统一下调招种植工倾向可以部分纠正高端对局的预测偏差，下一步需直接检查在给定现金、工人构成和可兑现收入下该招哪一类工人。对局实力依据独立整局比赛判定。

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python code/sapling_basecal.py \
  --init data/weights/sapling_1200k/tree_v4.npz \
  --tree "$TREE_MANIFEST" --elite "$ELITE_MANIFEST" \
  --out "$RUN_DIR/tree_v4_basecal.npz" --receipt "$RUN_DIR/tree_v4_basecal.json"
```
