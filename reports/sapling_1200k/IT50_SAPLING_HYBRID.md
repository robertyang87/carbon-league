# it50 与 Sapling 的双网络候选

这份候选将我方 PPO it50 和 Sapling cash V3 的动作分数按 75% 和 25% 相加。两张网络分别观察同一个当前局面，在同一合法动作集合和同一已选前缀上评分。每次选择一个单位的动作后，两张网络都用刚选的动作继续解码下一单位。双方只使用比赛接口当时可见的信息。候选为贪心、风格 2，守卫与搜索均关闭。

|---|---:|
| 我方 it50 权重参数 | 3,480,775 |
| Sapling cash V3 权重参数 | 1,206,476 |
| 合计 | 4,687,251 |
| 单文件包 | 6,070,670 B |
| 包 SHA-256 | `b54cc51f4109f19f4a7b508eafc9cf04a28b7e295a9f442c5208f0d33f10a9ca` |

自带破产守卫的单 it50 在历史考场取得 187 胜、113 负，平均分差 +262.12，U 为 0.5906。原场登记 Master3s2 源码 MD5 为 `57f9a594`、包装器为 `8d209ddb`。旧场逐局只记录考官内部错误数，搜索实际执行次数与深度未知。 [历史考场身份与计数](MASTER3S2_REFERENCES.md) · [原注册](../REGISTRATION_ABLATION_STEP1_FULL_20261116.md) · [格 D 读数](../CLOSURE_ABLATION_STEP1_20261116.md)

## 复现

在含 NumPy、CPU PyTorch 及 threadpoolctl 的仓库环境中，从仓库根目录运行。打包器验证两个上游文件的 SHA-256。逐槽验证用仓内各单网的原版解码器，把双网实际动作喂回两个单网，独立复算每个有效槽的 argmax。练习图 620098103 的 30 个根、184 个有效槽全合。

```sh
python reports/sapling_1200k/build_it50_v3.py
python reports/sapling_1200k/it50_v3_parity.py
python reports/sapling_1200k/it50_v3_exam.py --out /tmp/it50_v3_fresh.json
python reports/sapling_1200k/it50_v3_audited_seat.py --out /tmp/it50_v3_seat1_fresh.json
python reports/sapling_1200k/it50_v3_fresh_block.py --dir /tmp/it50_v3_four_new_games
```

两个外考命令使用 Linux CPU 4、独立研究图 620098101。考官为仓内原始 Master3s2，MD5 `57f9a594cce4f2ec9e3573d8d9d26ca1`，温度 1，内部采样未设种子，搜索根据墙钟调整预算。同一地图再次运行可以产生不同轨迹。报告保留各席、双方终分、实际搜索深度及每个角色的选择归属。第一趟席 1 记录器退出，无可恢复终分，在同一图同一席重新取样。外考首趟所用旧审计条件仅计 searched 和 single，而原考官深度 0 原生回退只加 aborted。重测采集每次调用的计数增量、深度和原函数实际进入数。初次失败的原始计数没有存档，无法追溯是否当场触发该路径。重测与第一席运行的宿主负载也有差异。
