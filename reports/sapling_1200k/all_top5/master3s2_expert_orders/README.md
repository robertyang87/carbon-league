## 可复核的动作监督

30 场共 8,970 个整队决策、81,030 个在场工人槽和 17,940 个基地槽。每帧只重建专家本席在行动前可见的观察。实际整队令从下一回放帧的 action 字段读出，它记录的是本帧发出的命令。程序用 Sapling 现有编码器处理 8,970 份原令，逐个验证发令往返一致，再沿真实队内顺序推进现金、占位和可选动作掩码。所有工人槽在相应前缀下均通过；省略命令恢复为 NONE。每局的公开观察、专家整队令与两席联合命令各有独立 SHA-256。

`inventory.py` 默认向标准输出写整份清单。完整研究源代码检出后，可用 `python inventory.py --orders 比赛ID` 对具有历史策略训练身份且通过地图隔离的比赛按时间输出 JSONL。每行的 `public` 只有当拍己席公开状态；`prior_own_orders_sha256` 锁定过去己方命令；`label` 单独存当拍专家命令和各槽实际前缀。原版对手当拍动作、隐藏碳、未来状态、终局得分、身份和地图种子均不进入 `public`。比赛级成绩只用于描述来源。每个状态只观测到专家实际采取的一个联合行动，替代动作的终局收益和专家抽样概率均未知。[清单与读出程序](inventory.py) · [公开观察字段](../context.py)
