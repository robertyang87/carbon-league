# 何时招工、何时把货送回

在 78 张抽样地图中，头部选手在中盘约一半的合法基地机会招工；到第 250 步起，只在约四分之一或更少的机会招工。在全库 1,324 张地图里，已有三步返程迹象的重载工，在随后十步完成交付的比例比其他同档重载工高约 15–17 个百分点。同一位 Master5s 在同一张地图上，既有载 201 继续采，也有载 213 马上回库的实例。训练时可让模型区分这两种状态。[抽样与全量分母](other_timing.json) · [原始回放清单](manifest.json)

## 1. 招募的机会与实际选择

从冻结的 110 张互打图按对手组合及排名在前一方的物理席各抽一张，18 个有覆盖的分层得到 18 图、36 次头部出场。对外按五位选手、两席分层，每层选择六个不同对手的地图，共 60 图、60 次头部出场、41 位对手。层内按固定文本和赛事 ID 的 SHA-256 排序，选图时不读取结果。逐图读取所有实际推进，合计 57,408 次基地决策、13,194 次至少一个工种可招、6,464 次实际招募。数目以基地计，同一席同一步可以有两个机会。[抽样和逐基地算法](other_timing.py) · [全部基地的前置条件和事后存活](other_timing_rows.json.gz)

**钱要按每座基地轮到时来算。** 原版先确定两类费率，再按席内基地顺序扣款、更新人数。招募条件是该工种可负担、当前队伍尚有名额。官方的这两条判断没有附加空基地条件。抽样发现 370 次基地在本步开始时有钱购买采集工，前一座招完后余额已不足且仍有名额。例为 it720 席 1 的 t13，初始 30.86，第二座轮到时只剩 0.86，价格 30。若把两座都列进可招分母，就会错算一次“放弃招工”。[正式规则](../../../code/env_raw/helpers.py#L963-L1004) · [该局](economy_games/01ddd5357eeffd9dbb1c8450bd66c060-1.md)

**基地被占与能否活下来要分开看。** 采样时基地上已有己方工人，依然成功招了 1,768 次（互打 744、对外 1,024），这些新人在下一帧全都在场。另有一次 Master5s 对 Master6，t211 敌工正占基地 160；席 0 开始余额 64.40，第一基地用去 30，该基地余 34.40，合法招出采集工 75，第五步还在场。敌工占基地仅有五次合法机会，样本不足以支持照搬这个操作。敌人距基地 ≤1 时，新人到第五步还活着的比例互打 167/206（81.1%），较远或当前无敌工为 2,186/2,445（89.4%）；对外分别为 197/236（83.5%）和 3,268/3,577（91.4%）。距离以行动前的最近任一敌工计算，包含平地遭遇和对方准备撤离等不同状态。这些差异可用来设计威胁特征，无法单凭距离确定拒招阈值。[敌占基地案例](economy_games/e71d5897d9c7908e11c4fb3a870c994f-1.md) · [分层证据](other_timing.json)

每行封存行动前的计划剩余步数、开步现金与逐基地可支配金额、采集工和种植工在场数、该基地轮到时的当前总人数、敌方人数和最近距离、基地占用方、两类价格与合法性，另列真实命令、是否扣款招成、新工是否活到下一帧和第五帧。现有工种数取步首，逐基地总人数反映同席前序招募。样本没有非法招募命令，有两名合法招出的新人即步消失。从零人恢复编制的中盘成功例在这批地图里缺乏证据，不能用开局的 t0 首招代表濒临灭绝时的解法。[逐次证据字段](other_timing_rows.json.gz)

## 2. 已经带货时，回库和继续采各发生了什么

沿用已逐局核账的触发条件：采集工已有 ≥200 货、距最近己方基地 4–8 格、三步前同工在场，同一工人相邻告警至少间隔十步，且局内有完整十步可观察。每次按前三步的距离是缩短还是持平／增加分组，再查同一工人在之后十步的逐笔正额交付。表中分子为交付命中，分母为触发次数，一局内可有多个工人、多次告警。[逐局资金账和告警](economy_extract.py) · [分地图、对手和席位覆盖](other_timing.json)

| 地图／头部席 | 前三步已接近基地 | 其他同档工人 |
| --- | ---: | ---: |
| 互打，两席 | 639/1,416（45.1%） | 500/1,793（27.9%） |
| 互打，席 0／席 1 | 45.3%／45.0% | 29.1%／26.7% |
| 对外，两席 | 3,713/8,344（44.5%） | 3,065/10,545（29.1%） |

互打两列各覆盖全部 110 张图，对外两列分别覆盖 1,199 和 1,204 张图，各涉及 81 个对手名字。告警预示了可兑现货物的多少；状态、路线与敌情由选手自己选择，两组差不能直接用作强迫返程的收益。继续采、迂回、避敌都可能出现在距离未缩短组。下列才是下一步实际发生的两个决策，来自同图同席。[全量分母](other_timing.json)

这两个案例按固定顺序在同一张互打图上各取一种已发生的行动。十步后未存入的货依然在工人身上，不能判为丢失；第二例入账由逐笔资金记录核实。模型训练可同时预测十步回款、工人存活、期末携货三种结果。在同一根局面比较“再采一拍”和“现在走”对整局存入、损失与胜负的影响，才能确定 Sapling 要改哪种选择。这份分析没有跑替代动作或改动参数。[该局逐局账](economy_games/04e2bd65b4b6e81980135e06cfadd7b0-1.md) · [两条逐时轨迹](other_timing.json)
