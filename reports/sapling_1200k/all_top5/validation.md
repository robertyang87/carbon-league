### 地图证据与可复现性

用仓内 `FastCarbon.reset(seed=回放所载的 randomSeed)` 生成初盘，命中 **0/1,324**。仓内原版 `populate_board` 创建了以 `randomSeed` 初始化的局部生成器，生成地形两处实际调用使用全局 `np.random`。天梯落盘的 225 格 `full_carbon` 可以准确重演这批轨迹；现有档案无法确定远端每局初始化时的全局随机数状态。

每局证据保存两种初盘摘要。`initial_map_sha256` 是初始全碳数组按仓内 JSON 规范编码得到的哈希。`initial_terrain_u8_sha256` 是 `full_carbon[0:225]` 按回放展开顺序逐格取一个无符号字节再算 SHA-256。后者严格检查值为 0 至 255 的有限整数，允许等值的整数和浮点表示。该字段用于跨编码识别同一棋盘。棋盘索引 gzip 的 SHA-256 为 `c70e0f7953ac7b4adc04e1a768b9a72c69f6057d6eca8f5f8cb58ffb9072f486`。上次单独研究的 26 张实际地图全在索引中。

新正式考试协议 `sapling-90-and-income/4` 将这 1,324 局的实际棋盘和种子自动纳入排除集。抽签时重建全部预定本地地图。遇到已见种子、已见棋盘或批内重复棋盘时，整次抽签退役。每个席位执行前在裁判中记录实际初盘 225 格，验收时比对冻结棋盘、该席原始记录、逐局汇总和独立动作重放起点。主考目标仍为 100 张全新地图换席跑 200 局，全体观察胜率至少 90%，官方平均分差至少 +500。

此前的录像保留历史格式。可在固定版本 `506b2045` 还原旧协议及其判据，新版的旧格式读取仍能重演既有动作和终局。老录像不具备的初盘见证继续保留为缺项。本次全部测试使用合成局面或旧开发地图，没有生成正式考试地图。

### 复核入口

- [逐局核验索引](validation_games.jsonl.gz) 含 1,324 条 JSON Lines。按 `id` 关联[总清单](manifest.json)中的原始回放位置。每条保存两席名称、官方分、回放规范与压缩哈希、初盘指纹、帧数、完整匹配推进数、灭绝/故障座序与差异位置。
- [全量棋盘台账](validation_maps.jsonl.gz) 提供比赛 ID、所载种子及确实见过的初盘字节指纹。[机器摘要](validation.json) 给出总数、冻结清单及代码 SHA-256 和独立原版四局的 ID 与步数。
- [核验程序](validation.py) 可从仓库归档在新路径执行。已存在缓存时运行第二条即可。归档恢复模式直接校验清单中的源哈希，无需下载时临时产生的收据。
- [四项回放对照](validation_tests.py) 覆盖未改动原件、植入可见碳/步号/计分差异、改写早期命令和合成平台超时。[终考地图门测试](../test_map_identity.py) 覆盖数值等价、同盘异种、同批重复、有效新盘、双方录制和旧录像的读取边界。
