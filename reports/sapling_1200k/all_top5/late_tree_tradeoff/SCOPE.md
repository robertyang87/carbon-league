# 晚局树投资与回库通道的观测口径

冻结至 `41e4177e`。主样本为该补编中 Master6 出战的全部地图。按此前 307 张 Master6 地图中是否出现过对手的完整版本名分层。历史败例对照收全此前所有落败地图，在同一对手完整版本名与 Master6 物理席的组合里，按比赛 ID 字典序取最小的一张胜局作参照。对手身份匹配仅用作分层，从不进入局面分数。此处已知赛果，不能当作盲测。

检验一个可在动作前计算的量。在剩余 1–50 次联合推进时，用四个可见邻格碳量合计乘规则的树吸收率，再乘仍可收息的推进次数。新种树扣首步，夺树另受旧树年龄限制。与实际公开买价比较，小于买价记为覆盖不足。分别列种树、夺树、剩余 1–10、11–30、31–50 步；这项静态估计不包括工人被吸走的货、碰撞、竞争树分流、再生与被夺。结果用实际每笔连续持有期间的吸收（含吸敌方工货）与碰撞现金扣实付款；反例全部计入。

第二个并存机会是运输：以载货至少100、离任一己方基地不超过4格，且本方种树工所在格与该采集工恰好相邻、走入种树工当前位置能缩短到基地的距离，定义为回库通道。符合者只选当前货最多的一名（同货按工号）。用实际行动区分种植工付费、让出格子和未付未动。分开记采集工是否实际进入该格、是否在其后五次推进内将货存入己方基地。移动的目的不能从录像确定。在相邻区域观察到回款也不能当作移动的额外收益。若交叉状态在新图上没有足量动作或两类行动，将保留空分母。
