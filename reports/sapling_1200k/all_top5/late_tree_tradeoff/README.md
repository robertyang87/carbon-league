## 规则与可见条件

工人能移动或停留；种树工停在符合条件的格子才会付款。已有树在吸收时直接把现金记入现任树主账户。老树枯死时在原格产生地碳，正常终局按账户现金结算。**没有主动卖树指令，也没有终局残值**。最后一次推进时新种的树当步不能收息，之后也没有下一步；同期夺取已有树仍可能当步收到吸收收入。15 张新图最后一次推进共有 13 个付得起的自种机会，Master6 一笔都没买。[工人指令](../../../../code/env_src/carbon_challenge-master/zerosum_env/envs/carbon/helpers.py#L232) · [枯树转地碳](../../../../code/env_src/carbon_challenge-master/zerosum_env/envs/carbon/helpers.py#L1019) · [新树当步不吸收](../../../../code/env_src/carbon_challenge-master/zerosum_env/envs/carbon/helpers.py#L1163) · [官方分数](../../../../code/env_src/carbon_challenge-master/zerosum_env/envs/carbon/carbon.py#L169)

对当前买得起、可以停留付款的格子，取四个相邻无树格的可见地碳合计，乘本局吸收率 0.0375，再乘剩余可计息步数。新树扣去出生当步；夺树还受原树剩余寿命限制。与当时实际公开买价比较。计算只需要本席可见信息。它把现在的地碳当作之后每一步的水平，未预测地碳耗减与再生、同格争夺、其他树分流、工人带货经过或树被抢走，因而不能充当收益上界。算不够时优先重审继续种树是否合算；有敌方重载路线时，须单算可能吸到的货。[固定口径](SCOPE.md)
