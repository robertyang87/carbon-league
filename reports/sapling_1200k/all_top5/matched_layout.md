# 第 60 步的布局优势，换成相同对手后还剩多少

**对外场“工人多的一方赢了 81.25%”在同对手内消失。** 第 60 步双方现金差不超过 300、工人数不同的 272 张对外地图里，工人多方赢了 221 张。能找到「同一前五选手遇到同一对手，既有工人多的时候、也有少的时候」的只有 12 组、36 张。先限到这些图，多工方只赢 21/36；再给每组两种方向同等权重，折算为 **48.84%**。这批样本无法支持给“多一个工人”加固定策略奖励。[逐组四格计数、地图 ID 与反例](matched_layout.json)

| 对局 / 第 60 步因素 | 全部有方向地图：较多方实际胜分 | 限双向组后，同一批图的原始胜分 | 同对手、两种方向平衡后 | 焦点选手从落后到领先时的组内胜分差 |
|---|---:|---:|---:|---:|
| 前五对外 / 工人数 | 81.25%（272 图） | 58.33%（12 组，36 图） | 48.84% | −2.31 个百分点 |
| 前五对外 / 树的未来 30 步可用量 | 68.99%（903 图） | 60.82%（125 组，638 图） | 54.74% | +9.48 个百分点 |
| 前五互打 / 工人数 | 73.33%（45 图） | 70.27%（7 组，37 图） | 65.38% | +30.77 个百分点 |
| 前五互打 / 树的未来 30 步可用量 | 61.54%（91 图） | 61.36%（8 组，88 图） | 57.40% | +14.79 个百分点 |

**怎样读后两列。** 每张地图只计一次。对外取前五一方，互打取冻结榜单中排名靠前的一方为焦点。先在同一焦点选手与同一对手的组里，用“焦点该因素较多时的胜分”减“较少时的胜分”，再按该组纳入的地图数加权。胜、平、负分别记 1、0.5、0。表中的平衡值等于 50% 加上差值的一半，是两种方向等权后的描述量，不是又打了一场考试。权重改为每个对阵等权或按组内两方向的有效重叠量后，对外工人的差值分别为 −2.78、−3.21 个百分点，对外树量分别为 +7.90、+9.57 个百分点。[可复算脚本](matched_layout.py)

固定快照为 T60。工人数含采集工与种植工。每棵树按 `max(0, min(30, 寿命上限－当前树龄))` 相加；该量假设树仍由当前玩家持有，不含未来易手、吸收速度或收益。对外 1,214 局中，2 局已提前结束，306 局现金不够接近；其余 906 局中工人数相同的有 634 局，树量相同的有 3 局。互打 110 局中 19 局现金差超界，91 局中工人数相同 46 局，树量相同 0 局。同值不分“较多方”。地图种子唯一，反方向才可比的对阵是两个因素各自筛选的。[快照定义与全量原始关系](layout.py) · [完整数据清单](manifest.json)

## 同一个对手，也会有相反结局

每行给出同一焦点策略对同一对手在两张不同地图上的案例，并非同一地图的替代行动。两局均满足现金差限制。每个因素／群体预先用同一展示规则，从既出现“较多却输”也出现“较少却赢”的组里取地图最多的组，两个方向各取字典序最小的赛事 ID。逐席现金、完整 ID 和最终双分均可从 JSON 定位。[逐局案例](matched_layout.json)

对外多工结论在 12 组中有 2 组正、7 组持平、3 组负；11 组的少数方向只有一图。互打工人的 7 组全部只有一图落在少数方向。两组均不足以把百分数当作稳定胜率。对外树量覆盖更充分，逐次删去任一对阵后的组内差值仍为 +8.48 至 +9.96 个百分点，但地图、兵种、席位、实际现金差、控制区域等仍可同时影响资产和胜负。此处衡量相同对手里的关联，不能据此推断某一手招人或种树的增益，也不能直接外推到 Sapling 对 Master3s2。
