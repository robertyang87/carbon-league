## 身份、规则和统计口径

- 考官：原始公开源码 `data/master3s2_source.py`，MD5 `57f9a594cce4f2ec9e3573d8d9d26ca1`；直接 `agent` 入口，注册wrapper未使用。保持 `_TEMP=1.0`、`_SEED=None`、原始搜索配置和规则层。
- 候选：官方 `cnet2_pack` 的实际 int8 单文件，teacher=2，五项可选守卫全关。两模型同一打包源码；各工件哈希见[原始JSON](external_3s2.json)。
- 地图：620050000、620050001，各候选双席。考官内部随机不由地图seed控制；搜索又依赖实时时预算，**不作逐seed配对收益推断**。
- 达到状态299，或按 `eval_v53._extinct` 任一方灭绝，才结束。灭绝方得分为 `t−301`；灭绝终局的幸存者保留最后一次推进前现金；正常299步结束采用最后现金。下表把官方得分和最后现金分列。
- t60/t100/t200仅取真实到达该状态的观测；提前终止以“未到达”呈现，绝不向后填充。正常本方基地交付与树吸收收入单列；树吸收收入含地面吸收与敌方载货抽取，不含额外碰撞转账，也不是扣除成本后的利润。
- NumPy BLAS为1线程，保留3s2源码明确设置的Torch 2线程；当前资源口径不是平台1.5核认证。

## 复跑与解释边界

使用含NumPy、Torch及threadpoolctl的环境；提供与JSON中SHA256一致的120万权重，在其他计时实验明确结束后执行：

```sh
python reports/sapling_1200k/external_3s2.py \
  --weights120 PATH_TO_TRAINED_NPZ \
  --out reports/sapling_1200k/external_3s2_new_run.json \
  --timing-release-note 'independent timing completed before this run'
```

脚本拒绝覆盖已有证据。程序步骤可复跑，但原考官保留随机采样及实时时预算，复跑不保证相同轨迹或分数。

本小场可检查退化、存活时长和终局计分现象；样本量与地图覆盖不支持正式强度裁定，也不支持用不同终止时长的总分差替代等步数生产比较。应将本页作为正式1,000局结果的机制补充，不能称“翻案”。
