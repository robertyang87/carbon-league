# 双网的末段回城实验

亲本为 it50（75%）与 Sapling cash V3（25%）共用前缀的双网。原封包 SHA-256 为 `b54cc51f4109f19f4a7b508eafc9cf04a28b7e295a9f442c5208f0d33f10a9ca`。候选权重逐字沿用亲本，另行生成的单文件为 6,075,136 字节，SHA-256 为 `8f15e40b6b4468ed656ef990e611a45f7a23659e90af16744b6c3aaae09d563c`。

## 从哪个动作开始改

原双网对同一单位依次计算两个策略的 logits，在同一合法前缀上相加，选出动作，再送给下一个单位。候选在选出混合贪心动作后、更新共享前缀前检查载货采集工。借用了仓内 `cnet2_agent.make_hook` 的步限触发思路，并按两项条件进一步收窄。

- 只处理载货至少 30、通往己方最近基地的距离为正、剩余步数处于“距离”到“距离加一”的采集工。若照原动作走一步后，按最短几何路线仍能赶上，则继续原动作。计时按真实可再推进次数 `299 - step`。
- 从己方基地做反向宽度优先搜索，排除敌方基地和当前可被较轻或等重敌方采集工够到的格。第一步还须合法、未被已解码友军预定，且余下安全路长能按时走完。符合的第一步按两网原 logits 排序。安全区域以**本步可见**敌人为依据，以后每回合重新规划。
- 后续单位全部沿新前缀重解码。若引入新的友军碰撞（含本步招出的工人）、改动的采集工与友军撞车，或使其他采集工走入原本没有的敌方直接威胁/敌方基地，整步退回亲本动作。归属计数记录网络在当时共享前缀上的选择，额外的 `_RETURN_COUNTS` 与 `_RETURN_LAST` 记录规则实际改动。
- 设模块变量 `_RETURN_ENABLED=False` 可走原解码路径，保留两网权重、特征历史和统计口径。构造测试用真实封包对比两席各十种情形，关闭后 20/20 根的动作字典和网络归属计数全部与亲本相同。控制策略下，两席最后一步原地不动的载货工均被改成回家，模拟器确实各存入 100。另覆盖死路、截止后、来不及、原行动能及时回、跨席方向、招工占位等反例。

在原双网对 Master3s2 的真实两图双席开发记录中，有一局终点持货 262.58、分差 −214.12，另三局分别持货 29.48、49.03、15.41，分差 −119.20、−1,284.13、−340.33。终点持货给出了“仅补记现存货物”这种反事实的金额，实际能否安全跑回仍须看路线和对手。

## 独立练习结论

**保留亲本，本候选停止升级。** 在四张预先固定的独立地图（620188310 至 620188313）上打两个席位，同地图同席逐步比较亲本与候选，按地图交替使用 `policy_v0_8` 和 `policy_v0_5`。两版共 16 盘，全部到 299 步。八组完整动作轨迹与终局状态哈希全部一致，分差、常规实际存入、末 15 步实际存入和终点未兑载货的八组配对差都为零。

| 覆盖与可干预量 | 观测 |
|---|---:|
| 最后 15 步受检的独立游戏根 | 120 |
| 载货至少 30 且到家余量在 0 至 1 步的单位决策 | 24 |
| 亲本走完当前步，仍可按几何最短路线及时到家 | 24 |
| 错过当前步便来不及回家的原动作 | 0 |
| 实际改变的根 | 0 |
| 亲本各局末 15 步的真实常规存入 | 575.28 至 1,068.57 |
| 各局终点在途载货 | 0 至 44.39 |

在这批局面内，窄规则没有机会发挥。构造正例证明它能在特定失误下兑现载货，不能据此推算实战得分。是否有更早出发才能避开的拦截、途中撞失的载货、或压迫下被堵死的基地，应在实际出现该现象的轨迹上另行归因。
