## 实际训练的版本

先前冻结的 101 场中，1 场已被 V1 数据使用，剔除后按对阵、整局和地图种子隔离为 79 场训练、21 场验证。十种对阵在两个集合中各有代表。两组罕见对阵各只能分 1 场训练和 1 场验证。更新后发现的 7 场另外封存，未用于训练或选权重。此前研究人员读过原有回放，后 7 场提供另一组样本。公开观赛恢复件与历史 Git 件均已归档，可离线复跑。[训练登记](top5_h2h_data.json) · [新增 7 场身份](../../data/sapling_top5_h2h_corpus/later7.json)

从已实战测过的 Sapling elite_bc_v1 出发，网络保持 1,206,476 个参数。模型看到该席当时的地碳、工人/树、载货、现金、历史和本方解码前缀。训练时对三类机会下的专家动作增加 1.5 倍损失权重：种树工可负担夺树成本且有目标，载货工受到碰撞威胁且能脱身，采集工够得到敌方种树工威胁的己树。机会由行动前公开局势识别，监督的是专家实际作出的完整指令，即使高手在该步放弃进攻、选择绕开也照常学习。攻防以外的经济选择继续参加训练，打包时没有“见树就冲”或“遇敌就撤”的动作覆盖。追击猎手是本轮另做的回放统计，本版专门加权的进攻动作限于种树工袭树。

79 场双席数据包含 47,168 个局面，501,325 个有效指令。固定 256 次更新、批大小 24，从 79 场都抽到了数据，共见到 5,747 个不同局面。训练在本地两核 CPU 用时约 156 秒。部分验证指标经过去除强制基地动作的独立复核。[训练程序](../../code/sapling_h2h_bc.py) · [冻结检查点](../../data/weights/sapling_1200k/top5_h2h_v2.npz) · [单文件 int8 考生](../../data/weights/sapling_1200k/top5_h2h_v2_agent.py) · [训练回执](top5_h2h_v2_training.json)

## 模仿的改进落在哪里

| 留出集及口径 | 上一版 V1 | 前五互打 V2 |
|---|---:|---:|
| 21 场，袭树机会下与高手实际指令一致 | 61.17% | 64.22% |
| 21 场，防守机会下与高手实际指令一致 | 58.58% | 62.17% |
| 21 场，所有确有选择的槽，含日常经营 | 57.42% | 61.99% |
| 新增 7 场，袭树机会 | 81 / 148 | 88 / 148 |
| 新增 7 场，防守机会 | 161 / 272 | 175 / 272 |
| 新增 7 场，全部可选指令 | 1,498 / 2,569 | 1,635 / 2,569 |

新增 7 场两席各取全程均匀分布的 20 个决策时刻。148 次袭树机会里，高手实际进树格或留在树上的有 69 次，V2 预测 87 次。其中高手放弃而模型选择出手有 26 次，高手出手而模型放弃有 8 次。进入目标格也还需要后续有资金、能停留，才可能真正夺树。这给下轮训练指明了“什么时候应放弃”这一类反例。[独立 7 场与动作明细](h2h_late_holdout.json)

**额外战术加权的作用很小。** 将倍率从 1.5 改为 1，保留相同训练集、初始化、抽样序列、批大小和更新数，再训一次。21 局所有可选动作的一致率为 61.98%，与加权版的 61.99% 接近。攻、守在对照版上分别是 64.08% 和 61.79%。两臂共同变化包括继续训练和更换示范集，两者的贡献仍不能单独拆分。以本次单个训练种子计，额外加权带来的差为进攻 +0.14 个百分点、防守约 +0.39 个百分点。下一笔预算优先补稀有局势和收益标签。[同批同剂量对照](top5_h2h_weight_ablation.json)

## 下一批数据该补什么

1. 从学生自己的新训练局面取样。分别采“有货且有安全返航路径”“有货但轻载敌工堵路”“资金付不起再招一工”“敌树可进但守军能赶到”和这些局势的普通对照。保持对手的状态与近期行动可见，用多步续弈比较现在出手、等待、绕路和回家对交付、丢货、树权及终局 U 的影响。不要把所有逼近敌树的动作都标为成功。在已封存的考试和留出比赛之外生成这批标签。
2. 从五家对其他风格的比赛中补稀有战例。原冻结库共有 1,056 局至少一家前五出战，其中 101 局是互打，其余 955 局只占一侧。先按触发局面和贡献比赛数选，保留出击成功、出击落空、主动放弃和无人威胁四类。整局隔离并按各类自然出现频率另行评估，免得训练后遇敌就冲。
3. 先看学生在独立新地图能否两席都从采收走到交付，付出多少死亡货物和机会成本，再以冻结考官、固定负载的整局分差和双方官方得分检验。若动作模仿继续提高、同一步的本方现金仍长期近零，应把新增算力用于学生自己走出的失败局面和多步动作价值，避免继续放大同分布模仿。

## 离线恢复与复跑

仓内新增 21 份之前缺少的原件，另 87 份复用既有 Git 对象。恢复后 108 场标准化回放内容全部核合，其中 10 份历史 Git 压缩件的序列化与当时的本地缓存不同。用恢复出的原件从空目录重建全部 100 场训练/验证分片，所得清单与训练所用清单逐字相同，含各数据和掩码文件哈希，SHA-256 前缀为 `566bd7437a99`。以下命令从仓库根目录执行，以新目录保存研究产物。

```bash
python code/materialize_top5_h2h.py /tmp/sapling-top5-raw
python code/build_sapling_top5_h2h.py --replays /tmp/sapling-top5-raw/frozen101 \
  --out /tmp/sapling-h2h-data --workers 2
python code/sapling_h2h_bc.py --manifest /tmp/sapling-h2h-data/manifest.json \
  --init data/weights/sapling_1200k/elite_bc_v1.npz --out /tmp/sapling-h2h.npz \
  --receipt /tmp/sapling-h2h-train.json --device cpu
python reports/sapling_1200k/h2h_late_holdout.py --raw-dir /tmp/sapling-top5-raw/later7 \
  --out /tmp/sapling-later7.json
python reports/sapling_1200k/top5_h2h_exam.py --arm top5_h2h_v2 \
  --out /tmp/sapling-h2h-direct.json
```

最后两条命令默认核验仓内冻结权重。对照计时可在评估命令上加相同的 `--cpus` 两个逻辑核心号。研究对局不启动训练机或天梯提交。
