# Sapling 提前三至五步拦截重载采集工

在八局 Sapling 对仓内原版 Master3s2 的历史轨迹上，可以从相距至少三格的位置提前切入，抢到原动作拿不到的货。但按最短路猜敌人返航，出手过多，己方损失的运输和采集机会超过收益。从天梯回放学习敌人三至五步后的落点，把出手率从 75.5% 压到 3.3%，在同一批历史根上改善了持货差。最终开发对局另列。抢到、保住、转成现金是三个不同结果。

## 开发数据与评分

- Sapling 样本取已完成的 V5 四局、interception 两局、tree-raid 两局。合计八局、三张地图。逐局验证考官、双方记录、官方终局分数及末态 SHA-256。每一个还可推进五步的根都纳入，提前灭绝那局只有 33 个可评根。重复根和同图不同候选高度相关。
- 天梯验证取既有分割的 16 局 Top5 对打，每局双席，按种子模五选起点，每五步取一根，1,888 个座位根。模拟器从第零步的权威地图启动，逐步比对双方玩家、全图碳、树与步数。训练的 32 张地图与这 16 张图互斥。行动预测器只接触当时座位可见的单位、基地、货量和前一帧单位状态。所有用于这里的地图都属于开发数据。
- 选择己方载货至多 15 的采集工，对手至少携 50，初距 3–10，目标离自己的最近基地 2–9。沿公开当前局面选一个对手、一名拦截者和一个 3–5 步交点。排除敌人基地，第一步避开队友和基地招募意图，必须实际改变根步命令。原动作与改动作由相同模拟器推进五步。
- 对手及其他单位延用记录动作，失去身份的后续命令逐条计数，严格子集剔除这类根。双方看到新局面可能改策，即使未来所有命令仍有合法身份，这种固定命令模拟也不能代替真身实战。每个根单独起算，分支收益总量不能相加当成一局的经济收益。现金差为本方现金改变量减对方，持货差同理。携货未兑现，表内分别列出。

落点表从 32 局获得 22,494 个敌方载货工根。学习的目标同时覆盖停留、转向、移动与卸货/消失。把位移转到朝最近基地的坐标系，按上一步方向、货量、与基地的距离分组，再以是否正采集、附近轻载敌人和另一基地的距离做细分，细分稀疏时退回粗分布。第一道 35% 门是事先定的，见到零触发后才尝试 15% 门，因此后者只作探索性结论。

事后对照知道对手未来落在哪里，不能部署，也涵盖一些几何预测不会提名的根。公开预测对落点和到达时刻同时猜对的次数很少，拦截也可能发生在路线相交的中途。例如地图 620106811、席零、第 91 步，预判三步后到 28 号格，方向连走 UP，实际在途中与带 407.80 碳的对手相遇；原动作收到 0，五步末这 407.80 仍在工人身上。

对探索性方案，八局中 70 次出手有 27 次遇到失效的后续命令；保留另外 43 次仍有 3 次指定目标捕获，现金差 −90、持货差 +1,248。天梯 75 次出手中的 45 次有全程有效命令，4 次捕获，现金差 −3、持货差 +1,953。八局和天梯的探索性捕获中，原动作均未从同一名目标取得该笔货。阶段内八局自己交付总额变化 −92.44、对方 −215.50，说明空追和耽误交货仍需逐局复核。

## 冻结的比赛实现

候选以原版 Sapling V5 1,206,476 参数网络产生每个单位的原动作。公开预测表只允许改一名轻载采集工。追击时每步重看目标货量、双方当前位置、剩余步数、基地与友方下一步的占位，再决定是否继续；目标消失、已卸货、追不上或同伴挡路时交还网络。最后不足五步不发起新追击。比赛包 1,712,059 字节，SHA-256 为 `5e03ebaf14b243570b7fb381c9ae6b8ee8984c453e6fa59868a401aa149e94b0`。

在八局的 2,098 个可评根上，单文件包与研究版逐项对齐起步的目标、行动、概率和交点。再从 70 个实际触发根上按部署逻辑每步重新观察，15 次取得指定目标货物，五步内兑现 0，仍在己方 3,556。剩余命令全部仍有效的 46 个根内，实际夺货 2 次、仍携 595。逐根证据归档在本目录 `ambush5_*` 文件。天梯证据与历史档案根不会进入正式地图池。

逐步重跑候选网络与拦截层，598 份输出都和比赛原始命令相同。两席各出发 9 趟，改令 16 与 20 步。18 趟目标实收为 0，随后的变现也为 0。对 36 个改动根分别固定对手当步真命令、恢复我方网络原动作，双方当步货物转移差也都是 0。两局最大的单步敌方现金优势增量为第 296 步 +524.45 与第 198 步 +485.20；向前各追五步，这两个窗口都没有拦截层在活动。

**失效发生在接触前。** 12 趟追到相距一格，10 趟我方按时到了选定格；对手按时到同一格为 0。另有 5 趟对手在窗口内确实到过所选格，但时间不同。例如席零第 53 步开始，对手带 174.67，从 43 号格出发，第 55 帧经过 42；我方第 56 帧才到 42，对手已到 41。18 趟中，仅 3 个目标在随后五步进自己的基地。其余多数不能视作被成功阻止交货。

针对这 18 趟，再从出发后一至五步的实际轨迹取所有邻近根。47 个“我方仍较轻、对手仍携至少 50、距离不超过两格”的根里，对手当步实际落点全部在追兵一步可达集合之外。逐个枚举追兵当步动作，即便事先知晓对手当步真实命令，额外实收也为 0。这解释了同一地图上，预录动作的五步模拟与会临场行动的对手差别有多大。一次换席开发赛不足以证明对手总能逃脱，但已足以撤下当前追击器，保留单文件包作为可复验的负例，不进入正式考试。

逐局原始命令与正式分数在 [ambush5_dev](ambush5_dev/)，详细追击轨迹在 [ambush5_live.json](ambush5_live.json)，47 个接触根的动作与真实对手落点在 [ambush5_contact.json](ambush5_contact.json)。

## 复现

在仓库根目录运行以下命令。回放目录为已经复原的 101 局天梯存档。两个大文件使用 gzip 压缩，可直接用 Python 的 gzip 模块读 JSON。稀疏表按训练清单重建，训练未使用终局分数或任何正式地图。

```bash
r=reports/sapling_1200k
python "$r/ambush5_probe.py" --out "$r/ambush5_results.json.gz"
python "$r/ambush5_top5.py" --replays "$TOP5_REPLAYS" --out "$r/ambush5_top5_results.json.gz"
python "$r/ambush5_learned.py" --replays "$TOP5_REPLAYS" --out "$r/ambush5_learned_results.json"
python "$r/ambush5_learned.py" --exploratory --replays "$TOP5_REPLAYS" --out "$r/ambush5_exploratory_results.json"
python "$r/ambush5_build.py" --replays "$TOP5_REPLAYS"
python "$r/ambush5_replay.py" --out "$r/ambush5_pack_parity.json"
python "$r/ambush5_replan_check.py" --out "$r/ambush5_replan_check.json"
```
