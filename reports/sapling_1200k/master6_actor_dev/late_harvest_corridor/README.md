# 还剩 5–12 拍时，多采几拍再回库是否更赚钱

**可撤销路线没有通过事前收益门槛。** 在四张独立于本构造诊断图的开发地图上，8 局换席全部能发出合法改令。但对三种会根据新盘面重新行动的对手，焦点工最后真正入库的新采货分别比原 Sapling 少 **7.74、9.46、5.48** 每局；原来带在身上的本金入库差都是 0。计双方终局收益，整队分差每局分别少 **7.05、10.80、14.47**。该构造没有占用完整原版 Master3s2 的新考位。[裁定和按图逐席数据](evaluation.json) · [事前协议](protocol.json)

## 为什么值得核这一项

前一项末两拍试验已经用完整原版的真实末拍确认，站在己库旁的工人安全多采一拍能小幅增收，8 图 16 席平均 +5.24。本项检查把时间拉长后，能否去更富的格、连续采 1–3 拍，并在敌人靠近时改道返库。剩余时间变长后，原网自己的下一段行程也有价值，会在回程中发现另一块好矿。[前一项真实原版末拍](../endgame_queue_dev/native_official.json)

原网每拍正常推理。候选只在已有货、原令朝己库靠近的采集工上做选择，比较当前格与相邻、在本席当前或过去两拍看见的资源。过时碳值每拍乘 0.7。寻路检查两个基地、真实队友提交的首拍落点、轻载敌工能到的格、敌树抽税及其寿命、剩余步数和距离。入场至少留一拍余量，额外预估净值至少 12。运行中若留守位置变危险、采收不抵延误或最初路线不可行，候选可提前返航或交还父网。每局最多发起一次。用相同根还做了一个只改首令、随即交还父网的对照。[选路与撤销逻辑](policy.py) · [敌工逼近、树税和信息隔离的构造测试](test_policy.py)

## 对手、地图与实收

使用 16 份已有的完整原版 Master3s2 对 `9c54df17` 父包的双方动作带。地图与上一项末两拍试验亦不重叠。诊断四图为 621481220/221、621495120/121；评价四图为 621478120/121、621497120/121。8 局评价原录均负，平均分差 −1,384.78。逐帧重放 4,784 次联合推进，核对官方盘面、现金、实体、席位和终分。公开输入与仅供核分的完整盘面/原版动作分开存放。[数据来源及哈希](source_registry.json) · [数据验收](data_receipt.json)

每局在还剩 12 至 5 拍的 8 个时点都问一次策略，因此共有 128 个候选时点。诊断 64 根中 20 根有改令、7/8 局实际发起；评价 64 根中 24 根有改令、8/8 局发起。逐局只取最早真改令根。其余同局机会不计作独立样本。评价 8 局首次改令全部为在原地停采，诊断 7 局中 1 局会先向相邻可见碳点绕一步。实际被选择的评价根，平均预期毛采收 23.33。按每拍采率 0.3、格上碳至多 100、计划最多 3 次采集，单次任务直接新采的宽松上限为 90；若地块连续耗竭且无外部补碳，满格上限为 65.70。这两项都未减原网本来就能采到的钱。[逐根清单](launch_scan.json.gz) · [公开可达量及上限](potential.json.gz)

首个改变同时执行原考官当拍实令。之后每拍，从各自的新公开观察重新运行真实父网，或运行父网加可撤销路线。对手采用三个事前规定的公开模型分别响应。逐个回合用官方规则和 FastCarbon 核现有货的下落、根后新增采集、税、碰撞转移及最终到账；同库撞死后票款流入己库仍计己方。15 个实际根 × 3 种对手 × 3 个本方策略，共 135 个分支、1,404 个核过的推进；同一根的三种对手不能当作三局独立证据。这里的终局分差只覆盖这些响应模型。对应的原录来自完整原版，分岔后原版没有出新招。[复算程序](evaluate.py) · [逐拍分支](branches/)
