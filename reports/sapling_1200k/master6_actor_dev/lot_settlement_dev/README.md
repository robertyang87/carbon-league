# Sapling 携货本金多久能到账

六张训练图、双方换席，合计 13,771 个己方采集工正载决策。预测器逐笔追踪当时已有的货，直到入己方现金、转手后入库、被对手收走、缴树税、落地或损耗、或仍留在终局库存。后续新增采集单独核算。同一运货过程会贡献多次决策样本。训练和留出按整张真实初盘隔离，考官均为原版 Master3s2。预测时只读取己席可见观察、过去状态和拟执行的己方首令。[数据和规则](protocol.json) · [本金追踪](lots.py) · [训练地图](train_sources.json) · [四张留图](held_maps_sources.json)

四张留图、八场共 8,993 个决策。4,036 个在第十步仍有未结本金。在这些未结本金中，按金额计算最终入己方现金的比例，逐图求值再平均为 **98.98%**。三笔旧反例第十步均无实收，第 17、13、16 步分别入库 120.00、171.58、248.08。把旧头的十步金额当终局实收，会在整份留图上平均低估 45.34。该诊断沿用过往开发地图，包括这三个已研究的根。[逐图与逐根预测](predictive_evaluation.json)

|---|---:|---:|---:|
| 十步累计已入己方现金的本金 MAE | 22.39 | 25.05 | 25.33 |

预测所有现有货都能回库的终局 MAE 仅 **1.15**。在确实损失超过 1% 本金的观察点，平均实际损失 31.30%，新头平均预计 3.97%。按预测风险取各图最高一成，只覆盖真实损失本金的 22.51%。训练目标和评估以决策点为单位，真实现金收益汇总须按原局独立记账。[基线与风险分层](full_recovery_diagnostic.json)

## 用本金额度选动作的实测

在与以上十张图均无交集的六张旧开发图上，找到 15 对现成的完整原版续局，共八个不同的决策根。每对只替换该采集工的一个合法首令，然后双方重新决策到正式终局。同一根的不同随机响应先平均，各图内再按根平均。[入选及排除的旧分支](branch_manifest.json) · [出手前冻结的打分](branch_predictions.json) · [两臂逐笔实收及官方终分](branch_transfer.json)

|---|---:|---:|---:|
| 620224311 席 1，第 290 步 | +4.58 | −16.41 | −44.91 |

| 621458920 席 0，第 231 步 | +0.15 | −24.25 | −693.78 |

其余五根，两臂都兑现相同本金。跟随预测的选令相对保留原令，六图等权每根少收 **5.54**。这八个根来自过往特定开发策略与战术，不能用作总体胜率样本。本轮保留模型作到账时间诊断，Sapling 现役选令保持原样。

## 复核与使用

[单文件预测器](lot_forecast.py) 大小 355,289 字节，接口为 `forecast(observation, history, worker_uid, planned_action=None, friendly_orders=None)`。未提供己方首令时使用状态视图。预测头随 [权重和模型摘要](release.json) 核验。[结果收据与工件清单](archive_receipt.json)

在本目录运行以下指令，可从已入仓的源对局重建只有本地缓存的训练分片，复查预测、并沿已记录的真实两臂动作核到账目。

```sh
python -m unittest -v test_head test_lots
python data.py train
python data.py held_maps
python evaluate.py
python diagnose.py
python transfer.py evaluate
python build.py
```
