## 与八步搜索的关系

H8 的 `7cbc89a2` 把局部搜索接在 `91e10203` 上；`91e10203` 的主解码又沿用 `85c47d5d`，只调整了首拍。H8 相对其直接父代在 1,794 个相同历史局面上改过 5 道整队命令。单改首拍的四场原版对照 0 胜，平均 +24.46，两张图的方向相反。若真正要量 H8 的附加贡献，直接父代应为 91e。这里比较的是两个有不同学生权重的包 `85c` 与在考的 `c5`。两类差异的分母和对照均已署名。[H8 入口验证](../README.md) · [两种首拍的真身对照](../../opening_pair_dev/RESULTS.md)
