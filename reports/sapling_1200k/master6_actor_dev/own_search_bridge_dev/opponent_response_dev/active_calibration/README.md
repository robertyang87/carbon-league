# 校准对手出动频率
冻结原版命令预测器。用原先六张训练地图上可选停留或出动的合法槽，估计一个停留分数偏移，使贪心预测的出动比例匹配真实出动比例。两个已检查过的行为留图和十六张已检查过的分支续局地图均只作回归诊断。先比较移动和招募的实际命中，再核四张历史留图上对应真实终分。此次不抽正式考卷。

六图共 34,351 个训练决策，其中实际出动 26,520 次，拟合出的停留分数偏移为 −0.43185。两张已曝光的行为留图上，8,678 次实际出动的正确预测从 5,331 升至 5,522；整队全中从 44/1,196 降至 42/1,196。[训练参数](fit.json) · [逐图评估](evaluation.json)

在四张已曝光的分支留图上，校准后的搜索相对固定父动作平均 +2.60 官方分；相对原有使用己方动作模型的八步搜索仍低 23.48 分。原版命令监督但未经校准的模型在同项相对父动作为 −20.35。三者选择的十六条分支均负，未新增整局原版胜场。保留现役包，正式考卷继续封存。[原版终局分支对账](terminal.json) · [逐根记录](roots.json.gz)
