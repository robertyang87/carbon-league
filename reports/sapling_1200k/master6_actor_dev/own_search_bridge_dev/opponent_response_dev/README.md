# 用原版 Master3s2 的实令训练 H8 的对手预测器

**在两张整图留出、双席合计 1,196 拍上，整队指令完全命中从 28 拍升到 44 拍，种植工从 993/1,967 升到 1,057/1,967。** 整队命中率仍只有 3.68%。当敌方重货工真的行动时，新模型更容易误判为停留。这项训练改善了部分对手预测；能否据此让 Sapling 选出更好的动作，另由配对续局的终分检验。[逐工全部命令](held_orders.json.gz) · [按图及角色指标](evaluation.json)

## 训练用什么

原 H8 用己方 Sapling 实令训练 1,530 参数的小网，然后让它同时扮演两方。新预测器有 **3,400 个参数**，仍为一层 tanh。标签换成完整原版 Master3s2（温度 1、原搜索时钟）在同一时刻提交的全部动作。两版的权重来源和职责已拆开。我方正式出令仍由 Echo4 和真实 Sapling 联合解码；模型的拟议替换点仅限 H8 的模拟敌方。[冻结方案](protocol.json) · [原 H8](../README.md)

- 训练六张早期已封存地图，每图两席，3,588 个真实联合回合。正常复原每步并验证官方回执、两队终分、敌方搜索配置和两席身份。另两张完整旧地图仅评分。两轮新开发场的全部种子与物理地形均被排除。第三份 64 根对照来自另外 16 张旧开发图，已有的真实应对分支都在选择之前签收。[实际来源、席位、分组和字节哈希](sources.json)
- 输入从 Sapling 席位当时的观察开始。过去可见的碳和当前公共单位、树、现金进入已有估计器，产生推测的敌方视角。训练时让旧预测器先出此前敌工的命令，以它自己猜出的目的地、占位、预算生成下一工的输入。原版同拍任何一个实令只参与标签。我方同拍行动、候选编号、源地图号未进入特征或选令。
- 训练包括 26,110 个采集工动作、6,640 个种植工动作及 1,441 个有可比选项的基地动作。另有 5,639 个基地仅有一个合法动作，96 个基地实令在预测出的前缀下不能表示；这些行均如数记账。留图打分保留所有在场单位，包括不出令的基地。固定 32 轮、种子 118063，Numpy 与 Torch 分数最大误差 2.63×10⁻⁶。[训练及复算](train.py) · [训练损失、排除及权重身份](fit.json) · [实际推理权重](opponent.npz)
- 在两张留图双席各取开局 40 拍，总计 160 拍，逐拍改写所有 Sapling 看不见的碳，再恢复真值推进。156 拍中敌方真实私有碳观测因此变化；160 拍的 Sapling 观察、影子编码和新模型命令逐项相同。由测试工具单独读取敌方私有观测，以证明扰动确实生效。[隔离收据](privacy.json) · [检查代码](privacy.py)

与先前工作相比，仓内的分桶预测使用其他策略家族的数据，已有的原版专项头只预测持货采集工。旧 H8 的目标覆盖全部角色，监督来自我方。此处复用了 H8 的特征、真实前缀和 NumPy 解码器，使原版实令可以按原有部署接口训练。[分桶预测](../../../../opponent_predictor_report.md) · [持货专项](../../opponent_cargo_calibration_dev/README.md) · [H8 旧标签](../bridge.py)

## 全席动作与真正出手的动作

此表从相同历史出发，两包各自把已经预测的动作送入后续工人的前缀，自由解码，不喂示范前缀。分母包括 NONE；非 NONE 列只要求当时实际采取移动或招募者，预测必须同时命中具体的方向或招募工种。

| 两图共同留出 | 全部机会数 | 原 H8 命中 | 新预测器命中 | 实际非 NONE 数 | 原 / 新命中非 NONE |
|---|---:|---:|---:|---:|---:|
| 全部单位和基地 | 13,291 | 9,295 | 9,511 | 8,678 | 5,412 / 5,331 |
| 采集工 | 8,932 | 6,139 | 6,277 | 6,708 | 4,467 / 4,352 |
| 种植工 | 1,967 | 993 | 1,057 | 1,741 | 896 / 949 |
| 基地 | 2,392 | 2,163 | 2,177 | 229 | 49 / 30 |
| 采集工携货至少 100 | 2,065 | 1,457 | 1,463 | 1,334 | 891 / 781 |
| 采集工带货且距自己最近基地至多 3 格 | 1,615 | 1,125 | 1,189 | 1,036 | 730 / 691 |
| 两格内有更重的 Sapling 采集工 | 2,080 | 1,445 | 1,484 | 1,651 | 1,152 / 1,175 |

新模型在 13,291 个槽上预测 NONE 共 5,139 次，旧版 4,558 次，原版实际停留或不招募 4,613 次。重载工真的行动时，命中少了 110 次；遇到更重的 Sapling 工人时多命中 23 次。种植工的提升同时覆盖全部槽和主动出手。整队准确的改善在两张图各为 +6、+10 拍。无论局面都出 NONE 的整队命中为 3/1,196。两张来源图有限，且相邻决策高度相关。[每张地图单独计数](evaluation.json)

为核验训练可复现性，再从头读取同一组签收动作带，写入独立的临时目录。两次产出的 NPZ 逐字节一致，逐轮训练损失及各角色保留行数也逐值相同。权重 SHA-256 为 `1af4840fad71259ac60e6ee70ea8d1021eae1a79b8be323b1c08df51d0cb82ac`。[第二次训练收据](reproduction.json) · [复现脚本](reproduce.py)

真实发生的 97 次招种植工，旧模型只命中 3 次，新模型为 0 次。重载工留在原地的 731 次，旧模型命中 566 次，新模型命中 682 次；同组四个移动方向的命中则全部下降。这解释了为何重载工总体仍能多命中 6 次，却未学好最影响回款的出发时机。两个弱项可直接定位到逐工原令，不需要从现金曲线倒推。[留图逐单位原令与双模型预测](held_orders.json.gz)

## 换成新对手模型后，H8 能否挑出更好的真实分支

**本版停止在历史分支复核，保留原 H8。** 64 个旧干预根来自另外 16 张真实地图，同根均有两份原版考官应对至终局的分支。把本版放到 H8 的对方解码位，维持己方模拟、两条共同随机流、叶估值与候选完全相同。先盲算 H8 选令，再用原始签收的对应终局评分。训练六图、第一组留出两图、这 16 张转移图，以及两轮新开发池，按种子和地形检查无交叉。[完整预测、原版实令与两臂终分](transfer.json.gz) · [模型替换与核验](transfer.py)

在两条相关的抽样流上合并计数，种植工实令命中由 118 增至 129/240，载货至少 100 的采集工由 149 降至 148/238，整队命中由 0 增至 2/128。两个流共享根和真实标签，独立根数为 64。三项中两项改善，动作预测通过了事前要求。

|---|---:|---:|---:|
| 前六批历史根 | 12 / 48 | +46.12 | +8.06 |
| 后两批留图 | 4 / 16 | **−20.35** | **−46.44** |

四张留图上，旧 H8 相对原动作 +26.08，新 H8 为 −20.35。两种 H8 在三图选出相同的终局分数，第四图有两根改变。回到原动作后，一根少得 1,231.07 分，另一根少损失 488.11 分，净额 −742.96。四图的父代、旧 H8、新 H8 所选择的 16 条真实原版终局都全负。这是一次历史分支选择检验，尚未进行用新预测器整局连续搜索的比赛。收益条件未通过，未签发候选比赛包，亦未启动原版开发场或正式考卷。[封存记录](entry_check.json)
