# 八步搜索的树收入估值

只改非终局叶。把最后一拍模拟中各棵存活树的吸收收入作为下一拍的参考，向前最多八拍按地块吸收率逐步衰减，并受剩余寿命和比赛剩余步数限制。双方对称估值。真实终局照旧结算。树权不被夺、敌工携货和邻格资源不突然变化均为近似，模拟收入不是真实标签。

固定原版已留有两种动作续局的 64 个种植局面，不调系数。前十二图与已研究过的后四图分别报告。后四图对原叶的平均官方收益须为正，且至少三张图严格改善，才进入新图开发实战；重复使用的四图只能提供开发信号。

另训练一份固定的树收益估计：用原先六图双席的实际联合动作重算每棵树在当前席持续持有期间的未来八拍实收。对当前拍收入、剩余寿命、敌方种植工距离与邻树竞争做岭回归，另外两图核预测误差。模型只替换上述树收入项，沿用同一实战准入条件。预测、分支选令和整局胜率分别记账。
