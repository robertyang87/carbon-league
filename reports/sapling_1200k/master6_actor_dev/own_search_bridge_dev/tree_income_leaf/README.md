# 搜索是否低估了继续持有的树

原有八步搜索计入已经到账的树收入，叶节点评价现金和折价在途货，没有给仍在赚取收入的树单独估值。本轮仅修改这一项，双方对称计价，精确终局保留官方结算。

第一版按最后一拍吸收额衰减外推八步。第二版在六张训练图的双席原版实战上，用当前收息、树龄、邻树竞争和敌种植工距离训练七个系数，目标为本方连续持有期间随后八拍实际到账的收入。两张行为留图均未参与拟合，十六张用于动作选择的图与这八张图物理地形不重叠。训练有31,757个树时点，留图有10,779个，同树相邻时点高度相关。实战预测器在模拟局面读取模拟器产生的收息；训练标签来自实际双方指令的规则重放。[训练与权重](learned.json) · [两版判据](protocol.md)
