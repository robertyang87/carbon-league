## 教师实际计算的数

原版 _S_REC 公开记录的 val 是每个候选的第一个 rollout，可能还来自不同深度。离线标注器保留仓内原版信念、前向、采样、演算、共同随机数和 0.58 秒内部时限，只替换候选生成菜单。在原搜索每次完整计算全体候选后复制 (candidate, rollout) 的 val 和每候选 dep。在同一深度与 rollout 集下求均值，缺值或提前淘汰的候选不与幸存者更深的分值混用。16 个根均得到 H8、每候选一个 rollout，这正是冻结原版 M=MMAX=1 的配置；每个原始矩阵和公共敌方根令均可读回。选择器也逐根与原版 EPS 裁决核对。16 次调用内合计 3.60 秒墙钟。

## 从真正的部署候选学习相对分数

另选五张与四张教师鉴别图均不重叠的旧开发图，09b4 双席的己方实际开局轨迹。每席固定 t64、t144、t224。候选来自自身完整前缀、守卫及去重后的联令，均含 A0。在四候选原生搜索里，H1 后会淘汰半数。为取得与验证过的 H8 同尺度的标签，对每个替代与 A0 分别做一次双候选原生搜索。整组必须在 H8、每候选相同 rollout 数、相同逐流敌方根令、重复 A0 的值相同才收录。共 90 次原版搜索，30 个有完整标签的学生局面，未补齐 0 根。
