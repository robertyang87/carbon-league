## 归档语料与隔离

从 108 个签收根取得两份合法首拍联令及其后原版完整真实响应的官方分。14 张训练图共 80 对，其中 78 对首拍只改一个单位，另有各一对改两个和三个单位。按原叶的四张未训练地图冻结了 28 对作留出，全为单单位首拍。对同一母局不拆划，8 个复测流及与原父代或续弈配置不一致的 32 例没有进主拟合。公共状态复演只用到 root 之前的比赛历史；只取登记的两个己方候选动作。根部敌令来自冻结自有小网，各自分支在第 2–5 步继续用相同部署小网重新预测双方动作。既有真实响应只提供终局标签及轨迹验签。已精确终局的模拟分支直接用规则，完全冻结预测。

另列 4 个第三个方向的真实响应，以及两根八拍整队教师接管与 8 对持续策略切换。后者以相同的首拍估值单独查验，7/10 的首拍己令逐字相同，因此两臂在首步模型下必须平分。真实终局还包含后续政策改变，这 10 对不能当作“首令反事实”样本训练，也没有验证新搜索自由产生的多单位方案。第三方向四对等权准确率两叶均为 1/4。

## 拟合与部署边界

两臂完全同用 09b4 根策略和 9f31d8e3 的棋盘编码、动作头、U 头、完整 H5 后继和搜索选择公式。只将经济残差头 16 个系数及 1 个偏置设为可训练，从原绝对标签拟合的参数出发；80 次注册更新同时学习成对终局分差与偏好。在双席成对分差中共同偏置相消，实变 16 个系数。模型只使用其模拟产生的状态嵌入和模拟现金差，未读当步记录敌令或后续实局观察。用旧系数复原每个根的已部署得分，逐根核对原叶选择，再在完全相同输入上换入经 float32 还原后的新系数。保存候选权重用于复核，未替换原部署包。
