# 在 it50 自己访问的中盘学八拍整队示范

前一轮连续让强教师操盘八拍，在两个旧局面分别改善最终分差 +632.04 与 +348.74。本轮把问题收窄到部署学生是否能学到这种指令。先取得同样时段的 96 个己席可见局面，给父包做一次有限预算的网络更新，再在隔离的地图上检查单文件包最终发出的全部指令。

**这次更新在两张留图上的净动作改善为零。** 预登记要求每图和每席都提高指令吻合度。学生确实在两席都改变动作，但一图提高一个单位，另一图丢掉一个。保留权重与逐步证据，这个包未触发新图原版对局。

每条轨迹取 t150–157 的连续八拍。教师从 t0 起按原始执行指令恢复己席可见历史，在当前学生真实访问的每一步给出建议，随后将实际发生的学生指令恢复进教师的信念跟踪器。用旧轨迹向前推进便能独立询问下一状态。复用前轮两图 t150 的两条已有示范，另调用 94 次原版搜索，总教师墙钟 41.59 秒。前一轮教师实际介入后的另 14 条指令属于其自己改变后的状态，不混入此处。八拍是连续查询窗口，学生每拍的标签仍来自一次含温度采样的教师行动。

训练只用四张图的双席，原先观测到正分差的两张旧图均列训练。两张留图及其双席完全排除在优化、模型选择之外。24 次固定更新，以教师实际联令的前缀计算 75% 固定伙伴 logits 加 25% Sapling logits，保留父代所选解码分支的回款修正，用父策略分布约束漂移。649 个非平凡有效单位，修补前缀 0，训练从量化父网实值开始。最终将训练改变量加回同源 FP32 Sapling 权重并重新量化。1,133,281 个参数的训练值有变化。前缀内监督使用父代在该状态的分支；自由部署会重新执行原 guard。评估对双方完整出令作对照，记录固有合法动作唯一的单位也计入分母。

本次数据只有六个物理地形，每图两席八个连续时点，模型在留出样本上的行为没有一致改善。前轮教师真实余局获益与本轮模仿未通过可以同时成立。两个结果都不代表学生已经获得一场胜利。
