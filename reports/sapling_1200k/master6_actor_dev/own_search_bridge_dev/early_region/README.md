# 改变一次种植工路线，对 Master3s2 的两图续局

在两张已用开发图上，从相同局面分别执行父代原动作和按两步内可见资源选出的新动作。根步之后双方自由应对至官方终局。表中分差取 Sapling 视角。

|地图、席位、步数|改动|父代分差|新路线分差|差值|
|---|---|---:|---:|---:|
|621471121，席 0，第 32 步|停留改向左|−1,228.73|−2,291.22|−1,062.49|
|621471120，席 1，第 92 步|停留改向下|−1,427.33|−1,301.03|+126.30|

第一图原地停留的工人当步死亡，向左的工人下一步死亡，两条路线均未种下树。第二图原地种树花 53.42，南移后下一步种树花 47.06。局部省下的 6.36 与终局分差的变化是两个不同的量。每臂只跑一次自然墙钟续局，终局差值包含双方后续采样与实际搜索的差异。

原版考官在两图各臂根后分别有 266 和 206 个搜索步，父代臂分别记录 1 和 3 次搜索中止，新路线臂均为 0。四条续局全负。预设的两图均改善条件未满足，本候选停止扩样。独立正式地图使用数为零。
