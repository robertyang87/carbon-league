# 中前盘种植选区对照

按最早步数、地图号、路径编号，从先前64个种植局面中为两席各取一个不同地图、步数不超过100的局面。父代原动作须为停留，选出的移动方向须与旧备选不同，且目的地的区域分高于当前位置。从四邻区域内的可占敌树、实收树息、已知邻格碳和已方占地构造两步半径的目标；先剔除下一拍可遭敌采集工接触的移动和友军冲突。只用行动前观测。目标地区只是行动建议，每次仅改根步，后续真实 Sapling 和对手自行应对。

原令和新方向在同一根、同一敌令和同一原版搜索初态开始，按物理席轮换两个 CPU，保留到官方终局的所有分数。两个不同地图均改善才扩样。根是开发诊断，单次自然墙钟续局不计作独立整局胜场。

首轮在64个既有根上实际选中零例，未产生任何新赛果。保留空清单。补充检验改用首个训练批次已有真实比赛的全部机会记录（步1至100），仍按最早步、种子、工号排序，各席各一图。与原版采样过的根单列；旧路线指原候选器在这个新根会首选的方向。保留相同的收益、冲突和地区排名要求。
