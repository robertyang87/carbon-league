# 父网可以提出哪些已实测种植工联令

### 回溯与范围

每根附根前 10 个实际联合动作、双方公开工人状态（位置、载货、角色）、树和现金，以及 3/5/10 步索引。邻近十步与后续收益的同现只提供查证入口，无法把整局变化归因给其中一拍。下面固定列出留图上第一处观察为正及第一处观察为负的例子。

- 图 621477120 席 0，第 103 拍，player-0-worker-25 从 NONE 改 LEFT，替代整队排名 2，观察到终局差 +203.29。此前在世时的步号、位置及指令为 97@160:RIGHT，98@161:RIGHT，99@162:RIGHT，100@163:RIGHT，101@164:UP，102@149:RIGHT。
- 图 621477120 席 0，第 179 拍，player-0-worker-9 从 LEFT 改 NONE，替代整队排名 5，观察到终局差 -73.60。此前在世时的步号、位置及指令为 169@216:LEFT，170@215:DOWN，171@5:UP，172@215:LEFT，173@214:LEFT，174@213:UP，175@198:LEFT，176@197:DOWN，177@212:RIGHT，178@213:UP。

原始 64 根全部来自预筛选的单种植工干预。采集工、基地和任意多工人组合的终局样本均为 0。已测替代的排名覆盖不能外推为任意局面的候选召回率。
