# Sapling 的中盘种植缺口

逐拍重放 18 场已有的原版 Master3s2 对局，每场取决策步 100–199，两边均按本方席位统计。18 场共 7 张地图，换席及同图不同分支都保留。种树、夺树按执行引擎实际扣款逐笔对应到工号，所有源轨迹终局现金与归档官方分数相符。[逐局身份、按图计数与总账](counts.json) · [工号、步号、受争夺与可见机会](opportunities.json.gz) · [计算程序](funnel.py)

空地排除现有树、基地和其他占位工人；移动一格可达与当前直接可种分列。种植工在自己站的格能看全相邻四格，按四格可见碳均值 ≥30 定义“富地”，任一敌工一拍可达即标为“受争夺”。在相邻目标，未知格仍未知；仅已见碳合计 ≥120 才能公开断定四格均值 ≥30。该分档在项目此前的回放分析中已有使用。树未来还会纳树税、面临夺取、支付动态价格，因此该档只代表当前可见碳丰度。

Sapling 总共少种 79 棵，其中 61 棵的差出现在安全富地。按 3s2 的在场留种比例做算术分解，少 64 次到位对应约 39.7 棵，其余约 21.3 棵对应到位后较低的留种比例。这只是把相同总差拆为两项。要测某个改令的实际收益，还需要在相同根局面让完整对手重新响应。按地图拆开，七张图的安全富格成功新种以及全体新种数，3s2 均更高。

仅供事后复核，读取完整碳图时，Sapling 当前或一格内有安全富地达 **1,900 / 5,314（35.8%）**，3s2 是 **1,116 / 3,093（36.1%）**。模型行动时不能获取这些全图值。实测支持试验“从自身可见历史预估邻格，再看下一拍能否真正支付下种”；单纯增加种植工或无条件要求静止，均没有解决本批数据里最大的差距。

### 往前追十步，工人当时在哪里

对每条记录按工号、物理席位回查当前与 3/5/10 步前的位置。此前尚未招出的同号工不进该回溯比例；先在同一张地图内合计，再对 7 张地图等权。第 100–199 步，全体在场种植工中，Sapling 有 69.9% 的工时距离敌工至多一格，Master3s2 为 44.4%。处于更靠近敌方基地的半场却仅为 41.7% 对 38.1%。实际在安全富格上种成的工人，十步前仍与敌工相邻或同格的比例为 57.0% 对 39.0%；当时站在敌树上为 11.6% 对 3.6%。差距更多发生在局部敌情上，仅靠距基地远近分类会漏掉这些工时。这里按后来确实种成筛选的记录只用于回溯，不能用来证明撤离敌工必然获利。[逐图、逐席与各个回溯步数](layout_history.json) · [计算方法](layout_history.py)
