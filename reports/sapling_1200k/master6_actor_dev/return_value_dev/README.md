## 为什么选同样快的另一条路

旧版提前返航把四局平均分差从 −1,197.57 拉低至 −2,118.51。终局在途库存虽减少了，整局入库均值却从 8,423 降到 7,741。另一次提高返库和避险打分的训练，在两张地图上得到方向相反的终局信号。这次保留父代是否采集、何时出发和直接交货的决定，只研究工人已载至少 100、v1 实际正在向最近己库靠近、且还存在另一种等距走法的情形。[原版提前运货对照](../../DELIVERY_AND_INVESTMENT_20261119.md) · [终局回报训练的跨图反例](../terminal_return_fit/multimap/README.md)

在四张发现图换席的八条真实轨迹中，≥100 的重货被对手碰撞接收 2 次，共 500.21，携同等规模货物正常入库 260 次，共 45,896.59。把高额丢货回溯三、五、十步，未找到两次都适用的临场逃步。另查 3,397 个重载工拍，实际被对方树吸税 12 个，共 206.52。877 个父代已返航且有两条安全等长路的工拍中，静态算到基地提示 10 次可以少缴税；跟踪同一工号到下一次真交付，10 次原有货物都已回库，途中真正给对方缴纳的树税为零，8 次还继续采集。最清楚的一例在 621473120 席 0 的第 132 步，工人载 499.84，按固定路推算可省 94.97，原工后续多采 132.18，第 149 步实交 632.02。不同根可属于同一运货过程。[全部事件和反例](lookback.md)

## 实际策略和三次发令

包内仍由冻结 Sapling 与 PPO it50 双网完成每拍全套出令。拟合只读发现集四图，用树龄和附近可夺树种植工的距离估计现有敌树在未来一、二、三拍仍属原主的概率。未计入未长出的新树。对每个移动比较从其落点开始、以后每拍距同一基地更近的最佳三拍路径。替代须与原令同样快、当拍可能被轻敌工抵达的动作剔除，原有行动的逐单位合法前缀全部重验。预测能多保住至少 8 且不少于当前载货 2%，同时预测第一步树税不升时，每拍至多改一工。候选只接收公开局面、自身实际命令和规则，其他工人与招工命令保持原样。[模型与路径比较](route.py) · [概率权重](weights.json) · [单文件构建与身份](release.json)

## 三笔本金在原版真实续弈中的去向

跟随原令继续到真实终局，三笔本金共 539.6622，全额回到己方基地，敌树税和碰撞货损均为零。三工在十步内都没有入库，分别在第 17、13、16 步兑现。第一和第二名工人在前十步继续采了 45.56 和 60.39。三笔首次毛入账分别为 193.67、231.97、248.08。从最初背包的最终回收比例看，原动作已经实现 100%；如果要证明改道仍有价值，应测提前兑现后多赚的现金、途中放弃的采收和整队得分。三步路径分数未提供这些证据。[逐工货权、十步轨迹和真实回款](factual_after.json) · [独立复算](factual_after.py)
