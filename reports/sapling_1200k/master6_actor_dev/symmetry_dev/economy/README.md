## 中盘每笔新植的收益

十图的第 51–250 步，Sapling 实付新种 306 笔，平均成本 62.32，首次连续持有 35.58 步，每笔直接净收入 27.66。考官新种 506 笔，对应为 58.59、40.96 步、47.67。双方在同图换席再汇总，10/10 图我方新种较少，10/10 图每棵净收入较低。我方 130/306 新树后来被夺，考官为 148/506。

按每局两边直接净收入分解，我方中盘新树差 -782.83。数量差按双方每棵平均净收入折算为 -376.64，每棵净收入差按双方平均数量折算为 -406.18。这是对已发生收益的算术分解，额外种植后考官可以改路线、夺树或交货。

第 285–294 步我方实际新种 25 笔，19 笔在终局前直接回本，合计 +375.06；过早统一关闭新植会撤掉部分实际赚钱的购买。[购入与再失逐段分层](cohort.json) · [分解算法](cohort.py)
