# 专家当拍命令与 12 步位移标签

312 场已签收的原版 Master3s2 整局构成候选来源。本版在看新标签前用物理地图身份和既有用途选 32 张图；每图两个专家物理席，各选一条完整实录，共 64 场。24 张训练图含 7 张既有训练图、1 张可直接新增训练图和 16 张已明确退役的历史开发图。另 4 张验证图、4 张回顾开发图仅作测量。地图、原轨迹 SHA 和全部取样时点已事前锁定。[分图与抽样清单](../sources.json)

| 分区 | 图数 / 轨迹 | 取样时点 | 当拍可选动作 | 有效工人生存标签 | 12 步内死亡 | 存活工人方向标签 |
|---|---:|---:|---:|---:|---:|---:|
| 训练 | 24 / 48 | 1,536 | 14,447 | 13,401 | 2,565 | 10,836 |
| 验证 | 4 / 8 | 192 | 1,821 | 1,654 | 318 | 1,336 |
| 回顾开发 | 4 / 8 | 192 | 1,830 | 1,704 | 307 | 1,397 |

每条轨迹从第 0 步按实际双方命令推进，使用专家当时的本席可见状态和真实先行动作前缀。官方现金路径、两席动作带与真实终局逐条核对。生存和位移标签在第二遍才按工人 UID 连接未来位置。终局前不足 12 步的 68 个样本保留当拍监督，屏蔽全部未来标签。工人死亡只记生存标签。位移以环形地图的最短坐标差取主轴，平手取横轴；缓存存储绝对物理方向，训练和评估另行转换到本席特征坐标。[缓存生成器](../prepare_data.py) · [分片回执](../data.json) · [逐根时刻与工人 UID](../root_index.json.gz)

独立校验从原始命令用 FastCarbon 重放上述 64 场，重算所有 23,040 个槽的方向、生存与掩码，包括 3,709 个跨地图边缘的坐标差和 2,408 个非零主轴平手。逐项一致，终局两边现金均与归档值吻合。此处计数的单位是同一批比赛中的多个决策或工人。[独立核验程序](check_labels.py) · [核验收据](label_audit.json)

从本目录的上一级运行以下命令可重建本地分片并独立复核，环境需要 NumPy、PyTorch 及仓库官方对局环境依赖。权重训练两臂共用同一批输入。

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python prepare_data.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python prepare_data.py --merge
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python data/check_labels.py
```
