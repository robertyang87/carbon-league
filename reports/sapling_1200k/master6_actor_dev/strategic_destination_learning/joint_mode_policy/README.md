# 把一支队的行动作为一个联合分布来学

在四张历史开发图、双席 192 个局面中，加入队内共享模式后，Sapling 发出的整队命令有 21 次完全复现原版示范。原包为 19 次，参数完全等量的逐单位模式对照为 20 次。共享版与逐单位对照仅有一个局面的实令不同。预先要求至少两处，且共享版的整队负对数似然须优于逐单位对照，本轮均未达到。这个版本留作行为实验，新增对原版整场为零。[事前登记](protocol.json) · [按地图与席位的实际判读](assessment.json)

训练用了 24 张历史训练图、1,536 个真实公开局面，监督是仓内原版当时提交的完整联合命令。基于冻结的 Sapling 棋盘表征，两臂都学习 471 个参数，通过当前工人角色与合法走法特征修改每个动作的概率。共享版在同队先行动的工人选完动作后更新模式概率；对照在每个槽恢复根部的模式概率。两者训练图、初始化、四轮批序与更新预算相同。最终单文件沿用两张自有网络和原有守卫；共享版 6,079,854 字节，逐单位版 6,079,847 字节。[训练代码和权重身份](fit.json) · [共享版](joint.py) · [逐单位对照](independent.py)

似然用保护逻辑前的完整合法前缀衡量。另取八图共 384 个局面，从开局逐拍更新可见历史，让最终单文件独立生成完整指令并执行守卫。旧父包的全部指令逐字核对。两个物理席位各取一个真实前缀，独立复算 PyTorch 与 NumPy 对完整指令的对数概率，最大误差 0.00000015。该复演单独衡量行为和数值，天梯资源认证须绑定未来实际出场包。[公开入口复演](public_eval.py) · [实发命令](free_orders.json.gz) · [双席数值复算](parity.json)
