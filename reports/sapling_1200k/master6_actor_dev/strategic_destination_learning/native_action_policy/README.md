# Sapling 实际整队命令的概率与攻防选择

量化单文件 `e830229d` 在四张留出地图的 96 个登记局面上，每次都能给至少三条不同的合法整队命令分配概率。实际固定随机流发出了 19 条不同于父代的命令。训练后，逐图等权的专家动作负对数似然减少 0.03452，四图中只有两图改善，低于预先要求的三图。因此本版留作能采集带真实动作概率的训练数据的工具，未进入新的整场强度比较。常规对照父包为已和原版 Master3s2 打过的 `ede48ad9`。[登记口径](protocol.json) · [发布包](candidate.py) · [验收数字](gate.json)

## 训练什么

保留父代实际出令用的 Sapling 策略网络和冻结的项目自有伙伴网。增加 1,272 个可训练参数，逐动作读取两网的联合评分、己席行动前的全局状态和真实解码前缀的行动特征，输出条件动作的分数修正。搜集原版 Master3s2 实际执令席的 24 张训练图，双席、每席 12 个预固定时刻，共 576 个根。只有实际专家在选择单位之前的已决定命令与当前父网一致、且专家动作在守卫后的支持集可达，才用该根监督新头。最终 242 根可用，采集工 186、种植工 50、基地 6。训练目标是分配给该单位真实专家动作的概率之和，按物理地图等权，CPU 单线程共 108 次更新。没有把历史胜负赋给未执行的备选；这一步提供了模仿初始化，尚未用任一备选的真实长程回报更新权重。[训练权重](head.npz) · [训练记录](fit.json) · [原版数据身份](../sources.json)

每六步一次，从第 6 步至第 294 步。按采集工、种植工、基地轮换优先工种，在可以选择的单位中选原联合网络熵最高的一个。用该单位各合法动作作为前缀，重新计算全队其余单位的预算、占位、守卫和命令；如果两条守卫前缀中任一条已不能招工，或比父令多产生己方冲突，相应概率并入父令。父令有固定 50% 概率，其余 50% 由新头与网络联合分数分配。公开入口先合并物理命令完全相同的路径，再抽样，常规步以概率 1 发父令。每次调用后的 `_LAST_POLICY` 可读出全部实际命令、概率、学前同菜单概率、实际抽样和对数概率、选择的单位及工种。部署决策只读取本席观察。未采样的替代动作仍需独立的原版终局响应才能定价。[实现](runtime.py) · [无学习头概率对照](receipt.py) · [共享招工资源的反例](guard_check.json)

## 复算

在本目录执行下列命令，均使用带 PyTorch、NumPy 和仓内正式环境的 Python。训练与核验只需一核。临时目录可恢复各个逐轨迹缓存，哈希不符时程序退出。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
python train.py collect --work /tmp/sapling-native-action-cache
python train.py fit --work /tmp/sapling-native-action-cache
python check.py --work /tmp/sapling-native-action-cache
python guard_check.py
python training_choices.py --work /tmp/sapling-native-action-cache
```
