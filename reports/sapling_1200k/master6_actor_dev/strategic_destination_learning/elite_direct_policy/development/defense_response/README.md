## 时钟和复原成本

选手从第 0 步起重建观察历史，到根的两席各有 209 次公开调用。Master3s2 的信念跟踪器在每拍记回原场实际执行的命令，避免用重建时温度采样到的其他动作改写后续信念。正式计入本次续弈的那次前缀有 105 拍进行了这种修正，原版调用累计 86.19 秒，Sapling 8.72 秒。第一次重建在取原版内存快照时发现源文件临时目录已清理，计分臂尚未启动。当次前缀的 209 次调用另行保留，耗原版 86.40 秒、Sapling 9.26 秒。

原版读回搜索开关、0.58 秒墙钟及温度 1。固定流只控制反事实配对的随机起点。同一步随主机负载达到的搜索深度可能不同。共享的第 208 步原场回执为 K=7、完成深度 8、墙钟 0.344 秒、CPU 0.560 秒。后缀运行于本机 CPU 0、1，原版 PyTorch 两线程。公开函数计时覆盖两边进程内调用；平台容器和端到端通信计时须另见整局考场收据。

这 360 次实时原版调用均有多个候选且完成正深度，达到搜索截止 58 次，零深回退 0 次，超过 1 秒的调用 0 次。最慢原版 0.771 秒，最慢 Sapling 0.225 秒。
