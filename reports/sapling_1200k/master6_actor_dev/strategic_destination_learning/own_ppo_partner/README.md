# 自有 PPO 能否替换 Sapling 的 it50 伙伴

仓内的 it74、it85、it95 都是有实际权重的自有策略包。以**同一考官、同一量纲上有优于 it50 的实战依据**为本轮筛选条件，三者均没有入围。此次没有生成新的 75/25 包，也没有消耗新的原版考试局。该结论覆盖固定的两棵仓树；未来取得同期对照后可以重新判定。[固定输入、逐行汇总及缺口](audit.json)

## 伙伴身份

从 Sapling 父代 `ede48ad9` 的单文件中解出伙伴，得到与独立 it50 完全相同的 3,598,748 字节，SHA-256 前缀为 `47dfce84`。另三个包的权重格式、张量名与形状均匹配，186 个序列化张量中各有 180 个与 it50 内容不同。它们来自较早的 snipe_n1 训练线；it74 还在该线改用终局 U 之前。it50 来自后来 PPOU2 的 m 臂。四者虽然以迭代数命名，却跨越了两次训练。现有证据能确认换件会改变权重；三种 75/25 组合在具体局面的最终命令差异未经测量。[工件复算](audit.py) · [早期训练口径订正](../../../../PPO_U_IT95_CORRECTIONS_20261114.md)

## it50 的同尺证据在哪里

固定 `e714939d` 和历史归档 `d599ec67` 后，程序逐件检查两棵树内全部 459 份去重 JSONL 对象，两侧 MD5 都检索。原始记录中，it50 的对手包括 Echo4、原版 Master3s2 包装及关闭搜索的 3s2 包装，与另外三件已核考官的 MD5 没有交集。it50 对 Echo4 的 2,000 局为 1,207 胜 7 平 786 负，平均分差 +212.13。它过去对完整 3s2 的 300 局为 187 胜 113 负，平均分差 +262.12，缺逐步搜索深度收据。另有精确相同的 it50 在一张开发图换席 0/2，原版考官 598 次调用中 597 次完成比较，445 次达到八层。两份实录用图不同，应各自使用。[原版对手与墙钟证据](../../terminal_return_fit/examiner_runtime.md)

另一个已登记伙伴实验把同一 25% Sapling 与 75% Echo4 组合，和 it50 伙伴在两张新图同机双席对照，双方均 0/4，平均分差分别为 −993.52 与 −1,642.21。另有 PPOU2 it55 对 Echo4 的同尺历史汇总，但相对 it50 的 ΔU 区间跨零，已核仓树未找到可打包的 it55 单文件。以上都不提供用 it74/85/95 替换 it50 的收益凭据。[Echo4 已做的伙伴对照](../../actor_partner_dev/README.md) · [it55 处置与区间](../../../../PPOU2_IT55_EXAM_DISPOSITION_20261116.md)
