# 对两套自有策略权重做量化感知训练

两臂复用相同的 8da4、两个历史训练来源、原版确实改令的 11 个训练槽，并各做 4 步 AdamW 更新。学习率固定为 0.00005。FP 臂在训练前向使用浮点主权重；QAT 臂先以服务端相同的逐输出行量化器取整、截断和反量化，并令反向梯度直接传给浮点主权重。每步逐张量比较训练量化器和实际 NumPy 导出器，完全一致。两臂在第一步后所有 FP32 参数的哈希一致，验证了父代恰好可由原量化格点表示。训练期间保持原父代实际逐单位前缀和整队仲裁的分支，探针比较时让两个最终导出重新自由选择各单位动作。[预先固定的训练约定](protocol.json) · [量化代码](quantization.py) · [配对实验](run.py)

| 第四步导出后的测量 | 起始 8da4 | 普通浮点训练后导出 | 量化感知训练后导出 |
|---|---:|---:|---:|
| 训练 11 个原版目标的平均 NLL | 2.28651 | 2.06746 | 2.01974 |
| 后续 12 个原版目标的平均 NLL | 1.99929 | 1.92974 | 1.92098 |
| 训练段 32 根，相对起点改变的整队物理令 | 0 | 5 | 6 |
| 后续 32 根，相对起点改变的整队物理令 | 0 | 2 | 3 |

NLL 用同一原前缀下的所有合法动作作分母。两臂各步导出再载入后，所有被监督槽的可行动作分数与 Torch 量化前向最大相差 0.0000153。四步配对实验在本地单核用时约 31 秒。[每一步与两份权重的读数](result.json)

**实际有代价的反例发生在第 212 步。** 两臂自由发令的差异一共只有两个局面，都属于地图 621704801、席 0 的 20 号工。训练段第 191 步，普通臂向左、QAT 向上，原版实际向上。后续第 212 步，普通臂向左、QAT 向下，原版实际向左。QAT 降低这 12 个目标的平均 NLL，却把这两个包在后段唯一不同的物理指令改成与专家相反。即使指令与专家相同，回放也不能估计换令后面对响应对手的终局收益。这两段均取自训练地图。[全部实令](commands.json.gz)

一步更新后的字节解释了为什么按“变动参数数”会高估干预。在 it50 的 3,453,696 个整数量化码中，只有 69 个发生变化，Sapling 的 1,192,273 个整数量化码均保持原值。8,825 个 it50 行尺度、2,902 个 Sapling 行尺度发生变化，同一行的许多反量化浮点数因此一同变化。到第四步，普通和 QAT 两臂分别改变了 52,495 与 84,939 个 it50 量化码，Sapling 为 120,168 与 171,703 个。可用脚本从父包和差分权重独立复算每项数量。[逐塔字节统计](encoding.json) · [复算程序](encoding.py)

输出可从冻结 8da4 与两份权重差分重建。运行 `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python verify.py`，独立装载两个完整单文件，从开局接收真实可见观测并对照归档实际动作，逐一复算受监督槽的合法动作概率。量化感知训练使这个小样本的导出损失降低，后续强度判断仍需真正响应的对手和未用过的地图。[普通臂权重](fp_int8_delta.bin) · [量化感知臂权重](qat_int8_delta.bin) · [独立验证程序](verify.py)

独立进程重建了普通包 `ca06dcc6…`（6,075,577 字节）和 QAT 包 `b43a7866…`（6,075,697 字节），两包各 64 根实际公开入口的整队出令均逐项对上。仅看原先有资格的目标单位，两臂各自在训练段命中 2/11、后段命中 1/12；两个导出之间多改的那两个单位都在这个严格口径之外。[两包独立复核](verification.json)
