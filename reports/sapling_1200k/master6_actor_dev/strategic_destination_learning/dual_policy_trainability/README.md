# 8da4 两套策略网络同时接收梯度

冻结包的两套自有参数都能从已部署的 int8 载荷完整恢复。it50 为 C128、8 个残差块、4 个空间注意力层，共 3,480,775 个参数。Sapling 为 C93、6 个残差块、D96，共 1,206,476 个参数。分别重建 PyTorch CNet2 后，186 和 105 个参数张量逐值相等。零次更新重新量化，两份压缩前的原始载荷逐字节相等。[冻结协议](protocol.json) · [双网实现](runtime.py)

从两张旧训练图按登记顺序各取 32 个连续的原版考官席位局面。每张前 16 个局面可用于更新，后 16 个用于检查。按比赛当时本席能看到的信息恢复历史，用父代自由选前序单位命令，分别解码有返航加分和无返航加分的整队命令，再经过原包的受保护单位与碰撞检查。64 个根的初始最终命令全同，两条分支的 128 个命令也全同；本样本的最终仲裁均接受有返航加分的分支，未验证拒绝分支的实际覆盖。6,562 个合法动作分数中 2,457 个逐位相等，其余的 NumPy/PyTorch 浮点误差最大 0.0000191。[来源与原轨迹](corpus.py) · [完整实测](result.json)

进一步要求原版搜索在该单位确实改了动作，原版和父代在这个单位之前的各项实际选择一致，且原版此处提交的动作在父代前缀上合法、与父代不同。32 个训练根得到 11 个如此定义的目标，32 个后续根得到 12 个。一轮 AdamW 更新的学习率为 0.00005。it50 和 Sapling 的梯度范数分别为 20.71 和 1.98，第一层卷积的梯度范数分别为 13.39 和 1.28。更新通过两条策略的编码器与解码器；离散指令和整队仲裁保持部署时的选择方式。[训练程序](train.py)

唯一生效的量化整队改令在 621704801 席 0 第 218 步。62 号工人从停留改为下移，58 号从上移改为左移，两条新命令都与原版当拍实令相同。该局只重放归档双方实际行动，新指令产生的终局收益未知。量化后的 3,303,250 和 1,111,241 个有效浮点权值发生变化，其中按输出行共享量化尺度；这个计数不能换算成变更的实际指令。[逐步物理命令](orders.json.gz)

重新生成的单文件为 6,075,653 字节，SHA-256 为 `fa43113ff10105c68f685777b459c4e76a5afe46c2e475a62a948022d1b77b27`。独立校验从开局向该文件的真实公开入口提交 188、223 次公开请求，预定 64 根的整队物理命令全部吻合。本地单线程的 64 次热调用均值 41.18 ms、P95 51.99 ms、最慢 113.73 ms。平台容器资格和整局胜负仍需单独测量。[公开入口读回](pack_check.json) · [读回程序](verify_pack.py)
