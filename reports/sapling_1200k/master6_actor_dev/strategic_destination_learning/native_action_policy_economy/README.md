## 正例与反例

- **绕开拦截。** 图 547 第 252 步，己方 24 号工携货 268.6362，原令向上，原版敌采集工当拍抢走全额。原地停留也会丢货，向左、向下、向右能避开。在同一个可见局面，学习头将这三条安全队令的合计概率从 16.86% 提高到 26.72%。相对 BC，净保货期望增加 71.777；相对未训练先验再增 26.487。该拍两席普通交仓差没有变化。之后能否把这笔货运回必须另由真实续弈验证。
- **把可兑现的交付改成等待。** 图 545 第 12 步，0 号工向右时能够完成交仓，改为停留会让当拍交仓减少 39.5067。原先验给停留约 10.94%，学习后给到 27.81%。全部队令合计使普通交仓期望比 BC 少 11.339。第 162 步出现相反的机会，18 号工从原地改向上可多交 70.9425；采样器能提出这个动作，学习头却把它的概率从 13.59% 降到 9.75%。
- **避开碰撞后种树。** 图 546 第 120 步，本方 29 号工与敌 25 号工在原令下同时消失。若 29 号原地停留，则双方避开那次碰撞，我方还会在 192 格新增一棵树。训练头把该令概率从 10.12% 提到 16.01%。到第 270 步，基准令本可在 196 格种树，改去周围任一格都会放弃当拍种树。这些改令总概率为 27.62%。余下步数、树的持有期与回收仍会影响这笔投资。

每个有差异的局面都保留敌方真实队令、不同己方物理令的概率和分项现金、被消灭的工人及树权记录。每图每项最佳／最差的非零期望局面另附前 3、5、10 步的完整双方命令与公开玩家状态。选例包含风险和收益，表内均值保留全部局面。

## 怎样复算

程序校验三份来源 ZIP 的 SHA、独立复演收据、公开观察、完整棋盘与官方终分，以及来源地图和模型训练／验证所用 32 张物理地图不相交。每条候选队令使用仓内原版对手程序在该拍已提交的命令，所有分支共享它。对 147 个探索时点的 712 个不同联合转移逐一交由官方裁判结算，并与独立模拟器的现金、工人、树、地面碳、计数器对读。其余 750 拍的新包完整命令逐拍与来源一致。无需运行或削弱原版的搜索。[复演程序](audit.py) · [冻结包及训练证据](../native_action_policy/protocol.json) · [原始实战与来源身份](../policy_window_returns/hosted/README.md)

在仓库 Python 环境运行 `python audit.py` 可只复演三份来源。完整复算从本目录执行下面的命令。

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
python audit.py --candidate ../native_action_policy/candidate.py \
  --sha e830229d23817cdcb8ad7e7e392cb3ae57cb1e04503e70ecefe91bf446fc20d4
```
