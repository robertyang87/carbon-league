## 同一地图为什么一席赢、一席输

- **席 0 的胜局。** 状态 288 时 Sapling 落后 236.49 分。动作 291 前仍落后 38.08 分，44 号、47 号采集工在这一步分别交回 352.28 和 126.89，下一状态反超 428.40 分。提前十步，44 号已载 280.46，距仓七格，47 号载 95.12，也距仓七格。提前五步，44 号载 338.14，距仓五格并停采，47 号载 126.89、距仓六格并左移。提前三步，两工均距仓四格，分别上移和左移。原版随后在第 293、297 步两次双工回款，最终只差 18.06 分。同图同席父代输 1,662.03 分。
- **席 1 的败局。** 图 513 换席后，新版输 1,121.20 分，父代输 258.59 分。动作 239 前新版领先 29.31 分，原版 43 号工本步交回 256.43，下一状态新版落后 240.15 分，此后未再领先。提前十、五、三步，该工分别载 132.90、180.36、231.36，距离基地均为三格。前两次停采，第三次开始左移，最后向下入仓。这席新版相对父代的正常交仓差改善 576.64 分，地租差却少了 2,310.46 分。

两场能定位钱在哪一步到手、哪名工人有机会回仓。改一条当时的命令后对手还会再选择，最终收益需用同局面的替代行动另测。已在两张退役训练图上做过这类试验，预占截格都延缓了对方首笔回款，但两次官方终局分差变化分别为 −1,070.16 和 +886.15。[双席原令与资金转折](hosted/economy.json.gz) · [两次截路对照](../delivery_interception/README.md)

## 天梯时限与证据范围

16 场均自然打满 299 步，官方引擎复核 4,784 次联合转移。双方分配独立的 1.5 核、512 MiB 断网容器，完整公开请求从发出至动作解析计时。各局双方无慢步、无超时。Sapling 最慢一步 0.15923 秒，各局 P95 最大 0.08765 秒，P99 最大 0.09166 秒，冷启最大 0.541 秒以内，容器内存峰值 74,436,608 字节。原版保留温度 1 和 0.58 秒墙钟搜索，4,776 次多候选调用全部完成正深度搜索，另有 8 次单候选。原版最慢一步 0.593 秒以内。整场墙钟最长 156.25 秒。结论覆盖这两份包与这 16 局。[逐局资源实测](hosted/settlement.json) · [托管执行记录](https://github.com/robertyang87/carbon-league/actions/runs/44646376344)
