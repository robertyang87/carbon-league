评估时给原版提供两个已登记的整队命令。己席信念从开局的公开观察和己方实际历史命令恢复；原版根据其可见状态自行采样当拍对手指令、两边后续命令及叶值。打分程序核对全部 108 个公开根的 SHA，在分数落盘后才接入真实分支终局。实际标签的两臂从相同敌方当拍命令出发，各自继续面对仓内原版至官方终局。一个估计的是原版内置推演下的相对价值，一个记录的是既定学生续弈下的实现分差。这项测量覆盖固定菜单上的标签质量，对 Master3s2 使用自身候选打整场的能力没有给出胜率估计。[计分与结算程序](native_teacher.py)

两组各把一对候选次序互换，实算值复原后的最大偏差分别为 0.00000012 和 0.00000036；九个走到终局的推演根、18 个模拟终分均按原版公式逐个复算。108 次比较合计约 20.75 墙钟秒，在本机一核运行。这里的计时只覆盖两案搜索，不含复原历史、实际原版续局或天梯通信。[独立核算](audit.py) · [核验记录](audit.json)
