# 官方分差与胜场对 Sapling 两张策略网的训练信号

**按原始官方终局分差重新计算，六图中只有一图支持 it50 从其余五图学到的更新方向，Sapling 有两图。** 这批比赛有分差可学，但其余地图上的同一步更新大多会降低留出训练图上估计的目标。同期 24 场全负，胜场指示在所有同图同席对照中相等。本次保留现有权重，正式考卷仍未动用。[逐图与逐场证据](result.json)

每个点积比较一张训练图的全策略网络梯度与其余五图梯度的等权平均。各塔分别需要至少四图点积为正，且 15 个不同图对的点积和为正。表中点积的尺度随奖励单位而变，跨行只比较方向和通过情况。分差训练时，it50 在图尾号 462 为正；Sapling 在 460 和 462 为正。图 463 上，it50 与 Sapling 的留图余弦分别为 −0.1662、−0.2817。其余反例及每张图的梯度长度均在证据中。[原判断规则](../alignment_protocol.json) · [原效用结果](../alignment.json)

对同一冻结包 851c、6 张训练图、双席、每席两次独立自然采样，程序从第零步恢复全部 7,176 个已执行的联合行动，按官方终分核对每一场。每局 12 个预定时点中，共 275 个存在两条不同合法整队令，13 个只有唯一命令。对每图的 48 个预定时点使用相同分母，同图同席的另一局提供回报基线。训练席官方终差为 −3,149.49 至 −499.87，全部保留原数值。二元动作概率与实际部署回算最大误差为 0.00000327，对数概率最大误差为 0.00000635。全策略参数分别为 it50 的 3,479,872 和 Sapling 的 1,205,800。[复算程序](run.py)

**胜率与平均分差同时达标的可能性，无法从这批训练谱估出。** 胜指示的 12 组配对差逐组为零，每个采样动作的对数概率梯度都乘以零，两塔的经验胜率梯度因此精确为零，余弦没有定义。分差目标保留了每对的输多输少，仍未出现跨图稳定方向。这个结果限于该包、六张图和当时实际发出的菜单。独立正式验收仍要求冻结候选在 100 张新图换席的全部 200 场中至少赢 180 场，且同批官方平均终差至少 +500。
