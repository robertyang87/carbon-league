## 双塔确定性复验

冻结行为为 851c901a 的真实部署参数与原 guard，工人槽的两个动作共用实际队内前缀。相对分数由 0.75 倍自有 PPO it50、0.25 倍 Sapling 的动作分数加冻结残差组成。登记图 621758460、席 0、draw_a 从第 0 步重放到官方第 299 步，核对每拍公开观察、全队发令及终分 6078.48 比 6860.60。12 个登记时点中，11 个有两种物理命令。Torch 两塔重新计算的第一选项概率与部署实录最大误差 0.00000113；当时所选命令的对数概率最大误差 0.00000323。

对每张网和每个可选时点，实际选择那一动作的输出偏置梯度为该网混合系数乘以 (1 − 所选概率)，另一动作的梯度取相反数。11 根共 22 组自动微分与手算的最大绝对误差为 0.00000085。同席兄弟局的实测效用作基线后，it50 的 stem / GRU 梯度范数为 1.1551 / 0.1955，Sapling 为 0.1487 / 0.0497。本次参数更新为零，权重未动，不涉及任何新图或实战。[可重放程序](audit.py)

这个梯度只在实际菜单、前序令与守卫选择固定的局部区域内成立。既往只更新 Sapling 的一次 0.10 步长已经使 67/288 个时点失去旧物理支持；其中 30 处失去实际抽到的命令。未来若双塔一同更新，需要在真正的量化执行入口重新比较普通步、单项步和双项步的命令及整队概率。旧 24 场已用于训练和模型选择；这些场及既有验证场各自继续保留原用途。当前证据能验证本方梯度方向和训练支撑，尚不足以估计新网对考官的胜率。[既有物理支持复演](../../cargo_tree_action_learning_dev/native_actor_corpus/league_policy/native_return_intake/physical_support.json)
