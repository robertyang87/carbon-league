# 八步神经干预的经济账本

每张登记地图只含一局真实来源对局，Sapling 使用 BC 对完整原版 Master3s2。来源打到官方终局。在第 256、280 步各分两个分支，同一根的对手先出同一份指令，后续自由响应。每个分支的两席收入、支出和官方终局分均可复算。分支续弈用于训练策略选择，整局胜负样本只数来源对局。

程序从独立验过的逐步收据读出实际命令。官方环境重建已登记地图、实体 ID 和每步盘面，另用现有 FastCarbon 逐笔解释现金写入，要求与官方两席每步余额、工人和树状态、最终正式分相符。证据文件以地图为单位去重，缺票或提前灭绝无法到达的根均有状态。训练和留出地图各有独立入口。

- 两席收入包括己方工人正常存入、敌方工人在本站交付、树吸收地面碳、树对敌方货物征收、碰撞直接落入树或基地的钱。支出列出招采集工、招种树工、种树和抢树费用。逐步四舍五入与灭绝的官方计分调整另列。最后 30 步逐棵查投入、后续回收、被夺和到期，列出结束时的树和未兑付的货物。活树没有额外的期末出售价。
- 敌方工人丢货后，能确认接收席位、数量、格子、获利树或基地，或幸存采集工的身份。采集工夺货当时计作载货。沿该工人追到首次交付、再度被撞或终局。中途没有树税且移动费、熔炼费均为零的，原夺货量能逐笔追至存入；存在可能的树税时只报告区间，以及整笔混合交付金额。当前规则没有给单个碳单位记录来源，随载货人死亡后转手的货物列为未由原载货人兑现。
- 每次现金差变化最大的正、负 1 步和 10 步窗口都回看之前 3、5、10 步，附真实指令、单位格点、角色、载量、距离本方基地、双方现金、树权变动与碰撞。全局、根后的分支和两臂相对现金差分别计算。已有提前灭绝时，仅在两臂共同可达的步段找相对转折。
- 同图同席记录两个干预根各自的正式终局分差变化及胜负变化，再按图对两根取均值。记录首个双方分歧是在相同盘面上由学生改令、考官改令、两方同时改令，或整个干预窗口双边都相同。BC 复跑与实际来源局的差额另列。真实墙钟与搜索深度可改变考官后续动作，一次条件续弈的数值是一次实现。
