## 同样换网，为什么有时赚钱、有时亏损

- 542 席 0 的 t256，两个网络首先对两名种树工的方向分歧。格 144 的 BC 向右，格 127 的 BC 向左，elite 对两人都选择向上。同一盘面上考官的动作一致。干预后续弈打到结算，Sapling 的地面树收入增加 590.24，考官减少 171.06。两边正常存入都减少。总账上改网多 424.39。这一例把可回查的战术机会落在种树工走位与后续树现金。
- 544 席 0 的 t256 窗口，在 t260 才第一次改变命令。两个采集工载货 162.168、214.9077，距己方基地 5、4 格。BC 分别向右、向下，elite 让两人原地停留。Sapling 最终正常存入少 168.92，地面树收入少 440.01，考官地面树收入多 251.80。此分支即使少花了 389.83 的种树钱，官方分差仍恶化 522.57。两项改令和后续经济反馈属于同一条已观测轨迹，逐项因果需要另行干预。
- 543/t256、547/t256 首次分歧发生在考官一侧，此时两臂物理盘面相同。547/t280 的八步双方实际命令全部相同，后续终局仍差 13.75 分。后者直接显示一次受墙钟影响的条件回报存在噪声。留出三图上强制换八步的六个根平均 −14.96。冻结选择器的六个预测都沿用 BC，未在留出集提供新动作。
