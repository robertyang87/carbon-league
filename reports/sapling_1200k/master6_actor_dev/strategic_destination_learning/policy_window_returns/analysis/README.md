# 学习何时把一个尾盘窗口交给另一张 Sapling 策略网

**新网没有获得开发出场资格。** 用原版响应训练出的选择器，在所有可达的第 256／280 步都选择 BC。三张盲图正常入口共 897 拍，发出的完整队令全部与 BC 相同，相对 BC 的已核干预收益为 **0**。八条来源游戏均由 BC 从开局对完整原版打到官方终局，均负。32 条后缀只属于 16 个配对干预；本包新增的独立整局数为 0。[学习结果](fit.json) · [盲测与逐拍核对](assessment.json)

这一实验比较两张自主出令的神经网。对手用原版 Master3s2。两臂有共同开局前史和原版根令，接下来连续八拍用 BC 或 elite 走完整队令，再都交回 BC。训练与检验单位是物理地图。预登记五图拟合、三图留验，每图最多有第 256、280 步两个条件根，合计八张图、最多十六对响应。[采集登记](../protocol.json) · [预先冻结的模型、干预和判据](protocol.json)

选择器接收行动前的公开局面。四个系数分别对应偏置、时段、双方可在终局前带回的货量差以及现金和活树的优势。带货估计按距最近己方基地的环面距离折减。每图总权重相同，用带正则的线性回归拟合 elite 相对 BC 的官方终局分差。窗口内两张网实际命令相同产生的结构效应记零，另存两条原版续局的原始终差。双方仍在同一个棋盘时对手率先改变响应（包括同拍变化），该根的可归因效应记为未知。所有已登记根保留，无资格根可从原始逐拍核验。[拟合与核验代码](learning.py)

实际部署入口在第 256 步先选择。正向预测即让 elite 连走八拍，再由 BC 走完整局。若未启用，到第 280 步用当时看见的局面再次决定。一局最多一个窗口。实现直接切换同一套特征和生产解码器里的 Sapling 学生参数，另一张项目自有搭档网、守卫、真实公开历史保留。另一种始终 BC、另两种固定在 256 或 280 用 elite 的做法分别统计。[部署实现](runtime.py)

每个时点的对照可以直接看同一根两份完整续局。若选择器与固定策略在不同时点启用，报告先在各自时点与 BC 做配对，再比较两个配对差。这个量包含独立响应带来的不确定性，并不等于三张新图实打该包的整局分差。未启用窗的 BC 行为、未能到达的登记根、同令响应和存在原版时钟混杂的根均需列出。三图只够做开发筛选。[预测、收益估计和门槛实现](learning.py)

复算按顺序运行 `python learning.py fit FIT_DIRECTORY`、`python learning.py predict HELD_PUBLIC_DIRECTORY`、`python learning.py assess HELD_FULL_DIRECTORY`。第二步只需三份带逐拍己席公开观察的来源记录，无需分支文件。须先固定拟合权重，再固定预测清单，最后开放分支官方结局。三个阶段均核对已写工件，输入冲突时保留原件。单文件实包还须独立验证天梯配额与计时。

## 原版响应与经营结果

五张训练地图各有两个窗口。按预登记，9 根在相同对手当拍命令下出现了本方真实动作分歧，都进入梯度；543 席 1 的第 256 步窗口中双方在第 261 步仍处相同盘面，原版先发出了不同命令，该根的原始差 −180.74 单列。可归因的九次比较有两次 elite 领先。最大正值 +424.39 局面上我方终分增 13.62、对手终分降 410.77；最大负值 −522.57 局面上本方少 268.80、对手多 253.77。一份网带来的现金变化须看双方。

冻结四个学习权重依次为 **−0.076613、+0.012278、−0.003906、−0.044672**。两个时点的时间特征取 ±1，其余两个输入绝对值有界于 1；即使后三项全部往利于启用的方向取极值，模型预测上界仍为 **−15.76 官方分差单位**。在开放盲根之前，已固定六个预测和三图全部选 BC 的决策。[逐根预测](held_predictions.json) · [量化后单文件，7,690,498 字节](candidate.py)
