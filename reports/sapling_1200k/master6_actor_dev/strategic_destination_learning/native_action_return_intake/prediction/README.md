# 把四组新队令送回冻结的终局打分网络

在八条新的原版应答后缀开始前，已锁定四组队令及以下预测。全部来自既有训练图；没有新增从开局开始的对局。旧网络能对其中三组的两条队令直接排序，第四组的备选在其物理候选集之外。[事前冻结的四行](registered.json) · [新两案的完整队令](../roots.json)

| 540／0 | 258 | 41 | 37／缺失 | 弃判 |

| 542／0 | 258 | 40 | 0／14 | +6.49 |
| 543／1 | 258 | 37 | 0／1 | +98.26 |

在后三图只提供这两个动作时，单看分数会选备选；保持旧网络预定的 100 分改令门时会留父令。开放其完整原菜单，四图实际都会选择两个登记臂以外的第三条命令。这批新增的终局只能验证三条有覆盖的两案排序。540 的备选可被合法前缀表示，但与旧网络的基准动作有两个单位不同，超过它原定的一单位候选集，因此未给出分值。所有四张地形与该旧网络即时、终局训练及当时留图的地形均无重合。

程序校验旧单文件的 SHA-256，从训练轨迹中只向旧网传递截至根步的本席公开观察与规则。八个隐层通道、队令对队友的前缀影响、拒绝冲突的条件和终局打分均使用被冻结包中的实现。两方得分方向始终为行动席减对手。根步的对手令、另一席碳视图与后续赛果没有进入打分。该评分网络既往四张留图的地图等权收益为 −39.65，保留本次预测供事后证伪；仅四个训练根不足以测胜率。[原冻结网络的协议与成绩](../../../joint_response_critic_dev/README.md)

用项目 Python 环境在当前目录运行 `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python score.py --out registered.json`。若文件已存在则检查复算字节一致。冻结登记 SHA-256 为 `7e5839a9e9a189a199b67dd300458fc78a575715eadb6aba2f4aef63c9a23d96`。[复算程序](score.py)
