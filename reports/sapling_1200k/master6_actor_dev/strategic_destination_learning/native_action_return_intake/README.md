## 一个工人怎样改变了两边的现金

- **540**。起点 73 格的空载工停留可采到 14.3202 碳，左移后仍为空载，随后在第 265 步的观察中已经消失。左移分支全队的终局差距反而缩小 111.96。两队普通交仓的净差相对改善 232.75，同时有额外招工和种植支出。不能从工人眼前单次采集量推导全队终局收益。[逐拍账目](tickets/621758540/economy.json.gz)
- **541**。起点 213 格的采集工携货 247.2885。停留后货量升到 254.5461，之后在第 281 步的观察中已经消失；下移分支中，该工人一直活到最后一次发令。下移分支的本方终分更多，但原版终分也上升，其净分差低 44.57。两队普通交仓相对恶化 60.57，地面树租相对恶化 63.79。[逐拍账目](tickets/621758541/economy.json.gz)
- **542**。携货 29.065716 的采集工选择向右或向上。原版在根步发出同一条命令，两臂当拍结束时该工都携货 26.1591444。实际差异在后续形成，上移分支两队地面树租的净差改善 319.15、普通交仓净差改善 125.64，同时多承担种树和夺树支出。最终分差追回 286.85。[逐拍账目](tickets/621758542/economy.json.gz)
- **543**。起点 132 格的工人携货 153.3147，左移和停留后货量相同。停留分支两队地面树租净差少 651.29、普通交仓净差少 304.33，同时相对少花种植成本 375.09。最终分差低 569.99。该路径上的现金差可逐笔核算，长期变化还包含之后不断变化的原版应手。[逐拍账目](tickets/621758543/economy.json.gz)

## 数据边界与运行环境

真实原版包保持温度 1、未固定随机种子及原生 0.58 秒搜索。分别按真实公共观察重演 259 次历史调用，依照源档案复原实际执行命令、意图状态和每拍四个搜索成本值；各图有 123、127、46、74 次影子出令不同，均按当时实发令修正。档案没有原场的私有伪随机状态。两分支从同一个新建的考官私有快照出发，保留真实物理墙钟与随局面变化的搜索深度。每一臂 40 次新应答的平均深度分别为 6.88 / 6.90、6.53 / 6.70、6.95 / 7.08、6.85 / 7.20（父 / 备）。所有分支完整执行，无重试或剔除。进程限同一逻辑核；计时属于本机训练诊断，天梯资源认证需另测。[逐图收据](tickets)

本批终局标签仅来自四张原版训练图。545–547 留用图、560–561 开发图和正式考卷均未动用。对其余菜单中的完整命令没有真实终局标签。较高或较低的终局分都只能归属于实际测试的整队命令及本次共同续弈策略；第 258 步采集工的四个响应也无法代表基地招募、种植工或其他步段。各图收入账保留现金转折前 3、5、10 步的公开状态、双方命令、实际到账、碰撞与树权变化，均由完整行动史核算至终局。[现金复算](economy.py) · [标签导出](training_pairs.py)
