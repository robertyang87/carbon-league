# 同一续弈策略的后继价值能否识别更好的命令？

把一名工人留在树旁或挪开一格，当拍两席现金都可能纹丝不动。这里用三组已有的原版 Master3s2 对局训练一个小网络，估计两条命令各自执行后的官方终局分差。其用途是给值得花 CPU 验证的命令排序。它目前没有进入 Sapling 的部署包。

## 训练与地图隔离

训练数据有 20 场，地图为 621758500、501、510–513、520–523（后九个编号同前缀）。每图双席，Sapling 使用同一份 ede48ad9，考官是原版 65f268b2。以原始逐拍请求和行动重放，逐拍核对己席公开观察的哈希，再核对官方终局计分。每局取第 150、153、…、297 步，共 1,000 条；局内 50 条共享同一个终场，各折一次排除整张地图的两局。数据清单可逐条追到来源压缩包、逐拍哈希、席位和官方分差。[来源与折外指标](fit.json)

网络估计从当前到终局还会增加多少分差，以当前可见两席现金差为起点。73 维输入包含现金及过去 3、10、30 步变化、双方采集工和种树工数量、携货与回家距离、货物附近更轻的敌人、树龄与当前树收入，以及原有公开特征的聚合。24 个 tanh 隐单元的投影固定，只训练带线性旁路的岭回归读出，使用剩余回合缩放。神经网络从己席公开历史读取后继局面。两条命令各自复制同一份历史，由官方规则推进一拍。离线重演的这一拍固定对手当时真实发出的命令，部署时仍需预测对手。[拟合实现](learn.py) · [分支实现](forecast.py)

## 留整张地图的终分误差

每折使用其余九张图。三种方法在同样的 100 条折外状态上计误差，十张图等权。分数单位均为官方终局分差。

| 预测方法 | 平均绝对误差 |
|---|---:|
| 维持当前现金差 | 646.70 |
| 当前现金差加其余九图同席、同一步的平均剩余分差 | 323.94 |
| 后继价值网 | 258.73 |

网络在 10/10 张图优于纯现金，在 7/10 张图优于同席同期基线。后一项为事后补做的次要对照，单独存档，从未进入拟合过程。此结果支持对整局终分进行估计。要判断能否分清同一局面的两个近邻命令，须验证小得多的成对差值。[全量折外行](out_of_map.json.gz) · [强基线逐图误差](seat_stage_baseline.json)

这四张图的地形都从拟合和折外校准中排除。两案均从第 258 步的同一公开历史起步，下一步现金差在四张图上均相等。正号表示预估备选动作提高 Sapling 的官方终局分差。

网络在邻近命令上给出的典型差值远小于其终分预测误差。量纲与模型都允许它做出细粒度排序，排序的可靠性需要独立真实续弈，不能从上表折外绝对误差推知。归档 critic 仅 3/4 对同时覆盖两个不同命令，且有独立输出尺度。四个预测只针对固定的 BC 续弈与该步实际敌令；每根只有一对真实后缀时，单次实现的符号可能不同于期望值。[冻结逐根预测](frozen.json) · [先前审批的动作 critic](../prediction/registered.json) · [双臂登记](../roots.json)
