# 四个训练根上的网络动作分布

本补充在查看新分支终局前登记。固定 540–543 四张训练图上已冻结的物理整队动作、两套概率和两臂选择。两个概率分布来自同一采样器，分别使用训练后的神经头和置零的神经头。每个局面另有一套确定的父代动作，供比较。[冻结动作和概率](roots.json)

每个根仅实测父令和一条备选令，其余动作仍占一定概率。分两种范围报告。

1. 在已测两臂内部，分别按两套网络原概率归一，以备选概率之差乘该根实际的备选与父令终局效用差。这给出只允许这两条动作、随后交回同一 BC 网络时的分布差。
2. 对整个根分布，按动作取训练后概率减置零头概率。两条已测动作分别乘各自实测效用。其余动作的效用各取 0 到 1，负系数给出下界增量，正系数给出上界增量。另与确定性父令计算同样的全分布范围。先逐图，再等权汇总。所有数值以已抽到的两条原版响应为条件，范围只反映缺少动作标签，额外响应抽样的不确定性未计入。

四图都在训练池，每个分支干预的是单拍，均以 BC 续弈。这项计算能检验对已有动作重新赋权的方向，并标出哪些判断还缺数据。它不产生新的独立开局胜场，不提供持续部署整包的胜率估计。[实现](policy_values.py)
