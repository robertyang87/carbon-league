逐拍、逐双方检查载货至少 100 的采集工。每个时点只根据当时位置、载量和基地枚举一步更近的所有格，登记哪些格能被更轻敌工同拍到达。另记有一条安全路线、同时有另一名我方工人能以更轻载量去争另一条危险路线的机会，并用双方实际命令核实是否兑现。这里的「安全」仅指一拍内没有严格更轻敌方采集工能到，等重同归、未来路线和队内冲突仍可能发生。这是一项几何机会指标。实际下令与死亡另列。

## 两个反例与训练选择

- 天梯唯一败局是 M9XJ 席 1。它在第 100 步现金领先 166，第 250 步还领先 430；终局地租多 1,599，却因正常交仓差跌到 −1,316 等原因以 155.92 分惜败。第 250 步的现金优势没有保到终局。原场 ID 为 `7080dd608162c47e5856f7594360841e-1`。
- Sapling 唯一胜局是 replication 的 BC 包、621758513 席 0。第 100 步现金已领先 1,329，地租领先 1,474；第 250 步现金仍领先 507，终局只赢 18.06。靠早段获利能打赢原版，长期保持收益仍是独立问题。
- 前五内部也有多条路线。ClaudeFable5.2-v7 的 9 胜在第 100 步平均净地租为 −18，it720 的 9 胜为 −139；Master6 两局为 +19，M9XJ 八局为 +373。第 100 步累计交仓差在五个人的样本均为正。Master6 的两局均胜，单独不能代表它在所有地图上的打法。

**训练选择**：优先在训练许可且不同于上述开发图的新状态中，抽第 60–100 步与相应较早布局，生成可执行的联合动作分支；同一状态比较正常经营、保护本方回款、干预敌方回款与树权交接，沿真实响应记录双方最终各自现金、交付和树租。网络训练保留双方分项作为辅助预测，主排序使用同根配对的官方终局分差，并记录分支无收益的情形。独立图只评价学成的整局策略。这里的数据能选择下一轮训练的覆盖范围，现有回放没有为同一状态下未执行动作提供终局标签，也没有识别某一种干预一定有效。[已有原版同状态防守反例](../elite_direct_policy/development/defense_response/README.md)

## 墙钟与复算

Sapling 三批 13,156 次原版调用均绑定程序 SHA。22 次单候选都在第 0–29 步，多候选零深回退 0 次。第 60–99 步的 1,760 次原版调用每次均完成正深度，54 次触发搜索截止，外部请求耗时 P95 为 0.558 秒，超过一秒 0 次。逐阶段及逐批次的候选数、深度、截止、CPU、公开函数墙钟和完整外部请求耗时均在对照工件中。天梯回放只提供配置；两组能对齐的是物理行动步和经济结算，无法按相同原版搜索深度作跨组估计。

以下命令从已有回放重算，使用仓内游戏环境和 NumPy。两份 profile 保留逐局两席的六个行动前检查点及第 299 步终局状态，比较文件提供聚合和分层。

```sh
python profile.py top5
python profile.py sapling
python compare.py
```
