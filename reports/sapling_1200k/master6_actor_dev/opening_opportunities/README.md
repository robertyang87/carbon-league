# Sapling 能否复制 Master6 的开局断粮打法？

**对原版 Master3s2，现金告急常见，能立即拦住关键运货工却极少。** Sapling 的 66 条开发实战轨迹共提供 4,977 个开局决策。Master3s2 有 867 个决策点连招一个最便宜的工人都付不起、且只剩一两名采集工仍有人带货；双方的合法路径可在两步内相遇的有 143 个。允许目标停留或沿最短路线返航时只余 13 个。这些根覆盖三张图，九图等权的触发率为 0.162%。用对手实际下出的命令重放，15 个一回合可接触的根里，单改我方一名轻工的命令能额外击杀且存活的为 **0**。原有的中游对手案例能说明牵制机制；这批真身实战支持训练对手走位、抢道与护送的判断，尚不足以启用“对手缺钱就追”的策略。[Master6 原案例](../../all_top5/master6_denial_cases.md) · [审计数据](summary.json)

## 公开观察给出的攻防窗口

每列均以同一批 4,977 个决策点为分母。威胁反转列从 Sapling 本席同一套公开观察计算，检验 Master3s2 的轻工能否碰到我方关键运货工。

|开局条件|Sapling 可攻|Sapling 需防|
|---|---:|---:|
|目标现金低于当回合最低招工价|1,494|1,852|
|目标只有 1–2 个活采集工，至少一人带有可存入的货|1,129|881|
|上述两条件同时成立|867|688|
|另需较轻敌工在任意合法路径上可相遇，一步 / 仅两步|15 / 128|26 / 107|
|另需目标停步或最短返航仍能在一步 / 仅两步接触|4 / 9|6 / 3|
|返航窗口里同时覆盖全部带货工 / 目标当前没有树|5 / 3|4 / 7|
|返航窗口里见证运货工随后五步实际回存 / 实际消失|9 / 0|3 / 0|
|最宽合法窗口里见证运货工随后五步实际回存 / 实际消失|122 / 1|105 / 0|

两个“仅两步”计数均排除了相同根上一回合已有机会的情形。Sapling 可攻的 143 个窗口里，唯一后来消失的运货工在根上先向上走、**已经入账 57.79**，四步后才消失。反向 26 个宽口径一步根，同样没有单改 Master3s2 一名工的命令就能新增击杀并存活的情形。对手现金放宽到不足 45 / 60 时，返航窗口从 13 增至 20 / 24；把“全队只剩两工”放宽为“全队可以有更多空载工，但可交货工至多两名”，则有 39 根。后者遇袭后仍可能有空工继续采集。三组计数均可由逐根条件复算。[统计表](summary.json) · [逐轨证据](games.jsonl.gz)

## 三处可看清前因的实战

坐标为 15×15 棋盘的原始格号；记录先在当前观察选根，再读取未来五次双方真实命令。每根见证选择最短接触时间，再选载货较轻的拦截方，工号作稳定排序。

- **3s2 真能绕过拦截并交货。** 地图 621458920，Sapling 席 0，t17。对手现金 18.23，有一棵树，过去五步其采集工从 55 经 40 到 39，停留积到 40.75。空载的我工在 99，存在双方第二步相遇于 69 的路线。对手实际走 54→55→70→69→68，t19 的推进在基地 70 交入 **40.7451**。第一步预测相同也不足以锁住第二步。[该局实际命令](../candidate/raw_621458920_0.json.gz)
- **无树、缺现金也未必急着回家。** 地图 620106811，Sapling 席 1，t9。对手现金连续六帧都是 20，无树。其工从 35 经 50、65、80、95 前出，根上在 95 带 15.96。我方空工在 80，可冲 95 攻击原地等待的工。真实对手却走 94→95→95→80→65，五步未存入，工仍存活。[该局实际命令](../../tree_exam_basecal/raw_620106811_1.json.gz)
- **护送要从装货阶段预警。** 同图另一局，Sapling 席 1，t69，我方现金 12.50、无树。运货工从 93 经 94 到 95，连续停留，把载货从 75.99 提到 136.92。对手空工在 79，两方均可走到 94。我方实际转向 110→125→125→140→155，五步内人还在，尚未入账。模型应识别的变化既有追兵靠近，也有连续装货扩大暴露额。[该局实际命令](../../tree_exam_soft_it50_v5_guard/raw_620106811_1.json.gz)

- **纳入与去重。** 冻结 Git 树 `4a400100aa53be4c3d7575a3baa4ded32cf60451` 提供 70 条有逐回合双边命令的完整赛制原始文件。排除 2 条执行异常的日志预试及 2 条纯 it50 对照，余 66 条。逐条验证原版文件 MD5、完整搜索默认配置、逐步搜索调用、实战双方命令、终局状态哈希和官方分；用初始棋盘、规则、两席整局命令重算整条轨迹指纹，66 条均不同。截取 t0 至 t75（含）；有一条在 37 次推进后按规则灭绝，保留全部 37 个可决策根。三份早期考场压缩包只有分数或累计台账，四条 `it50_v3_fresh_games` 只存动作摘要；从中局或终局根发出的短分支没有独立实战开局，均不并入分母。
- **同图相关。** 4,977 根按“棋盘、本席、步号、可见观察”合并相同历史后为 4,606 个不同当前观察；143 个可攻宽窗口去重后为 131 个，13 个返航窗口全都不同。另按每张图各占 1/9 权重，宽窗口可攻 / 需防率为 3.208% / 2.987%，返航窗口为 0.162% / 0.089%。样本是九张开发图、多策略重用；这些比例不用于推断独立地图的胜率。
- **规则与信息。** 检测只读 Sapling 当前观察中的双方现金、基地、工人身份/载货/坐标、树数及公开规则。各工种的当期招工价等于该工种基础价加上全场存活同工种人数乘涨价系数。取两价较低者，恰好够钱可以招；这批规则的两价实测都为 30。运货工须带货高于净化费、有本方基地且在剩余步数内几何可达。追兵须严格轻于目标；成本、招工、树收益和第三名工人仍会改变下一步状态。返航口径可在第一步覆盖原地或最短返航步；仅两步时双方持续向接触格推进，目标须在两次最短返航推进中尚未提前交货。我方第一步要求移动，以免空等采集改变重量。最宽口径给目标全部合法动作。当前坐标转为环面邻格，未使用隐藏碳图或未来命令来选根。[官方规则](../../../../code/env_src/carbon_challenge-master/zerosum_env/envs/carbon/helpers.py) · [实现与选择器](scan.py)
- **复原与反事实。** `games.jsonl.gz` 每行有源文件、物理席、棋盘/命令/原文件哈希、分项计数。每个符合宽窗口的根都附双方实际命令、逐格去向、死亡或货量、逐 UID 正常返家入账与前五帧位置。窗口相邻时可观察到同一笔入账多次。一步反事实枚举所有可撞上的轻工和带货工，将我工单条命令改为对手实际抵达的格子，复放该回合，要求原来活的敌工消失且我工在该格存活；其他单位按真实提交行动。未用实际对手未来方向给模型打分，也未测围堵、多工封路及对手对首步改变的响应，更未估计改令后的最终收入。[数据](games.jsonl.gz) · [一步翻转/动态招工价测试](test_scan.py)
