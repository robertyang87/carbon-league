# 中盘种植工走位二次检验

首轮的两名工人都走到了拟种地点。一个地点下一拍受威胁，另一个的实见碳低于历史估计。此次保留原收益评分、每局一次和次拍复核，只接受两个可在出发前检验的条件。敌工到目标的环面距离至少三格，下一拍即使敌方走近一格，也不能立即走入目标格；目标四邻的下一拍碳量保守下界须合计 ≥120。落点有价值仍须靠实际付款、持有收益以及两方重新决策后的终局检验。[冻结方案](site_protocol.json) · [公开信息下界与选令](policy_v2.py)

下界从 0 开始，只用该席当前确实看见的碳刷新数值。两次观测之间，树所在格、基地、可能留种的工人所在格可降至 0；采集工按最大可能采收率扣减，再扣已有四邻树的最大总吸收比例，不计再生，额外向下预留碳量三位小数的舍入误差。根步本方已确定移动的工人不能在原地采或种。用于行动的下界只读公开信息；原始引擎的完整碳单独用于事后校验。

树收益模型沿用在 322–326 号图已冻结的系数。此次用 320、335 两张既有开发图，身份为同一完整父包 c5ad3f43，两席各取一盘。原封重放 1,196 次联合决策，父包本方命令全部匹配。四盘合计 269,100 格次，每一格都检查当前下界以及下一步下界，没有超过实际土壤碳。每盘考察 100 个中盘行动，320 两席有 0、4 个候选，335 有 3、5 个。按事先顺序取第一处，并要求两席不同图，其余候选不补考。[逐盘核对](verified_prefixes_and_bounds.json) · [所有候选](survey.json.gz) · [选中根](selected_sites.json)
