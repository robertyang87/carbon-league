# 同一局面起，持续用哪个伙伴打到终局

这项实验固定己方 Sapling 实际出令权重为 25%，只比较另外 75% 来自自有 Echo4 it20 或 it50 时，同一支队伍在**接下来整段余局**的表现。根选在第 195 和 225 步。此前从开局考两套包的四张开发图通过原预注册清单排除，包含在跑的八场。训练和留出只用较早的 it50 父代对仓内完整原版 Master3s2 的真实公共轨迹。

## 为什么需要新的配对

核对了 16 张旧图、64 个旧根、128 段原版续弈，实际有 20,218 次根后搜索调用。它们只在根上改过一个工人的命令，随后两臂都执行同一份父策略。新实验固定根的敌方同时命令，在各分支的之后每一步继续用该分支自己的 75/25 包发整队命令，对手重新观察、按其原有温度和墙钟搜索。棋盘、历史记忆、后续终局和打分均实走。历史原版未存每个根的原始随机数及单步成本预测器，所用的是公开命令重建的信念历史、同根的新共同随机流与同一起始耗时估计；不把它说成复现了原局随机轨迹。[旧试验和重用边界](source_audit.json) · [源包与采样预算](protocol.json)

## 从公开局面构造候选

以行动前双方真实工种、树龄、现金、采集工携货、距本方回款点远近和可见敌轻工计算三项信号。敌方可安全近程回库货值加我方易被截货净差达到 50，产能落后至少一个采集工等价量，最近十步双方现金变化之差低于 −30；三项中达到两项就划为受压，否则为平稳。产能代理为采集工数加四分之一的尚存树寿命折算数，按当前规则 50 步树寿命计算。这是事前冻结的分组假设，价格阈值和树折算本身尚未被证明有最优性。报名者、地形编号、席位和终局信息均不进入伙伴选择。每个根保存此前 3、5、10 步公开资金和工人数，可对照变化趋势。[公开状态函数](policy.py) · [全机会清单](census.json.gz)

23 张符合来源的真实地图都按物理地形先分训练和留出，再在每张图的双席、第 195 和 225 步上检查可用局面。选定 6 张训练图（两组各 3），4 张独立开发图（两组各 2），每图只计一次。两组内部均涵盖两个物理席位与两个时点。取样与终局、高低分及两包是否立即改令无关。两个预先选中的训练根另换一条共同随机流，只用于检验改动方向是否敏感。[唯一根清单](roots.json)

在指定根与前两拍真实输出中，训练组 2 张、留出组 3 张有 it20／it50 联令分叉。去掉 25% Sapling 项后分别在 5 张图上改变 it20 或 it50 的实际动作。两包使用相同公开观察历史，it50 在审核步与原日志逐命令一致；在已热身的 it50 特征状态上仅替换伙伴权重，产生的联令逐项复现独立热身的完整 it20 包。第一个训练根的当拍命令完全相同，仍照常计算其后的整段政策。[实际入口及留席历史核验](mechanism.json.gz) · [共同根两臂实令](responses/root_fixture.json)

## 预算和裁定

每个训练组内，真实官方分差 it20 减 it50 的均值为正且至少两图支持时选 it20，否则选 it50。逐图留一后的六个预测，须实际用到两种伙伴、且平均官方分差同时高于两个常量策略。如果两个指定重复根的结果都随共同随机流翻转，同样停止。只在通过此门后打开独立开发根的原版响应，四图还需同时优于两常量且获胜数不低于任一。小样本整段响应不折算正式 200 局胜率。[拟合与判据实现](fit_gate.py)

总活跃预算 2,100 秒，训练最多 8 个成对续弈，留出最多 4 对，合计最多 24 条分支。单个真实考官使用一个固定 CPU 核、单线程 BLAS 和原来搜索墙钟。队列等另一项已登记的八场签收且共用原版工位释放，等待不耗预算，重启也不重置额度。每条分支逐步存双方联令、原版 RNG 与耗时预测器进度。状态可查看本机 status.json，恢复时以单一调度进程从任何目录运行本文件所在目录的 `supervise.py`。[原版响应与恢复](responses/native.py) · [单一调度](supervise.py)
