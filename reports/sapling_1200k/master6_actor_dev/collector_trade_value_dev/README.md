# 相遇时两名采集工往后 25 拍各能交多少钱

用三张已曝光开发图的六场原版 Master3s2 对局拟合岭回归，再用另两张地图的四场双席局评估。每次行动前仅用己席看到的人员、载货、基地距离、现金、步数。标签是该工号随后最多 25 拍实际交到己库的金额，死亡后为零；这个量没有计入牵制、转移到其他工人或整队的净收益。[训练入口](value.py) · [模型权重](weights.json) · [不可混用的地图与源件哈希](evaluation.json)

在两张留图的 16,740 个采集工决策点上，预测单工交付的平均绝对误差为 56.82，直接以当前载货预测为 58.90。同一局相邻时点重叠。用于判断是否互换时，选双方等载、距离不超过两格且距终局至少 25 拍的第一次相遇，同一对工号每局只留一个时点。在 269 对上，预测双方后续交付差的平均绝对误差为 **35.66**，假设两工等值为 **29.28**，四场均是等值对照误差更低。101 对的随后交付不相等，模型方向命中 65 对，固定猜己方更高命中 64 对。没有依据让这个头单独接管互换。样本仍是原策略走出的后续，不能据此推断改变首令的终局收益。[逐对预测与实际回款](pair_rows.json.gz) · [分席留图结果](pair_metrics.json)
