# 更换 Sapling 专家伙伴后的逐笔现金与局势回溯

两轮均使用仓内完整原版 Master3s2，候选将双网中的 75% 专家从 it50 换为 Echo4 it20，保留同一 25% Sapling。每轮各有 2 张开发地图，双方换席，父代和候选各 4 局。第一轮使用此前签收的父代；第二轮另选 2 张图，同批重跑父代和候选。各局保留原版默认温度与定时搜索，对手的随机轨迹各自独立。

| 开发批次 | 候选胜局 | 父代胜局 | 候选平均官方分差 | 父代平均官方分差 | 地图等权改善 | 两张图分别改善 |
|---|---:|---:|---:|---:|---:|---|
| 已经对过局的两图 | 1/4 | 0/4 | −976.11 | −1,346.81 | +370.70 | +606.23，+135.18 |
| 另两张开发图，同期对照 | 0/4 | 0/4 | −993.52 | −1,642.21 | +648.69 | +721.88，+575.51 |

两图只有两个独立地图簇。以各地图两席的平均差计算，自由度 1 的 t 区间分别为 [−2,621.89，+3,363.30] 和 [−281.18，+1,578.56]，只能作为小样本范围参考。

**第一轮**的候选平均每局比父代多得 135.58，对手少得 235.12。唯一胜局第 47 状态本方还落后 22.50，第 57 状态首次领先超过 500，当时领先 502.40。十拍净增 524.90 中，双方树吸收现金差贡献 +359.81，实际回库交付差贡献 +217.02，本方相对多花种树费 141.94。第 54–56 拍本方采集工连续上移，在 160 格基地兑付 220.61。同时种树工在 105 格停下花费 70.97。[历史对照八局与胜局逐步动作](historical.json.gz)

**第二轮**候选每局平均比同期父代少得 470.67，对手少得 1,119.36。候选自己的树吸收收入增加 319.74，交付收入减少 359.87；对方的交付收入减少 757.92。重演已核每一步双方到账和扣款，所有终局计分与官方一致。两批的资金构成不同，不能据此把比分差额归给某次改令。[同期对照八局](replication.json.gz)

**领先也可能守不住。** 第二张新图的两席分别在第 70、74 状态首度领先超过 500，最后仍负 344.51、706.39。席 0 在第 265→275 状态让出 743.72，其中 692.75 来自双方交付的净差。席 1 在第 84→89 状态让出 676.52，其中交付净差达 656.57。第一张新图的两席峰值只有 47.01、350.72，档案分别收录其 3、5、10 步最大回升期。每个所选步骤均有双方真实整队命令、单位位置与货量的前后值及现金流水。[四局过程与反例](replication_comebacks.json.gz)

从装有本仓依赖的 Python 环境在本目录运行下列命令可复算；只读取已经签收的游戏，不启动比赛。

```sh
python audit.py historical
python audit.py replication

```
