## 实际更新了什么

以正在做独立对照的旧父包 `c5ad3f43…` 起跑。固定自有 Echo4 it20 的全部参数和 75% 权重，Sapling 占 25%。106 个 NPZ 条目的身份和形状相合，仅 Sapling 的五个工人动作输出偏置改变。部署包保持原有两路返航解码、整队守卫和贪心出令。候选包 SHA-256 为 `1c2b60b1575767e6d800901e208e510acc4be95ef2c339aca6f80bca3e5d2fb2`。以前的单网 PPO 已用过胜败奖励，之前的双网融合训练学习过专家示范；这次实际用终局 U 改变 Sapling 可部署参数。[既有实现核对](prior_audit.md) · [参数前后值与包身份](package.json) · [权重](candidate.npz) · [可独立运行的包](candidate.py)

四张已曝光训练图各取两席。每席回放当时真实的公开历史，预先只在第 260、271、282 步查看当前可用工人，从三处选一个动作分布熵最高的工位。每根抽八次，允许抽回同一命令。抽样发生在该根，之后双方持续响应直至官方步限或灭绝。我方续弈由实际父包执行，对手用确定性的自有经济或袭扰陪练；原历史开局供恢复状态，真实 Master3s2 此次没有出招。不同根、地图与物理席均留有来源。两张开发图未用于更新或挑选参数，双方都从第 0 步打起。[训练数据与续弈](training/) · [地图声明](map_declaration.json) · [地图查重](map_clearance.json) · [历史动作带规则核验](world_verification.json)

每个抽样根只随机化一个工位。基础分支和返航修正分支各自在自己的真实合法前缀上计算 75/25 融合分布，用同一个均匀随机数选择该工人动作，后续单位重新解码。两个分支都完成后沿用原整队守卫。对双分支 CDF 的区间逐一求最终物理命令；相同整队命令的区间长度之和就是实际概率。训练代码从合并后的命令分布抽样，独立复核将每次抽样映回两个解码器共同使用的随机数，64/64 次原样得到实际执行的完整命令。实际 64 次抽样都没有触发保护回退；另有合成反例，受保护招工令变化使两个区间合并到同一实际命令，其概率和导数均核对。40 个“根 × 偏置”中央差分均维持相同支持集，最大绝对误差 0.000404。[真实联合概率实现](policy.py) · [实际出令和梯度复核](likelihood_evidence.json.gz) · [回退反例](test_policy.py)

64 个抽样观测在八根中共对应 24 个去重的真实终局分支，43 次抽到与该根父包贪心不同的命令。每次观测的优势用了同根另外七个观测作基准，41 正、23 负。每图等权，图内两席等权。L2 长度 0.5、0.25 的两次更新使部分过去可执行的联合命令概率降为零，被预先登记的信赖域规则拒绝。L2 为 0.125 的更新保持所有旧支持，各根最大 KL 为 0.0001763，实际抽中命令的新旧概率比为 0.9792 至 1.0184，训练替代目标增加 0.000711。四张开发席上的真实胜负与收入见上表。[优化器](trust_update.py) · [新旧概率及每次步长](update.json)

## 同一局面的三种替代命令

训练后按终局 U 跨度定位到 621471120 图、席 1、第 260 步。此根占八根梯度向量长度之和的 90.34%。第 250 步种植工 42 在 204 格，采集工 55 尚未出现；第 255 步两工在 203 和 10 格，第 257 步在 217 和 219 格，第 260 步在 37 和 23 格，采集工仍为空载。父代命令为种植工向上、采集工向下；三个替代整队命令都让种植工向右，采集工分别向左、向右、向上。四条完整续弈分别取得 −81.95、+641.05、+475.17、+434.43 的本方分差。最赚钱的分支到第 265 步两工均已消失。这个结果反映后续双方所有响应和收入，不能据此给“牺牲工人”或某个单独移动定价。该图原先已经用于训练，此处按事后极值选例。[前 3/5/10 步及后续分支](turning_example.json)

单个晚段配对根很容易因终局胜负翻转而主导梯度。这里用有限的训练图改变全局工人偏置，发现了能改变胜负的具体命令，却没有在新图持续增加相对收入。下一次同类实验需要把能与父代打到接近胜负线的陪练、涉及不同工种和不同路线的独立地图纳入对照，才值得判断按状态更新是否优于全局五个偏置。
