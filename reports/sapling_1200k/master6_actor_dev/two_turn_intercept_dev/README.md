# 提前两步封运货路线，原版对手如何应对

两张已用开发图、四个决策点。每点的原走法和封路走法共用全部前序、根步敌令、初始随机流与搜索成本估计；根后两侧自行出令，原版对手保持温度 1 和 0.58 秒自然墙钟。封路线允许次拍依据最新位置再选动作。以下四个案例中，第二次判断均保留该局面原 Sapling 策略的命令。分差取 Sapling 视角，均经官方解释器与现金账核平。

| 开发图 / 席 / 步 | 第一拍原命令 → 实验命令 | 原路线终局分差 | 实验路线终局分差 | 差额 |
|---|---|---:|---:|---:|
| 621758322 / 0 / 242 | 下 → 停 | +47.94 | −21.59 | −69.53 |
| 621758323 / 1 / 233 | 下 → 停 | −1,604.83 | −1,387.09 | +217.74 |
| 621758322 / 0 / 52 | 下 → 左 | −1,191.22 | −784.92 | +406.30 |
| 621758323 / 1 / 226 | 下 → 上 | −1,564.29 | −1,248.84 | +315.45 |

第一批把留在原地可采的碳算入估值，导致两个根的选择主要受采集驱动。第 242 步封路工停留后货量从 0 增至 9.32；第 233 步从 40.88 增至 50.24。两局均无预期截货。第 242 步根的原路线续局是本批唯一胜场，来自旧图、并非实验路线。

补测将两步预计截货增益与采集机会成本分别设门槛。两席各自的 266 个时点中各有 3 次符合；其中第一席三次集中在第 49、51、52 步，不能作为三个独立地图。每席取最晚的合格根，在读取新续局结果前冻结。两次改令都让终局少输，但实际没有截到目标货物，也没有延迟其第一笔交付。第 52 步例最清楚：走原路线时目标次拍向上，走实验路线时它向右绕行；它在原路线根后第 5 拍交 78.06，实验路线第 4 拍就交了 74.87。我方工人原路线在次拍死亡，实验路线存活。两条分支后面的采样亦有差异，此局不支持将 +406.30 归因为抢货或单一存活事件。第 226 步两臂的目标都于根后第 3 拍交回 231.84。把原轨迹的目标位置固定不动来评估封路，会漏掉真正对手绕行的反应。

实验路线 0 胜 4 负，原路线 1 胜 3 负。四根的根后原版调用每臂分别为 56、65、246、72 次。原路线/实验路线的原生截止分别为 0/2、0/1、1/2、1/1。无剔局。因实际截货条件未满足，不将本版本扩到新开发整场或正式考试。两臂使用重建历史、共同的新随机流，不能保证复现原比赛的机器时序。
