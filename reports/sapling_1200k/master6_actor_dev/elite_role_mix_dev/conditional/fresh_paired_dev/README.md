### 树是在什么地方少收了钱

逐次重放树账户后，席 0 相对父代的净树吸收收入下降 1980.42，其中来自地块碳的部分下降 2137.54，来自敌采集工货物的部分反而增加 157.12。按所有权合计可吸收的树步数（新树当拍无收入），候选本方从 884 降到 493，对手从 1868 升到 1945。本方新种与夺树的实际付款次数从 23＋12 降到 13＋4。用双方各自的平均每树步产出作对称分解，持有时长和数量贡献 −1090.05，单位树步收益贡献 −890.37。后一个数包含对手土地变得更高产，本方的单位树步收入实际从 2.06 升到 2.47。席 1 的净吸收变化为 +70.16；这些金额只解释本图已经发生的收益。树款、夺树费与树上碰撞另列。[双方账户与分解](tree_attribution.json) · [复算代码](tree_attribution.py)
