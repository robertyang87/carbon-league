## 开局隔离与计时

两张图为开发专用，已加入正式抽图排除。完整扫描逐图覆盖约 18,916 个文件或归档成员、1,116 个已记录的非天梯初盘与 237 个额外生成的初盘。另查本地 246 个师料缓存所对应的真实种子和地形，逐字检查冻结快照到开场前 main 的增量。冻结后来源中的一处文本命中是把这两张图加入正式考卷排除的声明，早期版没有这两号；保留了原始扫描及该处精确来源。另从单列执行故障局的真实 full_carbon 重算第 0 步地形，确认两张开发图与 1,548 张完整天梯图及该故障图的种子和地形均无交集。[初盘复核](clearance_fault.json) · [入场时 Git 增量](clearance_tip.json)

同一席的两臂并跑，在下一席、下一图交换物理核。每一对都申请相同的共享原版工位锁；相邻波次之间释放。真实出令返回后只读记录原版各步的完成深度、候选数、单路返回、零深回退、超时、是否改令、进程 CPU 秒与外部墙钟。计时记录和原版动作、RNG、费用估计同票据保存，中断后只补尚未确定的步。主机同核累计占用包含其他进程。每局 wall 文件绑定实际动作带 SHA-256。[运行绑定](games/binding.json) · [计时代码](clock.py)

计时汇总见 [各席的搜索深度、开销及 CPU 争用](clock_summary.json)，开局一步的两方联合动作对照与 100 步内实际经营轨迹见 [首处分岔](first_split.json.gz)。本次只衡量注册图组下部署运行的净结果。官方完整考卷仍按另外预定的 100 张图、200 局双席、至少 180 胜且同批平均分差至少 +500 执行。

从已有票据恢复时执行 resume.py。它先校验登记、两次地图隔离和全部在飞源码的 SHA，再由所有权锁判定谁可以续跑。实战完成后的 verify.py 会从八份动作带逐局重新执行官方计分，并校验全程原版时钟、两臂双席分母、收入与源码绑定。first_split.py 另取每对动作第一次分岔前仍共享的物理根，在完全相同的真实敌令下交叉执行双方各自的己令，用两个规则实现核查一步内的支付与伤亡。开局 1/5/10/20/50/100 步快照描述后续各自实际历程。通过这种分法可以追踪提前招聘或走位，却不能把第 299 步的全部分差都归到第一拍。

## Master6 的首拍与实际训练覆盖

事后回读此次学生体系的全部 218 张训练图、10 张验证图、18 张留图。Master6 在 246/246 份真实开局上都让物理基地 ID 后缀 0 招采集工、ID 后缀 1 招种植工。把开局输入原封不动交给三个部署单文件，在 28 张验证与留图上，现役学生和等预算单训对照均逐基地与示范 28/28 完全相同；按融合交叉熵训练的候选 28/28 均把第二座基地也改招采集工，因此完整指令 0/28 相合。仓外同一注册名的其他局面和算法身份没有在此验证。[全部真实基地、位置和所发指令](opening_teacher.json.gz) · [三套部署实际输出](opening_transfer.json.gz)

6,896 个训练候选根中有 26 个首拍。重建训练时的随机置乱后，2,048 个真正进入梯度更新的根中只含 8 个首拍，占 0.39%，全部标签仍是一采一植。重新计算的地图与步号顺序 SHA-256 与冻结的原始训练回执逐位相同。验证缓存 320 根和留图缓存 576 根均只含 1 个首拍。平均交叉熵可在首拍整队退化时照样下降。两张新开发图的真实比赛上，候选平均分差较父代改善 430.78，但四个席次全部打负。两张图给出按图配对标准误 42.22。如果额外假设地图效应独立且近似正态，1 自由度的双侧 95% t 区间为 [−105.64, +967.21]，两图尚不足以稳健估计跨图增益。两点可同时成立。训练暴露少、开局发生系统性改变均已验证；开局在第 299 步实际贡献多少须单独做同根续弈才可估计。[训练调度与具体首拍标签](opening_coverage.json)
