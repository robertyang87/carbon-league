# 鼓励晚段采集能否让 Sapling 多赚到钱

**本轮候选停在开发阶段。** 实际训练的 120.6 万参数 Sapling 更倾向于选择示范中能让新矿到账的动作；但在 31 张自然出现改令的天梯留图上，改变命令的工人共多收回 47.15 新矿，同时少交回出手前已有的货 430.49。同一现金单位下，两项合计 −383.34。种树工的动作也改变了 2.42%，超过预先冻结的 2% 保护线。本轮没有安排候选对原版 Master3s2 的新比赛，正式新图用量为零。[实验口径](protocol.json) · [逐图两臂差值](serving.json)

## 哪笔收入归到哪次出手

从已有 Sapling 源权重 `f82bfd47…` 出发，拿 Master6 的 48 张既有训练图，44 胜、4 负。登记四个后续补编中的全部 37 张 Master6 图作为本次模型留图，36 胜、1 负，逐图核对 ID、种子和 225 格初盘均与父模型既有 216 图训练集无交集。这批历史地图已用于前期天梯研究，不进入正式试卷。训练集中预留了一部分对手报名名，训练没有按收入挑选回放。[85 张图及资源身份](panel.json)

对 t≥225 的一个真实采集工选择，追踪从本步起最多四步由**同一名工人实际新采的货**。初始载货与碰撞拿来的货另算。每步根据同格旧货、实际树税和两席工人库存还原新矿，再一直跟到终局，登记五种去向：原工本人回到己方基地、缴树税、被敌工拿走、留在终局、其他损失或转手。相邻的标签窗口不重叠，每一份新矿只计一次。首步即便移动，后三步取得并最终交回的新矿仍可计入。帮助队友、中长期走位及初始货物交付不在这个正奖励里；这恰是本轮暴露的缺口。[资金追踪代码](lots.py) · [每图、每工、每次采集与本金结算](settlements.json.gz)

## 训练与留图检验

先用四折整图交叉拟合，以货量、距库、剩余步数、己方视野内地碳、敌工距离、敌树税区、双方工人数量等公开变量估计示范动作所在局面通常能有多少新矿入库。预测变量中没有该工本步动作。实际回款高于同类局面预期的示范得到更高权重。对照头按示范等权更新；两者的起点、48 次参数更新、每批 16 根、学习率和父策略 KL 约束一致。全网共 1,206,476 个参数，每臂实际改变相同的 4,101 个既有策略输出参数。两臂分别导出完整 NPZ；测试采用与部署一致的 int8 量化。由于只看到了天梯模型已选动作的结果，权重仍可能包含未观测的位置优势。[逐槽训练权重](advantage.json.gz) · [无同图的状态基准](state_baseline.json) · [等权模型](control.npz) · [新矿加权模型](candidate.npz)

## 自主选择后的账

每张图逐步重建本席特征历史，让三套网络各自生成前序单位动作再解码后续单位。37 张图、1,168 个稀疏根中，新矿头与等权头的晚段采集工相差 77/2,349（3.28%）；早段 191/9,588（1.99%），种树工 50/2,066（2.42%），基地 10/2,336（0.43%）。早段、种树工和基地去重后合计 207/10,624（1.95%），种树工单项超过 2%。这些改令来自实际推理，不涉及收入预测头。[完整前缀检验](serving_probe.py) · [各工位与各根命令](serving_evidence.json.gz)

每图按时间取首个确实改动已登记采集工的晚根，31 图命中，6 图无命中。候选和对照各自的完整首步动作进入模拟器，对手采用同一条真实已发指令，之后两席都重放后续记录。各工人可能因为首步差异死亡或走上不同路线，后续历史命令无法体现对手主动调整。这组数适合发现直接的错令和漏记成本。

|---|---:|
| 改令工人在首四步新采、最终入库 | +47.15 |
| 改令工人原有货物、最终入库 | −430.49 |
| 根时全体采集工的新矿入库 | −3.35 |

30 张具有可比终局的图，候选相对等权对照平均官方分差变化 −26.46；另 1 图在原记录结束时，有一路仍未终止，没有填造后续命令和官方分数。对安生 N22 的一局，t244 的采集工 15 带货 399.25。等权头让它向下，原有货物全部交付。加权头让它向右，原有货物最终入库为零，接下来四步的新矿也没有入库。该局面里，训练标签给两条路线的“新矿”都记零，无法表达向右的真实代价。[该局的原始天梯回放](../../all_top5/appendix_b5e6a7f8/1b9fde2723d41770bfe2ce652713e63c-1.md) · [两臂结算与终局可比性](serving.json)

下一种可检验的改法，是在同一个真实局面比较两种合法首令，按同一现金单位分别记已有本金、新矿、队友收益。候选即便多采，若损失更多本金，该动作也应得到负优势。实现上，将更新限定在晚段采集工的局部输出，其他角色保留父代推理；届时仍须从新图检验前缀传播和实际原版响应。这批 37 图只保留作已知反例。

## 复现

训练脚本以归档的公开矩阵及逐工结算为输入，重建两臂后运行自主解码诊断。动作输入不读取全图碳与终局分数；历史示范只有更早槽位的动作参与当前槽的教师前缀。已仅用这些公开矩阵重训，候选、对照及评分 JSON 三件的 SHA-256 均与原件一致。[独立重训字节校验](reproduction.json)

需要复核标签来源时，从原始回放重建原有 Master6 分片，再运行资金审计。[模型训练](fit.py) · [标签与选图](data.py) · [公开输入与现金审计](audit_labels.py)

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python fit.py
```
