## 已冻结以外的经济解释

按真实逐步现金写入对账，100–199 步看地面树收入，200 步起看自有基地交仓收入，均按本方减原版计算。表内数字比较正负两份在同图区分两席后得到的实际经济差。双方真实行动使轨迹不同；另在每条原轨迹上读了另一端点的公开入口以核对实际改令。这两项没有参与选模。
