# 在真实整局回报上训练部署中的 Sapling

这项实验从第 0 步开始让候选自主发令，每一步都接收对手实际行动后的新观察。训练目标只有终局效用。对局、训练和留出阶段使用同一对阵合同。己方为原 it50 组合包，保留 75% 固定 it50、25% Sapling 和原返航处理。对手为固定的 it20 组合包。两套代理都有各自独立的可见历史和行动前缀。训练只改 Sapling 网络已有的工人、基地读出矩阵和偏置。[冻结登记](protocol.json)

## 学习方法

将工人头及基地头的权重和偏置按动作行中心化，取工人头最大两个、基地头最大一个奇异分量。每个分量都是秩一的神经读出方向，实际分数增减随解码器当前的隐藏状态而变。每个方向沿正负 0.5 倍各打三张地图，在同一张地图、同一席位面对同一固定对手。两边都从开局打到官方终止。所有扰动都先实际量化到现役 int8 包，再进入环境。最终策略沿三个双边终局差组成的向量归一化，走固定的 0.30 倍一步，只保留一个候选，无论梯度和开发结果好坏都记账。

`U = 0.5 × WDL + 0.5 × sigmoid(分差/1000)`，按地图等权，每张地图两个席位各占一半。FastCarbon 推演整场，随后把每条联合命令带交给原比赛规则解释器，复核时间、灭绝、终分及双方效用。训练方向共 36 场。另有父代和成品在三张训练地图上的 12 场，以及两者在四张留出地图上的 16 场。每局都保存实际命令序列。对手是内部确定性代理，真实 Master3s2 的胜率需要独立交手测量。

这样可以补上先前两项工作的空白。既有 `terminal_return_fit` 曾用整局有限差分更新四个手写系数；同项目的 `deployed_mix_policy_gradient_dev` 优化神经参数，但只让 260/280 步的单个单位作探索。本次让神经读出处于整个对局的决策链中。

## 地图与部署

7 张地图在取分前冻结。训练为 621896120 至 621896122，留出为 621896220 至 621896223。种子和官方初盘与 2,669 个已登记地形比对，另核对了同项目的 4 张晚期训练图、2 张旧开发图及 280 张精英骨干图。留出结果须平均效用改善、至少三图正向、两席均值都非负、灭绝场次不增加。另在训练图父代实战轨迹的三个步段，固定取样核验成品是否真的改了联合命令。[隔离核验](clearance.json) · [增补地图核验](register.json)

所有登记对局均为单线程。8 场完成后，4 个空闲 CPU 核分摊剩余既定票。主进程暂停时保留在打的那一场、其他进程只取互斥的票，训练更新仍按冻结顺序读取终局。0 和 1 核每场与原版考位共用互斥调度锁。两张镜像席位可给出相同结果，独立的统计单位是地图。暂停期间的时长计入该场日志的墙钟，应使用整批墙钟或未暂停票估实际成本。

**候选停止。** 四张留出图的 ΔU 分别为 −0.16615、−0.06406、0、+0.56909，只有最后一张正向。新增两胜出自同一张图的镜像席位。平均 ΔU 满足门槛，逐图稳定性没有达到要求。三张训练图的跨两席平均 ΔU 均为正，主要来自前两张的 +0.53360 和 +0.64029。64 场都收到原规则解释器的完整终局。两份暂停票用其余 62 票的中位耗时估算，整批约消耗 0.56 单核小时。[方向、系数与冻结候选](selection.json) · [训练成绩](training.json) · [留出成绩与门槛](result.json) · [逐场独立复算](independent_audit.json)

部署包含 776 个量化还原后发生改变的 Sapling 系数。原登记在训练父带上预选的早、中、后期 30/24/30 个时点都未命中改令，行为门亦未通过。完整真实对局的同轨首处分歧则在三张训练图分别出现在第 43、24、22 步。三张有动作分歧的留出地图分别在第 16、21、17 步首次改令。第四张的父代和候选命令完全相同。两臂的首处分歧发生在相同历史上，其后对手对新局面的应对也已单独登记。[原登记抽样](mechanism.json) · [同图对手响应与双方终分分解](independent_audit.json)

**第 7 步双灭。** 地图 621896222 上，父代和候选均在两席复现了同一失败过程。每边开局花 60 招一名采集工和一名种树工，余 20；最低重招费用为 30。第 5 步双方种树工分别从格 128 和 126 走到格 127，相撞消失。第 6 步双方最后的采集工各携 17.2203，从格 81 和 83 同时进入 82。第 7 步双方无工无树，无法补员，官方终分 −294 对 −294。这个双灭可取得 U=0.5。两包在留出均为 6/8 局打满 299 步、2/8 局第 7 步灭绝，说明单一平均 U 会掩盖这种开盘失败。[双方逐步公开状态、命令与正式计分](short_game.json)

复建时使用给定的地图清单与地形摘要，在一次性工作副本中运行 `python full.py`，设置 `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1` 并绑定 CPU3。脚本会验证既有逐场文件、逐项核对终局，仅补齐所缺票；干净工作副本才适合重跑。随后执行 `python audit_result.py` 和 `python explain_short.py` 复核回报和短局。保留的独立学生权重为 [selected.npz](selected.npz)，实际对局包为 [selected.py](selected.py)，包 SHA-256 为 `09b41c24d0b478b8fea42a8919c98674841a690c20176d6992fd02bd0938ec01`。

三张打满的留出图，候选自己的终局得分分别比父代少 997.55、413.92、700.16。唯一转胜的 621896223 上，对手少得 1,256.76，超过了己方损失，净分差因此改善 556.60。另两张长图上，对手反而多得 617.73 和 111.94。三个对手席在双方首次出现决策差异之后，分别有 280、277 和 281 步改变了原有应对。[逐席终分、首次响应与分段经济](independent_audit.json)

冻结结果后，进一步对全部 1,794 个已记录训练父带状态检查候选实际公开入口，三个步段的联合命令改变数分别为 **26/600、26/600、22/594**。这些改变涉及采集工（16、16、16 次）和种树工（12、10、6 次），未观察到基地招募命令变化。逐席首次变化与真实对照局首次分歧逐项一致。这项事后全数检查解释了 84 根稀疏探针的漏检，原登记门和四图留出的结论仍按原样保留。[完整逐根变更明细](full_action_census.json)
