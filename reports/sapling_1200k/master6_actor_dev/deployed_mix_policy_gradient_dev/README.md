# 用混合策略自身的终局回报更新 Sapling 主网

本轮学习方固定为 **75% PPO it50＋25% Sapling**，对应部署包 9c54df17。训练陪练与验证陪练均是项目自有的另一完整策略 c5ad3f43（Echo4 it20＋Sapling），两方不共享可变状态。此前两次按混合策略实发概率作终局梯度更新，学习的是 it20 版本的五个输出偏置或十五个条件系数；本轮 it50 伙伴保持原状，Sapling 的卷积骨干、上下文和解码层一起接收终局梯度。没有加入动作示范、预测评分或新的部署守卫。[本轮预注册](protocol.json) · [历史五偏置版](../blended_policy_return_dev/README.md) · [历史条件输出头版](../balanced_return_dev/README.md)

在四张既有开发图、两个物理席、t260/280 共 16 个终局窗口上恢复本席可见历史。每次只随机化一个单位；其余单位跟着已选前缀继续解码，保持原返航机制。只有两条解码分支的前缀和选项概率相同、每个可抽动作都由原整队守卫发为唯一物理联合令时才收录。11 个窗口合格，每根六次独立抽样；66 次抽样共执行 27 个去重的真实终局分支（包含同根贪心对照）。每条分支由完整自有 it50 与 it20 双方重新出令；独立用官方引擎重放至终局。每个根的基准来自同根其他五次的平均终局效用，更新目标为 U + 0.10 × tanh(终局分差 / 3000)。[抽样与 logp](sampling.json) · [去重分支动作流](training) · [实发分布与采样代码](study.py)

一次梯度更新实际改变 **1,121,919 个 Sapling FP32 参数**；第一残差卷积的终局梯度范数 0.00362。与部署 NumPy 逐根比较，PyTorch 可行动作 logit 相对差最大 0.00000144。学习率 0.00015 会让一处旧整队命令失去支持，按事前规则拒绝；0.000075 导出的 int8 包保留全部旧支持，实际量化后的最大每根 KL 0.000554，抽样命令的新旧概率比 0.943–1.056。训练替代目标增加 0.000299。受控随机化覆盖的是特定残局决策，正式部署依然贪心。[更新回执](update.json) · [实际权重](candidate.npz) · [部署包](candidate.py)
