## 单独训练下一步购买成功率

读取已核验的 420 场 Master6 回放，只使用该席在空地实际停留且行动前现金够报价的种植工。419 图有符合条件的动作，328 图训练、91 图留出。预测用行动前双方工人类型、距离、货量、接近方向、基地距离、现金和阶段。购买标签取下一帧的新树及实际创造者身份。该头预测的是观察到的行动分布下的成功率，不能直接给没走过的动作作因果判断。

留出 3,620 次中购买成功 3,366 次。全体 Brier 损失为 0.04172，按相邻敌工类型分四组的基线为 0.04167；越低越好。在 298 个有相邻敌工的机会中，辅助头 0.26299、分组基线 0.23781。迁移到四张已有 Sapling 实战开发图，397 次机会中辅助头 0.04434、基线 0.05076，但有相邻敌工的 22 次中仍未改善（0.21985 对 0.21398）。两个分叉根的模型估计分别为 0.268 和 0.470，未能解释已知固定敌令下哪个工人能活。保留权重，不接入部署。单次终局差和这个当拍头都不足以支持晋级。[特征与训练](payment.py) · [权重](payment.npz) · [留图验证](payment_result.json) · [实战迁移](transfer.json)
