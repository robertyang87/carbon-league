# 终局分差监督的种植动作选择器

**一次开发续局赢了，完整新图首胜仍待取得。** 在已研究地图 621478121 的席 0，从第 89 步将同一工人的向下改为原地种植，随后 Sapling 与原版 Master3s2 自由应对至第 299 步。新流官方分 9,772.04 对 9,573.76，赢 198.28 分。同根同流的原路线输 340.85 分。工人花 61.27 种树，从这棵树收 84.14。全队分差改善 539.13，其中两方树收入差变化 +653.77、正常交付差变化 +276.28，也付出了更多种植成本。单棵树赚到的 22.87 只占其中一部分。

## 训练与留图

12 张图、48 组同根两动作的真实终局分差用于训练。每组经哈希核对原版轨迹，两臂根步只差一名种植工的命令。输入限于行动前公开局面，取两条路线的付款、可见邻碳、树龄、敌工距离，以及双方附近载货工与回库距离等特征差。删除一个训练地图各拟合一次，加上全数据模型共 13 份小型岭回归；全部同意改令才采纳。父代负责未改令局面。权重文件可由训练入口与源记录复算。[方案](protocol.md) · [训练程序](train.py) · [权重](selector.npz)

留出的 4 图、16 个局面采用原先记录的两条真实续局做选择评估。其中 5 次选择替代动作，3 次有正收益；4 图相对原路线的平均分差变化分别为 −18.40、−145.00、+8.55、+314.78。按图等权平均 +39.98，只改善 2/4 图，低于事前规定的 3/4 图。作为描述性对照，16 根全选替代动作的均值为 +97.18。此次权重保留研究，不晋级，不为它开新图整场。[逐根预测与真值](rows.json.gz) · [裁决](result.json)
