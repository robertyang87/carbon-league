# 最后三步还能追回多少现金

冻结父代 c5ad3f43 对原版 Master3s2 的 32 场完整实战覆盖 16 张地图。第 298 步只剩一次同步推进。22 场可作行动比较，共得到 634 个不同的联合指令，含各场父令。**用公开信息预选的指令改了 5 场，各自提升 4.26–31.63 分，全样本每场增加 2.85 分，翻盘 0 场。** 在此之前未做过末步两包对照的 7 张图、14 场中，2 场改令，平均增加 3.10 分。五张近期响应或新图仅统计财物。[预注册和全部来源](protocol.json) · [逐局结果](summary.json)

每个替代先强制改变父代一个具有合法选择的槽位，然后让两张原有网络按新的合法前缀重解码余下单位，并执行原返航与相撞检查。对手提案由它上一拍的可见位置和当前可见载重生成，分别测试原地、延续运动与重载返航。每种提案再用两种地面碳估计计算收益。选择流程只读取己方公开观测与历史。末步以真实现金为唯一计分。[选择与逐根枚举](check.py)

另用游戏官方解释器把全部 634 个末步指令与对手原记录的同步指令配对，确认每个分支的双方终分。即使事后知道对手的真实出手并逐局选最好的合法单点改令，这套动作空间也没能改变任何一场败局的胜负。第 296 和 297 步分别比较 745、667 个指令，其真实当步现金变化平均为 −0.03、−0.58 分。两步以后的对应续局回报尚未知。[官方逐分支复播](official_final.json.gz)

32 场在第 296 步平均持货 309.10，其中 286.64 位于三步可达己方基地的距离内；到第 298 步平均持货 100.56，一步可达的只有 54.57。最终平均账外货物 50.65。几何可达值未扣移动损耗、碰撞和共享格约束，无法直接加进终分。五次末步获益中，一次省下种树支出 31.63，三次改变实收树款 4.26、6.53、8.52，一次省下 20 抢树费且少收树款 8.18，净得 11.82。[现金拆解和可达性](summary.json)
