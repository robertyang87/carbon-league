# 种树、夺树后能守多久，能收到多少钱

在 1,542 局天梯回放的 145,177 笔真实购置上训练了两个预测器。面对未参与训练的 19 个对手登记名，前五选手的持有期平均绝对误差为 **10.48 步**，第一段所有权的实际到账误差为 **21.49**。把「预计到账大于买价就付」用作 Sapling 的出令规则却使原版 Master3s2 四张历史留图上的官方分差比父代**下降 18.29**。该学习规则止于诊断，正式考卷未使用。[训练前固定口径](protocol.json) · [原版双臂对照](native.json.gz)

原有 orchard 在前五互打的 79 张训练图拟合过单树毛收入，canopy 学习的是特定机会下专家实际付款的概率，tree_response_training 收集的是少量原版响应后的官方终局差。本次以买入前的 14 列己席公开信息，同时预测持有步数和自身实际毛收入，并扩展到前五对外盘。输入包括四邻中未长树格的己席可见碳、买价和己方现金余额、当地树龄、附近种植工和采集工距离、双方基地距离以及剩余步数。玩家名、行动、后续付款、隐藏碳图和终局信息均不进模型。[旧 orchard](../../orchard_train.py) · [canopy](../canopy_tempo_dev/README.md) · [原版双臂采样](../tree_response_training/RESULTS.md)

## 原版行动对照

预先固定只比较「预计本方首任期毛收入 > 根上报价」；相等时暂缓。每个根的本方两种指令都已用同一初始对手状态及完整原版分别实际续弈到官方终局。16 张原版响应地图与 1,542 张天梯地图的种子、地形哈希交集均为零。原版实验的 48 个旧开发根和 16 个旧留出根已有史料，本轮不以其结果拟合。[逐根双臂、公开特征和归属](native.json.gz) · [生成程序](native.py)

| 固定面板 | 根数 / 图数 | 改父令 | 相对父代分差 | 本方终分变化 | 压低对方终分的贡献 | 全付 / 全缓相对父代分差 |
|---|---:|---:|---:|---:|---:|---:|
| 全部 | 64 / 16 | 12 | −14.37 | −32.49 | +18.11 | +57.45 / −5.24 |
| 原开发 | 48 / 12 | 8 | −13.07 | −15.85 | +2.78 | +41.19 / −3.97 |
| 历史留出 | 16 / 4 | 4 | −18.29 | −82.40 | +64.12 | +106.24 / −9.06 |

在留出根上模型发 9 次付款指令，实际只扣款 4 次；父代 7 令兑现 5 次；全付 16 令兑现 7 次。全部 64 对中的付款臂兑现 33 次，对这些树的持有期和毛收入 MAE 分别为 12.36 步、19.65。预留的四次改令相对父代终局分差约为 −476、−263、−74、+520。站住并发令后能否清算，以及改走另一格后双方会怎样发展，都是单树收入预测未回答的行动问题。表内「压低对方终分」是两段真实续弈的结算差，不能全部归因为被夺单树的利息。全付对照在四张留图上两正两负，样本只覆盖预选的树款机会。[留图实际付款及分图结果](native.json.gz)

训练规则的预定推进条件要求全体与历史留图的官方分差相对父代均为正，两处都未达。

## 复算

在本目录依次执行以下命令，大缓存写入临时目录。公开预测接口 model.load().predict([feature_dict]) 每行输出持有步数和本方第一段归属期预计毛收入。导出权重以 NumPy 数字数组存储。1,024 条抽查的 NumPy 输出与原生拟合预测最大绝对差为 0。[版本与权重 SHA-256](fit.json)

    export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
    python dataset.py /tmp/tree_tenure_observed.npz
    python fit.py /tmp/tree_tenure_observed.npz /tmp/tree_tenure_predictions.npz
    python evaluate.py /tmp/tree_tenure_observed.npz /tmp/tree_tenure_predictions.npz
    python native.py
