# 原版 Master3s2 对夺树接近策略的真实响应

在冻结的新开发图 621758322 上，含 Sapling 实际推理的候选与同权重避险父代各自从第 0 步执两席，全部打满 299 步，逐局官方回放计分，无代理错误。选手会给可从当前格或相邻格夺取的敌树加分，其中相邻格需要额外一拍停留；以行动前可见状态估算最多 16 步树款，扣 20 成本，原策略仍参与联合解码。

**直接机制**。将同一候选真实轨迹的逐拍可见状态输入两份包，席 0 有 3 次不同出令、席 1 有 2 次，全部是种植工向相邻敌树移动。五次均抵达目标，下一拍全部撤走。到达时五个目标格的邻格都有敌工。保留原版对手当拍实际出令和所有其他单位命令，将这一名工人改为原地停留，在模拟器做一步对照，仅席 0 第 146 步接近的那棵在下一拍可夺成，另外四次均失败。这个对照只覆盖当拍响应，没有强迫对手沿着原回放继续行动。

每席全局各有 16 次成功夺取；不是上述五次新接近带来的立即夺取。两席自己的树吸收分别约 2,994、3,083，考官约 4,312、4,299。新路线两席分差均较好，但只覆盖一个地图，随机对手与全局连锁反应都可能影响差值。候选本轮 0 胜，暂不扩大开考。接下来有依据的改动是对接近后的第二拍局面定价，避免把“能走到”算成“能安全停留并收款”。[逐工轨迹与单步替代推演](approach_checks.json) · [全局夺树与变更](audit.json)

**考官墙钟**。每局考官公开入口调用 299 次，保持 0.58 秒自适应预算、温度 1。候选席 0/1 的考官分别有 241/245 步完成深度 8，原生截止 0/0 次；父代两席为 245/242 步，原生截止 3/1 次。考官总 CPU 秒/墙钟秒依次为候选席 0 的 132.6/132.8、席 1 的 134.0/134.3，父代席 0 的 130.1/130.6、席 1 的 133.2/133.3。同机交替绑核；逐步候选数、深度、时间与主机采样保存在 games 下的 wall 文件，全部结果均计入。正式地图使用 0 张。
