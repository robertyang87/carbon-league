# 在敌树旁采集，何时值得提前一拍回家

18 条原版轨迹中有 177 个己方采集工时点满足带货、原令停留、受尚存敌树覆盖。逐个枚举改为向己库走一格：314 个方向保持可通行，269 个避开不重于己的敌采集工，262 个确实能减少树税暴露。每个方向把少交给对手的税、自己保住的货与本拍放弃的采收量折到同一尺度，只有 8 个方向估值为正，无一超过事先规定的 8。177 是工人时点，314 以后是候选方向。这里对保住的货按全额估值，最终仍需真实送达才能计分。[公式与准入规则](routing.py) · [逐层计数](funnel.json)

该改动没有在这些原版比赛中产生新动作，整场新增开考数为零。两种树龄边界也复核过：原版在更新前树龄已达寿命才删除，所以寿命 50 的树在行动前 49 龄仍可收款。更正这一边界后仍无改令。[注册](protocol.md) · [全部结果](opportunities.json.gz)
