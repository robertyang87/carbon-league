# Sapling 分时段原版行动价值训练

目标是在一局内找到一次有收益的经营或护货改令。冻结的 v1 父代仍会做 it50 与 120.6 万参数 Sapling 两网的实际推理。只有 t255–295 且父代完整前缀通过合法性检查时才考虑替代动作，整局最多实际改变一名采集工的一次命令。

## 已锁定的图和预算

四张训练图，每图双席，每席三个时段各一个真实根。采矿、返航、避抢、转往可见富矿四类各六根，三个时段各八根，涉及 20 个不同的物理步数。起始携货从 0 到 186.23，覆盖身边两格内有可抢货轻工和没有此类轻工的局面。每根同时登记两套合法我方联合动作，双方共享真实根历史和对手已同时提交的根步命令，此后原版根据每条分支各自重新行动至官方终局。首张图席 0 的第一和第三时段另登记第二条独立共同随机流，以检验时钟搜索和后续随机决策产生的差异。复测不增加训练地图数或主标签数。

两张留出图都曾打过父代整场开发赛，此前的本项攻守改令和上轮单工标签未使用这些图。在四份留出局的 164 个预注册时刻，共 163 个有合法候选，447 张行动卡可追溯。核对时从第 0 步还原对局，只在每席第一次真实发出改令时续弈，整局不出手的席位计零。此前各项研究使用过的图及已处理的其他根在原始来源清单中逐条列明。这些图均为开发图。[注册](protocol.json) · [地图清单与用途](source/inventory.json) · [观察到的机会](support.json) · [行动卡](cards.json)

训练最多 26 对原版后续，留出最多 4 对，训练与留出共用单核 2,100 秒活动墙钟预算。原版占 CPU 1、每对释放一次共享考位。等其他组攻防复测期间不收取活动额度，调度总等候与运行截止四小时。上一轮实际 192 次原版后继调用用时 64.21 秒，均值 0.334 秒，中位数 0.344 秒；本批还要承担更早的根、更长的续弈、冷启动、逐工核账，训练的初估为 7–15 分钟活动时间。中断后按原始行动和随机状态接续，已登记地图、候选和收益阈值保持冻结。异常中断留下未关闭账本时，下次占到考位将保守计入该段耗时；不会凭重启获得新额度。[账本检查](budget_fixture.json) · [原版受理与逐步保存](native/run.py)

## 怎样决定哪些动作值得试

每个真实对手响应结束后，单独重建终局胜负及灭绝计分，追踪行动前已有货物确实交回多少、我方全队交付和敌方交付。四个差值是本次学习标签。分层覆盖不同资源和威胁条件，再按地图等权拟合正则化线性头。未来指令、未见矿图及终局收入均不能进入部署特征。14 个行动前特征覆盖携货、距终局、回库时间、可见矿、路径及其替代、敌轻工即刻与再下一步的威胁和敌树税区。另含四个动作类别指示量。[候选与可观察特征](actions.py) · [训练与留图判断](learn.py)

1. 训练根不足 18、少于四图、任一时段低于四根、少于三种动作、低于八个不同步数或货量/敌情缺少覆盖，直接停。当前行动卡已满足机会要求。
2. 每次留一张训练图拟合其余地图。模型须在至少两图的至少三根主动改令，计全部根的平均官方分差要增加、原有本金及本方交付不减、对手交付增量最多 +5。负结论保存真实拟合的权重及对照后停止。
3. 训练信号通过后，封存权重并重跑真实公开入口。每席只认第一次实发改令，完整两张留图都要有改令，官方平均分差提升，两席均不退，已有本金不减，全队交付增加且敌方交付不增加。失败在原条件下结案。
4. 只有留图原版门通过，才进入另外两张新开发地图的父代/候选双席完整实战。整场仍必须经官方重放核分。这组小开发面板与用户指定的独立 100 图、200 局正式考卷分开。
