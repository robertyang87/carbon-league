## 门后新开发图

另为通过留出闸后的完整比赛冻结两张新初盘。预检对照了 `41ff3340` 的全仓登记范围、另存的本地已知地形和比赛档案、活动计划以及正式种子保留区。两次全仓扫描均为零冲突。此时具名天梯清单 23 段合计 1,543 个不同开局，合并本地既有地图后有 2,592 个不同地形。每次新开一局都会再读最新天梯清单、扫描工作区后来增改的预留／赛果，并取得原版工位的全局锁。其他机器未在这些清单或共享工位公开登记的私有工作无法从本地证明。[开场前固定的用途与图号](pilot_plan.json) · [第一张全仓核验](pilot_preflight_0.zip) · [第二张全仓核验](pilot_preflight_1.zip)
