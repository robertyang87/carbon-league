# 用整队动作训练 Sapling 的经济决策层

**候选已经训练并打包，未通过原版留图，不启动整局考试。** 把两个可选动作都限制为已经获得真实原版终分的完整队令时，模型在 4 张留图的 28 对中九次改令，按图等权的官方分差相对父代 **−39.65**。按单图看三负一正。允许模型自由选动作时，它又有 22 次选择了这两条原版响应之外的第三种队令，其终局收益未知。[预注册](protocol.json) · [训练与留图裁决](verdict.json) · [单文件候选](candidate.py)

## 做了哪些实际改动

保留父代真实运行的项目 PPO it50 与 120.6 万参数 Sapling。对父代整队动作枚举采集工、种植工、基地的一单位替代。每份提案都写全同队命令，保持其余队友的物理命令，按新的顺序前缀重算特征、合法性、资金和友方占位。额外的 8,549 个神经网络参数读取双方公开资产、阶段、目的格的敌方可达与货物风险、队友分布，以及 Sapling 自身八个隐层通道。学习器联合评估整队命令，无须部署模拟器或预测对手当拍指令。终局层有 138 个拟合权重，分别估计本方和对方官方终分之差，再用两者之差排序。只有候选预测比父令至少多 100 个官方分才换令。未导入原版考官的任何权重。[合法动作与推理输入](actions.py) · [训练](fit.py) · [部署](serve.py) · [包与父代身份](package.json)

旧 K0 针对教师的候选分布做蒸馏，hybrid 调整两张策略网的出令组合，late_advantage 按采集工后来落袋的矿给示范加权。与本实验最接近的 stratified_action_value 在晚段挑一名采集工、一局最多改一次；它按真实原版响应训练过局部动作价值。本次覆盖从开局到终局的三类单位，训练、验证均按完整队令归属。[已有晚段实验](../stratified_action_value_dev/README.md) · [既有采集训练](../late_advantage_actor_dev/README.md) · [父包混合协议](../hybrid_protocol.json)

## 训练与留图

- **即时监督来自 25 张地图的 50 条完整原版父代轨迹。** 双席每局固定取 t12、28、44 等共 19 个时点直至 298 步，共 950 个公开根，生成 4,176 条合法对照，包括 1,900 个采集、1,824 个种植、452 个基地替代。使用该拍已同时提交的真实敌令，精确推进父令和候选各一次，记录两方净现金、携带货差、存活工人数差、树数差的当拍变化。敌令只进入离线记账。训练使用 21 图的 3,496 条，余下 4 图的 680 条完全持出。[原始轨迹身份](source_registry.json) · [一拍标签生成](data.py) · [即时训练权重](aux_weights.npz)
- **终局监督共 108 对、18 个地形。** 各支从同一真实根和同时提交的敌令起始，后续调用完整原版到官方终局。种植 66 对、采集 40 对、基地 2 对；母局、两臂全部动作、双方官方分、原版来源逐项验过。另 8 组随机流复测和 32 个父代或续弈配置不同的案例单列。14 图 80 对训练，4 图 28 对留出；留出为种植 16、采集 12，基地这次没有独立终局标签。两种监督按地图合并隔离，两张此前付款实战新图未用于本次训练或测量。[原版双臂签收清单](signed_roots.json.gz) · [可复验签收程序](native_labels.py)
- **即时学习能减少大误差，较少发生的变化仍容易被多报。** 在 680 条留出转移上，本方现金 RMSE 从恒零的 28.24 降至 21.02、对手现金从 6.52 降至 6.15、携货差从 33.31 降至 30.23。平均绝对误差分别从 7.63 升至 8.53、0.63 升至 1.37、8.13 升至 12.96。对手现金在这 680 条中只有 30 次真的改变，故两种误差都须保留。工力差 MAE 由 0.153 降至 0.122。净现金含到账和支出，不能直接解释成攻防收益。[误差与不变对照](verdict.json)

## 从能改令到能赢的差距

同一权重对 8 条留出父轨迹的 2,392 个连续行动逐拍出令，有 **2,125 次**与父代不同，其中采集工 **1,029**、种植工 **939**、基地 **157**；三个百步段分别为 **651、764、710**。这衡量的是模型看到真实父轨迹时的决策差异。另在两张留图的相反物理席，直接调用打出的实际单文件验证 50 个历史根，有 43 次改令，全部与独立重建相符，亦覆盖有真实双臂标签的命令。这些动作没有替换父代后继续打出新的完整比赛。[逐图逐拍改令](held_activity.json.gz) · [实包输入输出验证](package_parity.json.gz)

| 原版终局检查 | 真实响应根 | 预定阈值后选择替代 | 官方分差变化，按图等权 |
|---|---:|---:|---:|
| 训练，14 图 | 80 | 26 | +80.54 |
| 留出，4 图 | 28 | 9（8 个种植、1 个采集） | **−39.65** |
| 同批同初始化的无即时梯度对照，留出 | 28 | 7 | +44.87 |

留出图按整图重抽的探索性 95% 区间为 **[−101.51, +38.69]**，四张图各自为 −122.03、+75.69、−39.94、−72.34。训练模型对已签动作收益方向只判准 **8/28**。无即时梯度对照切到全菜单时有 27/28 根的真实收益未知，余下一根为负；它没有满足整队行动覆盖，不能凭表中的正值晋级。[含对照、逐角色和逐图的完整裁决](verdict.json)

最清楚的反例在地图 621477121、席 1、第 152 步。模型估计改变种植工指令可以改善 **159.1**，并在全菜单中实际选了这条已签完整队令。原版双臂中本方确实多得 **692.08**，但对手多得 **1,272.07**，官方分差反而少 **579.99**。也有相反例子：地图 621478121、席 1、第 164 步的种植替代和地图 621477121、席 0、第 293 步的采集替代，都是模型在全菜单中实际选中、已签实战分别改善 **217.48、36.06** 的完整动作。[全部逐根动作、对手终分与归属](decisions.json.gz) · [可还原的完整候选集合](native_inputs.json.gz)

28 个留出根的原版替代动作都存在于实际公开菜单；模型自由挑选后，3 次选父令、3 次选有真实续弈的另一条、22 次选未续弈的第三条。六个可计分选择平均 **−54.41**，没有把另外 22 次按零、按预测值或按同一单位的已知动作冒充真实收益。预定的正向留图收益条件失败，故未消耗开发整场或正式种子。这个结果区分了三个问题：这次扩大可改动作已实现；即时工力预测有所改善；该改动还未学会在新图上选出能改善终局的整队动作。

## 重现

本目录使用 Python、NumPy 与 PyTorch。两片即时样本和所有训练权重均已保存；重新采样只读历史回放，不调用考官打新比赛。逐图完整动作缓存由以下命令在临时目录重建。

    export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
    python data.py 0
    python data.py 1
    python native_labels.py
    python native_inputs.py
    python fit.py
    python build.py
    for i in 0 1 2 3 4 5 6 7; do python held_activity.py /tmp/jrc-activity --index "$i"; done
    python held_activity.py /tmp/jrc-activity
    python package_parity.py /tmp/jrc-activity
