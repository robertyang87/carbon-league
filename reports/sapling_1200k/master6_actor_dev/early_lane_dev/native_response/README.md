## 运行与恢复

在仓库既有 Python 环境从本目录执行。驱动首先核对八条原始录像上的候选动作、四个根的 live_protocol.json 和共享随机状态，随后等待第 06 批封存。只有取得第 06–07 批之间的独占租约才启动首臂。运行中可在各根目录中查看 status 和 checkpoint。已完成的动作带须通过 SHA 和双 DONE 核验。意外退出后，以同一命令从已封工件恢复。每对完成后，官方解释器独立重放至终局并与逐步现金账对齐。结果齐全后 result.json 与租约释放收据一起构成完成证据。[调度](run.py) · [逐臂复核](verify.py) · [租约状态](../../tree_response_training/supplement_01/early_lane_slot/)
