# 把敌工两步可达计入夺树选择，整局效果变差

在预登记开发图 621758323 上，Sapling 与同权重父代各自换席，从开局打仓内原版 Master3s2。候选沿用双网推理；当种植工打算接近一棵预计回本的敌树、敌工距目的地恰两格时，把前一版的接近加分改为减 0.6。上场前在旧图五个真实接近动作上，五个均改变。独立天梯回放也显示两格距离的当场夺成率较低。[天梯机会分析及 420 局 Master6 复查](ARCHIVE.md) · [赛前动作检查](preflight.json)

两臂均 0 胜；候选两席分差均倒退，保留失败记录并停止该规则扩样。四局均跑满 299 步，官方解释器重放一致。候选和父代交替绑核，考官保留自然采样、温度 1、真实 0.58 秒墙钟。候选席 0/1 分别有 254/262 步完成深度 8、0/1 次原生中止；父代为 242/240 步、3/2 次中止。考官公开入口累计墙钟/CPU 秒依次为 131.6/131.2、131.6/131.5、132.1/132.0、130.1/129.7。四局全部计入，本次正式考试用图为零。

在候选实际轨迹上重放父代，发现席 0 有 9 次工人动作改变，席 1 有 14 次。保留同一局面的原版对手当步命令，模拟执行父代整队出令；23 次原接近均能到达并具备下一拍夺取的现金和树龄条件，其中 22 次到达后有敌工在一格内。该检验只测首步后的威胁，第二拍未调用考官，不能断定 22 次都必败。候选自己的实战每席均夺取 17 次。席 0 候选树收入 3,133、回库 7,839，父代为 3,398、8,566；席 1 候选树收入 3,063、回库 8,515，父代为 3,459、8,414。单图不能区分哪些差值源于单次改令、后续策略还是原版采样差异。

对下一版有区分力的实验是实际比较“继续施压”和“撤到另一项任务”，同时量对手保树付出的回库机会和双方终分。仅按能否马上夺下来给接近行为扣分，没能在这张开发图带来收益。
