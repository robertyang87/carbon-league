# 单工回库残差的原版对手试验

**本版保留父代，不进入新图整局考试。** 已实际训练一个可以关闭的三头动作残差，并把它打进包含原有两张网的单文件包。四张留出图双席都有可执行的末段采集决策，学习权重八次全部保留父令。因此八个根的官方分差增益均为零。本次没有新增胜率或 200 局正式考试成绩。

## 哪一步改变了什么

保留冻结 v1 的 it50 专家与 120.6 万参数 Sapling 双网、相同前缀解码和守卫。仅考虑 t286–296 的采集工，在当前有矿且仍有回库机会时，比较停采与向本方基地近一格。每次至多改变一个工，第二个工的动作、基地招工和种树工命令均锁定。部署依据包括行动前可见地面碳、携货、到基地距离、现在能否带本金到家、可见轻载敌工、敌树税区和剩余步数。防误伤检查沿完整前缀重算合法性、友军占位及招工冲突。

先冻结四张训练图、四张留图，每图双席。每席只取 t286–296 中遇到的第一个合格根。真实分叉两臂共用根之前的公开历史及敌方同时发出的根步指令。根后我方执行冻结父代；对手按每臂实际形成的局面各自运行仓内原版 Master3s2，保留其温度与墙钟搜索。二臂用相同起始随机流，随后允许因局面产生不同的行动及账目。单个根只测一次配对随机流。

从每臂终局同时取三个真实差值：含灭绝规则的官方分差、行动前已有货物由该工实际回库的金额、我方所有工的真实交付。新采矿单独追踪，树税、碰撞转移和未到账的货不能充作该工本金实收。24 个可训练系数按图等权拟合，四图内分别留一图复算预测。独立核对涵盖逐步指令、原版后续搜索次数、终局双边得分和逐工分账。[注册与地图身份](protocol.json) · [训练代码](fit.py) · [训练权重](weights.json) · [实际原版响应](native/train_labels.json)

## 留图和公开入口核验

另四张隔离图的八个根均在 t286。冻结模型预测改令对官方分差的影响为 −79.07 至 −21.01，八次都不发出改令，逐图双席计全部差值为零。登记的入场条件需要至少两张图实际改令、官方分差增加、两席均不倒退、已有本金无损且全队交付提高。这一版没有通过。四图只检验了这些登记的根；未执行的替代动作在这八根的真实收益未知。[分母与逐席裁决](verdict.json)

公开包的另一路核对重建四张历史天梯图的完整行动前观察历史。两席共 68 个测试局面，其中 44 个在末段窗内、24 个在窗外，学习包和父包在这 68 个局面输出逐项一致。同窗改用恒正的机制测试权重，44 个根均只改变一名采集工。8 个显式关闭对照全部回到父包。父代的真实 Sapling 分支在测试根的解码记录中有 13 槽选出了与专家不同的动作。部署包 6,083,682 字节，SHA-256 为 `27bdbbff5ec0efa19a96c43ce5ff154cd67274be77a1be9555ffa2feb3948c04`。[运行包](candidate.py) · [构建身份](package.json) · [机制正控](mechanism_fixture.json.gz) · [训练后入口核对](package_parity.json.gz)

## 可研究的下一问

本次“每席取第一根”的样本全部集中在窗口第一步和同一方向。建议另行登记目标局面，按距终局剩余步数、距基地距离及父代本来的方向覆盖“再采一次”“现在撤出”“绕开敌人”三种机会，并直接比较直到回库或确认失败的安全路径。每条路径都要让对手重新决策，分别核算本金幸存、自己新增实际回款、队友被挤占的交付和敌方兑现。旧包和较晚根的原版续弈只可帮助设计这些分层。新方法要用另外的验证地图，本轮阈值和结果保留。
