## 复算与泄漏核验

1. 从原始开局配置和地图重放存档至共同根，保留创建者真实 worker/tree ID 计数。冻结生成器只读行动席当拍公开观察和己方亲本令。每个样本保留行动席观测、原替代两套完整联合令与源文件 SHA-256。后继结果仅供标注。
2. 按实际双方动作推进至正式终局。366 次物理推进逐次对比官方 Board 的格碳、双方资产与树状态。每臂的终局原版双席得分均与原始核分记录逐值对齐。现金流按座分别核账至终局现金，正式灭绝的奖励另算。树现金、正常交付、碰撞、招工、种／夺树、四舍五入都有原始渠道。
3. 根本金按同工自送、友方转运、被敌获取、树税、落地／费用、终局库存等去向交叉记账。严格新增采集仅计从环境中新获得的货，先剔除原货和碰撞转货，再逐批跟踪直到同工回库。两笔首本金不能再在后续采集拍当作新增收益。每臂全队正常交付亦用独立公开轨迹复算。

在已配置仓内官方环境的 Python 下执行 `python rebuild.py`。复核读取历史动作带并生成证据，未启动新的原版场次。归账函数可独立接入真正的新原版同根分支，须传入确含计数的未删减 FastCarbon 快照、真实配置、从根至终局的双席动作带与己席焦点工列表。[可复用的逐臂归账](account.py) · [重建与支持集匹配](rebuild.py)
