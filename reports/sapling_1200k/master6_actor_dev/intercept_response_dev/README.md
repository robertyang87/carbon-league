学习头在既有原版 2,884 个运货时点上，对下一步实际命令的首选命中率为 56.24%，仓内旧预测器为 54.82%；负对数似然由 1.128 降至 0.975。四条赛前轨迹上，有 360 个本方轻工时点可安全到达带有预测货量的格子，但每个格子的货量加权概率都低于 0.25。这解释了分数很难推动实际命令变化。后续若探索提前封路，需把未来可兑现的货款、己方离开原采集点的损失放在同一局面对照，并先证实有足够的实际行动差异。[训练、评估与覆盖](FORECAST.md)
