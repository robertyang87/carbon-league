# 敌方采集工让出地块后，Sapling 能兑现多少收益

**在十场已曝光开发对局的 57 次直接争地机会中，Master3s2 全部主动离开刚采过的格子。** 这个判断逐拍核对了实际同时出令。它排除了这些局面中靠走到旧格实现当拍抢货的可能。进入后己工 57/57 存活，52 个后继格无树、可见碳至少 15，且未落入不重于己的敌采集工的一步范围。是否能将采来的碳存入己库，还要等后续响应。[57 个局面和真实敌令](coverage.json.gz) · [公开后继局面](patch_yield.json)
