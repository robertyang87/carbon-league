## 现成反例

- 在另外四张发现图的 8 席历史实战里，货重至少 100 的采集工被对手碰撞接收了 2 次，共 500.21。同规模正常交付有 260 次，共 45,896.59。单次劫货很值钱，但过度规避风险也会妨碍频繁的正常交付。另两张留图的三次换路，原有本金 539.66 后来全额正常到账。这样的根若当作“必遭抢”，会给安全行为贴错标签。[旧护货根及实际原货去向](../../return_value_dev/README.md)
- 真实原版另有两次改令堵截。即使把敌工首次回库从 t229 延至 t237、从 t255 延至 t275，这两个敌工最后仍都存了货，全场各自反而多交 211.28、114.55。晚到账、当前敌方轻工几何可达、携货者死亡、货实际进入敌方采集工是四种不同观测，应分别留证。[同根原版应对](../../freight_deployment/first_response/README.md)

护货对象可用完整动作带按官方规则重放。直接被敌工取得要求记录本次被删采集工、其根前货重、唯一赢者的工人身份与归属。树或基地直接收款、同格最低货量平手双灭、落地、友军转运以及不发生碰撞的沿途税款应另列。工位仍由上层调度，本项来源审计没有开新的原版对局。[冻结及读回脚本](inventory.py)
