# 种树工发出付款指令时，停留是否比移动更赚钱？

**把付款落空也计入训练后，留一地图重算仍未找到值得晋级的改令。** 14 张训练图、56 个配对根都保留。每根有同一工人可执行的两个动作，两臂各自让原版 Master3s2 与 Sapling v1 从该决定继续到官方终局。其中 29 次停留实际付了款，27 次因当步结果没有付款。决策时两类情况都可能遇到。这个研究头学习发令时机；另一路预登记的实付训练与部署决定继续按其原协议执行。[训练来源与冻结设置](protocol.json) · [两臂实战](../tree_response_training/README.md)

用下令前公开的相对碳量、报价与现金、还能持树多久、两地的保护差、敌方回库货物以及两类敌工分别能否一步到达停留格和移动目的格估计终局分差变化，并区分自种和夺取现存敌树。给每张地图相同总权重，手里是否真的买到树只用于赛后分组。模型比较实际父代所选动作和该根唯一经核验的替代动作。只有预计换令能多得至少 100 分且输入在训练支持范围时才改令。相同门槛下也保留一个只会预测训练均值的对照。[估计、行动与计算程序](intent.py) · [冻结权重](weights.json)

例如训练图 621471120、席 0、第 118 步，模型改为向右走。原来停留花掉 20，而两臂的整局收益显示移动少得 863.28。其他根上，哪怕提前判断这一步可能付不成款，改变它也可能让之后几十步的交付和树息更差。这个实验每根每臂只观察一次续弈，14 图已经在此前研究中使用过，逐图留出属于暴露数据上的方法诊断。[逐图、逐根和全部反例](training_diagnostic.json)

下一批已经登记的两张采样图沿用原训练任务。程序先读取其公开决策根、封存逐根选择和权重指纹，再从完成的两臂计算差值；如果有续弈结果先于首份预测出现，会拒绝将这批列为前瞻检验。该比较复用上游开出的对局，额外原版对局成本为零。本实验结果不触发 100 图正式考试。[下一批任务口径](../tree_response_training/supplement_01/README.md)

## 两张新训练图的前瞻结果

第八批的八条选择在原版续弈出结果前已公开冻结。模型对发令后终局分差变化的估计介于 −56 和 +63，八根都保留了 v1 原令。两张图各四根，实际相对 v1 增益都为零。随后取得八对真实终局，其中四次付成，停留较移动的效果分别为 +34.20、+488.11、+738.80、+377.23；在其中两处 v1 原选移动、模型也跟着移动。这是对漏掉机会的直接观测。模型作为研究权重归档，未进入整局考试。[开跑前已封存的选择](prospective_decisions.json) · [八对实战及各图分差](prospective_scores.json)
