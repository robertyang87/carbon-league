# Sapling 收入辅助训练的原版开发对照

三臂使用同一个原版 Master3s2 对手和同一组全新开发地图。父代沿用 v1。控制臂和候选臂都把实际训练出的 120 万参数 Sapling 装回共享合法动作前缀的策略，Sapling 占 25%，我方 it50 占 75%。控制臂仅对收入预测头训练，切断收入损失对策略骨干的梯度；两臂的动作监督、更新次数和数据次序一致。候选臂允许未来十步、三十步的两席入库及树收入监督更新骨干。运行对局只用原策略接口。[训练结果](../result.json) · [开发对照登记](protocol.json)

在原来一张已知图的两个物理席，逐帧给入完整公开历史，固定抽查 22 根。两臂各自的嵌入学生权重逐张量与源 NPZ 重新量化的结果完全一致；整包实际发令与把对应学生直接接入旧 v1 的输出分别吻合 22/22。移去 Sapling 后，控制臂有 10 条工人命令改变，候选有 11 条；两臂与原 v1 的实发差异分别为 3 和 4 条。[逐根命令](mechanism.json) · [权重、字节数与包身份](release.json)

开发图 621497120、621497121 双席，三臂各四局，共十二局。每局保留完整原版搜索、原温度、正式灭绝或步限以及官方终分。独立官方引擎重放后，分别对原父代和同训控制计算逐图平均分差变化及逐席 U 变化。每一组对照都需两图分差均改善、至少三个同图同席 U 上升且胜场数不下降，才获得再验证资格。两图为开发比较，正式目标仍在另一批 100 张新图上考 200 局。[对照与恢复驱动](run.py) · [去留条件测试](test_run.py)
