## 对手突然拉开差距时

每局固定取我方现金差下降最多的连续十步，含两席实际动作、伤亡、回款、树息及此前十步的完整行动和双方各自可见的碳值；同时逐局归档最大单步下跌和对应上涨对照。

## 学生在实战发令中的贡献

候选四局 1,196 次真实公开观察均重现记录中的联合己方动作。保持同一个行动前局面、合法前缀解码和返航保护，移去占比 25% 的 Sapling 策略分数后，374 个回合出现不同发令，其中采集工 372 条、种树工 83 条、基地 16 条。这个消融只确定输出贡献，不能据此推算胜率。
