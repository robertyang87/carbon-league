## 是否追加原版续局

八根当步两席现金均完全相同，也没有任何工人或树因换令而新增、死亡或易主。t298 两条路已经有精确相同的终局分差。其余七根会改变位置，部分会改变下一帧货量，不能据此认定某步硬丢了大笔已到账资源。

最值得低成本复核的是 t288：候选同时把两名采集工从停采改为移动，当步合计少持 17.15 货。候选原局随后实收 t289 的 54 号 75.99、t297 的 41 号 90.90、t297 的 54 号 32.48。没有相同根状态下控制命令的完整续局，不能把这三笔到账全算成提早动身的功劳。若需要区分这种临终取舍，优先对此根做一对，两臂后续共 20 次原版回应，参考耗时约 9.4 秒搜索；另加状态复原、逐步核验及排队，重复不同考官采样的预算须按重复数计。将这项列为低优先定位实验，保留现有原版训练工位。
