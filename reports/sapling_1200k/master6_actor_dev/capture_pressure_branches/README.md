# 接近敌树能压低附近敌工的回款吗？

在同一张已曝光开发图的两席，各预先选最后一个只有一名种植工改变命令的局面。从真实开局恢复双方历史，根步使用相同敌令。随后每一拍双方重新决策，同一席的两臂共用 Sapling 续弈版本、初始 RNG 与搜索成本估计。考官用原版公开入口、0.58 秒自然墙钟、温度 1。这里的“附近敌工”在分叉前固定为离目标不超过两格的敌工，后续离开也继续追踪。时间窗口截至官方终局，收入取实际付款事件。

| 物理席与根步 | 保持原路线的分差 | 接近敌树的分差 | 接近相对原路线 | 当时附近敌工累计回款，原路线 / 接近 |
|---|---:|---:|---:|---:|
| 0，第 250 步 | −2,142.73 | −2,824.33 | −681.60 | 518.48 / 283.27 |
| 1，第 224 步 | −2,098.45 | −2,202.90 | −104.45 | 1,040.95 / 857.66 |

两例中接近后都没有夺到目标树，目标在两个分支均由敌方持有余下的 34 拍。两例都在接近后的下一拍观察到附近两名敌工的出令出现分歧。席 0 结束时，附近敌工少回款 235.21，但敌方全队正常回库多 253.81，树收入多 204.05；我方正常回库少 187.27、树收入少 46.57。根后第十拍我方相对分差曾改善 97.51，终局却少 681.60。

席 1 根后十拍，附近敌工回款从 215.22 变成 0，但我方全队正常回库也少 237.17。结束时我方正常回库多 261.98，树收入少 198.43，敌方树收入多 340.66。终局全账户结清后我方相对原路线少 104.45。局部封锁和全局收益在这些实际续局中方向不同。根步之后的收入还包含双方后续随机响应，不能把整段现金差归因给某一个工人。

四臂都走到第 299 步并落败。两席每臂的根后原版调用分别为 48、74 次。原路线/接近的原生截止分别为 0/0、1/0，具体候选数、深度、公开入口 CPU/墙钟和主机记录随每臂保存。对手的历史按原始实际命令重建，两臂共享新抽的初始随机流与重新初始化的成本估计；续局不会重现历史原局的 RNG 或实时时序。该批属于一张开发图的条件比较，新开地图与正式考试局数均为零。现有依据不足以把“少了多少附近回款”单独用作训练奖励或策略晋级条件。
