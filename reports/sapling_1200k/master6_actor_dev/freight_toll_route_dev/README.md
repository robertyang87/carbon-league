# 运货工走另一条等长回库路能省多少树税

在七张开发图的 18 条原版完整比赛里，追踪到双方 1,049 笔敌树从具体采集工货物里实际扣走的税款。一工同时被两棵树扣款会留下两笔。每笔保留付款工号、收款树、实际命令、行动前以及之前 3、5、10 步的工位和载货。按所有完整轨迹平均每局计，Sapling 原地停留时向敌树付 85.45，Master3s2 对应付 42.95；朝己库走时分别付 42.87、26.94；其他移动分别付 17.81、17.98。此处是总支付额，不表示离开当前位置即可净赚同额。[逐笔追踪](tax_ledger.json.gz) · [分局分席总账](tax_totals.json)

比较器限于父网已经决定朝己库移动的运货工。只有另一条安全且同样短一格的路线可少付至少 5，才替换当拍指令。18 局只出现 4 次，其中 3 次是同一工人在连续三步的机会；每次独立从原轨迹替换一步，不能把三步节省相加当作单局收益。同一真实敌令下，第一处席 0 货量由 77.12 升到 85.69，考官现金从 127.74 降到 119.17。席 1 货量由 123.46 升到 137.18，考官现金从 691.72 降到 678.00。后者是同工资换岗版的局面，两组来源分列。[改令与双臂实收](opportunities.json.gz) · [冻结口径](protocol.md)
