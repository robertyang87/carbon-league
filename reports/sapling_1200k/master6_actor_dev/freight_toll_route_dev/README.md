# 运货工走另一条等长回库路能省多少树税

在七张开发图的 18 条原版完整比赛里，追踪到双方 1,049 笔敌树从具体采集工货物里实际扣走的税款。一工同时被两棵树扣款会留下两笔。每笔保留付款工号、收款树、实际命令、行动前以及之前 3、5、10 步的工位和载货。按所有完整轨迹平均每局计，Sapling 原地停留时向敌树付 85.45，Master3s2 对应付 42.95；朝己库走时分别付 42.87、26.94；其他移动分别付 17.81、17.98。此处是总支付额，不表示离开当前位置即可净赚同额。[逐笔追踪](tax_ledger.json.gz) · [分局分席总账](tax_totals.json)

比较器限于父网已经决定朝己库移动的运货工。只有另一条安全且同样短一格的路线可少付至少 5，才替换当拍指令。18 局只出现 4 次，其中 3 次是同一工人在连续三步的机会；每次独立从原轨迹替换一步，不能把三步节省相加当作单局收益。同一真实敌令下，第一处席 0 货量由 77.12 升到 85.69，考官现金从 127.74 降到 119.17。席 1 货量由 123.46 升到 137.18，考官现金从 691.72 降到 678.00。后者是同工资换岗版的局面，两组来源分列。[改令与双臂实收](opportunities.json.gz) · [冻结口径](protocol.md)

## 与前五全部对局的量级对照

归入 1,590 个去重且有完整官方比分的回放；逐局核对物理席位、回放 SHA-256 与官方分。Master6 出场 432 次（按席），平均从对手在途货物收税 118、向对手树付税 78；己方正常回库比对手高约 3,635。Master5s 出场 302 次，对应是 147、82 和 1,296。再限定相同对手、相同席位、两个版本各至少有两场，留下 52 个对手与席位组合；各对手先均分席位、34 个对手再等权。Master6 相对 Master5s 的直接回库净优势高 2,689.05，而货物税净优势低 42.45。对手匹配未控制具体地图、历史时间或阵容演变，这组数据不能证明 Master6 的部署结构。就这些观测而言，少交几笔树税能帮助具体工人，无法解释头部对中游的全部压制。[前五逐局双边资金](ladder_tolls.json.gz) · [分席同对手复算](matched_top_two.json)

## 差距来自少交几次，还是每次交得少

把上述 34 个共同对手按比赛阶段对齐，0–99、100–199、200–终局三段分别计算。与 Master5s 的比赛相比，同一对手面对 Master6 时的回库款平均少 665、1,352、1,006；Master6 自己相应比 Master5s 少 427、少 137、多 231。中盘的对手回款差额里，按“交付次数 × 每次均额”的对称分解，约 1,255 来自次数差，约 97 来自单笔金额差。提前结束的对局之后按实际零交付计，分解会包含更早灭绝的作用，不能据此归因于某一种拦截动作。[按席位和对手的全量分解](bank_components.json)

Sapling 对原版 Master3s2 的七图 18 局呈现另一种短板。t200 至终局，Sapling 平均每局有 33.28 次正常正额回库，考官 32.33 次；Sapling 平均每笔实收 107.10，考官 128.40。追踪到实际交付的 599 / 582 趟货：两次交付之间每趟平均有 6.45 / 7.49 次有效采集，单次有效采收 16.35 / 16.58。未成功交货的路线和阵亡也保留在原表，但不进入这个单笔均值。用逐局对称分解，Sapling 在这段的次数贡献为 +105.52、单笔金额贡献为 −693.06，合计每局回款差 −587.54。应检验如何在安全且来得及回款的路线上增加一次有效采集，同时保留“多采一拍导致整趟货延误”的反例。[逐工行程与死亡记录](banked_trips.json.gz) · [逐阶段次数与金额](native_bank_gap.json)
