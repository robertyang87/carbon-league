训练使用 **218 张对外地图、6,896 个行动前局面、64,726 个至少有两种合法选择的出令机会**。每个标签都是 Master6 在该物理席当时真正选择的动作。统计结果可用来检查学生学到了哪些行为；强度另由原版 Master3s2 的实战衡量。[冻结分割](data_split.json) · [逐根、逐图和分片校验清单](data_receipts.json.gz)

## 攻、防、经营和终局的真实动作

每图在 t0–74、75–149、150–224、225–298 四段按固定哈希各抽最多 8 根。逐帧从开局推进可见历史和碳估计，输入只读公共工人、树、双方资产及当席可见碳。第 t 根的标签取自记录在 t+1 帧上的真实命令。双方换席时先转 canonical 坐标，再逆变换核对下发命令。按实际动作推进 Sapling 的 Prefix，逐槽复核合法性、占位与现金。训练、验证与留出的 7,792 个抽样根全部通过。完整碳图只存在兼容旧加载器的辅助监督列，训练方案只用动作损失及声明的策略正则。[样本构建](data_build.py) · [训练口径](training_protocol.json)

| 训练中动作前可见的机会 | 机会数 | Master6 所下动作 |
|---|---:|---:|
| 持货至少 30，原地受威胁且存在安全替代 | 2,508 | 2,442 次选了安全落点 |
| 持货至少 30，可一步抵达己方基地 | 2,220 | 1,367 次选择进基地 |
| 至少一个落点可触及比己工载货更多的敌工 | 8,453 | 5,885 次选择这样的落点 |
| 种树工原地无敌树，可一步接近到敌树所在格 | 1,473 | 814 次选择落到敌树格 |
| 种树工已经站在敌树格 | 762 | 398 次下令原地停留 |

| 基地可选择招工 | 2,477 | 1,419 次招工 |

各行机会可以重叠。能接触一名对手只表示公开可达，最终是否抢到货、守住树或按时回库取决于双方同时行动。训练还包括 t270 以后的 660 个根、6,624 个可选出令机会。每个分割均取两席各一图，与仓内完整 cnet2_build 对照；六图 192 根、18 个字段逐项相等。[逐类覆盖与构建对照](data_audit.json)

模型训练结束后另开一份历史失败诊断：原本剔除的 18 张输图均以双方官方 DONE 完成，共 576 根。名单、文件目录和收据独立。该组含曾用于其他训练或前五互打的地图，且按输赢挑选，只能检验对已知失败轨迹动作的拟合。[单独名单](data_loss_split.json) · [失败诊断收据](data_loss_receipts.json.gz)

## 重建

在含六批归档的仓库根目录运行以下命令。恢复器读取工作树或本地 Git blob，按每局压缩原件 SHA-256 核验。NPZ 分片放在本地缓存，仓内保留原始回放归档、选择器和每图的 SHA-256；训练器会复核分片身份。已有同名分片会先验身份再复用。

```bash
cd reports/sapling_1200k/master6_actor_dev
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python data_restore.py --include-diagnostic
python data_select.py
python data_build.py
python data_audit.py
python data_loss_diagnostic.py
```
