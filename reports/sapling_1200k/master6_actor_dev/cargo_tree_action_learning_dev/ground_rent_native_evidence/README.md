**回本与取胜分开验证。** 安全富格上四例停留都实际付钱。其中 621473120 席 0、t193，停种相对移动多收 416.34 整局地租差、官方分差多 443.44，复现了先前的正例。该种植工 t183 尚未出现，t188 在格 160 向下，t189 在格 175 停留，t190–192 连续向上才抵达根格。621472120 席 0、t118 同样落在安全富格，全场地租差多 1,430.41，官方终差反而少 311.56。另一个安全富格 t184，停种使全场地租差少 1,631.99、官方终差少 480.91。四个训练根合起来，只有一个同时提高全场地租差与终局分差，留图对此类局面没有覆盖。

留出的九个中盘根，停留臂只在一个根发生了即时真实付款。该根为 621478120 席 0、t164，支付 82.95，终差多 34.20，中盘地租差反而少 61.81，整局地租差少 408.09。留图中唯一同时改善中盘地租与终差的 t125 根，停留臂当步没有付钱。把这些例子写成“学到了何时落树”会混淆站位、即时交易与其后全队响应。
