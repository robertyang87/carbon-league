# Sapling 与 Master3s2 的逐格碳估计如何改变可选路线

**值得给 Sapling 学生补一类信息：己方从未直接看见、但已能用公开历史反推出碳量的格子。** 在 6 张开发地图、16 盘原版实战、两方各自的观察历史中，这类当前不可见格共出现 230,528 次。按各自真正送入骨干的地图量化精度，Sapling 平均绝对误差为 4.289 碳，Master3s2 为 0.077。收益最大的一类公开事实是从对手原地采收前后的货量变化推回地碳，然后推广到初始对称格。覆盖最多的一类事实是从己方直接观测反推初始对称布局，再递推各格后来经历的独立变化。

**改图能改变局面内的经营选择。** 补充分析仅在上述格使用原版的估计，保留 Sapling 当前地图精度及其他格。在真实可经营、有不同地碳价值的选择里，采集工选中路线与最富路线的平均地碳差从 0.433 降到 0.143，种树工从 0.158 降到 0.080。这里按目标位置的四邻平均碳量衡量种树工的路线。结果支持在学生侧做输入消融与训练。它尚不能说明真实对手响应后的现金、胜率或推理时间会改善。

## 样本、坐标和输入身份

从首胜父包的 345、346、348、349 号地图各取双席共 8 盘。另取已结束的 352、353 号地图，父包/H24、双方换席共 8 盘。每盘 299 步，从双方各自的己席视野重建两种估计，共 9,568 个席位局面、2,152,800 个格时观测及 86,362 个工人决策。统计遵循预登记清单。352、353 各有四盘，其余各有两盘，合计值按观测出现次数加权。格、工人、连续步、同地图双席和不同对照臂相互相关；本报告同时给出逐地图方向。354、355 和正式卷未参与。

从首胜单文件 `8da4b465` 内嵌的 cnet2_feat 逐步执行 Feat.observe，读回实际送入 Policy.encode 的地图第 0 平面。先转 float32 后按 0–255 量化，在物理坐标系还原。席 1 左右镜像、席 0 恒等；每帧同时核对全图量化、已见平面、每个工人的 UID 与位置、已执行移动的物理方向。原版 `65f268b2` 的 BeliefTracker.step 同样只接收己席可见碳与双方公开资产，set_actions 记录本席实际发出的命令。原版地图按其公开入口的精度取整；原始浮点误差也在 results.json 中。镜像不会交换物理座次。

初始四基地地碳均为零。Sapling 的其他 221 格均放 11，原版放 9.952；后者随观测更新对未识别格的先验。采集工只看到脚下，种树工只看到四邻。下注决策前未来动作、真实地碳及终局分数均不进入估计。完整模拟器只在输出两种估计后用于核对真值、还原现金与验回放。

## 哪里确实更准

| 行动前格时观测 | 数量 | Sapling 输入 MAE | Master3s2 输入 MAE |
|---|---:|---:|---:|
| 当前直接可见 | 142,987 | 0.058 | 0.143 |
| 当前不可见 | 2,009,813 | 1.920 | 1.343 |
| 不可见、Sapling 曾直见且原版已确定 | 1,635,344 | 0.056 | 0.121 |
| 不可见、Sapling 从未直见且原版已确定 | 230,528 | 4.289 | 0.077 |
| 不可见、双方都无上述历史 | 143,941 | 19.298 | 17.256 |
| 不可见、属采集工下一步可达格 | 240,464 | 0.477 | 0.245 |
| 不可见、属种树工下一步可达格的四邻 | 165,455 | 0.785 | 0.553 |
| 所有上述工人近区之外的不可见格 | 1,621,347 | 2.233 | 1.575 |

直接可见格未经量化的误差双方均为 0。双方已确定时，原版的整数碳量化通常更粗。不可见格按前/中/后 100 步（末段 99 步）拆开，MAE 依次为 5.299→3.734、0.314→0.134、0.094→0.125。最后一段全图替换会带来轻微退化。六图对应的全体隐藏格 MAE，345 为 1.896→1.240，346 为 1.841→1.422，348 为 1.831→1.296，349 为 2.773→1.735，352 为 1.610→1.068，353 为 1.897→1.458。

对 230,528 个可补格追到原版第一次确定其数值的途径。214,040 个格时观测来自己方直接观测触发的对称类重建；补入学生相同精度时，MAE 4.011→0.032。5,555 个来自对手采收证据触发的对称类重建，22.303→0.095。另有 1,195 个来自公开事件使地碳重置，5.303→0.021；9,738 个为预知的基地，双方本已准确。计数表示这些状态在后续轨迹中出现的次数，不能当作相互独立的新信息件数。

## 路线比较及反例

逐工人还原五个合法物理动作（停、上、右、下、左），按实际已发送的联合前缀推进。另设“可经营”子集：采集工去没有树和基地的格；种树工去己方没有树和基地、按当时现金可付种树或夺树费的格。后者只说明有落点、当时付得起，移动到格后还需在后续步完成付款，且存在碰撞、逃逸和队友竞争。地形排序对树的真实产权与对手后续反应不作假设。

| 有不同地碳真值的可经营选择 | 可计决策 / 全部 | 两种估计严格颠倒次序的动作对 | 原版纠正 / 改错 | 首选真值命中率，Sapling → 原版 | 平均错过地碳，Sapling → 原版 |
|---|---:|---:|---:|---:|---:|
| 采集工 | 65,603 / 66,410 | 1,896 | 1,828 / 68 | 97.82% → 98.70% | 0.433 → 0.108 |
| 种树工 | 18,221 / 19,952 | 1,042 | 948 / 94 | 97.18% → 98.28% | 0.158 → 0.063 |

并列最高的动作按均匀打破并列计分。采集工有 2 次少于两个可经营选项，另有 805 次选项真值全同；种树工分别为 1,715 与 16 次。六张地图上，两角色的平均地碳机会损失分别都下降；完整分席、两参赛方视角、阶段、每张地形、所有合法动作与可经营子集的分母在 results.json。未测收入的局部指标无法替代新图实战。

- **改善，349 号图，席 1，第 63 步。** 采集工 player-1-worker-0 位于格 120。向右实际有 100 碳，Sapling 估 24.7，原版估 100；该格已经由己方直接观察另一对称格推知。向上实际为零，Sapling 估 71.0，原版估零且仍列为未知。Sapling 地形排序会向上，原版排序会向右；历史实发为向右。
- **反例，348 号图，席 1，第 44 步。** 采集工 player-1-worker-11 位于格 94。向左真实有 84.45 碳，双方均未掌握该格，Sapling 估 40.39，原版估 24；留在脚下真实 31.12，双方都估约 31。单看地碳，原版先验会导致留在脚下，Sapling 反而能选中向左。历史实发为停留；仅凭地碳不能判定实战决策错误。
- **种树工的改善，353 号图，席 1，第 72 步。** 从格 45 向右，其四邻真实平均 43.90，Sapling 估 8.63，原版估 44.00。四个邻格均已由原版的直接或镜像证据确定，其中三格 Sapling 从未直见。停留的四邻真实平均 17.65。历史实发停留，可见地形排序与对局动作并非同一指标。352 号图第 27 步还有相反实例，详见 case_studies.json。

## 与旧两局读数如何对照

旧 measure_belief_mae.py 使用 rl2 的 NumpyActor2 和其 tracker，对 example 每十步取一次快照，仅在 belief≥0 的格计算当次 MAE，最后对 30 次快照简单平均。2000 图席 0 计入 5,948/6,750 个格时观测（0.157），2001 图席 1 计入 5,891/6,750（0.118）。那两局自身的估计覆盖也不足 100%，没有冻结 Sapling、原版 Master3s2 两个输入在相同局面上的对照。旧数不能当作本报告全体不可见格精度。

## 给训练线的接口

主候选把同一 Feat 输出同时交给 it50 与 Sapling；若只检验学生输入，应分别传入学生端修改后的棋盘及其所用的前缀动作特征，并维持伙伴和已冻结保护逻辑的输入身份。cnet2_feat 中 aux['est'] 来自相同坐标下的 fp16 往返，Prefix._dest 把它放入动作特征第 7 列。原版的 known 表示其递推器已识别，和 Sapling 的“曾直接观察过”含义不同；不能用它抹掉直接观察史。按已选办法把可补格的估计与可信度送入学生，需在未用于此次诊断的地形检验真实动作、交付和官方终局收益。

复现顺序为 audit.py（加 --pilot 可重做小样本）、summarize.py、information.py、case_study.py。cell_groups.json.gz 与 ranks.npz 与 opportunities.json.gz 保存逐盘统计和每个工人决策的五种选项；information.json 与 selective_ranks.npz 保存事后限定补格的明细。case_studies.json 保存四个正反例的物理格、前十步命令、视野、两种估计与真实地碳。
