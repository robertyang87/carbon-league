# 将已学习的碳估计接入 Sapling 的动作解码器

以前的学生只把碳估计送入棋盘编码器。这个版本把同一组 1,473 个已训练参数的预测再送入 Sapling 原有的逐动作解码。三张留图、双方各自视角的 1,794 次公开入口决策中，与仅使用编码器的学生相比，**7 个回合又改变了 8 条实令**。其中 7 条原先与母体相同，1 条回到母体选择。四个预选原版响应根上，新包和标量对照各有 4/4 的整队指令精确匹配父令；盲存时没有读取分支终分。[事前登记](protocol.json) · [盲存的完整指令](blind_commands.json)

## 实际改动

Sapling 的原生 `Prefix._dest` 将目的格碳量除以 100 后写入 15 个动作字段的第 7 列（从零计）。每个工人的五行依次对应停留、上、右、下、左。种植者这一列也是**目的格自身碳量**。基地的两个招募行读取固定为零的基地格，其余基地行原本为零。9 个单位字段都不读这张碳图。

新包沿用原训练目标的连续预测，把它以原生 float16 精度交给 Sapling 的动作特征，以原版本的 uint8 精度交给 Sapling 的编码器。只更新本席从未直见、当前不是基地或树的格。Sapling 通过 `din` 中展平的五行动作特征与 `V(move)` 两处读取第 7 列。已测学生与标量对照的包大小分别为 6,087,100 和 6,079,228 字节，较各自仅编码器版本均增加 479 字节。[打包代码](build.py) · [源包与生成包摘要](packages.json)

每个解码分支建立两个原生 Prefix，然后按本分支真正选择的融合动作同步推进。共享 Prefix 供 75% 自有 it50、原返航残差和原合法性判定读取，另一个只供 Sapling 读取。招募预算、占位、单位顺序、其它 14 个动作字段和原有返回保护均使用原定义。输出可能改变此前槽位的选择，从而在后续槽位改变双方共同面对的实发前缀。标量对照使用相同通路和先前训练的唯一偏置。

### 哪些输入引起了实际变化

对新学生的两个真实解码分支逐槽检查，共 39,460 次。所有非碳动作字段、9 个单位字段、合法动作、前缀资金与占位均匹配。4,840 个动作行的第 7 列改变，涉及 3,140 个分支内槽位；这些行全属于采集工。种植工行和基地行均有 0 次直接改值。所有 `din`、`V` 的实际输入逐分支核对，12,577 次返航残差调用均读取共享原碳输入。去掉另一路解码后最终被抑制的路径，实际的 8 条解码器新增变令也全属于采集工。种植工在本规则下直接看见四个方向邻格，这限制了通过该字段新增种植决策信息的空间。[逐步不变式及实际命令](held_turns.json.gz)

以首张留图按时间最早的实际差异为例，621471120 席 1 第 74 步，采集工 #16 在两包中的前四槽队令都相同。原编码器学生在解码时读到向下格 25.17 碳，新学生读到 61.18，伙伴仍读到 25.17。融合后的“向下减停留”得分从 −0.029 变成 +0.155，实令从停留变为向下。前一个槽位也有碳输入变化，但它的实令相同。该次改令对终局的影响没有配对实测。[逐动作数值](example.json) · [复现代码](explain_change.py)

### 本地耗时

新学生 1,794 次普通入口调用的外部往返耗时，中位数 51.54 ms、P95 64.03 ms、P99 96.91 ms、峰值 250.91 ms。没有调用超过 1 秒，六个独立进程的最高常驻内存为 89,836 KiB。标量对照的对应分位数为 51.27、64.59、87.05 和 229.36 ms。本机固定单核和一个 BLAS 线程，结果包含序列化、进程间往返和解析。这些数据适用于本机回放；先前托管测试的包是仅编码器的 bc69，不可将其托管成绩转记到新包。[本地环境与每席分位数](held_summary.json)

## 四个预选根的盲存

四个根来自此前冻结的历史训练地形。每个包分别从第 0 步重放至各根，只接收本席六个公开观察字段。学生和标量均在 621481221/0 t4、621472120/1 t8、621472121/1 t12 和 621475120/0 t4 精确选择登记的整队父令。没有一条登记替代令由这个新包发出。盲存文件 SHA-256 为 `c36d76b5f22ba79709de3cf0532b3641035d69c5c320800bd943753a2d545f59`。[盲存程序](blind.py) · [实际指令](blind_commands.json)

## 复现

`python build.py` 从两个已发布的单文件包生成两个实验包；`python blind.py` 独立在四个训练根封存实际指令。留图复查使用项目 Python 3.12 / NumPy 1.26.4 环境。分别执行 `held_eval.py timing <arm> <cpu>` 和 `held_eval.py audit <arm> <cpu>`，arm 取 `decoder_student`、`decoder_constant`，最后执行 `held_eval.py report` 和 `explain_change.py`。[候选单文件](candidate.py) · [标量单文件](constant.py) · [公开入口及逐槽核验代码](held_eval.py)
