# 四个有碳信息差的主动采样根

四张已登记训练地形各留下一个决策根，采集、种植各两个，双方各两席。四根里，母体和学生直接运行都会发出相同队令。这里另存的备选动作在学生本身的合法动作分布中排名第二或第三，且母体与学生对两案的行动相关碳估计确有差异。四条备选指令的终局得失有待真实对手响应。[冻结登记](protocol.json) · [可复演整队动作](roots.json)

两案碳差按“备选减母体”计算，表中列出新碳图对此差值的修正。种植两例均为方向选择，四邻均值衡量可能前往位置的地面资源；选择移动当拍本身不会种下一棵树。先验由该步真实 75%/25% 双网络、实际解码前缀和最终采用的原收益残差分支计算，温度为 1。

按冻结地形顺序，在既定目标角色的 36 个单工备选动作上检查了目的格、四邻和回库路线，22 个达到对应角色的 1 碳门槛，6 个达到全部门槛。同一图、同一合格时刻有多个选项时取实际网络先验最高者。前四张图已填满本批，另外六张未打开。旧的 108 个已签根按“地形、物理席、步”全部列入排除；其官方终局得分从未输入选择器。[筛选程序](select_roots.py)

每条备选均保存以下游贪心完成的整支队令。所有较早槽位服从母体，指定工人只更改一令，后续槽位重新运行两个真实解码分支及原有保护条件。四根的两套队令均无同队占位或基地招募冲突。存档还包含逐槽合法动作、招募预算、可用人口、原指令与备选概率、本席公开状态及先前联合命令摘要。独立验证器从第 0 步运行正常公开入口，重放同一前缀并核对两臂动作和碳特征。[独立核验代码](verify.py) · [核验结果](verification.json)

取得终分时按每案指定的物理地形重放封存前史；根步的双方分支使用同一已录敌令，根后本方均交回冻结母体，对手从下一拍起重新响应。这样每一个标签直接对应表中的一条受控单步替换。比较时需保留父令更优及提前终局等情形。
