2 张登记图中 1 张出现干预。原版温度 1，未设置随机种子，保留 0.58 秒自适应搜索。每张图各绑一枚物理 CPU，保留自然冷启动，在同一进程顺序完成该图分支。除根步外两臂己方使用完全相同的父代包。每个分支从同一个根后原版状态还原，包括追踪器、前次观察、搜索成本统计、策略 RNG 和进程内随机状态，重新核对语义摘要；其后双方收到各自变化的观测，搜索深度仍可随实际墙钟抖动。这里的终局差仅属于该干预和这次配对执行，不能推断总体胜率、上榜资格或新地图首胜。

run.py 产生按实际地图与席位的公共前缀、根状态及所有物理指令、对手时钟与每步观测哈希。settle.py 另起官方解释器逐个动作复演，并用 FastCarbon 独立分解每步双方现金，核对每步官方现金与完整终局。result.json 保存复核后的逐臂得分与资金流，原版每拍的候选、深度、墙钟及 CPU 见各局压缩文件。
