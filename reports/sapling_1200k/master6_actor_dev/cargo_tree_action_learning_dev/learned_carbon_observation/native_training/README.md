# 换一条合法工人指令，能否改善整局现金差

本目录保存十张历史训练图的公开动作普查和一批反事实训练标签。两套网络分别是 8da4b465 父包和使用学习型碳估计的 bc69b55e。对战考官采取仓内原版 Master3s2 的实际应对。正式考卷、留出地图与开发胜场单独计数。

## 原版的真实应对

每根各用一条早期历史轨迹重建原版信念跟踪器，更新时喂它该席实际发送的历史指令。根步从新启动的原版 0.58 秒搜索、温度 1 和自然随机数取得一次敌方真实联令。为两个选择共享该根令、搜索成本状态和随机状态，保存快照。历史记录里的该拍敌令用于追溯来源，另外保存。两条分支各执行自己的完整根令，下一拍起己方都交回 8da4b465，敌方自行观察与搜索到官方自然终局。无法复原历史对局进程当时的私有随机流和墙钟缓存。这里估计的是从重建公开状态开始、在这份真实响应下两案的结算差。

每图两支串行，奇偶图交替先跑父令或提案，同时最多两图、每图独占一个亲和核。既有公开调用时钟含每拍实际候选数、搜索深度和超预算回退。离线普查没有调用考官。按前一批 273 拍双支的实际 277.9 秒外推，这批每对训练标签约需 5 个单核分钟。所有结果均按登记顺序报告，单次分支试验含采样与墙钟变异。本机整体 CPU 配额为 4 核，两个考官分别绑核运行。正式天梯单文件、通信、1.5 核和 512 MiB 资格需在该候选的独立运行报告中判断。

## 计算中断与恢复

宿主切换时，六条完整分支已经原子落盘，最后两条只完成了一部分，进程 370567 和 370574 均已退出。interruption.json 记录恢复前的六份回执和四个原始快照。仅在 621472121 恢复提案支、621475120 恢复父支，两者从各自原根的同一敌令、跟踪器、模型随机状态和搜索成本状态重新续弈。未完成的半支没有可复演终局。新进程的墙钟调度与未保存的半支有别，实际完成的路线照实保留。

## 复核入口

- scan.py、10 份按图压缩的命令与采集文件和 summary.json 给出逐席分母、类别、局部重估及全部零机会记录。
- summarize.py、local_contrasts.json.gz、pilot.json 给出全部自然分叉与入选规则。active_duplicates.json、freeze_batch.py 和 batch.json 绑定主动提案、实际经济特征与数据源。
- collect_plan.json、collect.py 与 collection_authorized.json 绑定现场调用和放行提交。每根在 root_*/ 保留含敌方根令的回执、克隆状态和两支完整指令与时钟。
- settle.py 对相同指令独立重跑官方计分并用 FastCarbon 逐拍复算双方现金账。labels.json.gz 保存到账、地租、货税、成本、每拍现金轨迹及终局。另对 3/5/10 步跨度逐一扫描，正、负方向各保留现金分差变化最大的一个窗口，附两条世界线在这几步的全部动作、持货、活工、持树与到账明细；train_pairs.json 只收录四个用于拟合的带符号标签，含来源、公开状态哈希和两份动作。

四次干预在第 10 步的相对现金收益全部为正，完整续弈有一次正值、三次负值。621481221 的留步采集早期账在第 24 步跌至 −12.91、第 100 步跌至 −151.22，最后仍比父令多得 398.82 分。两臂的己方减敌方经济账分解为交付 +1,042、种植开销节省约 +545、地租 −1,243，另有其他收入与成本。621472121 的采集改向在第 24 步多 37.55，最终少 1,672.69；其中交付净差约 −1,617。621475120 的种植改向节省净种树支出约 1,606，却少收净地租约 4,567。短期余额与地面富度不能替代有真实敌方响应的终局标签。

四根在相同原版响应约束下各测一次。动作先验、局部碳变化和是否合法可以支持提出一个备选；替它颁发通用的优劣标签还需要跨地图及独立自然响应。四个新训练标签全部保留。就本批而言，训练图、历史开局、主动挑选两个合法命令这三点均使它不能记为新地图开发胜场。

实际八条完成的分支耗时 141.1–153.3 秒，总计 19.59 单核墙钟分钟。中断后丢弃的两条未完成半支另外耗时，未计入此数字。四根的原版搜索均实际跑到深度 8。根后 2328 次原版调用中实际最大完成深度分布为 H1=10、H2=27、H3=16、H4=80、H5=122、H6=193、H7=84、H8=1796。完整逐拍时钟另存两臂回执。
