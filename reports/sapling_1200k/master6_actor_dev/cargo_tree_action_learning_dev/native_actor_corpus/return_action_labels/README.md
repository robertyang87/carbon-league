## 新增证据与原版时钟

原有九个采用同一首胜包 `8da4b465` 续策的根落在 t4–138，其中原训练图上的四个都在前 13 拍。既有方向试验在训练图上没有能据真实两臂终分选择权重步长的根。另一部署 `4e3701f3` 只在 t128–159 替换权重，因此本次固定晚段仍会真实变令的 `6c548995`。四图来自原有十三张训练图，按种子升序取头四张，源历史席位依序为 0、1、0、1。`621472121` 席 0 的 t210–237 窗无合格令，其余七处均在签收结果前锁定。[旧方向试验](../terminal_direction/README.md) · [本次登记](protocol.json)

每张图仅从开局预热一次原版。每处先核两包真实自由命令，再冻结原版当拍的自然命令，以及包括搜索成本与随机源在内的完整根后状态。每臂从同一快照独立恢复。根步以后均由 `8da4b465` 续弈至正式终局，原版依自然变化的对局逐拍响应。14 条按官方规则结算的开发后缀、双方命令带、真实原版时钟与现金账存于 `native/`。四图共 1,780 次原版真实公开调用，多候选零深回退 0 次。每图两臂在同一核串行，核 0 和核 1 各处理两图。[采集程序](collect.py) · [独立结算](settle.py) · [冻结拟合程序](fit.py)

这些原版调用合计占用常规公开入口墙钟 777.24 秒、进程 CPU 773.63 秒，其中 1,397 次到深度 8，最长公开调用 0.774 秒。独立核算的首次尝试在第一张图的第二根前由公开哈希拦下。原因是官方裁判把工人和树的编号计数保存在进程全局，嵌套复演另一条支线会改变外层裁判的后续编号。修订后的核算先走完整条历史前缀并保存各根，再逐支重新复演。原版比赛、选根及拟合规则均沿用预登记记录。
