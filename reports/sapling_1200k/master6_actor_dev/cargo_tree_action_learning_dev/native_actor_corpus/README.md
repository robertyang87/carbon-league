## 训练数据与参数

冻结的历史清单有 29 张地图、58 条完整原版对局记录。逐一校验原始文件和官方收据，并重放双方实际联合命令，17,342 次推进与 58 场官方终分相符。示范者是每条记录的物理席 1−candidate_seat。原清单按地形分为 19/4/6，隔离先前首胜对照和这轮碳预测解码开发用过的七张地图后，实用 13/3/6 张。最新开发和正式保留区间均排除。诊断图 621497120、621497121 曾进入另一项旧蒸馏训练，621495120 曾作该旧项目的留图，H24 也核验过部分历史留图。这六图只衡量本轮拟合以外的历史行为匹配。[原始对局 SHA、物理席及地形分区](sources.json)

训练使用 26 条完整轨迹，各轨分 96 段并在每段预选一拍，获得 2,496 个不同真实局面，两物理席各 1,248、1,248 拍，前中后三段分别为 769、869、858 拍。27,964 个有归属的单位/基地槽中有 23,880 个可选专家动作、4,084 个只有单一合法令，遇到首个不可表示前缀 0 拍。每席通过所有公开观察维护自己的特征历史，目标只进入当前槽损失和后续槽前缀。训练时父包的自由解码先决定修正支路，随后固定 75% it50 项并对 25% Sapling 反传。验证和诊断由三个发布包各自自由解码并执行自己的守卫。[采样目录](training_roots.json.gz) · [冻结规则](protocol.json)

全策略网络和动作头各做 312 次更新，每次使用相同的 8 个局面。直接对比部署与 Torch 的 78 个训练根，实发条件下合法动作相对打分最大误差 3.1e-06。CPU0 单线程完成缓存提取约 131 秒，两臂优化、检查点核验及成包共 78.8 秒。第 78 步已在训练轨迹复核正常入口，两臂分别改变了 6 和 2 个工人指令。[中期检查点](checkpoint_78.json) · [训练过程](loss.json.gz) · [模型与软件身份](fit.json)

## 角色护栏的两种复算

原评估代码 d74e33630 将所有地图的同类工人合并计算 2 个百分点的退化阈值。该代码冻结后、三包首次留出自由入口调用以前，改为每张图等权计算。采用两种口径分别重算同一份实际命令，全策略网络均通过，动作头均未通过；动作头在主指标上低于全策略网络。[两版历史评估逻辑与判读](gate_audit.json)

| 相对父包，百分点 | 采集工，合并 | 采集工，地图等权 | 种树工，合并 | 种树工，地图等权 |
|---|---:|---:|---:|---:|
| 全策略网络 | +0.33 | +0.32 | +0.39 | +0.47 |
| 仅动作头 | +0.24 | +0.23 | +0.00 | +0.02 |

INT8 行的缩放系数改变会同时改变这一行多个解量化权重。两个发布包的固定伙伴、动作守卫和价值头保持同一身份。[分层权重审核](weight_audit.json) · [全策略部署包](full.py) · [动作头部署包](head.py)

## 重建

在含历史原件的检出中从本目录运行以下命令。缓存与优化器断点写入 work/，中断后从上一条完整轨迹或最近 26 次更新处继续。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
for script in audits.py prepare_data.py fit.py check_weights.py evaluate.py check_gate.py summarize.py; do
  taskset -c 0 /workspace/carbon-review-venv/bin/python "$script" || exit 1
done
```
