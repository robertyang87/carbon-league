# 用原版搜索实令训练廉价对手模型

以 63 张历史地图、260 个完整对局中的原版 Master3s2 实发命令，训练了 4,080 参数的对手网络。六张行为诊断图上，重载采集工主动移动命中由 508/849 提高到 540/849，但新网的地图等权负对数似然为 0.7758，差于已发表的 3,400 参数对手模型 0.7205。预先登记的联合条件未通过。[训练权重](model.npz) · [冻结合同](protocol.json) · [行为评估](held.json)

## 训练来源

扩容清单中可在新版本退役历史开发图的 67 张地图里，单独留出 621758345、621758346、621758348、621758349 的所有轨迹。它们是仓内有实际首胜 8da4 与原版配对的四图。剩下 63 个训练地形覆盖 52 个实战对手包和 77,478 个原版席拍。按每个地形、每个专家席预取 64 个不同局面，在同一地形与席的各场和各段之间分配，得到 8,064 根、76,444 个可选动作槽。13,022 个强制槽免于反传，训练根中首个不可表示前缀为 0。[逐对局来源及四组划分](sources.json.gz) · [逐根时点](training_roots.json.gz)

训练时从 t0 逐拍重建专家物理席的可见状态，当前槽的目标是实际执行命令。动作前缀仅在已经处理的槽内采用真实令。新网从随机权重起步，12 个固定轮次、2,400 次更新，4,080 个参数全部改变。CPU3 单线程用时 66.3 CPU 秒，含样本提取，优化约 5.0 秒。导出权重的 NumPy 分数与 Torch 最大绝对差 2.38e-6。[模型结构和前缀](model.py) · [训练收据](fit.json)

主基线由原版搜索发令训练，旧研究用 6 张训练图、2 张行为留图，另有独立历史分支检验。当时从 Sapling 可见信息重建对方视角，本次给三个对手模型相同的模拟对方己席观察。旧模型曾拟合本次诊断图 621495120。其他历史研究也接触过这 3 张验证与 6 张诊断地形，新网训练和温度校准均按本轮物理划分隔离。正式 100 图保留区、1,000 张历史固定考场和本轮 400/401 实战均不进入训练或模型选择。[旧原版实令模型](../../../own_search_bridge_dev/opponent_response_dev/README.md) · [已发表的停留校准](../../../own_search_bridge_dev/opponent_response_dev/active_calibration/README.md) · [扩容隔离登记](../expansion/exclusions.json)

## 可调用入口与复算

`OriginalOpponentRollout(seat).action(observation)` 由 NumPy 输出该物理席的整队命令。每个分支用独立历史，可先以 `warm` 回放同席过去观察，再以 `fork` 复制。双席 128 个诊断拍的 1,438 个单位或基地预测与行为评估逐项相同。单测输入观察到整队令约每秒 676 队。离线仿真中模型可用引擎生成的对方己席遮罩视图。若在 Sapling 实战搜索中使用，必须从 Sapling 当时可见的信息重建假想世界，然后从该世界生成对方观察。此实验使用 FastCarbon 的当前席可见观察和历史特征，未接入实战搜索。[调用入口](opponent.py) · [双席与分支状态核验](entry.json)

从本目录在含冻结对局材料的检出上运行。训练的中间张量只在系统临时目录缓存。所需 NumPy 1.26.4、PyTorch 2.5.1+cpu 和仿真器身份随合同记录。闭环只调用旧首胜包和三款廉价对手，原版实战动作均来自冻结档案。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
for script in register.py fit.py evaluate.py check_entry.py closed.py check_result.py; do
  taskset -c 3 python "$script" || exit 1
done
```
