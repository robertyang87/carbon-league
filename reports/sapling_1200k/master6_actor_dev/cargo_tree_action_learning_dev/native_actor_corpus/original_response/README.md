## 选取、原版时钟与复演

两根取冻结的六张诊断图中种子值最小的两张，首图用源历史考生席 0，第二图用席 1。原有训练划分、留图自由出令、两份留图结果和三个包的哈希一起锁定。两种部署都保留 75% 的 it50 与 25% 的 Sapling。首图父包先行，第二图全骨干先行，每图两臂在同一专用 CPU 上串行，两图同机并行。[冻结清单](release.json) · [执行合同](protocol.json)

从开局到根前，两个考生和原版各自通过正常入口读取本席的六项公开观察，官方解释器执行历史整队令。原版跟踪器在每一步记入实际执行的历史命令，根上自然求解一次。两臂采用同一份原版根令，分别从相同的根后搜索状态、费用估计与随机数状态恢复。分叉后，原版在各自的局面上独立执行原生墙钟搜索。温度为 1，原版内部随机源保持其默认配置。[执行程序](run.py)

在 1,196 次官方状态转移的独立复演中，两席公开观察、窗口内双方提案、窗口后 620 次本方部署命令、双方树数和现金、正式终分均逐拍核合。原版共调用 970 次，其中正深搜索 969 次，单一候选 1 次，多候选零深回退 0 次，最慢公开调用 0.747 秒。各根的共享快照及两臂的原始指令、逐拍搜索统计、复算现金账均存于 `native/`。[复演程序](settle.py) · [两席资产复核](metrics.py)
