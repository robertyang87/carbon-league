## 身份、覆盖和正式考试

核查固定仓库树 `8a74cf5a`。本次扫描 9,529 个结构化文件与容器路径、9,048 个不同 Git blob，递归解开 ZIP、TAR 和 Gzip 后查验 12,084 个叶文件。参赛包完整 SHA-256 为 `8da4b465f7fa6e601e51bd7c2e81f25825cb59b9b5ab285f7f56d0f6bbfe1cac`。从该哈希绑定的记录追到 8 份本机完整原始记录、12 份新图容器报名及其逐拍终局收据，另有一份旧图容器复测。对每局按物理席排列双方完整指令，键排序后取 SHA-256，再与地形合并取 SHA-256。21 组动作摘要和 21 组地形加动作摘要均各不相同。所有录像副本与同轨重放各归于原场。[仓库证据发现清单](discovery.json) · [扫描程序](discover.py)

350、351 两张图出现在保留或曝光名单、训练排除名单，未找到首胜包在其上的完整实战。以首胜包为初始化的八场采样训练实际使用 `2df31884`，属于另一策略。同图历史观察上的部署计时、只接管中盘的分支以及跨包政策的混合续弈各自保留原实验身份。[预留地形名单](../../../territory_sequence/windowed/fresh_original/clearance.json) · [采样训练说明](../../../onpolicy_native/README.md)

正式验收要求冻结一个包，在同一批 **100 张全新保留图**上各打双席，**200 局至少 180 胜、官方平均分差至少 +500**。本表汇总五批训练开发期间的十张图，这些图随后已曝光。正式考卷仍需单独举行。[正式验收协议](../../../../../MASTER3S2_90.md)
