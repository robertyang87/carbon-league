## 重建

在包含冻结 Git 对象及相应原件的检出中从本目录运行。官方复演只执行存档指令。默认解释器需能导入项目的 NumPy 及官方环境依赖。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
python partition.py
python replay.py --workers 4 > /tmp/native-expansion-5567aadd.jsonl
python scan.py --replay-cache /tmp/native-expansion-5567aadd.jsonl
```
