## 最后十拍实际还有哪些选择

每个起点只对同拍可达格有交集的我方在场工人展开。目标和这名工人都可上下左右或留在原地。其他工人及基地沿用该场实发命令。对每个敌令，先保留我方实令作对照，再枚举该工人的另外四项。每个差值都相对于**相同敌令下**的对照。四场原始对局共 1,196 拍，两席共 2,392 份行动前公开观察逐一与运行票哈希吻合，四组官方终分复现；44 个回溯局面实令分支的全图状态也与原对局实际下一状态一致。六名目标的 66 个起点中，35 个出现双方可能同格的走法，共有 920 个改令组合。同一局面和履历会出现在多个组合中，不能当做独立样本。

- **按原版的实令。** 184 个改令中，8 个能移动到目标同一格。4 次撞上去的是种树工，另 4 次是比目标更重的采集工。8 次都额外损失一名己方工人，目标均活，双方本拍现金的边际变化均为 0。具体到 450 席 0 的第 213 拍，己方 21 号留在 67 格会被对手 27 号撞死，己方少持货 96.7755、对方多持货 96.7755。实际走法保住了这名采集工。这四次发生在同一条轨迹的相邻决策机会，损失不能相加。
- **让对手也选择其余合法命令。** 共 24 个改令组合能额外杀掉目标，全发生在对手偏离实际路线时。固定这些组合各自的防守动作，对手五个命令中仍有 3 个（5 个组合）或 4 个（19 个组合）能让送货者活下来。24 个组合里，当拍现金分差的边际变化 21 个为零，其余为 −7.41、−9.81、−30.65。合法走法数不给出其发生概率，行动前双方也看不到对方本拍的命令。
- **进仓的碳归基地所有者。** 450 席 0 第 215 拍，我方 21 号若改向右进敌仓，对手 27 号的五种命令下，敌方基地都会比相同敌令对照多收到我方送来的 96.7755。这五种都是我方自带货进敌仓，六人样本里额外击杀成功的 24 种没有触发这笔收入。官方规则还允许胜出的采集工带着缴获的货，在敌仓把货交给敌方；双方同亡时，无树的基地格上掉落货也进基地所有者账户。击杀、己方保有货与对手本拍实际到账分别记在分支证据里。

## 布位机会出现在什么时候

表末列从交货动作前 10、5、3 拍的行动前局面起步，候选人须是**当时已经在场、当时持货量严格少于目标当时持货量**的己方采集工，且第一拍就能发出不同于实令的合法命令。允许后续走或留，环形棋盘最短距离必须够得到目标实际经过的位置。相遇至少距出发两次推进，地点在对手所有基地格以外，并且到真实交货到账还剩至少两次推进。把最后一个条件放宽到还剩一次推进，前三拍起步时，仅 451 席 0 的 268.69 那笔多出一名可达工人。

例如 450 席 0 的 905.20 是最大一笔。206 拍手上为空的己方 37 号在 224 格，实令向下；若第一步向上或向右，按环形距离可在行动前状态 209 到达 196 格，对应真实路线当时所在格，距实际到账还剩八次推进。到第 211 拍，即使已有四名较轻采集工，全部都赶不上定义内的仓外相遇。这是事后沿已知路线的宽松上界：其余单位的碰撞、沿路采收与树税、护送、对手观察我方后的改道和放弃己方回款的代价，均未作多步推演。它提出了值得用实际应手检验的提前布位窗口，不能记为守住了 905.20。

四场均按最大现金跌幅选取，六名工人都是最终交货成功者。因此这些分母只描述四场指定片段，不能外推天梯防守机会率或终局收益。逐项分支使用事后完整状态交给规则引擎复核；实际敌方未来轨迹只用于回溯，没有生成策略输入或训练目标。
