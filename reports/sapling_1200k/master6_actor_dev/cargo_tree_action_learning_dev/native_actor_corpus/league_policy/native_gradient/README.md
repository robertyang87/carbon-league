# Sapling 对原版 Master3s2 的训练梯度迁移

36 个自有对手采样局给出的全网更新方向，与 8 个历史原版采样局给出的更新方向夹角为 **103.83°**。两份梯度的点积为 −0.00495634，余弦为 −0.2390。比较覆盖 1,205,800 个可训练策略参数，双方都从同一个部署父包 `8da4b465` 求导。自有对手梯度的范数 0.10826830 与原训练读数相合，工人动作头的偏置梯度逐项误差为 0。原版历史样本给出的梯度范数为 0.19152118。[完整读数](alignment.json)

## 样本和动作

自有对手侧是 18 张图双方换席的 36 个采样局及同图同席贪心对照。432 个预定机会中 411 个有真实二选一。原版侧是此前 `onpolicy_native` 在 4 张已曝光图上采集的 8 个完整采样局，各自有同图同席的历史贪心对照。64 个预定机会有 60 次实际二选一，其中 34 次执行第二个联合动作。历史原版采样侧 0 胜 8 负，历史贪心对照 1 胜 7 负。双方的对手随机流和墙钟独立，原版真实对手的采样噪声进入配对回报。同图换席按一个地图看待。[历史考试台账](../../../onpolicy_native/README.md) · [重建过程及各局身份](original_data.py)

对每个有支持的根，先从开局逐拍重放物理命令、己方可见信息、单位出令顺序和已执行前缀，复现当时的两个不同合法联合动作及实际抽选概率。原版数据的部署 NumPy 对数几率差逐根与历史记录相同，Torch 对数几率差最大误差 0.00000382。每次抽选使用该完整对局的实际终局 U 减去同图同席对照 U。两个集合分别除以 432、64 个预定机会，缺少合法选项的机会贡献 0。报告同时给出各网络模块的原始梯度点积、范数和余弦。工人输出头余弦 −0.1844，GRU −0.1812，空间输入卷积 −0.2398；基地动作头在这批工人二选一中梯度为 0。[计算脚本](alignment.py)

## 实际部署权重的变化

原版梯度与 `8da4b465 → 510c527a` 实际导出、量化后的参数位移点积为 **−0.00063919**。在旧策略真实抽到的两令支持集上，用新的部署模型重新计算所执行动作的对数概率，其配对回报加权变化为 **−0.00062419/预定机会**。此量限于旧安全分支和出令前缀。两种计算对这批数据给出相同方向。

| 621758346 | −0.0508 | +0.00001804 |
| 621758348 | −0.2425 | −0.00084113 |

四次留一后的梯度余弦均为负。留出 346 又使实际参数变化的投影接近零并略转正，说明幅度和净效果对这张图敏感。这些属于训练样本上的局部诊断。总体胜率仍须独立完整对局测量。新原版试验及正式地图均未进入本次计算。

## 复算

在本目录使用仓内训练环境运行，临时缓存只保存本次重算的全网梯度，第二条命令会核验其哈希。程序全程重放既有命令。

```bash
python alignment.py reference --cache /tmp/sapling-league-reference.npz
python alignment.py finish --cache /tmp/sapling-league-reference.npz
```
