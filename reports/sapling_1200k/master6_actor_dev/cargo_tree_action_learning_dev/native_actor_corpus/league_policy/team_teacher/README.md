## 这八条尾盘怎样取得

取历史首胜包 8da4 在两张老图上已实际走过的前 200 拍。每张图上，一个流内的两臂共享此前历史、敌方根步命令、原版信念状态、随机状态和时钟成本估计。各方只收到本席公开观察。教师使用 ApexCarbon-V4TTA-Search 首版 `f2882881`，以本方实际历史命令恢复信念。在实验臂，教师替本方所有单位从 t200 到 t207 自由出令；对照臂一直由 8da4 出令。从 t208 到官方终局，两臂均由相同的 8da4 包决策，完整原版考官继续对各自的局势自然响应。八条尾盘都走了 99 次环境推进并负于考官。两个独立随机流估计的是同一地图的续弈变化，独立地图数仍为二。[执行代码](run.py) · [逐拍原始证据](results)

原版沿用公开入口、温度 1 和 0.58 秒自适应搜索。在两核上每图占一核，同图各流和各臂串行执行。按共享前缀只计一次，共记录 1,588 次考官调用，1,275 次完成深度 8。2 次单候选直接返回，另有 0 次多候选零深回退。考官公开调用耗时总计 696.84 秒，P95 为 0.559 秒，P99 为 0.572 秒，最大 0.656 秒。Apex 调用共 32 次。独立结算器把每条真实双边命令带从开局重放，在实际首次变令处切分双方资产和现金收支，复核全部八臂官方终分。[复算程序](settle_windows.py) · [复算收据](settled_windows.json)

这个负结果覆盖两张老图、两个席位和固定的八步接管策略。它支持将四个配对留作反例，排除了直接把这些整队动作统一标作正向示范的理由。独立新图整局胜率仍须由参赛候选从开局实打取得。
