# 两个 Sapling 动作对原版 Master3s2 的真实终局比较

**两根中一根满足训练标签条件。** 在地图 `621758461` 席 1 第 252 步，Sapling 有两个可行的整队命令，差别仅是工人 `player-1-worker-49` 向左或向右。原版考官对两臂发出了相同的根步命令。实际续局中，向左的较高分令比向右多得 **110.26 分终局分差**，效用 U 高 **0.01096**。这是同一训练局面、每个动作各走一次到终局的差值，重复采样的期望收益仍未知。

## 收支与对手响应

在合格的席 1 根，B 比 A 少花种植支出，为相对分差贡献 +211.66，但地租少 −200.92，树收敌货税少 −33.90，普通交仓少 −17.13，招工与夺树支出差再合计 −70.00。B 自己多得 100.57 分，同时考官多得 210.83 分。只用本方收入衡量这一步，会选反方向。

在席 0 根，Sapling 的一名工人从向左改为向下；原版同时改变三名工人的方向和招工基地。其首拍两次分别评了 21 个候选到深度 2、22 个候选到深度 3。这里的 −242.99 混有敌方命令变化，不能作为学生左右取舍的标签。[逐项现金账](economy.md) · [两臂命令和逐局证据](outputs)

## 重放和时钟

独立程序从官方初始状态重放每个不同的前缀及尾盘，核对双方公开观察、整队实发命令、学生候选与概率、官方盘面、编号、终止和分数。根步计入尾盘分母。两张图的公共前缀分别有 252 和 251 个原版多候选步，所有多候选步均达到正深；四段续局的多候选正深比例也都是 100%。合格根首步的搜索深度分别为 7 和 8，原版实际命令相同。时间门按同一臂的前缀和尾盘合计逐方判断，所有臂均无慢步，学生单次最高 0.220 秒。收据来自本地训练机，CPU 和内存配额见逐根记录，天梯资格仍须另测。[独立结算器](settle_pairs.py) · [现金复算器](economy.py)
