# 同时行动根只向原版考官索取一次命令

旧训练图 621758460 的第 12 步，Sapling 可以让同一个工人向上或向左移动。两条完整联合命令的模型概率为 0.6230 和 0.3770。Master3s2 只看到其在双方出手前可见的局面，实际搜索 9 个候选至深度 8，用时 0.2400 秒并发出一个完整命令。两个学生分支使用这同一个命令和考官刚执行完该请求时的全部私有状态。[逐拍证据](receipt.json)

根后继续运行真实考官。第 13 步，两臂送给考官的游戏观察不同，去掉计时字段后仍能区分；各自完成深度 8 搜索。第 14 步两臂的公开游戏观察重新吻合，现场仍是两次真实调用。全夹具计 17 次原版物理请求，分别为 12 拍前缀、1 拍共用根、两臂各 2 拍独立续弈。两臂的模拟时钟在根都扣同一笔耗时。两份三步动作带分别从同一根通过官方规则重放，双方观察、隐藏棋盘和编号生成器均吻合。此夹具未运行终局、未产生胜负或训练标签。[独立核验](audit.json)

接入训练程序时，先用 `LivePosition` 保留学生、考官和裁判的共同根。将真实学生菜单交给 `SharedEnemyRoot`，构造函数只向原版索取一次根命令，并保存这次真实调用之后的考官状态。每个分支调用 `issue(0)` 或 `issue(1)`，返回更新的双席时钟、已实际推进一拍的动作记录和考官状态收据。从下一拍才再次调用真实考官。重复比较同一根时应按给定这次考官应对解释终局回报，单次恢复不覆盖考官所有可能应对。[可复用实现](shared.py) · [功能夹具](fixture_shared.py)
