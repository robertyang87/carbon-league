# 保留整队候选的 Sapling 神经评分头

**本轮止于离线检验。** 在 6 张物理地图上逐图留出，估计的平均终局效用变化为 **−0.00397**，仅 2/6 张图改善。预登记要求均值为正且至少 4/6 张图改善。没有为这项改动增加原版 Master3s2 比赛或占用正式地图。

## 改动及数据

父网 `851c901a` 在已曝光的 6 张训练图上双席各进行了两次自然采样，共 24 场对原版 Master3s2 的完整比赛。这 24 场全部输了，组内的终局效用差仅含分差项。设计前已经知道整体败绩，下面的回算只适用于这份回放和本次留一训练。

新增 272 个可训练参数。父网先从完整局面提出两条不同的合法整队命令。两条命令共享一个 8 隐元网络，输入由各自命令的目的格、敌我基地和工人位置、敌我携货与现金、敌我树、回款与冲突风险、原策略分值等 32 个行动前特征组成。两个分数之差最多让原对数赔率变动 ±0.25。零输出初始化精确还原父网概率。原网络继续负责全部动作提案、前缀解码和普通步。进攻、防守和经营的取舍由有界的学习分数参与。完整训练头的单文件 SHA-256 为 `d0985f023769c9c06e75ce74a0d33166c3e26c3b846f72e3eaf6f92632159232`，作为研究件保存。

将每张地图对应的留出模型导出成单文件，按原状态和顺序重演了双方席位共 7,176 次公开调用。6,888 个普通步和 13 个调度单例均与历史实发令一致。275 个双令局面全部保留历史真实选令，两份物理命令的身份和顺序逐一吻合。单文件的选令概率与离线前向的最大差为 8.9×10⁻¹⁶。在这些留出局面中，新概率更偏好的整队命令在席 0 改变 31 次、席 1 改变 28 次。[逐局公开入口核验](audit.json)

## 留一整图成绩

每折将一张地图的双席及两份整局都留下，只用其他 5 张地图的 20 次终局回报训练。该折在留出轨迹每一处真实抽签上计算已发整队命令的概率比，将这些比值乘成整轨权重 W。普通步和单例的比值为 1。每个同图同席组的配对变化为 `(W_A − W_B) × (U_A − U_B) / 2`。12 组等权进入平均。所有输局、低权重和反向例都保留。

24 条整轨权重范围为 0.354–1.589，重要性采样的有效样本量为 22.32。12 个同图同席组有 7 组估计为负，删去任一张图后剩余地图的均值仍在 −0.00584 至 −0.00184。估计来自共享训练图的六个模型，有限数据仍容许抽样误差。这些权重估计沿用收集时的原版考官策略和墙钟分布。冷启、单步耗时和平台资源资格需在真实执行器另测。六图合训得到的研究件实际胜率未知，本次没有让它进入新图考场。

## 复算
