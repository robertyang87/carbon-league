**本次训练结果为 0 次参数更新。** 462 席 0 第 84 步，原令 A 与替换令 B 都没有让指定种植工实际付款。两个分支均打到官方终局，B 相对 A 的终局分差改善 984.70、效用增加 0.078213。按事前约定，此差值只能记作整队指令的观察结果，不能赋给种树收益。463 继续保留检验用途。研究分支和生产模型都没有新增训练权重。[资格回执](outcome.json)

训练票固定在旧图 621758462 席 0，检验票固定在旧图 621758463 席 1。两票都必须经官方规则独立验算。真实 A 与替换令 B 共享一个对手根请求，其后由原版按各分支的新公开观察自然响应到终局。还要求该名工人的两种行为在当拍确有登记的实付种树、夺树或交仓差别。任何一项不符就记录原因。资格与用途见 [预登记](protocol.json)。

**学习的参数。** 对每份完整物理指令，按拟执行动作重放 851c 内 Sapling 的 GRU 前缀，提取 96 维隐藏状态。按 5 种工人动作和 3 种基地动作分别累加，除以活跃槽位数，再把向量长度限制在 1。训练的是一个 8 × 96 的新读出层，原候选和原网络都可复原。新评分为原行动边际概率的对数加读出层分数，再对整份菜单归一化。对同一指令的跨类提案概率只计一次。[特征与完整菜单预测](model.py)

**只做一次更新。** 先在合格的 462 票上重算两臂的官方效用，令 d = U(B) − U(A)，以两份完整指令的特征之差乘以 0.125d，从零初始化更新，并把整层参数范数限制为 0.125。任一菜单指令的 logit 改变量绝对值由此不超过 0.125。胜负与分差均进入官方效用。若两臂效用相同或特征相同，权重保持零；证据缺失不产生训练权重。

**验证次序。** 程序分别固定 `artifacts/readout.npy` 和 `fit.json`，在读取 463 的结局标签前，先将该票所有候选的新旧概率和排序固定至 `holdout_prediction.json`。正、负、零方向均报告。此单根更新只供研究，提交资格和整局胜率须在独立试验中判断。

从此目录执行 `python mechanism.py` 可在旧图 460 的两席公开历史上复算方向检验。该检验为相同的合法物理指令分别指定 +1、0、−1 的人工测试标签。两席实测对数赔率改变量依次为 ±0.01859、±0.03596，零标签对应改变量 0。全部 768 个梯度坐标的差分误差不超过 2.8 × 10⁻¹²。[复算结果](mechanism.json)
