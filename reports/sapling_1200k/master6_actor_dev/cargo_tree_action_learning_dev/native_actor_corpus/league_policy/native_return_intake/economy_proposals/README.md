# Sapling 经济决策采样覆盖

851c 既有采样器在 48 个预登记局面上给出了 92 个完整队伍指令。加入招工、种植与携货选择后，同一批局面共有 315 个指令，其中 223 个来自旧采样器覆盖以外。按新策略实际抽样，这些新增指令共占平均 21.11% 的概率。开发样本取自两张旧训练图，无法据此估计胜率或终局分差。

**新增选择落在了哪些局面。** 14 根出现新的基地招工选择。44 根出现新的种植工指令，其中 9 根是在对方树上比较驻留与移动，38 根是在可尝试种植的位置比较两者。46 根出现新的携货工指令，其中 3 根可改走己方基地，8 根可从原先的进基地选择改走其他格。上述类别和方向可重叠。对手可能同步移动，种树也会受实际预算影响。本表只按行动前已知信息标识机会。

**训练入口。** 在 851c 的公开观测历史上调用 `proposals.build(model, x, aux, public)`。原包、权重及部署入口保持原样。在注册的 12 个时点，生成器先解完整队伍的基准令 A0，再使用原包的前缀解码器强制一个合法动作，逐单位重算后续决策，复核解码路径和己方冲突。四类各占 1/4 的提案概率；每类按模型分数检查至多 4 个合法候选，保留至多 2 个不同整队指令。类别无合格候选就采用 A0。即使在注册时点，A0 的平均概率仍为 72.12%。其他时点由原包照常出令。

`draw(menu, rng)` 返回物理整队指令及其边际概率。多个类别或单位指向相同指令时合并全部路径。用 `propensity.marginal` 可在固定菜单上求该指令的概率和对各见证单位原生 logits 差值的对数概率导数。在全部 315 份指令上逐个对回概率，最大误差为 0；1,822 个导数坐标的中心差分误差最大为 2.75 × 10⁻¹¹。固定菜单适用于局部学习，若重新构造后候选集合或解码路径改变，应重新核算策略支持。

**回报归属。** 生成器只见当时己席公开状态；封存新指令及其概率后，审计才读取原对局当前步双方动作。四条既有轨迹共 1,196 次联合推进、2,392 个双方公开观测哈希全部对齐，旧支持中的全部 92 份物理令均可在新菜单中找到。原先自然采出的行动 A 可能与 A0 不同。后续分支实验要按真实 A 去重，记录所选 B 的条件概率，并让对手续弈至官方终局。这里所有候选的当拍经济差和终局效果均留空。

冻结方案在 [protocol.json](protocol.json)。逐根公开状态指纹、完整行动、槽位与前缀、概率和原轨迹比较见 [roots.json.gz](roots.json.gz)，分席统计见 [coverage.json](coverage.json)。同目录执行 `python propensity.py` 可复算概率与导数；执行 `python audit.py all --shards /tmp/sapling-economy-shards` 可由注册的原始轨迹复算菜单。
