# 新经济动作菜单的单拍官方复核

在 2 张旧训练图、4 场真实原版轨迹的 48 个决策时点冻结候选。旧菜单共 92 个正概率整队命令，新菜单包含全部 92 个及 223 个新增命令。独立程序从开局重放真实前缀，在每根固定对手当拍真实命令，将所有 **315 个**不同的候选逐一交给官方规则推进一拍。现金账、工人与树的身份和位置、持货、地面碳量、编号计数都与单独的 FastCarbon 账核对，并确认原始 4 场一路重放到相同官方终分。

## 哪些经营决策真的变了

下表比较各正概率候选与该根默认整队命令。增加和减少的分母均为 48 根；同根可能同时存在两个方向的候选。末列先按新菜单给每个物理命令的实际概率求期望，再对全部 48 根等权平均。

| 当拍指标 | 旧菜单可改变的根数 | 新菜单可改变的根数 | 新菜单可增 / 可减 | 新菜单相对默认的平均变化 |
| --- | ---: | ---: | ---: | ---: |
| 招采集工（人） | 0 | 13 | 6 / 7 | −0.0071 |
| 招种树工（人） | 0 | 13 | 9 / 4 | +0.0082 |
| 实际新栽（棵） | 1 | 20 | 17 / 3 | +0.0076 |

两根相反的例子来自同一张图同一席。在 `621758460` 席 0 第 84 步，`worker-6` 从向右改为停留，会让当拍交仓少 102.55，分支概率 3.25%。第 252 步，`worker-60` 从停留改为向右，会让当拍交仓多 75.99，分支概率 5.53%。两条都是旧菜单没有的真实选择。夺树的五个变化全部是放弃本可当场夺取的一棵树。这 48 根均未出现能改变当拍抢货、己方带货人员死亡或对手当拍交仓的候选。

这些读数只适用于记录中的对手命令和紧接的一次官方转移。种树和招工会先花现金，携货也可能随后回款；当拍现金差不能作为终局收益标签。此次新增原版对局和终局动作标签均为零。
