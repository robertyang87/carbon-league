# 原版训练局的 275 个决策点能教给 Sapling 什么

在 6 张训练图、双席共 24 条已完成的轨迹中，Sapling 有 288 个计划抽样时刻。其中 275 个时刻确实提供了两条不同的合法整队命令。固定对手当时实际提交的指令，将两个选项各推进一拍。在这 275 个时刻中，**只有 2 次可以决定本方这一步种不种树，0 次可以改变本方夺树，0 次能从敌采集工身上抢到货**。7 次可以改变本方普通交仓，1 次可以救下载货工。[全部 550 次推进、逐笔现金及碰撞](one_step.json.gz)

| 本方当拍事件 | 至少一个选项出现的决策点 | 换选项后实际数量或金额发生变化的决策点 |
|---|---:|---:|
| 新栽树 | 24 | 2 |
| 夺取敌树 | 15 | 0 |
| 新招采集工 | 31 | 1 |
| 新招种植工 | 22 | 0 |
| 普通交仓入账 | 65 | 7 |
| 丢失本拍起始时已有货的采集工 | 1 | 1 |
| 本方存活采集工拿走敌工携货 | 0 | 0 |
| 我方树从敌工携货中收税 | 260 | 0 |
| 我方树从地块收碳 | 261 | 3 |

两条命令中有 183 个采集工指令、96 个种植工指令和 1 个基地指令不同，分别分布于 182、94、1 个根。一个根可能同时改变多个单位。种植工指令有一项为停步的只有 3 根。本方现金总变动在 12 根有差，其中包括支出差异；较多现金保留到下一拍，不等于该选择最终更赚。第 200 拍起的 93 个有选项时刻，本方新栽、夺树、招工、货物被敌方活采集工拿走及当拍地租的两臂差异全为零，普通交仓发生差异的有 2 根。改变移动方向仍可能影响以后多拍的布局、回款与夺树，此项研究只约束当拍的训练覆盖。

## 复核口径

- 使用训练清单 SHA-256 `63daa51e127aafea36401ebdce6400de60faa772d3929a1803ce768e121be5b4` 的全部 24 条轨迹和全部 13 个无二选一时刻的计数。每条历史轨迹从开局复演至原终局，7,176 次联合推进均核过行动前两席观察哈希、实际指令带与最终官方分数。无新增比赛。
- 每次分支由仓内官方二人裁判推进，同时由 FastCarbon 的现金写入点解释每笔支付与碰撞。逐分支核对全图碳、双方现金、人员位置/角色/载荷、树的归属/年龄/当拍吸收以及真实编号计数。根号、席位、对手原令、两条整队命令、实际选择、概率、逐工收款及树变动均保存在证据中。敌工刚被抢的货、本方工继续活着所携的起始货量都和当拍存款分开。
- 这里测的是既有训练分布与实际候选菜单的覆盖。对手此拍同时下令，其后对我方改变的战略反应及实际终局差需要另做分支续局实验。各备选当拍金额不能跨根相加充当新策略的整局增益。

复算时从本目录运行 `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python coverage.py`。运行只读取已归档的裁判与两侧历史指令。[复算代码](coverage.py)
