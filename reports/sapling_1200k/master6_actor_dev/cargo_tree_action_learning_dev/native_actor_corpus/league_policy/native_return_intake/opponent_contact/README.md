# 原版 Master3s2 下一步会不会踏入我方种植工的目的格

**数据与决策时点。** 原始数据是 24 场含 851c 实际决策、对原版 Master3s2 的完整归档训练局。四张训练图 460、461、464、465 共 16 场，35,796 个敌采集工行动；另两图 462、463 共 8 场、17,962 个行动。每图两个席位、每席两次独立自然对局。全部 7,176 次推进复演，双方 14,352 个公开观察指纹和 24 份官方终分逐一匹配。每个当时在场的敌采集工均提供一个五类动作标签，包括空载和当回合死亡者。模型输入先于当拍双方命令计算，碳量只在己席可见的格子上读取。[逐场清单](dataset.json) · [可复算数据](dataset.npz)

**它学了什么。** 139 维输入包含敌工货量、之前三次位移、近期位移和货量变化，以及每个可达方向相对于双方基地、工人、树和己席可见碳的几何关系。一个 32 隐元的 tanh 网络（4,645 个参数）输出敌工的五向概率。去掉历史的几何对照用同一种网络、初始化、批顺序和训练预算。两图合集的五向命中率由 57.32% 升到 **59.78%**，仅延续上一动作是 38.51%。训练后没有调阈值。[实际权重](full.npz) · [几何对照](geometry.npz) · [训练程序](train.py)

**动作风险的分母。** 对每名我方种植工每步分别列出原地和四邻格。留测有 30,315 个意向格，其中 7,873 个格子有敌采集工一步可达。若多名敌工都能打到该格，以各自五向概率估计“至少一人来”的概率，汇总时采用条件独立近似。标签取自原版当拍发给各敌工的实指令。未向该格行动的种植工同样有可核的敌方意图标签，同一拍的五个意向格彼此相关。可达的驻留机会有 2,931 份，2,685 次有敌人真的踏向此格；可达的四向移动有 4,942 份，674 次有敌人真的踏向此格。最终碰撞胜负、地租损失与撤退代价须另行核算。

**已经曝光的第 84 步。** 在另一条 462 席 0 实战轨迹上，仅利用行动前历史，模型给敌方空载 7 号从 130 向左冲到 129 的概率 **66.54%**，无历史对照为 **73.03%**。Sapling 的 6 号种植工若停在 129 会受到这一威胁，若上移到 114，当拍没有敌采集工可达。原版真实出令是向左。两臂实际结果为上移生还、原地被撞且没有种树。这个局面在本实验设计前已曝光，单列展示；两张留图的预测指标均没有使用这条新轨迹。几何对照在这个具体例子上押得更准。[先封存的概率](example_prediction.json) · [对原令及实际碰撞的核验](example_observed.json)

下一项可按冻结模型将“停留被踏入的概率”和各个可走邻格的对应概率作为网络输入，保留不加这些输入的父代对照。当前证据支持做该项试验。以 0.20 直接强制撤退会同时误报近千次，尚缺真实付款、整局收益及机会成本的对照依据。
