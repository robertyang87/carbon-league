# 敌方采集工行动预测是否能改变种树决策

8 条原版 Master3s2 整局的 96 个调度窗口中，带历史和去历史预测头在全部窗口选择的最高概率整队命令相同。若两边使用同一个均匀随机数自然抽样，按实际概率相加，96 个窗口预计共改变 **0.309 次**整队命令。现有档案中可独立核验这项改动的合格双臂终局为 **0 根**。本轮止于离线消融。[逐局、逐根结果](results.json)

## 两个策略怎样作决策

462、463 两张图各取双方换席及两趟自然采样。档案中的原始己方自然取样决定候选 A，冻结的 Sapling 851c 经济动作目录在同一张公开盘面寻找可比较的 B。它们须让同一个可种树或夺树的种树工在留守和撤出之间选择，其他单位仍按各自前缀重解码。两条完整命令须都有正的目录质量。每个头用同一公式抽签，给每条命令的目录质量乘上该工人目的格避开敌采集工的预测概率，然后对 A、B 归一。两个头的结构和训练轮数相同，只有敌工可见历史的使用不同。8 条轨迹均与这两个头的拟合地图隔离。抽签只在还原出的局面计算，本轮未改变实际历史轨迹。[试验口径](protocol.json) · [复算程序](compare.py)

## 碰撞、实际付款和交仓

每个机会固定原版考官记录中的这一次同时出令，分别推进 A、B 一拍，用官方引擎核对独立记账模拟器。86 个比较中，实际历史命令 A 下焦点工人死亡 3 次、付费种树或夺树 11 次。B 下单步反事实有 39 次死亡、30 次实际付费。两份命令在经济与存活上有明显取舍。将这些后果按两个策略的自然概率加权，带历史的头在 462 图合计少损失 0.0221 工、多 0.0322 次付款，在 463 图多损失 0.0091 工、少 0.0013 次付款；双方当拍普通交仓的概率加权差均为零。这些金额和次数只描述根的第一拍。[官方单步与现金事件](results.json)

两个反例说明预测的边界。462 图席 0 第一趟第 180 步，留守的 B 会被撞死，带历史的头把 B 的选择概率从 6.63% 降至 2.66%。463 图席 0 第二趟第 276 步，带历史的头把 B 从 7.51% 升至 12.23%，这步两种命令都会损失该工人。敌采集工是否进入目标格与工人是否最终存活是两种不同的监督标签。[逐根数据](results.json)

## 能从终局识别什么

8 条轨迹在 96 处注册窗口均无共同的完整前缀；各根只有实际 A 打到终局。另查事先曝光的 462 席 0 第 84 步真实双臂：完整头预测留守 B 的接触概率为 66.54%，去历史头为 73.03%；它们都首选撤出，完整头却把留守的选择概率从 2.32% 提到 2.86%。原版 7 号采集工这一拍确实撞死留守的 6 号种树工，两个分支都没有该工人的种树付款。虽然 B 整局比 A 多 984.70 分，这个动机样本既未通过预登记的实际经济事件检验，也与 8 条档案的任何根都不相同。它不能给出完整头的实战增益。本次未开新局、未增训参数、未更换生产包。[双臂收据](../../economy_proposals/terminal_intake/verify.json)
