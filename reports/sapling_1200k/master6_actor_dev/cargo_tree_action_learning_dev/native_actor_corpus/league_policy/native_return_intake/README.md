## 树权、招工与交仓的训练覆盖

旧采样器从工人槽的前两个合法网络动作中寻找分数接近的一对；基地不能直接成为被挑选的槽。复演 24 局的全部 275 个有效时点后，固定当时的原版敌令，只在 2 个时点能用两令改变本方当拍种树，7 个改变交仓，1 个能救下有货的工人。没有一个能改变本方当拍夺树或抢得敌货。改动较早的走位仍可能在后续产生影响。[命令分支与官方规则对账](menu_coverage/README.md)

新训练采样器按招工、种植、携货和普通行动生成候选，逐个重解码后续队友，记录每份完整物理命令的抽样概率。在两张旧训练图双方换席的同一批 48 个时点，原菜单给出 92 条命令，新菜单保留全部原令并另加 223 条。官方规则下，能改变当拍种树的时点从 1 增至 20，交仓从 2 增至 11，抢取敌货仍为 0。这些数据可用于检验训练能否接触相反的选择，不能为新动作沿用旧局的终局回报。[采样器与可训练概率](economy_proposals/README.md) · [315 组行动的独立结算](economy_proposals/verification/README.md)

已结算的两张训练图尾盘中，只有 461 图第 252 步的两个动作获得可用的同根标签。同一原版首令下，学生工人向左的终局分差比向右高 110.26；旧评分头却提高了向右的概率。另一根的原版首拍应答改变，不能把 −242.99 归到学生单次改令。后续比较已验证先让原版在共同观察上真实出令一次，从该次调用后的私有状态分别响应两臂。[两个真实终局对照](live_curriculum/terminal_pairs/README.md) · [共享原版首令的独立检验](live_curriculum/shared_enemy_root/README.md)

## 防守训练进展

第 84 步的一次实际对照中，敌方空载采集工此前连续十拍都踏入本方种植工刚刚让出的格子。本方种植工继续前进时存活，留在原格时先被撞掉，随后没有发生种树付款。两个整队命令还改变了另一名工人的路线，所以记录的 +984.70 条件终差只属于这两份完整指令各自的一次续弈。在第二张旧训练图上，四个窗口都未出现同一工人立即交仓与留货的对照，Sapling 自然打满 299 步，以 6921.60 比 7605.95 负于原版。这两张训练图未产出符合原计划的经济训练标签，768 参数研究评分头没有更新。[完整原版应答与终分](economy_proposals/terminal_intake/README.md) · [过去 3、5、10 步的双方状态](economy_proposals/terminal_intake/root_462_mechanism/README.md)

从 24 场真实对局重建了 53,758 个敌方采集工动作。在其中四图的 35,796 个动作上训练一个 4,645 参数的小网，任务是从可以看到的双方状态和历史位移预测下一拍。其余两张图的 17,962 个动作上，五向命中率由同架构、仅用当前局面的 57.32% 提升到 59.78%（两图等权）。对 7,873 个敌方一步可达的种植工备选落点，接触概率的 Brier 分数从 0.07794 降至 0.07667（同样按图等权）。重放上述第 84 步，含历史模型给出驻留格风险 66.54%，几何对照为 73.03%，两者对撤离格均给 0。这段新轨迹已因复盘曝光，未用于预测头拟合或留图计分。胜率归属仍以冻结的整局包为准。[训练权重、分图分数及误报漏报](opponent_contact/README.md)

对含历史的防守预测又做了行动层复核。冻结同一套种植工行动和采样方法，仅切换两份预测权重。八场留图轨迹的 96 个固定时点中，86 处有两份可比的完整命令，34 处概率变化。首选整队命令改变 0 次，共用事先固定的随机数时实际选择也改变 0 次。允许随机数在全区间取值，两版本在这 96 处预期会签发不同命令 0.309 次。本批没有同根、同首拍敌令且双方均有合格经济终局的配对，得不出部署胜率收益。预测头保留为训练工件。[逐图行动差异和原版反例](opponent_contact/policy_ablation/README.md)
