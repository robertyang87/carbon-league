## 学习目标与实际上场动作的差别

训练选中步长 0.10。在父网原来的二选一命令上算，新网的平均 KL 为 0.00292。把新网按公开入口重新解码，288 个训练时点有 67 个时点的至少一条原有物理命令变得不可选；其中 30 个时点失去了当局实际选的命令。因此若按整队实际行动分布定义，正向 KL 在这 67 处为无穷。按实际行动计算的平均总变差距离为 0.1364。[实际联合动作支持审计](physical_support.json)

在更早两张训练外开发图的四场父网轨迹上，每一拍向两份包输入相同的历史公开局面。在 1,148 个普通时点，**147 处默认整队命令改变**；在 48 个抽样时点，7 处默认命令改变，46 处分布改变。这些普通时点没有进入 275 个有符号动作的训练目标。这解释了为什么训练时的概率指标不足以预测对局表现；该复演只能测到动作差异。[四场 1,196 拍的同局面动作对照](replay_actions.json)

## 新图实战结果

新网在两张事前冻结的开发图换席对原版 **0 胜 0 平 4 负**，官方平均分差 **−1511.21**。同采样父代在同样地图与席位也为 **0 胜 0 平 4 负**，平均 **−1230.12**。新网席 0、席 1 的平均分差为 −1965.46、−1056.96；父代为 −1494.03、−966.21。按地图聚类，两图双席平均变化分别为 −560.72 和 −1.46，整体 −281.09。两个地图簇不足以定位总体效应。本轮不晋级，新包仅存为实验版本。

八场都打满 299 拍，无灭绝、超时或执行错误。新网四场最慢一步 107.06 毫秒，峰值内存 74,924,032 字节，最长整场 155.59 秒。对新网的原版共 1,194 步走到正搜索深度，另 2 步只有一个候选。新网场均少被夺货 50.23，但相对地面树租差恶化 434.92。此账目包含原版自然应对后的整局发展。[逐局官方比分与墙钟](validation/hosted/settlement.json) · [逐拍经济复盘](validation/hosted/economy.md)
