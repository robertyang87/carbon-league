# H24 训练权重用在哪些步

两张新开发图上，父包、全时段 H24 和固定窗口 H24 分别对原版 Master3s2 打双席。要回答的是，同一份神经网络更新限在第 128–159 步使用后，对原版的终局分差是否比父包和全时段包高。窗口取自前一轮的响应实验。发布包在四条历史轨迹的 1,196 条公开输入上验过。窗内 128 个动作中与父包不同的有 67 个，窗外 1,068 个与父包全部一致。每次新对局中，三臂都由公开入口自然应对对手。两席独立采样，换席控制地图和起点，不能锁定对手轨迹。[窗口与权重](../README.md)

父包为 `8da4b465`，全时段包为 `adc4d78e`，窗口包为 `4e3701f3`。程序从原始 FP32 检查点逐字节核验最后一个包的四个 U/V 张量。三种次序在四组里轮换，第一种出现两次。两张图的种子和初始碳图已查重，今后均归开发集。[赛程及包身份](protocol.json) · [地图核验](clearance.json)

启动条件是先取历史任务 `44594279145` 四份原始收据，验证上一组八局均有官方计入结果，且全时段 H24 在四局里至少一局没有取胜。本地对原始行动复演后，全时段包四局均负。手动工作流启动时会在取证作业中重新验证这个条件。每个地图和席位占用一台机器，三个包先后冷启，各自与原考官共享同一套主机硬件。双方分别受 1.5 核、512 MiB 和天梯逐局计时限制。共十二局，每局最多 1,500 秒，合计对局上限 5 机器小时，含准备和归档的工作流上限 408 runner 分钟。[主持及验收脚本](matrix.py)

两项主要结果分别取窗口减父包、窗口减全时段的官方终局分差。同图两席均报，再按图等权汇总。所有胜平负、犯时判负、档案缺失均须报告；无官方数值的场次保留该状态。另报考官完成深度、零深回退与双方逐步时钟。独立地图只有两张，可用于决定是否值得扩大复测。
