# 队友相撞后，货最后去了哪里

**撤销“把普遍避免队友碰撞作为下一条训练主线”的建议。** 在 58 场历史对局和四图 16 场原版开发对局中，双方纯队友碰撞里的全部正货量，均先转入同队存活采集工，随后实际进入原货主己方基地。没有一笔转到敌人、落地或被地块容量截断。74 场中也没有同一队已有两人到场、敌方又到场的混合碰撞。[场次和分类分母](summary.json) · [逐格、逐工与货款去向](collisions.json.gz)

## 哪项经济差额值得保留

当前候选相对原版的 t100–199 纯地面树租差，在 345、346、348、349 图分别为 −749.93、−133.28、−539.16、−735.73 分/局，均为同图双席平均。四图等权约 −539.53/局，量级远高于即期碰撞货损。每局 ≥200 的普通交仓笔数在四张图分别少 2、4、2、3 笔，不过全局普通交仓金额在两图多、两图少。树租是已兑现的经济缺口。现有材料仍缺跨图的同状态证据来说明哪次换位或买树，在原版对手重新决策后能增加终局净收入；这份审计没有据此开新试验。[各局双方现金原账](../../replicate_original/accounts/four_map_economy.json)

## 复算

根据双方当拍状态、实际招工付费和双方同时指令重建落点。每次推进后对模拟器的死亡工人表逐一核对 ID、阵营、载货和受益方，全部 7,383 名碰撞死亡工人均匹配。每场另核官方回执、原字节、终局分数。对每个纯同队或三人以上混合格，留存实际参与者 3/5/10 步前坐标、货和动作。对转入存活工人的每笔原货分别跟踪；这批局移动及冶炼费用为零。遇到可能抽税、地面混合或终局未交仓，就停止作整笔现金归属。同一货物跨碰撞重转时毛流量可能重复，不可当新增现金。依序运行 audit.py、summary.py 可重建结果。[追货与验证](audit.py) · [汇总](summary.py)
