# 让 Sapling 从自己可采取的动作学习避险与交仓

本试验比较两种同成本的行动后果监督，最终参数写回 Sapling 主网络。固定伙伴 PPO it50 占部署打分的 75%，被更新的 Sapling 占 25%。不加推理头或手写保护。训练父包是四图开发中取得过一胜的 8da4b465，原版考官在本项中只提供已经记录的同期指令。新的原版整场没有启动。[实验约定](contract.json) · [留图判据](evaluation_contract.json)

## 和以往工作的区别

旧的 loaded_cargo_defense 使用晚局几何阈值，在其三次实际高货量受害事件上均未触及该工人。既有对手货运头学习对手工人的回库概率；cargo/tree 行动头根据不同地图上相似机会估算实录动作的收益；另一个在飞的 onpolicy_native 使用整局终端回报。本次在同一个单位、同一份己方公开观察和同一个真实解码前缀上，依次尝试多个实际可发的方向，并保留每个方向的即时生存、保有载货、正入库与实际种植付款。前一步对手也会同时出令，各个方向共享该局原版考官已发生的当拍指令。[旧防守实验](../../loaded_cargo_defense_dev/README.md) · [先前现金动作训练](../README.md) · [四图风险诊断](../replicate_original/accounts/README.md)

## 数据与比较方法

来源限定为此前冻结的 29 个物理地图、58 盘有原版同场实令的历史回放，保留 Sapling 实际处的那个物理席。每张图两席归同一集合，沿用既有 19/4/6 训练、验证、测试拆分。诊断过的 345、346、348、349 和所有新图均不在这 29 图内。留图是相对本次实验的隔离，原始档案属于已曝光开发地图。按公开当拍条件区分载货受威胁、近库、安全停采与安全种树，每场每类最多 12 个决策，按局、时刻和单位身份的哈希选取，选取时不查将来的死活或收入。训练根中原版考官都相同，跨对手的推广未测。[对应原始回放和收据](../panel.json)

两个实验臂在每个根都计算全部合法候选。前缀中该工人之前的实际命令保持一致，把候选放入发布包两种返航分支，从该位置一路解码到最后一个单位或基地，通过实际分支选择才接纳。后续友军可以响应。给模拟器的己方联合命令来自该分支的真实重解码，敌方给同期原版实令。因此另一分支是同一物理状态和对手响应下的一步模拟，不等于该工人将来在原版动态响应下能活多久；其余本方工人也可能改令。训练使用的是**同一目标工人**的结算。回放每场沿真实双方动作推进并逐场核对官方终局现金。[数据生成](gather.py) · [根目录与地图映射](roots.json.gz)

两个动作条件预测器结构、初始化、根顺序、批量大小与梯度更新次数相同。它们分别预测下一步存活概率、保有货物加已经入库的金额、直接入库额。货款目标按当下货量加 40 归一化，输出截断于 1.5；安全停采允许计入这一拍新增的持货。对照只看该父包实际会选择方向的结果，联合训练同时学习同一状态多个合法方向的结果。训练图分三折，给主网络的教师排序一律来自没有见过本图的那折预测器。验证与测试只由训练图合训的预测器计算。在种植机会两臂均锚定父代原始分布，未给“当拍花钱买树”正奖。

把动作偏好蒸馏回原 Sapling 的 U.weight 和 U.bias。它们把已有的 96 维工人隐状态变为 32 维动作查询，再与每个方向不同的已有移动特征打分；无需在发布包里运行训练期预测器。两个臂均为相同 KL 目标、同一单次配方和规定轮数的最后一步。正常部署验证逐根调用出厂整队入口，重新联合解码，然后在相同已发生敌令下结算。另报 Sapling 自己在父包合法前缀上的首选，分别看网络本身和 75/25 整队组合起了什么作用。[训练](train.py) · [正常入口验收](evaluate.py)

## 检验结果

**多动作监督教会了 Sapling 自己避开一部分会死的选择，但没有让实际 75/25 组合在受威胁样本上多救活一个工人。** 预写的四条一步机制判据均通过；在实际组合里，风险与入库两项均允许与对照持平。没有据此启动新的原版整场。

共保留 2,614 个决策、13,061 个完整可发动作。训练 1,717 根、验证 365 根、测试 532 根。731 个候选导致后续友军或基地改令；13 个因完整守卫分支与前缀不符被拒，另有 1 个只能产生一个动作的根被排除。历史母带由较早策略打出；所考察的 2,615 个选根中，当前父包重新解码出的完整联合动作有 1,964 个与原带逐字相同。其余根的结果以当时物理状态、当前解码的本队命令和同一原版敌令进行一步模拟。真账核验与这一替代推演分别保留。两席 8 个输入检查中，修改不可见碳和额外伪造的敌令字段均未改变公开动作。[数据回执](dataset.json) · [输入核验](input_check.json)

六张测试图中的 144 个受威胁根共 720 个动作。预测下一步存活的 Brier 分数从同成本单动作对照的 0.14363 降至 0.07127，六张地图分别都有改善；只用训练集整体存活率的参考值是 0.12363。用相同合法前缀衡量 Sapling **自己的首选**，父网、单动作对照、全动作候选分别出现 3、8、0 次死亡，验证图为 3、4、0。例如 621497120 席 0 t260，载货 55.20 的工人按父网或对照的首选停留都会死，联合候选的首选向左能存活并保住全部载货。[拟合回执](fit.json) · [训练期预测器及导出复核](predictors.json)

候选对父代在测试席 0 改变了 8 个被追踪工人的命令、席 1 改变了 4 个，合计 12/532 根，另外 520 根的目标工人命令相同。受威胁类别仅一根改令，从向下改为向上，两臂均存活并保住 92.76 货物。验证集 96 个受威胁根三包也全部存活。近库新增 3 笔的效果与单动作对照相同。更需要保留的反例是测试图 621497120 席 0 t296，三个包都让载货 149.67 的 worker-53 向左；父代及联合候选另让 worker-32 向下，worker-53 死亡，单动作对照让 worker-32 停留，worker-53 存活。工人死亡的归因应保留到队友的联合出令。按原始实令，53 死亡时其 149.6745 全部转给己方 32，32 合计持有 243.2565，下一拍 t297 在己方基地全额交仓。这里按标记工人计算的持货差不能记作全队损失或敌方收益。历史 58 场中，本方 50 个纯同队碰撞格含 51 笔正货量死亡工人的转交，全部已追到己方现金；一个格可涉及数名工人。这项审计撤销了从此例推出普遍避碰训练的建议。[双边完整碰撞审计](collision_audit/README.md)[逐根真实出令与物理后果](held_rows.json.gz) · [队友命令反例](near_home_example.json) · [判据和分地图、分席结果](held.json)
