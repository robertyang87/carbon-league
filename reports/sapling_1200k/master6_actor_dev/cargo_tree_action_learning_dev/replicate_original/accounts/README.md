## 在当时的局面上，两张网各会选什么

在 4,784 个公开本方局面逐次调用当局发布包，恢复该刻真实的观测历史、前面单位已下的指令、合法性与实际采用的返航分支。全队输出逐步与动作带完全相同。共 52,451 个有效单位位置，两个网络在 16,966 个位置的首选不同，其中 16,249 个是工人位置。对于指定类别中的 3,481 个分歧，各自复演一次共同的当拍决策：只改一个本方工人命令，保留本方其他实令和原版 3s2 同拍全部实令。每个实录分支的现金、对应工人入库和付款逐项核回，并用下个公开状态核实存活和载货。对会新撞上队友目的地的比较予以剔除。重复遇到同一工人、同一局面属于多种类别均有可能。[全量分母、逐图与首个工人机会](network_differences.json)

**防守最值得先教。** 101 个当拍新增死亡中，96 个实际命令恰好也是 it50 的首选，余下 5 个来自混合策略的另一个选择。只保留每场每个工人第一处合格分歧，仍有 50 次换令死亡、16 次存活无变化、零次救活。在 345 席 0 的 t53，己方工人站在有 100 碳的 173 格、载货 57.48，敌工距一格。实令向右让它存活，20 步内真交仓 57.48；Sapling 首选停采，按同拍敌令立刻死亡。父代八盘中，换用其自身 Sapling 首选则是 5 次救活、13 次新增死亡，不能把所有版本或所有场景都归成一种行为。两个时期的轨迹也不同，单独看发生次数无法直接归因于那 485 个更新参数。[双向反例，含对手实令](network_examples.json)

**近库要区分立即收钱与值得再等一拍。** 候选 55 个少收例中，54 个原本执行 it50 首选。仅留每个工人第一处，仍是 47 次少收、1 次多收。348 席 0 的 t121 提供一个反例：Sapling 当拍进库确能收 114.33，实令停在安全地采集，其后真实记录交仓 128.97。同拍多收并不保证最终赚得更多。[近库反例](network_examples.json)

**继续采集和购买树木都需要远期标签。** Sapling 的另一选择在四图合计 1,267 个分歧当拍多持货或入库，70 个分歧反而更少；前者中，实际走原路线的 755 个根也在随后 20 步发生过普通交仓。安全种植的 34 个额外付款机会来自 19 个“单场×工人”，实际离开当前格子后，7 个根在四步内也买了树，其中 5 个为新建的安全富树且首次持有期内 25 步土壤收入过成本。345 席 0 t136，改成原地种植立刻花 70.97；它将来能否赚回，不能用这盘按原令向左后的地租作答。[原轨未来和单步替代样例](network_examples.json)

## 可以据此训练与检验什么

在与这四图物理隔离的历史局面上，给同一个公开工人状态的多个合法动作分别标注“下一拍是否死亡、真实到账多少、回合结束仍带多少货”，对手当拍实令仅作监督。先训练网络能在真实前缀上把救活并交仓的动作排在必死动作之前，覆盖双方都活、改令反而死、提前进库反而少赚的例子。再用独立续弈衡量未来 10–25 步的**实际普通回款或扣完树价的首次持有期土壤收入**；监控增加即时持货却降低终局现金的反例。这四图保留作动作核验，另用新图双席原版整局判定胜负。用截止本步的敌方位置和公开历史作模型输入，以未来对手实际命令作推理输入会泄漏答案。

每份 rank 文件有该局每一拍按真实前缀的两个首选、执行动作及其两网名次。每份 account_steps 文件有同一拍双方联合命令、双方后现金和每项现金变化。结果包含父代八局、候选八局及所有输局。复核时依次运行本目录的 review.py、policy_trace.py、summarize.py。复算第一批的相同环境现金工具和此前原始动作带从仓内读取。[复算现金](review.py) · [复算网络排名与单步](policy_trace.py) · [独立核对逐项结果](summarize.py)
