# 敌方载货工未来十步能兑现多少钱

模型可以提前标出最值得盯的运货工。在原版 Master3s2 两段实际反超前，按预计回款排序第一的，分别是已经带着 560 和 628 现金往回走的工人。模型低估了另外两名距离基地 6 格、最终也交出整车货的工人。对局中可以用这些预测决定先检查哪条回库路线。采取一个拦截动作会损失多少自己的产出、能阻止多少对方兑现，仍需同根双响应实验来检验。[两段逐工预测与实收](development_turns.json)

## 钱如何记到当时这名工人

场上双方工人的位置、载量和身份在双方 `players` 表中公开。隐藏地块碳量不进入预测。每个根只使用本席到当拍为止的观察，工人 ID 仅用于对齐三步、五步前的记录和提取事后标签，模型没有对手名字、种子、胜负和后续指令。

给根上已有的货物做金额标记，十步内同一工号正常向己方基地实际交付时清算。沿路的新采收或从其他工人夺得的货不会增加标记金额。树按比例抽税时标记货同比例减少。工人被消灭或将货送入敌方基地时失去该笔原货。货物混合后采用同比例归属约定。与此同时另记同一工号的实际回库总额，允许其大于初始载量。步限或真实提前灭绝后没有新的收入。所有 246 张地图均对齐逐步双方现金、工号、位置、工种和载量，逐工到账在结算阶段读取。每个根只贡献未来 1 至 10 步的数据，包括第十步。[标签与逐步检验](data.py) · [金额与信息边界回归](checks.py)
