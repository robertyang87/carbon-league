# Sapling 中盘种植工能学会选地、落树和夺树吗

**模型比较容易学到“到了好地方该停”，较难学到“上一步该往哪里走”。** 在五张留出图的原版 Master3s2 自席实令中，真正盈利的新树有 87 个当拍停留例，模型选中了 80 次；另有 87 个移动后下一拍由同工在落点种出盈利新树的例子，方向只选中 47 次。在真实原版配对续局里，模型确实改变了 3 次种植决策，所得分差分别为 **+443.44、−941.72、+34.20**。按图与按局面的平均差符号相反，当前证据不足以把该模型接入整场候选。[训练权重](primary.npz) · [按图行为](evaluation.json) · [逐根原版实战](native.json.gz)

## 给每一次命令贴什么标签

每个可选方向都读取自己当时能看到的邻格碳和已知比例、双方当前树龄及覆盖、种植和夺树报价、双方现金、队友和敌方不同工种的距离、自己上一次位置和该步能否被对方工人争夺等。候选不接收当拍敌令、其他己工当拍实令、私有碳图或赛后得分。政策头学习示范者的实际五选一动作；另一个头仅在真实选择的动作上学习四个结果。标签为首持盈利的新种、首持未盈利的新种、已夺得现成敌树、其余。训练目标的两项交叉熵相加。[可运行的动作评分器与输入字段](model.py)

对于停留，要求当拍在该格发生真实种树或夺树扣款。对于移动，要求属于同一 UID，真实下一拍在移动落点扣款。逐树核算从购入时开始，计入实际树吸收和树格碰撞现金，减去实际买价，截止于首次易主、枯死或正式终局。先移动再停下可能给同一购置贡献两条决策标签；金额按付款事件去重一次即可。反事实方向没有写成亏损标签，模型对这些方向的预测属于外推。

## 模型具体学到了什么

在同一模型上分别取原始行动概率最大的动作，或给行动概率乘上“一加该行动下新树首持盈利的估计概率”再选最大。该系数在看留图前固定。它只给新种加权，同时保留移动和夺树的原始政策概率。经济动作列按新权重真实计算。

| 留出示范 | 仅用原版训练的经济动作命中 | 混合训练的纯动作命中 | 混合训练的经济动作命中 | 盈利加权实际改令 |
|---|---:|---:|---:|---:|
| 原版 1,876 工步 | 985 | 1,013 | 1,003 | 86 |
| 天梯 996 工步 | 459 | 480 | 471 | 50 |

原版已停留的工步上，估计此次会种出首持盈利新树的按图等权 Brier 为 0.1029，用训练组同类到账率恒猜为 0.2645。对已移动工步判断下一拍会盈利种植，分别为 0.0470 和 0.0505。天梯留出对应的两组 Brier 为 0.0763 对 0.2437、0.0555 对 0.0603。后者正事件稀少，改善很小。在原版留图真实当拍夺树的 64 次中，模型均选停留；在择方向后下一拍夺树的 65 次中，62 次选中实际方向。账上同时保留未成交的停留、亏损的新树和仅路过的移动。[所有实际动作、购价、首持到账与预测](decisions.json.gz) · [地图、比赛胜负和选手分组](evaluation.json)

## 真改 Sapling 的命令能得多少分

复用 16 张旧地图里事先配对的原版自然应对分支，只查看第 100–199 步的 34 个根。27 根位于可新种的空地，另 7 根为活敌树，按新种约束沿用父令。裸模型可以提议五种动作；只有其唯一改令与已签收替代整队命令完全相同，才读取那个分支的官方终分。模型想走第三条路的局面全部退回父令。另一个外部补充根沿用父令，且其地形与已曝光败局附表重合，单列。[回放校验与对照代码](native.py) · [每根两臂的实收、存续及签收哈希](native.json.gz)

| 根 / 席 / 步 | 真实父令 → 选令 | 涉及树的首持净现金变化 | 官方终局分差变化 |
|---|---|---:|---:|
| 621473120 / 0 / 193 | UP → NONE | −21.15 → +26.48 | +443.44 |
| 621475121 / 0 / 165 | NONE → RIGHT | 0 → 0，两臂都未购置 | −941.72 |
| 621478120 / 0 / 164 | DOWN → NONE | −45.82 → −4.73 | +34.20 |

34 根中，父代和经济选令都选中了 6 笔新种、1 笔夺树。新种首持盈利笔数从 4 到 5。经济选令相对父代按 16 张图等权为 +9.16，按全部 34 根等权为 −13.65；所选终局胜负完全相同，都是 1 胜 33 负。混合网络的纯行为版本只改一次，按图等权为 −19.62。原先留出的四张续局图有 9 根，仅一次改令，按图 +4.27，九个所选分支全负。尚无使用此头跑满全场的成绩。尤其值得保留的是 t165 的反例：原地和改道都没买到树，整局却差了 941.72 分。单用购树能否盈利无法解释这类整队后果。
