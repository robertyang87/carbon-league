# 原版搜索究竟改了哪个单位，学生能否学会

**结论：本轮逐单位学生未过预登记门。** 在两张留图上，相对只学原始概率的对照，它都提高了对真实搜索改令的预测概率。但在图 327 上它落后于整队监督，两张图的三个新模型也都落后于训练前父代。保留训练权重和负例，本轮没有新开实战。

## 来源与恢复

原版每拍先用队内 RNG 按温度 1 抽样，再用独立的搜索随机源选择最终提交给环境的联合行动。训练图 800/801 的旧响应包有初始 RNG 整数，322–327 的响应包有完整 MT19937 状态。按预登记表固定各图两个旧续局分支，用原游戏动作重建两席状态及教师、学生各自的可见历史，然后恢复保存的温度采样器。每拍实际运行原版行动入口，仅在进入搜索时截取已抽样的全队命令和原始 logits，并从搜索返回已经归档的最终联令。下一拍看到的信念历史与原局一致。模拟重放到终局后逐席核对现金。

16 段共 2,794 拍。实际重建的队令是否不同与原搜索改令收据 2,794/2,794 一致，999 个未改拍的采样与执行字典完全相同，1,795 个改令拍共改了 2,636 个单位。没有发生学生前缀修补。投影单位动作时先把同拍前序单位推进到实际执行的动作；每个单位以己席行动前可见状态为输入。训练/评估按物理地形分开。相同局面起始的两个续局是配对分支，共用地图，不当两张独立图。

六张训练图 12 段，1,986 拍，1,900 个真实改令单位；两张留图（326、327）4 段，808 拍，736 个改令单位。三组使用相同 120.6 万参数父代、相同 384 个根及其顺序，均为 48 次更新。raw_control 在所有有效单位学原始分布；team 在实际曾改令的拍，给全队每个单位 50% 执行动作监督；unit 仅对实际被换令的单位混入 50%。各组均以所有有效单位作同一分母。最后一组收到的执行标签数量较少，实验同时反映了监督落点和有效监督总量的变化。
