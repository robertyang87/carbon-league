# 把原版搜索终选排到采样动作前面

本轮冻结六张训练图和两张留图。以 Sapling 父代为参照，直接学原版搜索改掉的单位在同一行动前局面中，最终动作相对于初始采样动作的偏好。两者须在已执行前缀下都合法。每个样本查原版 RNG 的逐单位签名。其余单位只保留父代行为分布。训练完全去掉原版 raw 教师 KL。640 个不同的根、945 个偏好实例，80 次更新。学生部署仍是 Sapling 正常单文件入口。

预登记门未过。每个包从第 0 拍起在相同公共轨迹中自主解码。以下分母是双方在各自自由解码前缀下均能合法选择原来两个动作的单位；326 为 328/328，327 为 405/406。每图包含一个历史根的两条配对续弈，两个地形分别来自两席。训练集和两张留图互不交叉；它们都属于研发数据。

| 图与席位 | 终选排在采样之前（父→学生） | 实际输出了终选（父→学生） | 未改单位命中（父→学生） | 全队命令发生变化 |
|---|---:|---:|---:|---:|

两侧未改单位退化均在容许范围内，但主要指标在两张图上都下降。存在个别判断变好的根，完整冻结样本仍然判负。本轮没有进入真实对手续弈或新图考试。源动作是原版搜索曾选择的动作，不带被换动作在相同状态下的真实终局反事实。数据也只覆盖八张物理图的特定续局，尚不能据此断定更广策略或模型容量的上限。
