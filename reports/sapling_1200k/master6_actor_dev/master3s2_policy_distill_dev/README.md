# 将 Master3s2 的原始策略先验蒸馏到 Sapling

同样的 256 次局面展示下，保留教师的整个动作分布，比只学其最高概率动作少了 0.00134 的留图 KL。两种学生实际自由解码时，在两张留图、24 个原版席位局面上仅有 2 个单位出令不同。软标签的增量很小。两者都学到了父代尚未拟合的教师偏好；仅凭这项实验无法推断能打赢完整搜索的 Master3s2。

| 独立测量 | 父代 | 硬标签对照 | 软标签学生 |
|---|---:|---:|---:|
| 10 张留图、给定同一单位前缀，图等权 KL，越低越好 | 0.87303 | 0.82156 | 0.82022 |
| 5 张原版留图、历史前缀、530 次可自由出令，图等权原版实令一致率 | 60.97% | 62.29% | 62.48% |
| 两张留图、学生自行解码全部单位，252 个单位与原版实令一致数 | 166 | 162 | 162 |
| 同一自由解码面板上，24 个局面整队与原版完全一致数 | 1 | 1 | 1 |

**教师与监督对象。** 直接加载仓内原版 Git blob，SHA-256 为 `65f268b2919c…`。每一步先取己席公开观察，推进原版 BeliefTracker，复用实际历史动作，再走原量化输入与风格的 _POLICY.forward。政策头输出的是每格在温度 1 下的空间动作概率。学生保持 Sapling 自有的输入、嵌入和解码顺序。对席 1 翻转左右后，按此前单位的已定动作、可支配现金和工人数上限，把教师概率投影到 Sapling 的合法集。输入不含全图碳真值。旧 it50 软标签是另一位教师，旧强教师提案和对手反应小网也没有给这版 Sapling 主网提供这份监督。

每个根各保留真实历史出令前缀和教师贪心前缀。原版的温度抽样、回家规则、占位仲裁和限时搜索都可能改变最终指令。5 张原版留图上，原始先验众数与提交的 530 个可选单位指令中有 465 个相同。训练集中有个采集工位置，原始分布给向右 96.22%，实战却向上。根本身具有相同信息，两种目标仍不同。[标签证据](source_evidence.json) · [逐值验证](smoke.json)

**训练与隔离。** 共 28 张物理地图，18 张训练、10 张留出。原版历史全场的两席都可作教师观察来源，其中一席是 Sapling 真身或混合策略曾到达的公开局面。另有真实的天梯前五席位，包含败局。每席从开局开始维护历史，固定抽第 0、12、38、63、89、115、143、170、199、228、261、298 步，共 528 个真实局面、1,056 条前缀记录。训练地图和留出地图来自先前已归档的开发对局及天梯回放，地图没有在此次两分组间重复。记录描述为历史已访问分布，受训学生没有控制这些轨迹。两臂都用相同的预先冻结初始化、批序、更新数和优化器，均未优化碳预测及价值头。[源清单和哈希](manifest.json) · [预注册](fit_protocol.json)

**实际部署形态。** Sapling 共 1,206,476 个参数，软学生 1,147,924 个参数数值发生变化。独立单文件候选约 1.67 MB，只载入自家学生权重，关搜索和手写守卫。20 个留出根的 574 个合法 logits 上，量化学生 NumPy 与 PyTorch 最大误差 0.00000227，未出现 argmax 分歧。真实公开入口在固定两图的原版席位上相对父代改变 15/24 个联合令、28/252 个单位令。自由解码与之前给定历史前缀的测量使用不同分母。[训练与数值验证](fit.json) · [逐令实据](entry.json.gz) · [学生权重](student.npz) · [独立部署包](student.py)

**复现。** 在安装项目依赖的环境，从本目录依次执行 `python builder.py smoke`、`python builder.py build`、`python source_evidence.py`、`python fit.py`、`python entry.py`。原版代码必须与源哈希相同。天梯回放读取本地缓存或其收录的 Git 归档。训练权重及对照文件均带 SHA-256。[训练器](fit.py) · [硬标签权重](control.npz)

### 原版实际应对

两张旧开发图各提前固定一处自然改令，两处都是第 271 步。只干预当步，随后两臂均继续使用冻结 Sapling 父代。Master3s2 自根步起在每一臂重新决策。每臂 28 次调用均实际完成搜索，原预算 0.58 秒、温度 1。两对的首个敌令恰好相同，此后 27 个敌方联合令都发生分叉。
