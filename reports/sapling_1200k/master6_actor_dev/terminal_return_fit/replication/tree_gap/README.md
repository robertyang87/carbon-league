## 失树当步是否还能救

候选四场合计被夺 40 次，由此开始的考官持有期实收 1,832.60。考官四场被夺 47 次，对应候选实收 1,887.33。候选被夺前的持有期平均 14.90 步，反向被夺前对手平均 18.72 步；只比较发生过被夺的产权段。候选 40 次失树里，对方付款当步、前一步，本方采集工距该树至多一格均为 **0/40**；提前三步才有 4/40，提前五步 2/40。这个分母只覆盖抢成功的事件，未覆盖因附近已有守卫而放弃的抢树。

一个实收金额最大的个案在 621461321 席 0。考官 t206 夺取 `player-0-tree-18`，候选最近采集工距树 5 格。接下来考官持有 46 个树步，实际入账 159.05。守这棵树需要更早布局；159.05 是对手真实收入，派己方工人回防能挽回多少、会放弃多少运货，需要同根主动应答才能知道。两组八场合计 2,392 次联合动作可逐步复核；候选四场和亲本四场各 1,196 次。[失树前 1、3、5 步的守方工人、载量及抢树工距离](spells.json.gz)

## 下一轮训练该比较哪些决策

候选在中盘每局有 260.5 个种植工决策，考官 157.0；站在付得起的可种格分别有 209.75 与 117.75 次，实际新种却是 7.50 与 12.25。把四局可种机会再按公开状态筛一次：四邻无树格当前地碳×吸收率×余下有效步数达到当刻报价，且最近敌采集工至少两格、敌种植工至少三格。这个条件能在发令前计算，未纳入未来地碳、在途敌货和对手应答。

| 段 | 本方合条件格 / 实种 | 考官合条件格 / 实种 |
|---|---:|---:|
| t0–99 | 100 / 19 | 178 / 34 |
| t100–199 | 115 / 21 | 153 / 37 |
| t200–298 | 54 / 12 | 107 / 35 |
| 四局合计 | 269 / 52 | 438 / 106 |

这区分了两项可训练的决策。**先验证去哪个格，再验证到了以后是否付款。** 候选落到上述位置的次数更少，到达后实种率也较低（19.3% 对 24.2%）；这些机会是同一工人的多次连续选择，不能直接把 269 个格都标“应种”。可在有两条真实合法前缀的种植工上比较“朝可兑现地块走一步”和“沿父代线路”，另在已到格时比较“付费停留”和“继续移动”。各自让双方看见新状态后续弈，用官方终局收益和实际净树息、运货牺牲共同判断。两图四席均负的观测还不能证明发力这项能提高胜率。[地产估值在更多天梯地图的回款与反例](../../../../all_top5/late_tree_tradeoff/README.md)
