# 中盘封回库路线的第一次原版对照

十场历史整局来自五张换席图。从 t100 到 t200 的 1,010 个己方联合决策中，24 个允许改变一个轻采集工的动作。按原有实际敌令重放首步，没有一次备选动作直接夺得目标货物。24 次中有 11 次的目标工在原轨迹十步内真的交货；同一工可能出现多次。这些是可干预的局面数，不能按 24 张独立地图推断。[覆盖与首步碰撞](coverage.json.gz) · [具体工号与十步回款](carrier_paths.json.gz)

两席各取登记地图上的首个合格局面，分别跑到原版终局。席 0 工人原地卡住编号 10 的格，货主的两个向库方向是格 26 和 10，考官实际去了格 221。货主在占路分支第八拍交 122.83，父代分支第十一拍交 166.92。席 1 卡格 79，但考官走的是另一个向库方向格 63；两臂都在第二拍交付全部 146.40。两席后四拍都未触发额外改令。[根步分岔与真实落点](paths.json)

既有十步回款预测器在这 24 个机会上的 Brier 分数为 0.194，距离基线为 0.220。预测概率至少 0.65 的六个历史机会都出现了交货，其中两次是同图同一工人的相邻回合。两个轻工同拍改令且封住所有向库出口、无己方冲突、无可达轻敌的筛选在这十场中为零。下一项试验改为在高回款概率局面维持已有的卡位，其机制和分支单列。[预测对账](signal.json) · [双出口筛查](double_exit.json)
