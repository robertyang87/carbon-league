# 天梯种植工停留、存活与实付

在 1,542 张独立天梯地图的真实对局中，种植工有 196,707 次在本可种树或夺树的位置停留。随后有 145,177 次实际成交，17,378 次当拍阵亡，34,152 次存活却没有付款。同拍死亡和同拍没付钱是两个不同的监督目标。对于想学会防守的策略，最有区分力的现象是，行动前资金够、敌工一步可达的 21,240 次停留里，仍有 4,964 次成功。需要根据局面估计风险，硬禁停会去掉这些成功案例。

## 人群与时间

这批资料来自前五报名策略参与的对局，包括对外比赛的两方物理席，一共 459,160 次环境联合推进。1,542 局均有数值终局分，有 1 场退出、257 步、终分为空的回放仍留在原始统计中，未混入此批。每个时点收录当时身处空地、已枯树格或活敌树格的全部种植工，排除基地与己方活树格。收录时不看现金、下一动作或下一帧。分母是 1,534,075 个工人决策，其中 1,337,368 次移动、196,707 次停留。训练者能区分选择怎样行动、行动后能否活下和是否扣款。

| 行动前现金 | 敌工距本格 | 停留次数 | 成交 | 阵亡未付 | 存活未付 |
|---|---|---:|---:|---:|---:|
| 够当前报价 | ≤1 | 21,240 | 4,964 | 16,141 | 135 |
| 够当前报价 | >1 或无敌工 | 138,774 | 135,215 | 9 | 3,550 |
| 不够当前报价 | ≤1 | 1,726 | 88 | 1,228 | 410 |
| 不够当前报价 | >1 或无敌工 | 34,967 | 4,910 | 0 | 30,057 |

旧选择账收了 1,359,485 行，限定“拍前付得起或拍后实际成交”。若用它训练拍前付款能力，会漏掉 **31,695 次**拍前现金不足、停留后未成交的反例，并且保留资金不足但随后成交的 4,998 次。新表保留两组。历史停留都是原始动作字典没有该工人键，按规则解码为停留。它标记已选择驻留的可操作经济机会，策略想不想付款无从观察。走开的工人也有实际生死标签；若它当时留下会有什么结局，单条回放没有给出。

## 使用与复核

- `labels_000.npz` 至 `labels_024.npz` 以 64 张地图为一批。每个列数组一维对齐，最后一批 6 张图。行键为 `(map_index,t,seat,worker_number)`，工人身份为 `player-{seat}-worker-{worker_number}`。局索引、两席名称、可核到的报名 ID、地图种子、225 格地形哈希、原始回放 SHA-256 与仓内提取位置在 [maps.json.gz](maps.json.gz)。报名 ID 为空表示该席未在源卡中绑定 ID。
- 行动前的输入白名单见 [schema.json](schema.json) 的 `availability.pre_action`。价格用双精度按当拍规则计算。碳量只读本席可见的相邻格，距离按环面最短路。身份列只用于关联、分组和拆分。动作 `0/1/2/3/4` 对应停留、上、右、下、左。动作编码表示最终出令；评估某候选动作时可传该候选。
- 所有下一帧标签均以 `y_` 开头。`y_paid` 要求该工停留、同一个 UID 存活且该目标格已被本方购得。`y_actual_price` 为对应扣款、未付为 0。`y_post_cell=-1` 表示下一帧工人已死。两边的下一帧命令和收入均不应进入推理输入。
- 历史地图划分直接继承 [树首持数据](../tree_tenure_dev/maps.json.gz)，训练 906、校准 164、独立地图 114、留出对手 358。按真实地图与登记对手报告。某格驻留的天梯成功率依赖天梯策略自选动作；要确认干预对 Sapling 的实际收益，还要比较同局面两种动作的后续实战。
- [source.py](source.py) 按原始回放内容寻址并逐帧重新提取，只有地图身份和全部分片一致才发布 [coverage.json](coverage.json)。每个分片的 SHA-256、行数、覆盖局及每局分母都在该文件中。[verify.py](verify.py) 独立读取旧官方逐工人付款账和新标签核对，并从原始回放抽图重建。默认运行 `python source.py` 然后 `python verify.py`。重复运行会核对封存文件，可加 `--help` 指定其他缓存路径。

最小读取示例：

```python
import gzip
import json
from pathlib import Path
import numpy as np

here = Path(__file__).resolve().parent
with gzip.open(here / "maps.json.gz", "rt") as f:
    maps = json.load(f)["maps"]
with np.load(here / "labels_000.npz", allow_pickle=False) as rows:
    near = np.minimum(rows["enemy_collector_dist"], rows["enemy_planter_dist"]) <= 1
    stopped = rows["action"] == 0
    deaths = stopped & near & (rows["y_survived"] == 0)
    i = np.flatnonzero(deaths)[0]
    print(maps[int(rows["map_index"][i])]["id"], rows["t"][i], rows["seat"][i])
```
