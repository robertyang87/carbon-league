# 在 Sapling 的共享骨干中学习经济后果

与纯行为克隆对照共用同一份 1,206,476 参数初始网络、240 张训练地图、7,640 个起点、随机排列、批大小 16、478 个更新及现有的动作模仿与 KL 损失。差异只有一个训练目标：对决策后最多 25 步的经济结果做五维回归。上下文取自动作解码器已经使用的共享网络表示。额外线性头仅在训练时存在，部署时仍运行与对照相同的原始策略入口。两条线都保留单网输出与原来的 75% 冻结专家＋25% Sapling 组合输出。[试验注册](protocol.json) · [执行代码](fit.py) · [纯行为克隆对照](../broader_elite_backbone_dev/protocol.json)

五个标签依次为本席相对对手现金差的变化、双方树实际收到的钱、双方基地正常收取的采集工货款。树收益包含地面与树税，基地入库排除碰撞散落等其他入账。每局从记录的权威地形和开局状态回放，按引擎实际记账位置归因，83,190 个过渡逐步核验双方官方现金。临近终局只累加剩余步数，最短 1 步。以训练地图、席位、拍号和回放哈希连接；未来收益与真值地图仅在离线制标签一侧使用，零占位值／碳标签仍由原策略加载器剔除。[标签程序](labels.py) · [目标数组](labels_25.npz) · [回放校验](economic_labels.json) · [分集分布](label_diagnostics.json)

经济差按 200、四类收入按 100 缩放后作 asinh，五头平均 SmoothL1 乘 0.15 加到原动作目标。核验首批经济损失能单独反传至残差卷积权重。留出 20 张验证图、20 张未见测试图，另外沿用主线已冻结的 14 张完全未见对手注册名地图，均固定正常入口和观察窗口。每一对策略在自己的完整合法前缀上发令，再和实录执行动作比较。现金预测另与只用训练集拟合的分阶段中位数比较。[测量程序](evaluate.py) · [真实续弈准入与已曝光地图](native_conditions.json)

训练前后的数据质检暴露出一次实现错误。初版按上游事件名 `base_deposit` 累加，实际记账钩子已经将自己的工人正常入库命名为 `own_delivery`，导致两列恒为零。无效试跑已中止，未产出检查点；更正后从同一初始权重重训。7,640 个训练根中，五列非零根数为 7,640、7,541、7,203、7,558、7,334，6,981 个根有完整 25 步窗口。另取五名示范选手各自两席，从官方回放的现金和逐树收益重算现金差及双方树款，与标签的逐项最大绝对差均低于 0.001 分。入库标签只计工人向自己的基地送碳，敌工误送另记。[分布与独立来源复核](label_diagnostics.json)
