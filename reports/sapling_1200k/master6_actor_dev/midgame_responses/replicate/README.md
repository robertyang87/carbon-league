## 夺树，遇敌时停留还是撤离

按原行动席计，首轮 ΔU -0.030395，追加 ΔU +0.012969，两条流均值 -0.008713。

两条流的第一步都一样：原令保住工人；改令停留时它立刻阵亡。

首轮的目标树实收（己方／敌方）：原令 73.16／49.92，改令 0.00／123.08。两案终局分差的差额里，正常交付变化 +393.62，树息变化 -1,240.36；支出、对敌交付及其余资金项见逐笔账。

追加的目标树实收（己方／敌方）：原令 65.27／57.81，改令 0.00／114.15。两案终局分差的差额里，正常交付变化 +155.09，树息变化 -50.25；支出、对敌交付及其余资金项见逐笔账。

## 守树，采集工停留还是离开

按原行动席计，首轮 ΔU -0.010640，追加 ΔU +0.007654，两条流均值 -0.001493。

两条流两种动作下，焦点工人均活过第一步，差别从站位和此后响应产生。

首轮的目标树实收（己方／敌方）：原令 111.45／0.00，改令 102.18／0.00。两案终局分差的差额里，正常交付变化 -215.06，树息变化 -111.98；支出、对敌交付及其余资金项见逐笔账。

追加的目标树实收（己方／敌方）：原令 68.90／32.91，改令 88.39／0.00。两案终局分差的差额里，正常交付变化 +48.18，树息变化 -47.67；支出、对敌交付及其余资金项见逐笔账。

两个根中有 2 个的终局分差方向随新流翻转。夺树根两条流里都能复现停留当步损失种树工，当步结果适合作为局部辅助标签。守树根首轮两案皆守至树末，新流中原令在 t258 丢树，敌方随后实收 32.91；停守的树保有至 t280。学习终局收益时应一并保留这些分歧。

训练时保留每根的两对标签和采样阶段，同一根在训练／验证划分中只出现一次。每条流描述一次真实响应，对某一动作的平均优势或所有中盘局面的强弱，只靠这两图估不准。考官为原版温度 1、全搜索，墙钟预算可能使实际搜索轨迹发生变化。
