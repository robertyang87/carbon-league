# 中盘争树的两条真实响应训练标签

选根范围是三张已用于研究的开发地图，每局由 75% it50／25% Sapling V3 双网亲本对完整原版 Master3s2。读取自己当时可见的单位、树、现金和准备执行的友方命令，从 t170–245 选出可以原地争树或离开的一名工人。共有 105 次可夺树、41 次可守树，1,447 对候选满足两根异图、异席。样本只用于训练研究；所有结果按原先冻结的选根保留。[筛选规则](protocol.json) · [分母、选根和原局身份](roots.json)

四条续弈全部到官方第 299 步，两张图各保留一对终局标签。席 1 的种树工离开后，己方在第 222 步重新得到目标树，实收 73.16；当场停留会阵亡，这棵树余下 123.08 收入全给了对方，最终分差比离开低 273.94。席 0 的另一个局面里，采集工即时离开或停守，己方都把树守到第 280 步最后一次结息。停守没有多保一回合，全队后来相对敌方交付少 215.06，终局分差比离开低 154.89。两种动作的所有后续差额都是单流条件结果。[分差与现金来源](results.md) · [公开局面与成对目标](action_pair_labels.json)

树号中的玩家号指创建者，决策时的归属以当时双方树册为准。单步重放在选根冻结后才读取同一真实对手根命令。两臂之后均通过各自公开观察重新调用双网策略和原版考官，直到官方终止。一次流内共享起始温度采样状态与初始搜索成本；墙钟限时与双方分支历史会改变后续计算。每根只有一对结果，无法据此估计动作的平均收益或胜率。[两根的决策前输入](roots.json) · [根步碰撞与资金核验](root_checks.json)

运行时依次执行两个根各自的两条分支。每个分支独立进程，保留两侧实际动作及搜索计数，可在同一固定核心从检查点恢复。完成后以官方解释器逐步复演，按现金账拆出双方回库、树息、招工和种夺树等各项对终局分差的贡献，并另外跟踪目标树的每步所有者和收入。ROOT 观察、全程动作、终局标签各自单列。

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python study.py register
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python check_root.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 taskset -c 3 python -u study.py run
```
