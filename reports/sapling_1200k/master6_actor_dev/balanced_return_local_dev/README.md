# 两个已训练时点上的采集工头回归

上一轮把 15 个条件系数折叠进所有工人的共享输出头。在两张新图对冻结 it50 的完整换席对局中，父代与全局版都取得 2 胜 2 负。全局版在两张图各多交货 436.65、493.05，同时各少收树息 1,100.11、622.18；最早的实际改令发生在 t13、t66。本轮用同一批暴露过的地图定位改令来源，两图都已参与提出假设。这次回归只检验工程和作用范围。[上一轮独立开发](../balanced_return_dev/README.md)

### 出令条件

训练实际给出终局行动回报的只有 t205 和 t271。局部版仅在这两拍选择至多一位采集工。其货量、距本库的环面距离须落在同一时点、同一轻重组（40 为界）、相同可见风险的训练范围；风险指更轻敌采在下一拍可以到当前格。训练范围只读 32 个采集根的公开三列特征；部分格子的区间由一两个样本决定，证据密度很低。每拍按父代返航校正解码的 T1 合法动作熵确定焦点，前缀内须有至少两个合法动作。训练时可由图席配额指定重载或轻载，实际部署不传图号和来源席配额。[冻结口径与各层实际范围](protocol.json)

候选以父代双网完整包为底，取上轮已训 Sapling 工人头的 FP32 矩阵和偏置。焦点同时在基础解码及返航校正解码使用该头，伙伴仍占 75%；之后的每一工位及基地依实际已选动作更新前缀，按父代参数重新推理，最后沿用原包的整队安全检查。某个采集工动作改变后，下游种植工或基地仍可能因占位预算不同而改令。候选绝不把从另一前缀解出的命令拼回当前队伍。[重建程序](build.py) · [单文件包](candidate.py) · [发布与权重身份](release.json)

冻结登记后重读旧父代和全局版的真实动作带。全局头在父代轨迹与全局版轨迹上分别产生 60 和 68 个整队差异，其中 42 和 44 个出现在 t205 之前。两个精确训练时点上的已观察分歧均为 0；与两个时点相距 ≤5 步的分歧分别为 2 和 4。这说明过去的平均分变化主要由其他时点上的真实行为差异累积而来；这些重复使用的历史动作不构成局部版的新比赛证据。[每个真实分歧的步号](previous_timing.json)

### 真实前缀与邻拍

对 8 张训练图的 32 个原决策点独立复演，32/32 个根均有符合条件的焦点。按公开熵选择的焦点有 22 个与训练时的配额选择相同。真包中，基础与返航校正两条解码的全部 64 组焦点评分均被新头改变，实际贪心命令改变 0/32。位置、合法性、前置动作与前缀特征共逐槽核验 3,022 次；这个数字含邻拍与择焦点的真实调用。[独立机制验证](mechanism.json)

在前两张训练图另测锚点前后各五拍，两份来源行动带覆盖两个物理席位。80/80 拍在实际部署均未启用新头，向环境发出的完整命令与父代逐个相同。若在这些邻拍临时使用最近锚点的资格范围，80 拍均有可选采集工，只有 1 拍会改变整队贪心命令。该动作的终局后果没有测量。

分析采集工已获资格但命令未变的原因：在 32 个实际训练锚，返航校正后首选与次选的父代中位 logit 差为 0.623。新头对同一工人所有合法动作造成的相对分数变化幅度中位数只有 0.078。15/32 根首选优势缩小，仍全部保持首选。基础解码最接近翻盘的根更新后只差 0.0030，返航校正解码最小差距为 0.0491。训练能够移动采样概率，而本实验考核的是公开包的贪心出令；两者必须分开审计。[64 路实际合法动作分差](decision_gaps.json)

为验证测量工具确实能抓到动作改变，另用同一邻拍做可反证的阳性对照。图 621471121 席 1 t206，保留实际剩余步、真实观察与权重，只在测试进程中把资格判定映射到 t205。工号 12 从 RIGHT 改为 LEFT，之后第二个槽的返航校正解码也确实读到不同的前缀。恢复原门后该工立即回到原先的 RIGHT。此测试没有推进环境，无法给出这次转向的经济收益。[差异命令与下游槽位](positive_control.json)
