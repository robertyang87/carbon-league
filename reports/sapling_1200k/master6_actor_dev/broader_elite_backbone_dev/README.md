# Sapling 全骨干精英动作训练

这组实验训练 1,206,476 参数的 Sapling，从既有 Master6 actor 检查点开始，对残差骨干、位置和单位编码、解码器与策略头一起求梯度。每张图的各步段等权，步内同时考虑采集工、种树工和基地。训练中保留一项父网络合法动作分布的前向 KL。唯一候选是一个遍历周期的最后一次更新。

训练有 240 张新地图、7,640 个实际局面。Master5s 提供 52 张，Master6 提供 44 张，it720、M9XJ、Fable 各提供 48 张。每个玩家在两席平衡，演示方 222 胜、18 负。共覆盖 79 个对手注册名，49 张地图上的 27 个注册名在列明的祖先训练表中首次出现。按记录的合法动作前缀，采集工有 52,653 次可选决策、种树工有 15,689 次、基地有 3,443 次。四段各有 1,920、1,920、1,904、1,896 个局面。三张短局按实际结束时间保留。

训练与两个评估面板按比赛 ID、种子与初盘地形 SHA-256 去重。验证与留出面板各 20 张，玩家与席位均衡。私有碳图仅用于存档核验、数据构建器的通用占位产物；策略特征按行动席实际可见历史生成，加载器删除价值、隐藏碳图辅助目标并填零。所有 8,920 个注册样本都能将下一帧命令逐字回译至上一帧决策的合法前缀。分片、原始回放、所属比赛和源码摘要均可从冻结文件追溯。[训练登记](protocol.json) · [比赛和排除表](panel.json) · [分片收据](shards.json) · [训练与评估代码签章](recipe.json)

部署保留两个入口。一件只含当前 int8 Sapling。另一件沿用原包 75% Echo4、25% Sapling 的 logits 配比和已冻结的返航处理，仅替换 Sapling 张量。这能分别测到网络自身的动作变化和它在组合包中的实际作用。价值和辅助头权重被冻结，共享表征发生变化，新的价值估计需要另行验证。两个包在预定回放时点各依照自身选择的合法前缀发出命令。其余时点推进同一来源逐帧可见的历史。动作一致率的统计单位、分母和聚合方式见登记。[主指标](primary_metric.json) · [独立网络检查](standalone_protocol.json)

## 复建

固定数据来自仓内列明的 29 组 Top5 数据清单与逐图地形核验记录。原始回放缓存按比赛 ID 存放在 `/workspace/sapling-all-top5-20261119/replays/<id>.json.gz`。复建时保留冻结的 panel、protocol、recipe 与原始回放，使用一次性工作副本和一个 CPU 线程，设置 `OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1`。所有脚本均在本目录运行。

1. 从原始官方回放生成分片时运行 `python freeze_data.py build`。输出分片位于 `/workspace/sapling-broader-elite-v1-shards`，先将随工作副本带来的旧生成收据单独保管。重新生成的配对/数据哈希须与归档一致。
2. `python train.py train` 读取权重和已验证的分片。冻结的种子为 7924059，batch 为 16，AdamW 学习率为 0.00009，梯度范数上限为 1。输出 `candidate.npz`、`candidate.py`、`standalone.py`、`fit.json`、`package.json`。在本次运行的 CPU3 上仅启用一个 Torch 线程，训练期间沿用初始网络的归一化运行统计。
3. `python serve.py` 验组合包，`python standalone_serving.py evaluate` 验纯网络，`python primary.py` 汇总同图配对的指标。每图可决策的时刻从 0、20、50、80、110、140、170、200、230、260、285、297 中取。输出同时包含双方每个单位的真实命令和各自前缀下的合法选项。
4. 真人工件对应的 Master3s2 响应续弈另见子目录 `native_gate`、`pure_native_gate`。整局强度、存活和胜率应由对手会作出反应的比赛检验。

`freeze_data.py freeze`、`train.py freeze` 和 `standalone_serving.py freeze` 分别用于重新生成登记文件。预注册文件和已完成产物使用创建时独占写入，保护已归档结果。`standalone_protocol_before_tempfix.json` 保留了跑实验前首次评估程序签章，现行签章将父网络的辅助量化文件写到临时目录。两版样本与统计相同。

## 实际结果

一个 CPU 核用 489.6 秒完成 478 次更新。1,205,800 个可训练参数中，1,205,798 个数值改变，937,440 个残差块参数中有 937,438 个改变。FP32 导出与载回的每一个参数逐值相等；量化后纯网络文件 1,665,697 字节，组合包 6,075,519 字节。[拟合与权重变化](fit.json) · [两个包与权重指纹](package.json)

|---|---|---:|---:|---:|---:|

纯网络在留出图上，采集工、种树工、基地三个独立分母的一致率分别增加 1.783、4.907、2.786 个百分点，15 张图上升、3 张下降、2 张持平。75/25 组合包在独立留出图上的一致率近乎持平。这里的结论只覆盖示范轨迹上的实际发令，局面分布由精英双方产生。对原版 Master3s2 重新交手时，双方会形成不同的局面和终局经济结果。[主统计](primary.json) · [纯网络逐局分解](standalone_serving.json) · [组合逐局分解](serving.json)
