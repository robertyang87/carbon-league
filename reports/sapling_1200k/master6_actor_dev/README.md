## 哪些动作学会了，哪些仍在丢分

实际更新了 40 个张量中 323,636 个参数值，模型总量保持 1,206,476。训练使用 218 张地图、51 个对手、6,896 个决策局面中 64,726 个可选动作。18 张预留图覆盖 17 个外部对手，全部是 Master6 胜局。量化单网在这 18 张图上逐图都提高了动作一致率，整体从 51.67% 提高到 54.80%。示范遵从率受对局来源和局面覆盖影响。[训练记录与权重](ACTOR_TRAINING.md) · [数据范围与复算](DATA.md)

## 面对敌种树工时，留下和离开值多少钱

另取两张已经曝光的开发图，各自只改一条我方命令，两方从下一步起根据新局面重新出手。第一张图 t211，我方种树工站在敌树上，敌种树工距一格。原动作右移后工人存活，己方在 t222 夺回此树。改为停留夺树，自己的工人当场死亡，此树剩余 123.08 全进敌账，终局分差比右移低 273.94。第二张图 t239，我方采集工站在己树上，敌种树工也只有一格。原动作离开后，己方仍持有此树直到最后一次结息。让工人留下，持有时间相同，全队相对交付却少 215.06，终局分差低 154.89。每个局面各有一组配对随机流和两个真实终局，适合保留为训练反例，重复抽样与跨图推广另计。[双边实际行动和终局标签](midgame_responses/action_pair_labels.json) · [双方现金与焦点树的收支](midgame_responses/results.md)
