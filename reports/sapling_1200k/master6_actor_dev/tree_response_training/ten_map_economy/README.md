同一棵树被夺走时结束上一段持有，再为新所有者另起一段。净收入只计此次持有产生的树息、树上碰撞现金以及实付，不含对手可能因此损失的未来树息、工人移动成本和这笔钱的其他用途。

20 局中，从某一步起现金持续落后直至终局，该步的中位数为 186。只看终盘会错过第 51–250 步中我方少种的 200 棵树。两边这段夺树次数几乎相同；末段我方反而多种 47 棵。值得检验的改动，是在中段还有时间回本、地点安全且买得起时提早付款，并在尾段评估剩余收益。逐局真实持有收益不能直接给未选行动贴上收益标签。[逐步核账](census.py) · [逐树核账](tenures.py)
