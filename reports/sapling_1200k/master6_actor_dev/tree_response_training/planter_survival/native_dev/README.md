# 公开信息选撤离方向的 Sapling 种树工

候选保留 v1 的双网络推理。只有 v1 要停留、当下可付费、替代移动合法且没有友军冲突时，才比较这名种树工停留与移动的一步阵亡概率。停留风险至少 0.20，且改走能降低至少 0.05，才改令。每席每拍最多改一名工人，其他命令直接取自 v1。[冻结方案](protocol.json) · [权重及制品身份](release_manifest.json)

此前 03 源图的 12 次救工使用了离线地图种子来抽取一个合法方向。真实原版考场向 agent 传入的 `randomSeed` 为空。此候选按物理席位、步、公开工号及合法命令的哈希选方向。风险头与阈值均沿用冻结值。03 再验公开选择的一致性，04 两张新源图另验真实命令、救回和反伤。只有四张源图每张均净救工、且零新增当拍死亡，才允许进行八局整场开发对照。[离线结果](../veto_replication/README.md) · [选择与标签复验](parity.py)

开发图为 621481220、621481221。共享工位由训练端签发，父代、候选顺序执行，各在两张图交换席位。对手使用未改的 Master3s2 原版搜索与温度。每局保存命令、搜索调用、墙钟、官方双方终分和现金账；在候选实际轨迹上逐步重跑父代与候选，验证每笔改令。观察两图的方向差异与全部输赢，判据只决定是否值得继续验证。[地图核验](clearance.json) · [整场驱动](run.py)

在已安装本库原版游戏依赖的 Python 环境中，于本目录执行 `python run.py status` 查看离线复验、签发状态和两臂已完成局数。执行 `python run.py supervise` 会接续已有片段并在必要时等待训练考位；多个进程以文件锁互斥。此目录保存开发对照，独立正式考卷另行预留。
