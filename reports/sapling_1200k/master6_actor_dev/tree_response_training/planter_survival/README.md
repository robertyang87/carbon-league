## 标签与复现

每拍从真实前缀恢复完整资源和按创建者存储的树与工人编号，事实与每个替代联合动作均分别由官方 Board.next() 和 FastCarbon.step() 推进。逐拍核对两席全部资产、树账和碳图。本人停留、存活、形成新树或夺得敌树且出现同工号同格的扣款，才记实付。已到寿命的树可枯死后重种。敌方当拍命令和完整碳图仅用于标签。预测输入为本席可见局面、己方拟定命令和此前最多三步的可见运动。

选根沿用真实前缀，占位冲突的停留或替代移动排除。指定种植工以外的队友保留原命令。每局排除分母、逐根风险、实付、反向例由分片、权重和指标文件重建。复现顺序为 extract.py train、fit.py、extract.py validation、report.py。model.death_risk(weights, public_obs, history, own_orders, uid, cmd) 可直接调用，无引擎或科学计算库依赖。实际策略调用耗时尚未测量。
