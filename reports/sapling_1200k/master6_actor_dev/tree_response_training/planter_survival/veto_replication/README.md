原 v1 命令和现金前缀来自归档源局。替代移动由冻结的采样器选取；删去敌方同拍命令、结局及超出合法性所需的其余字段，四局所有采样记录仍选出相同移动。到标签计算时，双方其余命令沿用该拍已提交指令；官方 Board 与 FastCarbon 必须对每个分支的工人、树及碳结果逐项一致。同一席同一回合有多个触发时，只对公开 UID 排序第一人计改令。逐工身份、物理命令、双方死亡以及本应归属该工人的支出保存在证据中。

这些数字覆盖既有 v1 轨迹上的单步干预。目标是核实能否救回当拍的工人；转移后接下来的双方行动、树的未来收入、整局比分均未测量。所列金额是没有发生的购树支出。地图数只有两张，保留每图方向，不据此估计胜率或签发新参赛包。
