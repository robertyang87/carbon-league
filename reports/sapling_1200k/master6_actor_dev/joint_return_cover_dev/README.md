# 两个方向一起封，能否堵住重货的最短返程

沿用 18 条原版完整对局，并补入在 621758330 的候选双席，共 20 场。敌采集工携货至少 100、距己库 2–5 格且有两个以上最短下一格时，用本方实际整队命令作基线，检查能否同时派出不同轻工，把所有最短下一格全部占住。保护友军目的格、招工格和已决定的正额入库，己方采集工不超过 30 载货且必须比目标轻。若方案存在，固定原本同时出手的真实敌令，复播双方当拍完整行动。

20 场共 5 个时点可改变出令做到覆盖全部最短下一格。在这 5 处，原版敌工在原轨迹上全部自行选择别的去向，新增当拍截获为零。已记录每个工号、双方去向、替代的联合动作和结算。它只排除这 5 处利用既定路线当拍截货，对手在新局面是否被迫多绕路、以及之后现金差如何，仍未实测。未用这一规则开新图。[实现与逐局枚举](pairs.py) · [完整来源](sources.json) · [逐根动作与实收](positions.json.gz)
