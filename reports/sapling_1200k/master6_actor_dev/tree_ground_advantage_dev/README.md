# 中盘在什么地块多种一棵树

在原版对手的 18 场历史分解里，中盘己方每张图平均只新种 7.9 棵，对手 12.4 棵。己方同期夺树更多（5.5 对 3.9）。先测试在裸地上提前新种；以行动前估计的**第一段连续持有期从地面吸到的现金**单独给地块定价。[历史双方树收入分解](../elite_role_mix_dev/conditional/fresh_paired_dev/historical_tree_income.json)

每个席位分别保存自己实际看到过的地块碳量。采集工只看脚下，种树工只看四邻；从未见过的地块用固定初始估计，过时记录按当前邻树吸收或空地再生近似推进。地块特征包括预计剩余寿命、可吸收的邻格数、记住的碳、被己树或敌树同时覆盖的邻格碳、附近采集工和种树工。模型只在实际付费新种的树上训练；逐树用模拟器现金账回放，从吸收款扣除敌方工人被抽的货，一旦易主即停止记账。**一棵树吸到的地块碳并不等于全队因此多吸的碳**，新旧树可能重复竞争同一片地。地块总价与全队增量分开核验。[特征与决策](decision.py) · [付款和持有期标签](purchases.json.gz)

**行动规则**在 t100–199 每局最多改变一次原令。父网原本要将种植工从一块裸地移向另一块裸地，当前位置不受敌工当拍威胁、没有友方落位冲突，预留其他我方招工和种夺树的资金后仍买得起，才比较两个位置。只有“当前位置预计地块款 − 价格”大于零，且高于“原定下一格预计地块款 − 价格”的正部时才停下来。下一格比较按今天的价格估算，实际价格可以在下一拍变化。包保留双网父策略的完整推理，只覆盖已站在可种位置时这一个停移决定。[可复现打包](build.py) · [完整单文件候选](candidate.py)

- **已打过的真实两臂**。在与训练地图无交叉的 18 张已曝光图、66 个归档的相同根双方真实后续中，逐一替换焦点工的停或移。8 个根符合地形、资金和安全条件，1 个从移动改成停。当时是 621473120 席 0 的 t193；在 130 格停种花 82.95，地块收 109.43，净 +26.48；走到 115 格后次拍另种花 70.97，地块收 48.29，净 −22.68。两条真正续局终局分差分别为 −768.98、−1212.42，地块净收改善 49.17，双方全队地块收入差改善 416.34，官方分差改善 443.44。两臂均负。余 65 根和父代方向一致。原先标作 hold 的 4 张图 16 根没有改令，另两张外部诊断图也没改；本项没有新增独立胜局。历史考生为当时的 v1，候选上的复现另列。[66 根两臂身份和选择](paired_decisions.json.gz) · [分组计数](paired_summary.json)
- **实际部署入口**。在 621758335 的两份精确父包轨迹从首拍重建记忆，598 次调用零偏差；第 126 步席 0 的 163 格和第 161 步席 1 的 169 格各出现一次新种。固定对手当拍真实指令，官方引擎和 FastCarbon 的后继完全相同，均存活、付款且新树成立。8 图 22 个原始轨迹上首次改令均核到真实交易，其余来源只核规则覆盖，不能视作相同包的整局表现。本轮没有为新包另开原版整局，331/335 等已曝光地图也不作正式考试。[逐源身份、实际命令和交易](coverage.json)
