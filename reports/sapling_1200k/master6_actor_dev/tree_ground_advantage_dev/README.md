# 中盘在什么地块多种一棵树

在原版对手的 18 场历史分解里，中盘己方每张图平均只新种 7.9 棵，对手 12.4 棵。己方同期夺树更多（5.5 对 3.9）。先测试在裸地上提前新种；以行动前估计的**第一段连续持有期从地面吸到的现金**单独给地块定价。[历史双方树收入分解](../elite_role_mix_dev/conditional/fresh_paired_dev/historical_tree_income.json)

每个席位分别保存自己实际看到过的地块碳量。采集工只看脚下，种树工只看四邻；从未见过的地块用固定初始估计，过时记录按当前邻树吸收或空地再生近似推进。地块特征包括预计剩余寿命、可吸收的邻格数、记住的碳、被己树或敌树同时覆盖的邻格碳、附近采集工和种树工。模型只在实际付费新种的树上训练；逐树用模拟器现金账回放，从吸收款扣除敌方工人被抽的货，一旦易主即停止记账。**一棵树吸到的地块碳并不等于全队因此多吸的碳**，新旧树可能重复竞争同一片地。地块总价与全队增量分开核验。[特征与决策](decision.py) · [付款和持有期标签](purchases.json.gz)

**行动规则**在 t100–199 每局最多改变一次原令。父网原本要将种植工从一块裸地移向另一块裸地，当前位置不受敌工当拍威胁、没有友方落位冲突，预留其他我方招工和种夺树的资金后仍买得起，才比较两个位置。只有“当前位置预计地块款 − 价格”大于零，且高于“原定下一格预计地块款 − 价格”的正部时才停下来。下一格比较按今天的价格估算，实际价格可以在下一拍变化。包保留双网父策略的完整推理，只覆盖已站在可种位置时这一个停移决定。[可复现打包](build.py) · [完整单文件候选](candidate.py)

## 预登记的两个新原版响应对照和三步位置复查

新包的两份来源都要求父包 SHA-256 为 c5ad3f43。选地图 621758320 席 0 和 621758335 席 1，均未参加地块头拟合，各取 t100–199 首个实发改令。逐拍运行完整父包与候选，第一根前 117 拍与第二根前 161 拍的整队命令完全一致。根前确认两个分支使用相同且为正的原版暖机参数和相同随机流。门槛是两处均真实付费新种，并各自提高官方终分差。[先行登记](protocol.json)

320 的 t117，种植工已经站在 175 格；向 190 格前进才是种植工原令。模型根据本席在决定前实际看过的地块估脚下 175 格首持地款 66.32、下一格 190 仅 46.89，故当场购置。实际花 53.42、收地款 58.41，净 4.99。但父代走过 190、205，到 t120 在 220 格支出 61.27，收地款 112.92，净 51.65。根步就能给 205 和 220 估出 71.09 和 73.53；220 四邻的上次本席观测距今 1、5、9、20 步。220 是从真实父代后续才辨认出的落点，这些估计逐格只使用 t117 前能看到的信息。[当时四邻位置、碳量和时间](seat0/parent_path_at_root_prices.json) · [两条实际付款轨迹](seat0/focal.json)

在看到这一反例后，冻结一个三步选址诊断。先遵从父代已经选择的第一步，再考虑最多两步可走到的新地。路径格不能有当下敌工在相同步数内可达，目的地不许占用现有树或基地。所有可吸收邻格必须有本席亲自观测、其中至少一格在 50 步内见过。机会收益按实际行程扣掉对应天数的平均地款，保留原规则对立即种植的条件。原 66 个配对根中有 43 个找得到这样的远端格，在原规则给裸地定价的 8 个根中有 5 个有远端格。两规则最终选择逐根相同，均只改变一次父令；新增比较没有独立的正例或负例。[诊断预注册](lookahead_protocol.json) · [逐根远端位置与排除原因](lookahead_rows.json.gz)

这个三步条件仍会错过 320 的 220 格。根前敌 27 号种植工在 221，能在两步内到达途中的 205，离目标 220 只一格；允许它选择任一合法动作便会排除父代真实采用且成功的路线。335 的 t161，延伸诊断提出可经两步去 183 格，预计地款扣时间和价款后净 147.21，高于原地种的预期净 76.20；远端评估在该根终分落盘前保存，特定路线没有重新开考。[320 的合法备选](seat0/reachable_alternatives.json) · [335 的合法备选](seat1/reachable_alternatives.json)
