### 能实际执行的控制器

父代是终局回报训练得到的双网 `9c54df17`。四条原版 Master3s2 训练轨迹共 1,196 步。从 t50 到 t180 的 524 个双方物理席决策中，父代共下达 1,142 次种植工移动。控制器只读取本席碳观测和六步记忆、公开地图资产、现金、树龄、工人位置及父代当步命令。沿用按独立天梯图训练的 16 项特征和首持净收益权重，预估的是实际付款后的条件收益。将相邻落点上学到的估值用于两到四格外的地块，属于这次专门检验的外推。[输入、报价与训练数据边界](../planter_option/value_notes.md) · [运行时代码](runtime.py)

出发时，同一工人按原命令第一步可接近的目标都参加比较。新目的地的条件净收益至少 25，扣每步 3 的路线分后，须比父代的最佳同类路线至少高 8。每次最多接一个任务；行进与付款均按新局面重查其余支出、可用现金、目标身份、收益和敌情。只接受能通过双网真实前缀重解码、其他工人和基地命令完全相同、没有新增冲突、与原策略动作分数差至多 1.5 的命令。把四个正根的可见现金改为零、把对方工人移至目标、或令空地周边碳记忆失效，三类反例均能否决目标。[候选构建和依赖哈希](manifest.json)

四个根之前的实际历史上，关闭 Sapling 分量、只用同一 it50 分量重演，分别有 9/53、14/50、8/50、18/59 步的执行命令改变。首步出发到任务结束后继续采用父代。独立可执行候选 SHA-256 为 `c2a2974d6910bbc5e89e9995b254f062a9d3f17474d8c04f77168ef2199c9897`。[双网策略包](agent.py) · [前缀重建](build.py)

双方短分支在同一物理状态起步，对手随后使用原轨迹的历史命令。20/96 个改道根的后续出现了已死亡单位的历史指令，或出现了原来的指令带未覆盖的新增敌工。其余 76 个根中有 12 个付款；这些对手的决策仍固定。所有四个首发反例和全部 13 个有付款的根，共 17 根 34 臂，已从 t0 独立用官方游戏引擎和 FastCarbon 逐步复现。付款当步核实了官方买家树的坐标、工人和双方公开资产，每臂保留五步的完整双方指令。官方规则复算验证的是五步的物理与现金结果。要判断树的首持收益、对手改策后能否抵达或胜率，需要单独的真实响应研究。[17 根官方逐步验算](replay_audit.json.gz)

### 已有实验和复算

旧的落点干预改变过 8 个相邻方向，随后 0 次即时付款。一次更早的真实响应实验也针对向相邻敌树移动。后来的两步付款选项沿用父代原本的移动，专门判断到达后是否付款。本次测量覆盖原先均未处理的出发地点、未来 2–4 步持续执行和主动撤出。现有数据最值得用于学习的标签是**行进中哪一拍开始出现敌工威胁、动作偏好分歧，以及目标碳观测是否变旧**。这三者都能从本席历史抽取。拟合可达性时应以全新地图检验，与树本身的条件收益分别报告。[旧相邻改道](../../planter_routes_dev/README.md) · [相邻敌树实验](../../root_recovery_branches/responsive_batch_01/approach/live_protocol.json) · [已在脚下的付款选项](../planter_option/README.md)
