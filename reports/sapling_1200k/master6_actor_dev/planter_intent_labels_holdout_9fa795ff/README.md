# 五张新天梯地图的外样本

这里保存比分索引冻结在 `9fa795ff` 的全部五局，均为前五选手对外的完整 299 步对局。五个原始回放均通过官方 Board 和 fastsim 的逐帧复核。这批地图的种子、地形、比赛 ID、原始回放散列均与首批 1,542 图不重叠。

`labels.npz` 沿用首批的 28 个字段、动作编号和类型。每行身份由本批 `maps.json` 的局部地图号、行动步、物理席位、工人号确定。字段的可用时点见[冻结规范](../planter_intent_labels/schema.json)。`y_` 开头的列来自结算。停留可由指令字典省略工人键表达，观测没有区分等待与主动购买意图。

5,021 条行动中有 744 次停留，527 次真实成交、146 次未付且存活、71 次未付且死亡。另有 224 次移动后死亡。27 笔付款发生在行动前现金不足的条件下。两席和每张地图的明细、逐工付款核对、六类回放实例、原始来源及产物摘要见 [verification.json](verification.json)。只用于冻结模型的外部评价。

在本目录运行 `python extract.py` 可重建数据并重新核验已存在的产物。
