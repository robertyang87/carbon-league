# 用终局回报训练 Sapling 混合权重，第一轮

冻结的 75% it50、25% Sapling V3 父代有两个网络。它们在同一个已执行动作前缀上给出各单位的动作分数。本次只训练合并两个分数的六个系数，以官方终局现金计算分差和效用 U。每盘正常打满 299 步或按官方灭绝规则结束。20 份双边逐步命令在本目录，原版游戏解释器逐局重放，全部奖励与账本吻合。训练和留图的对手均为本队 it45，关闭搜索、开启原版守卫。

每张图两席都跑，每项两个席位的分差恰好相同。训练有两张独立地图，留图也只有两张。正、反扰动按采集工、种树工、基地三类分别调整 Sapling 系数，在第 180 步切换第二组。训练回报选择了反扰动，前段系数为 0.35、0.14、0.13，后段为 0.15、0.33、0.34。它在训练集的平均 U 比父代高 0.01364、平均分差高 126.41。留图平均 U 低 0.09741、平均分差低 911.70，未通过事前写入的收益和分差门槛。本轮没有消耗原版 Master3s2 开发题或任何正式题。以上胜负只描述自家训练对手。

独立重算覆盖留图四席共 104 个根，各根都保留此前全部观察。改权重后这些根有 32 个与父代输出不同。把 Sapling 系数置零后有 48 个与入围策略不同，104 个入围策略输出与保存动作全部一致。

失利地图在第 60 步已比父代落后 506.66，到第 120 步落后 2478.49。差距扩大最快的 20 步在第 98 到 118 步，双方交付差的相对变化为 −955.05，树吸收差的相对变化为 −447.96。整局树吸收净差相对父代为 −2638.83。这一分解比较两条已经分叉的真实轨迹，可定位局面和账目，不能识别某一步改子的独立效果。

从仓库根目录执行 `bash reports/sapling_1200k/terminal_blend/command.sh` 可检查或续跑。两臂的权重、种子、选参条件、正式规则奖励和逐局 SHA-256 见 [results.json](results.json)。真实动作改变见 [attribution.json](attribution.json)，逐步收入对账见 [economy.json](economy.json)。
