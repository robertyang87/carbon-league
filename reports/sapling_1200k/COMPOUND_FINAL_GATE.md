# 双网 Sapling 接入独立终考的身份与动作核验

正式入口接受两份已验证的双网候选。亲本为 `hybrid_it50_v3.py`（SHA-256 前八位 `b54cc51f`），D1 一步搜索版为 `d1_sapling.py`（`429ec9a2`）。两者的 `--weights` 都须指向仓内实际训练权重 `data/weights/sapling_1200k/cash_v3.npz`（`df0cf175`）。保留原单网和守卫版的验证路径。[身份适配器](compound_formal.py) · [终考入口](tree_win_gate.py)

冻结前、考场开赛前各自从提供的 NPZ 查模型架构、全部张量键、形状、数值有限性，在临时目录重新导出 int8 学生。用该导出的等字节学生包、冻结 it50 和真实联合解码器重建双网；D1 再从该双网与冻结的原始 D1 源重建。在本版本上，两条链各自得到与候选完全一致的单文件。自报 manifest、其他学生权重、给合法包加一行空白这三种输入均未通过。[阳性与阴性实测](compound_formal_test.json)

**按实际执行动作验学生贡献。** 从每局的完整命令带重新生成双方可见局面。在候选每个活动槽上，用两个原始单网分别对当时已执行的动作前缀打分，检查动作合法性和两网加权后的选择。D1 搜索须额外保存本局实时产生的逐根记录，绑定命令带、地图、座位、包和实际动作。每个发生搜索替换的根单独重建原双网 A0，检查完整比较轮和被强制的动作，继续核对所有未强制动作。只在无需搜索强制且合成首选与 it50 单独首选不同的槽记学生贡献。全考卷没有观察到任何这类选择时拒绝签发。分数照常用仓内原版 Master3s2 真身和官方终局。[考场与恢复入口](tree_pack_arena.py) · [D1 实时记录器](d1_sapling_arena.py)

开场和正式读回均核验考官源码实际采用的 25 个搜索设置，包括温度 1、内部采样无固定种子、0.58 秒中止预算和深度上限 8。原始动作带必须带有空的观察器异常记录，每个完成搜索的调用须在深度直方图与用时数组中各占一次。新增的双网候选无法通过仅验胜率的旧计划签发。这里验证考官原设置及真实执行计数；共享机器的墙钟仍会影响它每步完成的深度。在本机单线程对 D1 的 310 席 1 单独复算 299 根实际双网归因，测得 15.85 CPU 秒、16.79 秒墙钟。按所有 200 局都走满、出场及验后各复算一次线性估算，单归因环节约增加 1.76 核小时；这项开销发生在保存动作后。

晋级需要预先冻结 100 张新图、每图双席，200 席全数有效，观察胜率至少 90%，同时全体 200 局官方平均终局分差至少 +500。少一席、重复一席、180 胜而 200 局合计分差少 0.01，均过不了联合判定。当场净现金和官方分差在灭绝时可不同。仓中 t37 原例候选得到 −264、对方 89.64，该局按 −353.64 进入分差。[判据代码](income_target.py) · [原始灭绝对局](tree_exam_soft_it50_v5/results.json)

**所用地图。** 本次只在已归档的开发动作和临时元数据上做接口测试。夹具将历史开发记录的“上游构建清单”身份改绑到真实 NPZ，同时重算临时文件哈希；原始动作、分数和仓内原件均保留。证据中的边界分数是用于测试判据的人工值。代码未申请正式地图。另独立检查新增天梯 26 场，26 个不同种子均在正式专用区间 `[1887000000, 1888000000)` 外；逐个种子和清单哈希随证据保存。开正式场仍须提供彼时完整的已用种子清单。[天梯来源](latest5_inventory.json) · [接口与种子交集测试](compound_formal_test.py)

复跑本次接口检查可在仓库根目录执行以下命令。需要与考试相同的 NumPy、CPU PyTorch 环境。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python reports/sapling_1200k/compound_formal_test.py --out /tmp/compound_formal_test.json
```

历史已冻结考卷和开发回执应按各自保存的 `protocol_sha256` 对照运行。要重跑原货运逐帧报告，可在独立 checkout 取 `ce394625`；要重跑原双网 D1 直接对局的逐动作证书，可取 `491e7911`。使用历史回放/证据做独立复算无需新开真身考试；复算 D1 开发记录可运行以下命令。游戏中的原版考官独立采样，再开场可能产生不同比分。[D1 原始结果与执行记录](d1_sapling_results.md)

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python reports/sapling_1200k/d1_sapling_certify.py reports/sapling_1200k/d1_sapling_dev --out /tmp/d1_official_and_prefix.json
```
