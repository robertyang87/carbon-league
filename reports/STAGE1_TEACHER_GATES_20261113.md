## 2. q 收益闸（S1-2a-q；`code/stage1_teacher_gate.py --mode q`）

- 评的对象：**实际用于训练的 q 分布**。主指标 Q 收益＝
  mean[Q(argmax q) − Q(greedy)]；同时必报分布级指标
  **软收益** mean[Σ_a q_a·Q_a − Q(greedy)]，以及行为温度 τ≠1 时
  q^τ 归一后的软收益——生成侧若加温度，闸的结论只覆盖被评的那个
  行为分布，不得只验 argmax 后给整份 q 背书。一致率/熵只作诊断列。
- 独立锚点：30 个局面子集（种子预注册），q-argmax 臂与 greedy 臂在
  冻结续弈策略（双席 guarded greedy、同种子配对、F01/F04 计分）下
  真实续弈到终局，报实现 ΔU 点估计＋95% CI（只作符号检查，不作闸）。
- 阈值（作战室 14:08 定死）：通过＝Q 收益 ≥ **+0.01 U** 且严格改进率
  ≥ **25%** 且锚点 ΔU 点估计 > 0；不过＝Q 收益 ≤ 0 或改进率 < 10%；
  其间为不定，只许同协议种子顺延扩样一次，再不定按不过处理。
- 场景集：真实对局回放（非自博、非训练语料）；与 ΔU 闸对局集不交，
  与 ds_m3s2 对局集不交（采样前逐 id 核对，驱动在给清单时硬拒绝重叠）。

## 4. 稀疏标注（S1-4）

- 每个被标局面必须记录**抽样概率 π**（随机覆盖的基础抽样率与关键
  局面加标的倍率分开记），标注产物随 F05 生成发布一并落盘。
- 两种口径二选一，预注册写死、表述与实现一致：
  (a) **逆概率校正**：策略损失按 1/π 加权，目标是逼近全量局面平均
      策略损失——gen-1 首轮默认采用；
  (b) **有意加权**：不校正，声明为有意让网络更重视关键局面，必须配
      与 (a) 的消融对照才许下收益结论。
  抽样分布的校正不消除教师 q 本身的估计误差，两者分开记账。
- BC 锚点默认无；启用须按 §0 显式声明。
- 预算口径：标注只是总成本一项。报价必须同时含 q 收益闸与 ΔU 闸的
  续弈成本、生成成本与训练成本。参考量级（Studio 单价 5.55 秒/局面、
  串行单 worker）：119,600 局面全标 ≈ 184.4 小时；10% ≈ 18.4 小时；
  闸成本见草案 (c) 成本表并以 Stage A 实测重标为准。

## 5. 多样性与对手配比

- 对手配比自博 50%／历史 25%／外部 25% 是**首轮冻结的待验证起点**，
  不是效果保证；防遗忘/防循环/防过拟合的结论只能来自历史对手交叉
  评估，不得由配比本身推出。
- 破对称是显式机制（探索温度、开局多样化、异质对手），不是“受控
  探索”一句带过。和棋证据的口径：Studio 探针 22 局全平是和局证据；
  **mean_u≈0.5 本身不是**——胜负各半同样得到该均值，且双席位平均时
  两方 U 本就互补。多样性 A/B（平局率、margin 分布）必须在统一
  guard 的生产配置下测，不得用 guard-off 镜像局作证据。
