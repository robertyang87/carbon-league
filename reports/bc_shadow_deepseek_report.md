# 影子 DeepSeek 报告（榜二/榜三行为克隆 · 高强度陪练工件）

日期：2026-11-03。任务：克隆天梯第 2 名 NaMnSi-DeepSeek-RL-policy-1
（2578 分）与第 3 名 NaMnSi-DeepSeek-RL-light-1（2528 分）作高强度
陪练。**定位先行：影子只作陪练与病灶探针，绝不作我方基座/提交
谱系。**数字全部实测；评测与录痕全程走 `.eval_lock` 共享锁、两侧
统一播种，6 局留痕核对差全部 +0.00。训练/评测与多条结构线并行
共抢 4 核，ms/步为共抢口径。

## 结论先行

- **影子已落地**：`shadow_deepseek.py` + `shadow_deepseek_weights.npz`
  （301,546 B），标准 agent 接口、NumPy 推理，11–27 ms/步（共抢
  口径）。架构/解码沿用影子 Alpha v2 已验做法（工人头分布采样＋
  顺序采样落点预留、基地头 argmax、自家基地格豁免）。
- **离线保真（留出集）**：工人 top-1（目标两策略的留出局）
  **0.5350**（采集 0.5420 / 停留基线 0.3651；种植 0.4957 / 基线
  0.2368）；分策略 policy-1 0.5319、light-1 0.5161。低于影子
  Alpha v2 的 0.6020——目标是 RL 策略且留出局全是打榜首/榜五的
  顶级对局，行为更难预测；样本量也薄（见语料节）。
- **闭环保真（对 example 2 局）**：种树 23/27 次（真值均值 25.0，
  几乎逐项命中）、树收入 3802/4114、存款 1960/5559、现金
  3364/5890（真值环境为顶级对手局，均分 7386，环境不可直接比）。
  **头号失真：抢树 0 次（真值 15.6 次/局，每局必抢 7–27 次）**；
  其次终局滞留 833/1499（真值 ~33）与步 200 编制一局塌陷。
- **陪练强度定位：对 base_v53 不合格。** 配对 4 局全败，场均
  **−16,069**，影子终分 20/20/26/20——不是被压制，是**开局经济
  锁死**：开局双采集员在第 26–101 步内被 v53 混合碰撞杀死（携碳
  54–225），现金剩 20 < 采集员招募价 30，基地头此后永不招募
  （全场工人决策仅 59–176 次 vs 正常 ~2000）。三变体（全校准/
  全无校准/混合）终分逐分一致，证明与校准无关，是 BC 克隆的
  结构性病灶：示教者在「0 工人」状态下几乎没有样本（真策略死人
  当步即补招），克隆的基地头在该状态分布外、argmax 恒为 none；
  且克隆工人头的碰撞规避微操达不到真 RL 策略水位，开局对在真
  对局里活不过 v53 的猎杀。**影子可作中压陪练（经济型、树战型
  参照）与 DeepSeek 行为探针，不得用作 v53 级高压陪练。**
- 家族模型（NN 兄弟扩容语料）仍在训练中（见第 7 节），其留出
  对比与对 v53 复测是第一顺位后续。

## 2. 训练与校准（三变体证据链）

流水线与影子 Alpha 逐字相同（train_bc_ds.py = train_bc.py 换 val
集；特征合法性契约不变，`full_carbon` 从未进入）。targets 模型：
工人网 early stop 于 epoch 22；基地头 RECC recall 0.630 / RECP
recall 0.768（未校准）——RECP 明显好于 Alpha v2 的 0.532，与目标
「每局必种必抢」的行为一致。

校准环节出了本轮最有价值的负结果：
- 工人 stay 偏置：脚本选 delta=0.5，留出 stay 率 0.3446 vs 真值
  0.3457（几乎完美），argmax 损失 1.1 个点（0.5350→0.5241）。
  **保留。**
- 基地偏置：脚本选 delta=2.25（b_b3[0] += 2.25），pos 率
  0.145→0.096（真值 0.073，仍过冲），代价 RECC recall
  0.630→0.543、RECP 0.768→0.646。闭环配对验证（对 example 同
  seed 双边各 2 局，三变体）：全校准现金均值 2848（且双峰：
  一局种树流、一局 7 招募死局）；全无校准 3681；**混合版（工人
  校准保留＋基地偏置撤销）4627，且两局编制/种树都在线**。
  **裁决：出货 = 混合版**，基地偏置 2.25 撤销（证据在
  eval_shadow_ds_results.jsonl 与 eval_shadow_ds_nocal_results.
  jsonl；Alpha v2 当年基地 delta 恰为 0.0，同向）。
- 对 v53 的 4 局：三变体终分逐分一致（20/20/26/20 对
  16165/16247/15711/16207 一组、其余组合同理）——经济在任何
  基地决策生效前已锁死，校准与崩溃无关（第 4 节）。

留出准确率总表（argmax 口径，出货权重）：

| 分组 | 工人 top-1 | 采集 | 种植 | 基地 RECC recall | 基地 RECP recall |
|---|---|---|---|---|---|
| RL-policy-1（n=5462) | 0.5319 | 0.5387（基线 0.391*) | 0.5029（基线 0.237*) | 0.739 (n=46) | 0.556 (n=45) |
| RL-light-1（n=5348) | 0.5161 | 0.5257 | 0.4396 | 0.348 (n=46) | 0.757 (n=37) |
| 两目标合计 | 0.5241（含 stay 校准；未校准 0.5350) | 0.5319 | 0.4798 | 0.543 | 0.646 |

（*policy-1 分项基线以合计口径近似；小样本 recall 噪声大，只作
参考。两目标的基地召回呈镜像互补：policy-1 的克隆更会招采集、
light-1 的克隆更会招种植——n≈40 量级，不作强结论。）

## 4. 强度定位：对 base_v53 配对 4 局（病灶证据）

| seed/边 | 影子 | base_v53 | 分差 |
|---|---|---|---|
| 1000 P0 | 20.00 | 16164.89 | −16144.89 |
| 1000 P1 | 20.00 | 16246.50 | −16226.50 |
| 1001 P0 | 26.01 | 15711.29 | −15685.28 |
| 1001 P1 | 20.00 | 16207.26 | −16219.36 |
| **场均** | **21.5** | **16082.5** | **−16069.0** |

崩溃机制（轨迹实证，非推测）：
1. 影子开局双招采集（与真值开局一致），两名采集员在第 26/35、
   31/36、77/101 步（各局轨迹帧）被混合碰撞杀死，携碳 54–225
   全损，存款 0–6。
2. 现金定格 20（80 − 2×30)，**低于采集员招募价 30**——此后即便
   基地头想招也招不起；而基地头在 0 工人状态下 argmax 恒 none
   （示教分布外），双重锁死。全场招募数 = 2、工人决策 59–176 次。
3. v53 在无抵抗下的账本：存款 10.7–11.1k、**树收入 8.2–8.8k
   （场均 ~8.46k，完全无竞争——影子种树 0、抢树 0）**、种树
   51–57 次、死亡仅 3–4。这是 v53 对「树战缺席者」的标准收割
   形状。

**抄送结构路线图的两条**：① v53 的最大单一收入项在陪练缺席时
是无竞争树收入 ~8.5k——我方任何版本若树战掉线，等于直接送它
8.5k；② **开局保险是我方自家策略的设计约束**：开局双招后现金
20 < 30 的经济结构没有容错，任何自家版本都必须保证开局对在
首次存款前不被双杀（或留 ≥30 的招募储备），否则同样一锁到底。
另注：本节 INDEX 里 fork_c 对影子 Alpha v2 的两局（18.39 /
8.36）呈同一锁死形状——**这是 BC 影子的通病，不是 DeepSeek
克隆独有**。

## 5. 已知失真清单

1. **抢树为 0**（真值 15.6/局）：克隆的种植员从不执行夺树——
   夺树要求种植员预先站上敌树格，工人头的位置分布没学到这一
   前置行为链。影子打不出 DeepSeek 最具辨识度的进攻项。
2. **0 工人吸收态**（对强猎杀对手即锁死）：见第 4 节。家族
   语料含大量 NN 兄弟的补招样本，或可缓解——待家族模型复测。
3. **终局滞留高**（833/1499 vs 33）：终局返航变现弱，dep_last30
   仅 146/342。
4. **双峰编制**：对 example 两局一局步 200 全灭、一局健康，
   与 Alpha v2 的双峰同源（基地头 argmax＋采样闭环正反馈）。
5. **死亡结构半像**：中位丢碳 0.0 像，但总量高一个量级——
   克隆的满载规避不如真策略。
