## 2. 计量定义

**（a1）DP 计划层税（自由规划采集员，逐员逐回合）**：在 base 原样算出
惩罚版动作值 q5 后，同回合用同 G/lam/term 重跑两次反事实 DP——
仅去掉 minreach 层（avoid1/avoid2）得 q_mr；两层全去（再去 cnt2 soft
层）得 q_all。regret = max_a q(a) − q(a_pen)，a_pen 为惩罚版 argmax。
regret_all 是「在无惩罚价值函数下，惩罚使我放弃了多少计划价值」；
soft 边际 = regret_all − regret_mr。另记 burden = q_all(a_pen) −
q5(a_pen)（所选计划自身携带的惩罚量，辅助量）。camp/guard/rover/
shadow/mark 角色单位的 DP 不驱动其动作（被覆盖），其 regret 单独记
（'role' 列），不进标题税。
注：逐回合 regret 按 12 步视野计算、回合间视野重叠，逐局求和是
**上界口径**（同一段未来价值会在多个回合重复计入）。裁决时按下文
对该高估的敏感性说明处理。

**（a2）动作层致命改道税（逐员逐回合）**：记录每动作被安全层实际
扣掉的量（致命 −1e6[+500 原地]、等重 −(tie_cost+c)[+camp_occ]、
终局缩放 −(0.7/0.45)(c+30)；run 模式的期望损失扣减**不算**——那
已经是行为定价）。let_loss = 只恢复致命扣减后，最终 q5 argmax
相对实际选择的后悔值；all_loss = 致命+等重+终局三者全恢复的后悔值。

**标题规避税/局 = Σ regret_all（自由单位） + Σ let_loss**（与路线图
案 C 的口径一致：DP 层扣值 + −1e6 改道机会损失）。

**（b）敌方出击率**：逐回合转移、(敌采集员 e, 我采集员 m) 对级：
机会 = ec < mc 且我所选目的地 dm ∈ N1[e 位置]（e 下步可达我选定格）；
出击 = e 的实际落点 == dm；逼近 = 落点 ≠ dm 但距 dm ≤ 1。等重对
（ec == mc）单列（机会/出击）。按 ec 分档：0 / 1–80 / 81–150 /
151–250 / 251+。另记回合级（任一对成立即计）。

**（c）实际截击损失（对照事实）**：我方采集员次回合消失者，按其
目的地格上现存单位的上回合携带归因：敌采集员更轻 → 干净截击；
敌采集员等重 → 等重对耗；自家采集员更轻 → 自家相撞；格上有人但
无上述 → 其他；格上无人/无目的地记录 → 未知（实测内容为无采集员
格的全体相撞，如踩敌种植员格）。归因总额与环境账本 death_cargo
逐局对账（见 §5，6/6 精确吻合）。

## 4. 敌方出击率（分档样本量与置信度——准）

机会样本出乎意料地薄，先说为什么：机会的定义是「敌可达**我所选**
目的地」，而我所选目的地本身就是在现行惩罚下挑出来的——现行政策
已经把目的地避开了更轻的敌人（选择效应）。所以下表测的是现行
政策边际上的出击倾向，**不是**取消规避后的反事实出击率；定价时
不许把 0% 直接当真实风险用（见 §7 的先验设计）。

| 对手 | 机会对 (ec<mc) | 出击 | 逼近 | 等重机会对 | 等重出击 |
|---|---|---|---|---|---|
| shadow_v2（两局合） | 3 | 0 | 2 | 94 | 0 |
| v0.5（两局合） | 0 | – | – | 2 | 0 |
| example | 0 | – | – | 0 | – |

分档（shadow 两局合并）：ec=0 档：机会 1、出击 0、逼近 1；
ec 1–80 档：机会 2、出击 0、逼近 1；ec 81+ 各档：机会 0。
回合级：shadow 机会回合 3、出击回合 0、逼近回合 2。

解读：(i) 样本量只够支撑定性结论——「在现行政策留下的边际上，
敌人（含 NN 型）几乎从不真的扑向我选定格，等重对峙 94 次也 0 次
兑现」；(ii) 任何单一分档的样本量都 < 30，**按纲领红线，这些分档
一律不许直接定价**，定价须用带先验的后验 + 上线后在线统计回填
（§7）；(iii) 但「被扣分动作数」是厚样本：shadow+v0.5 四局共
790 个动作被致命扣分、736 个回合被收费，而同期出击 0 次——税的
收费面与风险的兑现面完全不成比例，这才是定价化的实证地基。

## 6. H1 裁决

**H1（对 NN 型对手规避税 ≥300/局）成立。** 依据：对 NN 型参照
shadow_alpha_v2 的两局标题税 7520.3 与 327.9 均 ≥300，均值
3924.1。对上界口径的敏感性：即便把逐回合 regret 的视野重叠高估
按 2 倍折损，DP 层（334 均值）打折后约 167，但致命层 let_loss 是
逐步实现的动作值差、不受视野重叠影响，shadow 均值 3590  alone
即碾压 300 线；最保守读法（只取两局中较小局的致命层 94.9 + DP 层
全额 233.1 = 327.9 的构成）也在线上。**案 C 不让位案 D，继续
定价化改造**；案 D 的树战役估值按路线图原排序在 A 之后，不受
本裁决影响。

同时记录税的对手依赖性：无威胁（example）税为 0、规则型（v0.5）
均值 452、NN  swarm 型（shadow side0）7520——现行安全层已经
「按密度收费」，定价化要改的是**费率与风险的标定关系**，不是
收费面的有无。

## 7. 定价化改造点（案 C 第二步施工单）

基座内部已有行为定价的成功先例（run_b 出击率桶 + run_mode=3 的
EV 冲门，L1830 起）；以下把同一思想推广到主安全层。改造点按
税的实测构成排序（soft 与致命层优先，minreach 层最后）：

1. **soft 层（base L1759–1767，DP 税的 70–94%）**：现公式
   pen = soft_w·(c+30)·f(n2)，f = 0.06/0.25/1.0 是未标定的拍脑袋
   先验。改为期望损失：pen(z) = P̂ · (c + 30)，P̂ 为「距离-2 内
   n2 个可截击敌员中至少一人两步内扑到 z」的后验概率，由新统计
   桶（键：n2 档 × 敌携带档 × 我携带档）在线估计；样本 n<30 的
   桶维持现 f 值（准红线）。
2. **致命层（base L1925 一带，`elif m < c` 分支）**：−1e6 只保留
   给「威胁者距 z ≤1 格 **且** 我携带 c ≥ 150 **且** 该桶 P̂ 高」
   的格（护货红线区）；其余情形降为期望价 P̂·(2c+30)（货归敌的
   双倍摆动，照 run_ev 的口径）。等重分支（tie_cost + c）同步
   定价：等重出击实测 96 次机会 0 兑现，现扣减按 P̂_tie 缩放，
   但保留下限（等重对耗是单位交换，单位本身有价）。
   终局 R≤6 的缩放分支保留不动。
3. **minreach 层（base L1753–1757，DP 税的小头）**：C1/Cr 的
   avoid1/avoid2 平罚改为 P̂(z,c)·(c+30) 形式，P̂ 复用第 1 条的
   统计桶（键改为 minreach 携带档 × 我携带档）；冷启动先验 =
   现行 0.5/0.15 不变，n≥30 才允许后验接管。
4. **统计管道（新）**：照 probe 的 (b) 定义在 Bot 内加一组 watch：
   每回合对每个「可达我所选目的地」的敌采集员记 (桶键, 是否
   出击)，与现有 pstay/run_b 同生命周期管理；这组统计同时是
   S2 原型识别与共享预判模块的现成输入（09:56 纲领：预判是
   共享地基）。注意选择效应：统计永远是在当前政策下采的，
   定价放宽后必须继续在线更新（费率随兑现率自校准），不许用
   本报告的离线 0% 一次性定死。
5. **pred_next 并入（路线图原案 C 第 3 条）**：predict=1 的周期
   mover 下格预测目前不喂主 DP；定价化时把「预测落点 == z」
   作为 P̂ 的一个强特征（该敌员的出击视为近确定），避免被
   平均费率稀释。

**目标函数与验收（按 09:52 纲领稳/准/狠）**：
- 稳（护货红线）：定价版对 shadow_v2 / v0.5 / 镜像三档配对评测，
  逐局 death_cargo 不得高于同局 base 配对值，任一局恶化 > +50
  即回滚该档定价；逐 seed 报分布与最差局，不只报均值。
- 准：每个被定价的桶须 n≥30 且报告后验均值与 90% 区间；上线
  评测后做出击率预测对账（P̂ vs 兑现率）表，误差 > 2 倍的桶
  自动退回最坏情形罚。
- 狠（兑换证据）：标题税的可兑换部分以账本验收——定价版相对
  base 的配对局，deposits + tree_income 增量须 ≥ +300/局
  （对 shadow 档）且 death_cargo 不破红线；兑换率 = 实测增量 /
  本报告所测标题税（shadow 均值 3924），预期兑换率 < 100%
  （税是上界口径），报告须给出该比值而非只报税省了多少。
