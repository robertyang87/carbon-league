# 影子 Alpha v2 报告（扩容重训 + 采样去相关）

日期：2026-11-03。任务：用扩容后的 Claude 家族语料重训 BC，并修 v1 的头号
失真（自家工人叠格自杀）。数字全部实测；训练/评测全程与 RL 阶段一并行
共抢 4 核（torch 限 2 线程），ms/步为共抢口径、偏高，勿与 v1 的轻载数字
直接比。**定性不变：影子是陪练工件，不是提交候选，更不是 Alpha 强度标尺。**

## 结论先行

- **去相关结构性修好**：新口径（死亡归因）下，v1 对 example 两局自家碰撞
  死亡 56/64 次、其中**野外叠格 44/55 次**；v2 同口径评测局为 2/44 次，且经
  播种诊断 + 留痕轨迹双重核查，**v2 的野外自家碰撞死亡 = 0**——残余自家
  碰撞全部发生在自家基地格（设计豁免），货物由赢家采集员合并保全（诊断
  局估算真实碳损失 = 0）。对 v0.5 两局自家碰撞死亡 33/30 → **2/2**。
- **离线准确率全面上涨**（同一 5 局 val）：工人 top-1 56.4% → **60.2%**，
  采集员 58.6% → **62.8%**，种植员 45.2% → **47.0%**；基地 RECC recall
  76.0% → 77.3%，RECP recall 59.6% → 53.2%（val 仅 47 个 RECP 样本，噪声大）。
- **但经济画像的闭环保真度反而退步**：对 example 两局 v2 呈双峰——一局
  种树 63 次/步 200 编制 2 采 8 种 14 树（真值 31.5 次 / 7/2/7），另一局
  种树 0 次/10 采 0 种；存款 4698/9885（真值 ~8065，v1 为 8442/8599 两局
  都贴真值）。**v2 是更好的陪练（死亡纪律、护货、对 v0.5 的抢树压迫都
  更强），但作为「Alpha-2 画像标尺」v1 的经济配比更像。**详见保真度逐项表。
- 对 juzi 参照局（seed 3000，影子 P0）：**20.79 : 16101.66**，被完全
  压制——只作强度参照，不下结论（juzi 本就以 ~2830 分/局压我方最强规则
  策略 v0.5，影子不在同一量级是预期内）。

## 1. 数据扩容（施工单第 1 步）

合并口径：`replays/index.json`（快照 400 局，自带 order）+
`replays/accumulated/index.json`（52 局，dict 格式、**无 order 字段**），
按对局 id 去重（快照优先）→ 注册表 430 局，其中 accumulated 独有 30 局。

accumulated 的 order 用回放自身反推：`replay["rewards"][p]` 是回放玩家 p
的终分，索引 scores 按槽位（a/b）记，取使 |rewards − scores| 最小的指派；
`rewards` 为 None 的局用终局共享 players 块现金兜底（本游戏 cash 即分数）。
**验证**：在 400 局快照（order 已知）上跑同一推导，387 局吻合、**0 局
判错**、13 局因分差过小（gap<0.02）属不可判（这些局用快照真 order）；
30 局 accumulated 独有局 0 局不可判。抽取沿用 `extract_bc_fixed` 的修正
配对 (obs_t → act_{t+1}) 与原规范化数组，产出
`bc_data/claude_family_v2.npz`（+ manifest），校验计数干净
（仅 skipped_non_active=53，即各局终局条目）。

## 3. 采样去相关（施工单第 3 步）

**做法**（`make_shadow_v2.py` 生成，`shadow_alpha_v2.py` 落地）：同一方
同一步内按规范槽位顺序逐个采样工人动作，维护「本步已预留落点」表；
若某工人采样到的动作落点已被自家工人预留，则把该动作从其分布中
**掩码清零、重归一化后重采样**（可重复直至无冲突；全部动作被掩码时
保留原采样并记 fallback）。**自家基地格豁免**：碰撞在存碳阶段之前
结算、赢家采集员合并全部货物再统一存入，基地格叠格是整合不是丢失
（也是标尺对象 Alpha 终局的固有模式）。

**代价记账**（评测 5 局实测）：冲突检出 28–73 次/局、重采样同数、
**fallback 0 次**、工人决策约 2,000–2,700 次/局——即约 1–3% 的工人
动作被改道，分布扰动很小；无额外 ms/步 量级变化（14.2–37.9 ms/步，
共抢口径）。

**归因口径**（本轮新 instrument，`eval_shadow_v2.py`）：每步用双方
实际提交的动作字典 + 步前状态重构每个工人的落点组，按组构成把死亡
分为自家碰撞 / 混合（含敌方）/ 其他（单人组，如空载踩敌基地删除）。
该口径先在 v1 身上验证：重构出的 v1 终分与 v1 原评测 4 局中 3 局逐分
一致（416.41 / 107.73 / 9031.39），第 4 局差 ±250 内（example 随机源
未播种，见留痕注）。

### 死亡归因结果（影子侧）

| 对局 | v1 死亡（自家/混合/其他） | v2 死亡（自家/混合/其他） |
|---|---|---|
| vs v0.5 s0 | 42（33/9/0） | 37（**2**/25/10） |
| vs v0.5 s1 | 41（30/8/3） | 35（**2**/29/4） |
| vs example s0 | 60（56/0/4） | 12（**2**/5/5） |
| vs example s1 | 75（64/2/9） | 84（44/16/24） |

- **野外叠格清零的证据链**：①播种诊断局（example 随机播种 777，
  `diag_shadow_v2_deaths.py`）：v1 自家碰撞 56/68 次中野外 44/55 次；
  v2 自家碰撞 3/21 次、**全部在自家基地格、野外 0 次**，死者货物
  1827 中估算真实丢失 = 0（赢家合并/基地返还）。②留痕轨迹分类
  （录制局）：v2 对 example 两局自家碰撞 3/7 次，全部自家基地格。
- **对 v1 报告口径的一处修正**：v1 的「丢碳总量 10–19k」是账面口径
  （死者货物不论归属全额计入）。归因后看，野外自家碰撞中死者货物
  绝大多数被组内自家最低载货采集员吸收（整合），真实碳丢失远小于
  账面；v1 死亡纪律的真实代价是**单位 churn**（每死一个单位亏 30
  招募费 + 路线中断 + 被迫补招），不是碳本身。v2 把这一项压下去了：
  对 v0.5 死亡 42/41 → 37/35 且自家碰撞近乎归零；对 example s0
  死亡 60 → 12。
- **残余问题**：example s1 评测局自家碰撞仍达 44 次（该局影子 0 种树、
  93 次招募的漏斗抽样：死亡→基地头按 seq 特征补招→新兵与返航者同挤
  2 个基地格→基地格死亡→再补招）。基地格死亡货物不丢，但单位成本
  实打实。是否取消基地豁免不能一刀切——豁免同时是终局整合的前提；
  更对症的是给基地头补招加节流，不在本轮范围。

## 4. 保真度复验（施工单第 4 步，与 v1 同口径）

真值 = alpha_analysis.md 对 AlphaCarbon-2 的 12 局深挖中位。对 example
两局是其「典型弱对手环境」（注：example 用未播种随机源，单局数字有
对手噪声，v1 的两局同样如此）。v1 数字除标注「归因复测」外均引
v1 原评测（eval_shadow_results.jsonl），v2 引本轮评测。

| 画像项（真值） | v1 两局 | v2 两局 | 结论 |
|---|---|---|---|
| 步 200 编制 采/种/树（7/2/7） | 7/1/5、9/0/1 | 2/8/14、10/0/0 | ❌ v2 双峰跑偏，v1 更近 |
| 全场存款（~8065） | 8442、8599 | 4698、9885 | ❌ v1 两局皆贴真值 |
| 种树次数（31.5） | 33、22 | 63、0 | ❌ v1 更像 |
| 树净贡献（~+1440） | +2580、+2357 | +3554、0 | ❌ v1 偏高但稳定 |
| 死亡/局（34） | 60、76 | 12、84 | ⚠️ v2 均值 48 更近但方差大 |
| 单次死亡丢碳中位（~57） | 71、101（归因复测） | 4.2、2.6 | ✅ v2 死得比真值还穷 |
| 终局 30 步存碳（+997） | 1369、2160 | 115、762 | ❌ v1 更像 |
| 终局滞留（183） | 1035、323 | 53、453 | ✅ v2 两局均 <460，v1 一局破千 |
| 对 v0.5 现金（参照） | 416、108 | 683、387 | ✅ v2 略强 |
| 对 v0.5 抢树次数（参照） | 6、2 | 37、31 | ✅ v2 压迫感强得多 |

逐项结论：**死亡/护货/滞留四项 v2 胜，编制/存款/种树/树净/终局冲刺
五项 v1 胜**。经济配比漂移与去相关无关（去相关不碰基地头决策、冲突
改道仅 1–3%），与语料配比变化（Alpha v1 本体局数 3→18）同步出现，
且 RECP recall 下滑（0.596→0.532）与「要么狂种、要么不种」的双峰
同向——基地头的种植招募决策是漂移的落点。

## 5. 剩余失真与下一步建议

1. **双峰经济（头号剩余失真）**：基地头 argmax + 采样闭环的正反馈让
   单局在开局几十步内锁定「养树流」或「纯采集流」，Alpha-2 本人是
   稳定混合流。候选修法（v3）：Alpha-2 样本加权/单独微调基地头；
   或给基地头也做带温度采样 + 招募节流。需要更多 Alpha-2 本体局
   ——其 62 局全量回放仍未落盘（`replays/alpha2_full/` 为空，浏览器
   沙箱下载不回同步，待主会话定取回方式）。
2. **基地漏斗死亡**：坏抽样里「补招→基地挤死→再补招」循环可达
   44 次自家碰撞/局（货物不丢、单位成本实亏）。与第 1 项同源（基地头
   无节流），合并处理。
3. **对强对手仍是经济崩溃型**：对 v0.5 现金仅 387–683（真 Alpha 对
   同级对手能拿 7300+），对 juzi 20.79。克隆到的是行为风格与纪律，
   不是决策质量——RL 阶段一拿它当陪练时，强度标尺请用 v0.5/juzi，
   不要用影子自评。
